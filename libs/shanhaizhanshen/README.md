# 山海战神

## 游戏名称

《山海战神之简单武力》，源自 archives/山海战神.rar。本作是在史巴克 (Spock)
开发的英文科幻引擎 "Final Frontier v0.6e" 基础上二次改造而成的中文版本 ——
属于 `simple`/ES II 引擎系列（本项目转换的第一个、也是最"标准"的一个样板库，
后续绝大多数修复经验都是从它身上总结出来的）。

## 简介

不要被"山海"两个字骗了 —— 这并不是传统武侠/仙侠泥巴，而是一款偏科幻背景的
"战斗模拟"类文字游戏：人物属性叫力量/敏捷/智力/注意/体质/技术，护甲分为传统、
动能、光学、粒子、爆破五种类型，攻击方式也带着浓厚的机甲/激光对抗色彩。整体
规模不大，更像是一个演示引擎战斗系统的小型试验场，而非内容丰富的大型世界。

## 如何运行

```
cd libs/shanhaizhanshen
~/src/fluffos/build-debug/src/driver config.fluffos
```

驱动分配的端口是 **40001**。

## 如何连接游玩

用任意 telnet 客户端或本项目自带的脚本连接：

```
python3 scripts/mudclient.py 127.0.0.1 40001
```

登录流程会依次询问：
1. 英文名字（**只能是英文字母，3-20 位，不能含数字**——第一次输入若带数字或
   符号会被直接拒绝并重新提示）
2. 确认创建新角色 (y/n)
3. 中文本名（真实的中文名字，如"秦风"）
4. 密码，并再输入一次确认
5. 一个用于防止重复登录的邮箱地址（随便填一个能过格式校验的地址即可）
6. 分配六项属性点数，总和必须凑够 60（游戏会给出每项属性的上下限，按提示
   输入，例如 `10 10 10 10 10 10`）
7. 选择性别 (m/f)

以上全部完成后即正式进入游戏世界，可以直接用 `look`、`score` 等指令查看
周围环境和角色状态。
