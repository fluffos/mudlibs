# 笑傲江湖 II

## 游戏名称

**笑傲江湖**（本项目内部代号"笑傲江湖II"，游戏登录画面自称"虚拟人生"）。
属于"XO mudlib"引擎家族（源自 TMI-2 / ES2，由 Falcon 于1996年重写），
与本项目另收录的《笑傲江湖迷你版》《XO最终版1.2》同源但是独立的、更晚
的一个站点快照（站内公告显示自2003年4月1日开站）。

## 简介

以金庸《笑傲江湖》为背景的经典武侠世界：从华山派、少林、玄武等门派
体系出发，讲述"温故知新"的江湖故事。整体偏正统门派养成向武侠 MUD，
拳脚、轻功、剑术、刀法等修为体系齐全，适合喜欢门派归属感与传统武侠
数值成长的玩家。

## 如何运行

```
cd libs/xiaoaojianghu2 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40068**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40068
```

或用任意 MUD 客户端 telnet 连接。注册流程比较标准：

1. 连接后直接看到英文名字提示，**输入 `new` 开始注册**。
2. 取一个英文ID，确认(y/n)。
3. 取一个**中文名字**（不要用金庸小说里的人物名，不能再修改）。
4. 设置密码（两次输入确认）、填写邮箱、选择性别(m/f)。
5. 完成后直接进入游戏世界。

**重要提示**：本站对同一 IP 地址的"新建角色"操作有防刷屏限流（短时间
内只能新建一次），如果你注册失败后马上想再试一次新角色，可能会遇到
连接没有任何反应的情况——这不是故障，请等待几分钟后再试，或换一个
角色继续用刚才创建的账号登录。

## 已知问题

- 全新角色出生地点（"新手村"相关房间）在本存档中缺失，系统会优雅地
  把你放到一个空白过渡地带而不是报错崩溃；这不影响其余指令（look、
  score等）正常使用，只是缺少这一段新手引导场景的具体描述。
- 退出游戏(quit)有"必须先玩到10点经验才能存档"的限制，这是游戏本身
  的设计，不是故障。
- lpcc 编译扫描约97.6%通过，缺口集中在少数任务/独立道具脚本，日常
  游玩基本不会碰到。
- WASM 版本可以完整游玩：注册、look、quit 等流程与原生（native）驱动
  下表现一致，包括上面提到的新手房间缺失问题（同样优雅降级），未发现
  WASM 专属的阻塞性问题。注意：本站有单 IP 防灌水限制，短时间内多次
  连线会导致后续连线无声无息地被拒绝，建议在一次连线中完成注册全过程。
