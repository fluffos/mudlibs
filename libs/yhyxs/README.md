# 炎黄英雄史（游戏内也称"皇朝再现"）

属于 ES II 引擎家族（2003 年"炎黄"分支），与"炎黄武魂Ⅱ"是关系很近的
姊妹作，共享同一套底层引擎，但拥有各自独立的剧情内容与世界细节。

## 内容亮点

- 武侠题材 MUD：玩家从"世外桃源"出发，可以在"猛士型""智慧型""耐力型"
  "敏捷型""均衡型"五种角色定位中做出选择，随后踏上自己的江湖之旅。
- 整体节奏和"炎黄武魂Ⅱ"相近，但地图、剧情、平衡数值都是独立设计的
  内容。
