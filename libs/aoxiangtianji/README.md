# 翱翔天际

一个脱胎于经典《西游记》题材 MUD 的中文武侠/仙侠游戏，登录横幅另称 "翱翔天际之擎日挽月"。新角色从"南城客栈"起步，先培养力量、悟性、根骨、 敏捷、灵性五项天赋，再从光明磊落、狡黠多变、心狠手辣、阴险奸诈四种天性中选定初始气质，随后沿着呼应《西游记》原著的"大闹天宫""西行取经"等关卡主线闯荡江湖，个人档案面板还会同步显示道行、武学、法力、内力四项境界评价。游戏保留完整的门派与联盟体系，适合长线培养角色成长。

## 内容亮点

- 玩家从"南城客栈"起步，培养力量、悟性、根骨、敏捷、灵性五项天赋，并
  在光明磊落/狡黠多变/心狠手辣/阴险奸诈四种天性中择一，塑造角色初始
  气质。
- 保留了呼应《西游记》原始题材的关卡系统："大闹天宫""西行取经"等，
  `score` 个人档案面板会专门列出这两条主线的进度，以及"道行境界/
  武学境界/法力修为/内力修为"四项境界评价。
- 进入游戏世界前有一幅像素风格的电脑显示器 ASCII 画，配一句"你是
  不是也象我一样。。。"的感伤台词——比常见的"侠客上路"开场多了一
  分怀旧网吧年代的气氛。
- 门派与联盟体系完整，适合长线成长型玩法。
- 界面上仍能看到少量"西游记"旧题材遗留的系统提示文字——这是该库从老
  西游记底本二次改造而来的历史痕迹，不影响"翱翔天际"本身的实际内容。
- 巫师/管理账号有独立的二次密码校验机制：首次登录会要求额外设置一个
  专用巫师密码，此后每次登录都需要在常规密码之后再验证一次。
