# 翱翔天际

## 游戏名称

本游戏自称 **翱翔天际**（登录横幅另称"翱翔天际之擎日挽月"），登录时的
ASCII 艺术标志竖读左侧一列即为"翱翔天际"四字。

## 简介

这是一个脱胎于经典《西游记》题材 MUD 的中文武侠/仙侠 MUD（部分系统提示
文字仍沿用"西游记"旧称，为历史遗留，不影响游戏内容本身）。玩家从"南城
客栈"起步，培养力量、悟性、根骨、敏捷、灵性五项天赋，选择天性（光明磊
落/狡黠多变/心狠手辣/阴险奸诈），在门派、联盟体系中闯荡成长，同时保留
了"大闹天宫""西行取经"等呼应原始题材的关卡系统。

## 如何运行

```
cd libs/aoxiangtianji && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40101**。请在 `libs/aoxiangtianji` 目录下启动（保证日志正确
写入同目录 `log/debug.log`），看到 `Accepting telnet connections on
0.0.0.0:40101.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40101
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40101`。

连接后请先选择编码：输入 `utf-8`（游戏内部已是 UTF-8，无需选择 GBK）。
注册新角色请在英文名字提示处输入 `new`，随后依次：
1. 英文代号（3-8 位纯英文字母，不能含数字）
2. 中文姓名（2 到 4 个中文字）
3. 管理密码（≥5 位，用于密码遗失时找回）
4. 普通密码（≥5 位，日常登录使用，需与管理密码不同）
5. 是否接受随机天赋（y/n）
6. QQ 号码（4-13 位数字，必填）
7. 电子邮箱
8. 性别（m/f）
9. 天性（1-4 选一）

完成后角色会进入"南城客栈"这一起始场景。

## 已知问题

- 少数房屋模板、故事系统 NPC 等内部对象设计上只能通过系统自身的克隆流程
  创建（不能被通用编译检查工具直接单独加载），这是原始设计如此，不是
  故障。
- 界面上极少数系统提示文字仍沿用了本游戏早期基于"西游记"题材开发时的
  旧称呼，纯属历史遗留的文字未更新，不影响实际的"翱翔天际"游戏内容。
- 新注册账号如果在半小时内退出登录，会被系统自动删除存档（这是游戏本身
  的防灌水设计，不是缺陷）。

核心的注册（含中文姓名）、登录、探索（look）、查看状态（score）、退出
存档流程，以及管理员账号登录与权限，均已在原生（native）驱动与 WASM
（浏览器）驱动两种模式下反复验证工作正常。
