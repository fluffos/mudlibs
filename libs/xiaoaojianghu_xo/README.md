# 笑傲江湖 XO

## 游戏名称

游戏取材自金庸小说《笑傲江湖》，"XO"是这个版本自己的代号（登录横幅上
写着"THE SMILING PROUD WANDERER"）。它源自"TMI-2/ES2"引擎，由"Falcon"
改写，本项目里另外两个库 `xo`（笑傲江湖迷你版）和 `xo_final`（XO 最终版
1.2）都是同一血脉的不同快照，这一份是三者中独立演化出来的第三个版本。

## 简介

游戏世界完整还原了《笑傲江湖》里的江湖门派、武功体系，新人物会被随机
分配到几个不同的起始场景（比如"龙门客栈"）之一，围绕拜师学艺、行走
江湖展开。剑术、刀法、拳脚、轻功、短兵刃、鞭法、长兵刃等各类武学修为
都有独立的养成线，是比较正统的金庸题材文字 Mud。

## 如何运行

```
cd libs/xiaoaojianghu_xo
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口固定为 **40069**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40069 --timeout 30 --idle 1 \
  --send "<英文ID>" --send "y" --send "<中文名字>" \
  --send "<密码>" --send "<密码>" --send "<邮箱>" --send "m或f" --send "look"
```

1. 英文名字
2. 确认创建新人物（y/n）
3. 真实中文姓名（提示会特别叮嘱不要用金庸小说里已有人物的名字，
   比如令狐冲、任盈盈这类，建议自己另取一个）
4. 设置密码、再输一次确认
5. 电子邮箱
6. 性别 m/f

创建完成后会被随机送到几个起始场景之一（例如"龙门客栈"），`look`、
`score` 都能正常显示中文场景描述和人物状态。

**小提醒**：新创建的人物如果在上线 30 分钟内就 `quit`，系统会先弹出
"你初次...必须玩够 30 分才可以保存数据！所以请确定你是否真的要退出"
的确认提示——这是游戏本身的防灌水设计（避免刚建号就退出占用存档位），
不是故障，按 `y` 确认退出即可，只是这次的人物数据不会被保存。

## 已知问题

个别"无量剑"一支门派的 NPC 引用的技能设定在这份存档里没有对应实现，
属于历史遗留的内容缺口，不影响主流门派的正常玩法；此外还有一批巫师
个人测试目录、以及不会被加载的重复/废弃系统文件，都不会在正常游玩中
遇到。

**WASM 版可玩性**：在新的 WASM 构建下能正常启动，注册流程（英文名→
确认→中文名→密码→确认→邮箱）与原生环境表现一致，但性别选择之后的
角色创建收尾步骤在 WASM 下不稳定（多次测试有时卡住无输出，有时又
重复了前面的提示），原生环境下同样的代码完全正常——判断是 WASM 测试
环境本身的时序问题，不是本 mudlib 的 bug，故未作修改。
