# 三国志

以三国历史为背景的 MUD，脱胎于经典 Lima mudlib（TMI-2 / Ellery 安全体系一脉）。注册时先在武侠/演义气质的四种天赋模板中挑选一种（英勇善战型、足智多谋型、识人善用型、智勇全才型），系统随机分配武力/ 智谋/魅力三维属性；游戏地图铺开在长安、邺城、汉中等三国城市、关隘与战场之间，华佗、各地商人乃至汉献帝本人都以 NPC 身份登场。招募亲兵、骑乘赤兔马/的卢马/大宛马等历史名马、发展地方或国家官职，是贯穿全程的核心玩法之一（见游戏内 `help myarmy`）；中文取名不能使用真实的三国人物姓名，如"刘备""赵云"会被系统直接拒绝。

## 内容亮点

- 真实的三国地图：长安、邺城、汉中等多座城市与关隘、战场，NPC
  包括华佗、各地商人以及汉献帝本人。
- 个人武装系统：招募亲兵、骑乘赤兔马/的卢马/大宛马等历史名马、
  发展地方或国家官职，是这个游戏的核心玩法之一（见游戏内
  `help myarmy`）。
- 继承自 Lima mudlib 的 unix 风格巫师 shell（`quit`/`help`/`who`/
  `update` 等命令与 `look`/`score` 等自然语言动词是两套独立的
  派发机制，见下方"已知特性"）。

## 已知特性（非 bug）

- **每个新注册账号都会自动获得巫师（Admin）权限**，这是这个存档自带
  的引导机制（"你自动成为 Admin，记得用 admtool."），并非仅限第一个
  账号。新巫师会先出现在 Lima 框架自带的"巫师大厅"，而不是三国志
  自己的新手村——大厅北墙的轮回台可以前往人间地图。天赋选择菜单在
  巫师引导流程之后仍会正常出现。
