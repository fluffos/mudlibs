# 侠客行 (The Quest of Oriental Chivalry) — 北美 2001 版

属于 ES II/"侠客行"引擎家族(与 xkx2001、xuanjianlu 等同宗),此为
1996-1999 年 XiaKeXing Gaming Group 制作、于北美地区运营的一个版本。

## 简介

「侠客行」取材自金庸同名武侠小说,以"侠客岛"为核心背景——新玩家一入
游戏就会由岛上的"赏善使"或"罚恶使"两位使者之一迎接,带你前往挂名处登
记,随后才能真正踏入江湖。整体设定紧扣原著世界观,门派、武功体系完
整,是早期中文 MUD 里颇具代表性的金庸武侠作品。

## 如何运行

```
cd libs/beimeixiakexing2001
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口:**40039**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40039
```

连接后会先看到一个隐藏问题 **"Do you want to use BIG5 code?(y/n)"**——
这只是询问客户端使用繁体(BIG5)还是简体(GB)字库显示,与账号本身无关,
回答 `n` 即可(本项目环境统一以简体/UTF-8 显示)。

注册流程:
1. 英文 ID(新玩家可任选喜欢的名字)
2. 确认创建新角色(y/n)
3. 中文姓名(请避开小说中已有的人物姓名,如"韦小宝"等会被系统拒绝)
4. 密码
5. 确认密码
6. 分配天赋点数(接受随机方案,或输入 n 重新随机)
7. 电子邮件地址
8. 选择性别(m/f)

新角色第一次进入游戏会先被带到"侠客岛"的迎宾/登记流程——此时只能使
用 `look`、`follow`、`say`、`quit` 等少数指令(这是游戏本身刻意设计的
新手引导限制,并非故障),需先跟随迎宾使者、并用 `register 你的邮箱地
址` 完成登记,之后再次登录才会进入真正可自由行动的江湖世界。

  响新手体验。

  正常),不受底层驱动 IP 检测限制影响。
