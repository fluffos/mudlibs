# 未明空间 (Weiming Kongjian / "wmkj")

原始压缩包自称"未明空间"，但实际连接后显示的游戏名是**"江湖风云之
夕阳再现"**——这是"夕阳再现"（Sunset Reappears）引擎系列的一个分支
版本，与本项目中的 xiyangzaixian_fengkuang、jianghufengyun 等同源，但
master/登录/安全模块各自独立开发，并非简单换皮。

## 简介

「未明空间」以传统武侠江湖为背景，玩家从"武庙"一类的场景踏入江湖，习
武、闯荡、结交侠士。作者"龙宝宝(xiha)"在 2001 年发布了这份单机存档供
其他人搭建自己的服务器游玩，因此内容截止于当时的版本状态，而非一个持
续运营到今天的活跃游戏。

## 如何运行

```
cd libs/weimingkongjian
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40049**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40049
```

注册流程没有隐藏的编码/年龄询问，比较直接：

1. 英文 ID（新角色）
2. 确认创建新角色（y/n）
3. 中文姓名
4. 设置密码，并再次确认
5. 天赋点数：会问是否接受一组随机分配的数值（输入 `0` 由系统随机、`y`
   接受）
6. 电子邮件地址
7. 选择性别（m/f）

完成后会被送入其中一个随机起始场景（如"客店""北疆小镇"等），`look`、
`score` 等指令均已确认能正确显示中文内容，并会在公共频道里广播一条
"听说又来了一位叫做XXX的少年侠士"式的欢迎消息。

## 已知问题

- 个别房间/道具脚本存在原始存档遗留的小瑕疵（例如个别武器物品的继承
  关系写错），均属边角内容，不影响主线注册和基础游玩。
- 游玩过程中偶尔会看到"编译时段错误"提示，是驱动器把无害的编译警告
  显示给了玩家，并非真正故障。
- WASM（浏览器/无网络端口）构建下能干净启动。原先登录会被本库的 IP
  黑名单检查（`BAN_D->is_banned()` 把格式不正确的 IP 一律判为"禁止"）
  拦截；现已改为本机/格式异常 IP（WASM 连线的两种形态）一律放行，
  同时本机连线也豁免了本库的按 IP 连线数/登录数限制。
