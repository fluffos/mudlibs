# 炎黄英雄史（游戏内也称"皇朝再现"）

属于 ES II 引擎家族（2003 年"炎黄"分支），与"炎黄武魂Ⅱ"是关系很近的姊妹作，
共享同一套底层引擎，但拥有各自独立的剧情内容与世界细节。

## 简介

一款武侠题材 MUD，玩家从"世外桃源"出发，可以在"猛士型""智慧型""耐力型"
"敏捷型""均衡型"五种角色定位中做出选择，随后踏上自己的江湖之旅。整体节奏
和"炎黄武魂Ⅱ"相近，但地图、剧情、平衡数值都是独立设计的内容。

## 如何运行

```
cd libs/yanhuangyingxiongshi && ~/src/fluffos/build-debug/src/driver config.fluffos
```

端口：**40061**

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40061
```

登录流程：

1. 输入英文名字（**只能用英文字母，不能带数字**），确认时回答 `y`。
2. 依次输入中文姓氏、名字（各自不超过两个汉字）。
3. 设置管理密码和普通密码（均需两次输入确认）。
4. 选择角色类型（输入 1～5）。
5. 选择性别（`m`/`f`），完成后进入"世外桃源"。

## 已知问题

- 刚进入游戏时会被提示"还没有选择品质"，需要按提示前往附近完成天赋选择后，
  `score` 等状态指令才会显示完整信息，这是正常的新手引导流程。
- 少数深层区域（例如"天龙寺"相关的一处子区域）在存档中并未完整包含，属于
  内容缺口，不影响主线区域的正常探索。
- 个别历史悠久的玩家留言板内容存在早年的数据轻微损坏，只影响那一块留言板
  本身，不影响正常游玩。
- 本存档在新的 WASM（浏览器/Node 沙盒）模式下此前无法进入注册流程（原因与
  同源存档"炎黄武魂"相同：登录横幅里一处版本检测调用没有做异常保护，而版本
  检测模块依赖的网络功能在 WASM 环境下不可用，导致连接在英文名字提示出现之
  前就中断）。**WASM 启用专项（本次更新）已修复**：两处 `VERSION_D` 调用都
  加了 `find_object()` 守卫，守护进程不存在时直接跳过版本检测，不再阻断登录
  （守卫写法与 `yanhuangwuhun` 相同，尚需一次 WASM 实测确认解除阻断）。
