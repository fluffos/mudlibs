# 海洋II

## 游戏名称

本游戏自称 **海洋II**，游戏内还有一个更常用的招牌名字——**星月传奇**。
属于经典的 "ES II" 引擎家族（与本项目中的 es1_win、xkx2001、rzrmud、xo、
武汉站、炎黄武魂等同宗），是当年一批中文武侠 MUD 中流传较广的一支。

## 简介

这是一个传统的中文武侠泥巴（MUD），世界观以江湖门派、拜师学艺、行侠仗义
为主线，登录后即可看到"江南水乡""明教""高昌""日本"等多个地图分区。
游戏规模较大（工作目录内近三万个文件），涵盖武功、门派任务、婚姻、帮派
等一整套传统武侠 MUD 玩法，内容相当丰富完整。

## 如何运行

```
cd libs/haiyang2 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40057**。启动后请确认在 `libs/haiyang2` 目录下执行（日志会写到
同目录的 `log/debug.log`），控制台看到 `Accepting telnet connections on
0.0.0.0:40057.` 即表示启动成功。

## 如何连接游玩

用任意 MUD 客户端或 telnet 连接 `127.0.0.1 40057` 即可，也可以用本项目
自带的测试脚本体验：

```
python3 scripts/mudclient.py 127.0.0.1 40057
```

**特别提醒**：连接后的第一个提示不是取名字，而是一个编码选择——

```
Please select 国标码 〖GB〗 or き絏 〖Big5〗 (GB/Big5):
```

这是当年为区分简体 GB 码 / 繁体 Big5 码而设的隐藏前置问题，**必须先回答
`g`（或 `gb`）** 才能进入正式的角色创建流程（本游戏只支持简体显示，选
Big5 只是切换客户端解码方式，不建议使用）。之后依次会问：英文代号 → 是否
确认新建角色 → 中文姓名 → 密码（两次）→ 随机天赋是否接受 → 邮箱 → 性别，
即可进入游戏。

另外，本游戏对同一 IP 的注册频率有限制（短时间内重复创建角色会被拒绝），
如果测试时提示"请稍后再login"，稍等片刻或重启服务端即可。

## 已知问题

- 少量帮派/门派专属 NPC（如明教分舵的几名弟子）引用了并未包含在本压缩包
  内的功法文件，属于原始资料本身的内容缺失，不影响主线游玩。
- 个别公告板（比如新手客栈的告示板）存档数据在原始版本中已经损坏，读取
  时会自动当作"空白告示板"处理，不影响正常使用。
- 英文/中文名字互译词典（用于把英文名翻译成中文显示）的存档数据同样是
  原始版本自带的损坏文件，翻译功能会退化为"原样返回"，属于外观问题，不
  影响正常登录和游戏进程。

总体而言核心的注册、登录、探索、查看状态（score）等功能均已验证可正常
使用，江湖世界完整可玩。
