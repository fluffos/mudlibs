# 海洋II

本游戏自称 **海洋II**，游戏内还有一个更常用的招牌名字——**星月传奇**。
属于经典的 "ES II" 引擎家族（与本项目中的 es1_win、xkx2001、rzrmud、
xo、武汉站、炎黄武魂等同宗），是当年一批中文武侠 MUD 中流传较广的一支。
`hymud`（海洋V·星月传奇）是它独立演化的续作，共享的却是本项目
`hy5`（海洋5）那套 191 个地图分区的骨架，而非海洋II自己规模较小的
世界。真正与海洋II血缘更近的其实是 `hy5`：两者 master.lpc 逐字节相
同，地图文件约九成字节相同——本质上是同一份世界基础，`hy5` 只是在
此之上扩建了约五十个新地区（越南、朝鲜、日本、西藏、新疆等）。海洋II
本身近三万个文件构成的世界以门派江湖、拜师学艺、行侠仗义为主线，地
图涵盖江南水乡、明教据点、高昌乃至日本分区，并叠加了完整的婚姻系统
与帮派玩法。

## 内容亮点

- 世界观以江湖门派、拜师学艺、行侠仗义为主线，登录后即可看到"江南
  水乡""明教""高昌""日本"等多个地图分区。
- 游戏规模较大（工作目录内近三万个文件），涵盖武功、门派任务、婚姻、
  帮派等一整套传统武侠 MUD 玩法，内容相当丰富完整。
- `enable_player()` 每次重新触发都会叠加一次同样的指令绑定——这一点
  在深度测试中被发现并修复，此前会导致失败指令的副作用被悄悄重复
  执行。
