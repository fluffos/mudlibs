# 海洋II

本游戏自称 **海洋II**，游戏内还有一个更常用的招牌名字——**星月传奇**。
属于经典的 "ES II" 引擎家族（与本项目中的 es1_win、xkx2001、rzrmud、
xo、武汉站、炎黄武魂等同宗），是当年一批中文武侠 MUD 中流传较广的一支。
`hymud`（海洋V·星月传奇）是它的独立演化续作。

## 内容亮点

- 世界观以江湖门派、拜师学艺、行侠仗义为主线，登录后即可看到"江南
  水乡""明教""高昌""日本"等多个地图分区。
- 游戏规模较大（工作目录内近三万个文件），涵盖武功、门派任务、婚姻、
  帮派等一整套传统武侠 MUD 玩法，内容相当丰富完整。
- `enable_player()` 每次重新触发都会叠加一次同样的指令绑定——这一点
  在深度测试中被发现并修复，此前会导致失败指令的副作用被悄悄重复
  执行。
