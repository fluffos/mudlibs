# 龙云梦·炎龙封印（源码版）

作者 Wenwu，属于"夕阳再现/炎龙封印"（XYZX/YLFY）引擎家族的一个独立
分支——与本项目中的 `ylfyxa3`（炎龙封印·笑傲江湖阿飞
站）同宗但各自独立演化，并非同一份内容的翻版；也和另一轮处理过的
`xyzx`/`jhfy3`/`xajh4gkb`/`xyzxyl201412` 是同一个真正的"夕阳再现"
血统（`d/city/sj.lpc` 逐字节相同）——注意本项目里还有另一批同样打
着"夕阳再现"招牌、地图却是完全不同的"天涯"家族的档案（`xysylmhb`/
`xyzxiiylzymh`/`yzxiiizylfy`/`xyzx3` 等），品牌名称不能作
为判断血统的依据。

## 内容亮点

- 带有奇幻/仙侠色彩的武侠 MUD：除了常规的膂力、悟性、根骨、身法等
  武学天赋外，角色还需要在光明、土、火、水、木、气、雷、心灵、黑暗、
  空间、金等十一种"魔法天赋"元素中选择自己的先天亲和属性，融合了
  传统江湖门派玩法与元素魔法体系，内容量较大（近两万个游戏文件）。
- 木人是安全的陪练对象，会原样镜像挑战者自身属性进行对练。
- 门派体系完整可拜师，例如华山派岳不群门下即可正式拜师习武。
- 帮会系统会实时追踪每个分舵"掌门大弟子"的归属，帮会内部权力结构
  会随实际游玩自然演化。
