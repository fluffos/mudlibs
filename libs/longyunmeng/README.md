# 龙云梦·炎龙封印（源码版）

## 游戏名称

**龙云梦·炎龙封印**（作者 Wenwu），属于"夕阳再现/炎龙封印"（XYZX/YLFY）
引擎家族的一个独立分支——与本项目中的"夕阳再现III之炎龙封印"、
"炎龙封印-笑傲江湖3阿飞站"同宗但各自独立演化，并非同一份内容的翻版。

## 简介

带有奇幻/仙侠色彩的武侠 MUD：除了常规的膂力、悟性、根骨、身法等武学
天赋外，角色还需要在光明、土、火、水、木、气、雷、心灵、黑暗、空间、
金等十一种"魔法天赋"元素中选择自己的先天亲和属性，融合了传统江湖门派
玩法与元素魔法体系，内容量较大（近两万个游戏文件）。

## 如何运行

```
cd libs/longyunmeng
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务端口：**40094**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40094
```

或用任意 UTF-8 telnet 客户端连接 `127.0.0.1:40094`。

注册流程比一般武侠 MUD 稍长，依次是：英文角色代号 → 确认创建（y）→
中文名字 → 密码（两次）→ 一个"身份标识"（类似第二密码，至少 9 位字符，
且不能包含 `//`，需输入两次确认）→ 天赋点数分配（直接输入 `0` 使用系统
随机分配）→ 输入 y 接受这组随机天赋 → 选择魔法元素（输入 0-10 中的一个
数字）→ 电子邮箱 → 性别（m/f）→ 进入游戏世界。没有需要提前得知的隐藏
客户端版本暗号（这套引擎在其他姊妹版本里出现过的"Tomud客户端暗号"关卡，
在本服普通端口下不会触发）。

## 已知问题

登录、`look`、`score`、`i`（查看物品）等基本指令均已验证正常工作，男女
角色的性别化文本（称谓、服装等）也都正确。整体内容量很大，个别边角
内容存在历史遗留的小瑕疵，不影响主线体验：
- 极个别管理员专用命令（如查看在线用户底层状态的工具）依赖的功能在本
  环境中未启用，普通玩家接触不到。
- 少数迷宫类地图区域中存在的一处引擎自检测试相关的边界情况，仅在特定
  自动化检测环境下才会出现，在实际游玩、含新手区域内均未观测到任何
  异常。
- 在 WASM（浏览器/Node 沙盒）构建下测试：驱动能正常启动，但由于该驱动
  版本自身对 WASM 连线 IP 格式化的已知限制，本游戏自带的地址黑名单检查
  会误判每一次连线为"不受欢迎地址"，导致 WASM 环境下暂时无法登录——这
  是驱动侧的已知限制，并非本游戏程序的错误，原生（非 WASM）环境下登录
  完全正常。
