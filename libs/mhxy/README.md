# 梦幻西游 (mhxy)

## 游戏名称

《梦幻西游》(MHXY)，青岛站，自 2002 年 1 月 15 日起运行，隶属于经典的
"西游记"引擎家族（与本项目转换的 fluffos_xiyou2000 等同源），底层引擎标注
为 MudOS V22Pre11。

## 简介

一款以《西游记》神话世界观为背景的中文文字网游：新角色要"想一个符合〖梦幻
西游〗神话世界的中文名字"，随后获得体格、根骨、悟性、灵性四项天赋，踏上取
经之路。新手村是长安城中的"南城客栈"，黄飞鸿、孙悟空等耳熟能详的角色都以
NPC 身份出现在场景里。整体氛围偏休闲，帮会、门派、九重天/十二宫/冥界等玩法
名词在角色档案里都能看到痕迹。

## 如何运行

```
cd libs/mhxy
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40016**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40016
```

连接后请依次注意：

1. 首先会问 `gb` 或 `big5` 编码——现在的客户端一律回答 **`gb`** 即可（`big5`
   分支的界面文字有些是错乱的历史遗留问题，不影响 `gb` 分支）。
2. 接着是一个"你是否是中小学生"的年龄提示，回答 `no` 即可继续（这只是一个
   老式的形式化提示，不会真的验证年龄）。
3. 输入 `new` 注册新角色，然后依次设置：英文 ID（3-8 位纯英文字母）、真实的
   中文名字、密码（需再输入一次确认）、"身份标识"（一个至少 6 位、同时包含
   大小写字母和数字/符号的附加密码，也要再输入一次确认）、电子邮箱、个人主
   页（可直接回车留空）、ICQ 号（同样可留空）、最后选择性别 `m`/`f`。
4. 进入游戏前会有一次"天赋"分配界面，直接输入 `9` 接受默认天赋，再输入 `y`
   确认即可正式进入长安城的"南城客栈"。

登录后 `look`、`score` 等指令均已验证工作正常。

## 已知问题

- 少量涉及内部邮件服务器等辅助网络守护进程编译存在小问题，但不影响正常登
  录和游戏功能。
- 有极少数场景/NPC 文件在整体 lpcc 扫描中未通过（约 97% 通过率），均为非
  必经路径的边角内容，不影响主线登录和城镇游玩。
- WASM 版本可以正常启动，但登录流程会在识别连线 IP 归属地时报错（因为
  WASM 驱动目前无法提供真实的连线 IP 格式），导致注册卡在最开始，无法
  完整体验。这是 WASM 驱动本身的已知限制，不是本库的 bug——同一段代码
  在原生（native）驱动下已完整验证可以走完注册、进入长安城南城客栈、
  查看属性等全部流程。
