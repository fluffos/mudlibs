# 大唐西游完整修正版

一个西游记血统的 MUD（大唐西游 / Journey of the East），共享
`convertd.lpc`/`feature/encoding.lpc` 这套典型 ES II 家族的 GB/BIG5
编码切换机制。和 `xyj2006n`（西游记2006年，AKAI Studio 的 Tomud 品
牌版）地图逐字节相同（`d/gao/gate.lpc` 等场景内容完全一致），核心
系统档案是同一套的两个不同发行版本，此前两份档案都没有互相记录这
层关系。游戏世界以三十三天、蟠桃园、蓬莱、天宫等取经沿途地标搭建
《西游记》神话世界观，另设 `d/zhanchang` 战场场景，`d/g_quest` 任
务目录里则登场了长孙无忌、太平公主、钟馗、红娘等唐代历史/传说人
物，与常规探索、门派玩法并行展开；注册时会先询问是否为中小学生，
管理密码（改密/备份/自杀等敏感操作专用）与登录密码彼此独立，且规
则更严格（须含大小写字母+特殊符号，至少 7 位）。

## 内容亮点

- 《西游记》神话世界观：地图有三十三天、蟠桃园、蓬莱、天宫等取经
  沿途地标，和"三界神话"系家族（99-101、118 号等）的地名风格相
  似，但代码库不同（这份档案共享的是 `convertd.lpc`/GB-BIG5 编码
  切换机制这一支 ES II 家族血统）。
- 注册时会先问"是否为中小学生"，是这批档案里少见的显式未成年人访
  问提示。
- 管理密码（用于改密/备份/自杀等敏感操作）和登录密码是两套独立密
  码，且管理密码规则更严格（需大小写字母+特殊符号、至少 7 位）。
- `d/zhanchang/` 提供战场场景，`d/g_quest` 是一套独立的任务档案
  目录，和常规探索/门派玩法并列。

## 注册流程

连线后先选择编码（gb/big5，两者现在都安全）→ 是否为中小学生
（yes/no）→ 英文名字（键入 `new` 注册）→ 新英文名字 → 中文名字 →
管理密码（需大小写字母+特殊符号，≥7 字元，用于修改密码/备份/自杀
等敏感操作）→ 确认管理密码 → 游戏登录密码（≥5 字元，不能和管理密
码相同）→ 确认登录密码 → 电子邮件地址 → 性别（m/f）→ 天赋数值确
认（0-3 重新设置某一项，9 接受当前设置，再需 y/n 二次确认）。

## 本次修复的关键 bug

- `adm/daemons/convertd.lpc` 的希腊字母表数据里混入了一个多余的反
  斜杠（`"α\",` 应为 `"α",`），这是整个西游记/ES II 家族的通病，本
  档案有 45 处，导致 simul_efun 编译失败。已用标准的 CRLF-安全 sed
  修复。
- **两份 `logind.lpc` 陷阱**：本档案同时存在 `/daemons/logind.lpc`
  （未被任何宏引用的死代码，流程更短）和真正被 `LOGIN_D` 宏指向的
  `/adm/daemons/logind.lpc`（流程更长，多了"管理密码"设定和天赋数
  值二次确认这两个环节）。一开始误读了死代码副本，得到一个完全不
  对的注册流程用来测试——务必先查 `LOGIN_D` 宏的实际定义再动手。
- GB/BIG5 编码选单（本地 int 旗标覆盖 + `convertd.lpc` 的字节对查找
  表机制）：实测选择 BIG5 会疯狂输出"Invalid GB code"并把画面弄花
  ——这个查找表假设驱动内部字符串是原始 GB2312 字节，但这个项目的
  转换流程已经把全部内容转成 UTF-8，所以选 BIG5 反而会把正常的
  UTF-8 中文字节当成字节对来转码。已将两个选单选项都对应到
  `encode=0`（这个家族的 `convertd.lpc` 本来就把它当成安全直通）。
