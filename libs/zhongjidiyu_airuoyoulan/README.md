# 终极地狱之爱若幽兰

## 游戏名称

游戏登录后自报家门为 **"地狱泥潭---爱若幽兰"**（压缩包标题为"终极地狱之
爱若幽兰"）。属于 **ES II → XKX → "地狱"（hell）分支**引擎家族，与
`zhongjidiyu_zhijian`（指间MUD版）是同一套"地狱"引擎核心的姊妹版本（两者
master 文件内容完全一致），与另一个同样带"终极地狱"字样、但内容完全不同
的 `zhongjidiyu` 压缩包**不是同一款游戏**，只是名字碰巧相似。

## 简介

同样是"地狱"世界观下的武侠向 MUD，主题偏"爱若幽兰"这一支线剧情。整体
系统架构和 `zhongjidiyu_zhijian` 基本一致（角色创建、门派、装备系统等），
但没有那个版本专属的手机客户端协议层，可以直接用普通 telnet 客户端游玩，
没有额外的连接门槛。

## 如何运行

```
cd libs/zhongjidiyu_airuoyoulan
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40073**

## 如何连接游玩

```
telnet 127.0.0.1 40073
# 或
python3 scripts/mudclient.py 127.0.0.1 40073
```

注册流程没有隐藏的编码/客户端门槛：

1. 英文名字 → 确认创建新角色 `y`。
2. 依次输入中文姓氏、名字。
3. 设置管理密码、普通密码（各输入两次）。
4. 选择角色类型（1-5）、性别（`m`/`f`），随后进入游戏世界（起始地点"世外
   桃源"）。

用纯文本客户端（如 telnet）游玩时，偶尔会看到类似 `lbadd0`、`bnway`、
`licon 00915` 这样一串看起来像乱码的前缀文字——这是引擎内部为某种富文本
客户端准备的隐藏标签，普通文本客户端不会解析它们，只会原样显示出来，
可以直接忽略，不影响正常阅读和游玩。

同样，新角色需要先找水笙 `register <邮箱>` 完成注册，再走"投胎做人"流程，
`score` 才会显示完整数据，之前会提示"还没有出生呐，察看什么？"，这是正常
设定。

## 已知问题

一些非主线的周边内容（例如个别 NPC 身上的"写日记"式互动）因原始压缩包本身
就缺少对应文件而无法使用；另外有一批"国际挑战者"主题的随机剧情 NPC，设计
上就是"没有玩家在线时会自动消失"，属于正常机制而非故障。这些都不影响主线
的拜师、探索、`look`/`score` 等基础玩法。
- 本轮重新验证：LPC 代码已全部跑过格式化工具，并在重新编译的最新驱动上
  完整回归测试通过。**WASM（浏览器/纯 JS）模式下目前无法完成注册**——
  原因是测试工具本身的一个限制（并非这个游戏本身的问题）：WASM 测试环境
  没有把游戏自带的 `log/static/` 目录一起复制过去，导致角色刚连线时的
  第一步写日志操作就失败，从而在还没看到"英文名字"提示之前就被断开连接；
  原生（telnet）模式完全不受此影响，可以正常注册和游玩。
- 2026-07 WASM 适配补丁：版本同步（versiond）和消息精灵（messaged）等
  依赖 socket 的守护进程加载失败时不再拦断登录；本机/回环连接不再受 IP
  封禁检查影响。另外修复了一个原始存档就有的老 Bug：**每次重启后的第一次
  登录所有命令都无效**（连 quit 都提示"什么？"，第二次登录才正常）——
  根源是登录时懒加载的消息守护进程抛错打断了首次登录的初始化，现已修复。
