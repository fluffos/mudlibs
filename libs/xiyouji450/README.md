# 西游记450

## 游戏名称

**西游记**（这是一份专门用于建立"镜像站"的发行包，内附教学说明，供其他站长
在其基础上另开一个分身站点）。与本项目中的 `fluffos_xiyou2000`、`mhxy`、
`menghuanxiyou2002` 同属一支血缘极近的"西游记/xiyouji.org"引擎家族——核心
引擎文件（`master.c`、`chinese.c` 等）与 `mhxy` 几乎逐字一致，只有站点自定义
的登录/安全层与世界内容各自不同。

## 简介

以《西游记》世界观为背景的武侠/神话文字 MUD，与同系列的其他版本一样，玩家
从长安城的南城客栈出发，探索天地三界，习练武功、结交门派，逐步在这个混合了
取经故事与江湖侠义的世界中成长。作为一份"镜像站"发行包，世界内容与
`fluffos_xiyou2000`/`mhxy` 系高度相似，但拥有自己独立的注册与安全体系。

## 如何运行

```
cd libs/xiyouji450
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40078**

## 如何连接游玩

```
telnet 127.0.0.1 40078
# 或
python3 scripts/mudclient.py 127.0.0.1 40078
```

登录时会先问选择编码 `Select GB or BIG5 (gb/big5)`，简体中文用户输入 `gb`；
接着是"是否为中小学学生"的问题，回答 `no` 即可继续。之后依次输入：英文代号
-> 确认新建角色(y) -> 中文名字 -> 密码 -> 确认密码 -> 电子邮箱，即可正式
进入游戏，落地在"南城客栈"（与姊妹版 `xiyouji` 不同，本版没有性别/天赋
选择环节）。

## 已知问题

- 一个古老门派管理员命令（`imm cast1`）对应的文件在原始压缩包中本身就已经
  损坏截断，仅影响巫师专用的管理指令，不影响普通玩家的正常游戏。
- 少量深层剧情文件（如"雾镇/wudidong"区域的个别对话）存在原始压缩包自带的
  文字截断，均为非主线内容，不影响新手路线与日常游戏体验。
- **WASM（浏览器/无网络监听端口运行模式）下可以完整游玩**：注册、登录及
  look/quit 等基本指令均已验证可以正常工作，没有遇到其它同系列存档中出现
  的"连线地址格式"限制问题。
