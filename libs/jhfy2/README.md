# 江湖风云2 (jhfy2)

游戏内标题为"江湖风云II 之 辽宁风云再起"，金庸题材 mudlib。地图目
录结构和"天涯"家族（`tybxjh`/`xhcii`/`zxty`/`ffxymud`）几乎一致，
`d/city/sj.lpc`（"世界之巅"跳崖场景）内容也相同（本档案这份文件
被排版格式化工具误加空格，但核心内容确认逐字对应），是这批档案里
第六个确认的成员，此前没有任何一份档案互相记录过这层关系。

## 内容亮点

- 和"天涯"家族共享同一套金庸门派/地图世界观（华山、武当、峨嵋、
  丐帮、明教等场景齐全）。
- 天赋数值有六项，其中"福缘""容貌"是隐藏属性，比常见的四维属性设
  定更细致。
- 地图里门派场景和"天安门"这样的写实地标混搭在一起，是这批金庸题
  材档案里比较少见的处理方式。
- 早期的 WASM 验证只走了注册流程，没有测到战斗/死亡，实际深度游
  玩后还是发现了几处常见 bug 类的实例（见下方"深度功能测试新发现
  的 bug"）——档案本身不算"完全干净"，只是问题都藏在注册流程之后。

## 注册流程

英文名字（3-10 个英文字母）→ 确认建立新角色（y/n）→ 中文名字（可
留空让系统自动跳过取中文名，本次用真实中文姓名验证通过）→ 密码
（至少 5 位）→ 确认密码 → 天赋数值（六项属性，其中福缘、容貌为隐
藏属性；输入 0 交由系统随机产生，随后需再输入 y 确认这组数值）→
电子邮件地址 → 性别（m/f）→ 进入游戏世界。

## 本次修复的关键 bug

没有发现任何需要修改的 mudlib 代码——`MASTER_OB`/`SIMUL_EFUN_OB`
宏本来就和 `config.fluffos` 一致，`is_chinese()`/
`check_legal_name()` 本来就是正确的 Unicode 码点判断，指令表
（`commandd.lpc`）开箱即用，也没有发现 `this_player()`/
`previous_object()` 顶替 root 身份一类的 ACL 问题。完整的注册→
`look`→`score`→`quit` 流程第一次真实连线测试就顺利通过。（这一轮
只测到注册流程，没有测战斗/死亡——见下方"深度功能测试新发现的
bug"，实际不是完全没有 bug。）

## 深度功能测试新发现的 bug（§10.7，2026-08-04）

- **§7.34 printf 调试泄漏**（两条并行代码路径都有）：
  `adm/daemons/logind.lpc` 的 `get_name()`/`get_resp()` 里各有一行
  遗留的 `printf("%O\n", ob);`，已删除。
- **§7.68 复活软锁死（第 15 例）**：`d/death/npc/{wgargoyle,
  bgargoyle}.lpc`（鬼门关的白无常/黑无常）已按标准修法拆分。现场
  验证：死亡→鬼门关→未被打断的完整复活序列→成功落地"武庙"
  （`REVIVE_ROOM`）。
- **§8.9 食物/饮水错误对象判断**：`enter_world()` 里
  `ob->query("age") == 14` 查询的是连线对象而非角色对象，已改为
  `user->query("age")`。这份档案里角色食物/饮水另有默认值来源，
  所以这个 bug 目前观察不到明显后果，但判断逻辑本身确实是错的，
  按既定原则修正。
