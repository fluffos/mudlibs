# 武林列传Ⅲ

武林列传Ⅲ（WLLZ Mudlib 3.0b，副题「天无际，海无涯」）是 MoonLight 巫师组在东方故事（ES2）底层上开发的第三代武侠文字 MUD，2008 至 2009 年间运行。故事和人物取自金庸的十几部小说，玩家从桃源城的客栈出发，足迹遍及少林、武当、峨嵋、华山、明教、星宿、逍遥、古墓、唐门等二十多个门派和扬州、杭州、苏州、长安、大理、泉州等六十来个区域。新手要亲历陈阿牛、史青山、林平之等一串背景事件；此外有渔夫、矿工、小偷、裁缝、铸造师等不能转换的职业，铸造师可以锻造带五行属性的兵器，玩家可以自建帮派并升格为门派、自创武功，还有结婚、保镖护卫、驿站马匹和仿六合彩的彩票。

## 内容亮点

- 起始地桃源城：关帝庙、客栈、当铺、马厩、枫林武馆、华清池澡堂、布庄、小贩，死后从鬼门关
  经地藏殿由判官送回阳间。
- 职业系统（`help career`）：渔夫出海、矿工开矿、小偷夜间行窃、裁缝修补衣物、铸造师锻造兵器，
  一旦选定不能更换。
- 兵器锻造（`help aboutforging`）：剑、刀、杖、鞭、枪五类，每类九种、可配十一种特性；玩家锻造出的
  兵器以独立文件保存在 `data/founding/`，档案里留下了一千多把当年玩家的作品。
- 玩家帮派（`help faction`）：`factions create/allied/hostile`，帮派够大可以升为门派。
- 背景事件（`help background`）：每个玩家都要经历的一串主线任务。
- `wllz` 频道原本是几个武林列传站点之间的跨站频道。

## 注册流程

`new` → 英文名（3–8 个字母）→ 中文名（可直接回车随机生成）→ 密码（须含大写、小写字母和其它字符，
例如 `Mud-123`）→ 再输一次 → 电子邮件 → OICQ 号码 → 性别（m/f）。建好之后用 `levelup <属性> <点数>`
分配 30 点属性（`help levelup`）。

## 关于源码

这份档案的发行版只带编译后的 MudOS `.b` 文件，大部分 `.c` 源码被抹掉。这里的源码树是从 9,365 个
`.b` 反编译还原的，并用游戏自带的原驱动逐个重新编译比对确认一致；仍然完整的原始源码保留原文。
还原工具在 `scripts/mudos_b/`，过程见 `NOTES.md`，`rebuild.sh` 可以从档案重做一遍。
