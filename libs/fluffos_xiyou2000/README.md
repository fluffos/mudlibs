# 西游记 2000 — fluffos_xiyou2000

## 游戏名称

**西游记**（"西游记之新纪元"，xiyouji.org，1996-2000 年代的经典老牌
MUD）。属于 **东方故事(ES) / 西游记引擎家族**，与本批次其他"西游记"
系列（如 `xiyouji2003`、`mhxy` 等，不在本批次内）同源。

## 简介

以《西游记》神话世界为背景的取经冒险 MUD。玩家扮演一名踏上西天取经
之路的江湖人物，起点是长安城的南城客栈，可以在游戏中习得各类西游
神话相关的武学、法术，游历天庭、地府、花果山等经典场景。是国内最早
一批以《西游记》为题材的经典 MUD 之一。

## 如何运行

```
cd libs/fluffos_xiyou2000
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务器监听端口：**40012**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40012 --timeout 30 --idle 1.5 \
  --send "gb" --send "no" --send "new" \
  --send "英文名字(3-8位纯小写字母)" --send "你的中文名字" \
  --send "密码" --send "确认密码" --send "邮箱" --send "m" \
  --send "9" --send "y" \
  --send "look" --send "score"
```

连接后会遇到几个容易让新玩家困惑的提示，请注意：

1. **编码选择**：提示中会看到一行显示为乱码的 BIG5 提示文字，这是
   历史遗留的正常现象，直接输入 **`gb`**（国标码）即可，普通中文
   系统都用这个。
2. **"您是否是中小学学生或年龄更小？(yes/no)"**：这是游戏内容本身的
   一道真实的年龄提示（并非账号/客户端版本校验），回答 `yes` 会被
   直接请出游戏（"好，赶紧去学习才是正道理"），**想要游玩请回答
   `no`**。
3. **注册新角色请输入 `new`**：普通登录提示写的是"您的英文名字：
   （新玩家请键入 new 注册）"，新玩家不要直接填自己想要的名字，而是
   先输入 `new`，之后才会让你另外取一个英文 ID。
4. 之后依次是：英文 ID（3-8 位纯小写字母）→ 中文名字 → 密码（至少 5
   位）→ 确认密码 → 邮箱 → 性别(m/f)。
5. **进入游戏前有一个"天赋分配"环节**：系统会展示体格/根骨/悟性/灵性
   四项初始数值，可以输入 `0`-`3` 调整某一项，满意后 **输入 `9`**
   接受当前设置，随后再输入 `y` 确认，才会正式把角色送入长安城的
   南城客栈。这一步是这个版本特有的，如果用脚本发送指令，记得给
   系统留出约 1 秒的心跳间隔（`--idle` 不要设得太小），否则天赋
   分配菜单可能来不及弹出就被跳过。

也可使用普通 telnet：`telnet 127.0.0.1 40012`，跟随提示手动输入即可。

## 已知问题

- 编码选择提示里那一行 BIG5 提示文字本身在源文件里就是乱码显示，
  纯属历史遗留的显示问题，不影响实际游玩（直接用 GB 即可）。
- 少数 lpcc 编译检查中发现的失败文件多为非必经路径的边角内容，不
  影响登录、创角与日常指令使用。
- **WASM 兼容性**：已在新的 WASM 构建下完整测试，包括编码选择/年龄
  提示/`new`关键字在内的完整注册流程、`look`、`quit` 均可正常完成。
  （曾发现并修复一处仅在 WASM 环境下触发的问题：站点镜像验证逻辑在
  DNS 相关模块因沙盒无网络而未能加载时会报错卡死连线，现已修复为
  "该验证模块不存在时直接跳过检查"，不影响原生环境下的行为。）
- **本地/回环连线不再受限**：封禁站点检查（含严格封禁）、无 IP/IP
  格式检查、按 IP 的多开人数上限、巫师登录站点白名单，现在都只对
  非本机（非 127.0.0.1）连线生效。
