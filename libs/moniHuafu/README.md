# 模拟华附 (moniHuafu)

作者"阿飞"/"Jjgod"（糊涂泥巴工作室），2000 年作品。以"华附"（华南
师范大学附属中学，广州知名中学）为原型，属于"风云3"引擎系列（与本项目
转换的 zzfy/fy2/fy2005/fengyun434 等同一底层引擎）。

## 内容亮点

- 这不是传统的武侠/仙侠泥巴，而是一款把中学校园生活搬进文字游戏的
  另类作品：新生要先上"军训课程"，之后拿到文具盒、运动鞋、校服作为
  初始装备。
- 属性名也换成了校园化的说法——"膂力""悟性""根骨""身法"，还有班级、
  社团、运动队、校园卡等系统，是这批归档里题材最特别的一个。
- `quit` 时会自动丢下初始的文具盒/运动鞋/校服，用同样的账号+密码重新
  连接即可读档回到原来的角色。
