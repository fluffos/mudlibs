# 模拟华附 (moniHuafu)

## 游戏名称

《模拟华附》("Simulated Huafu")，作者"阿飞"/"Jjgod"（糊涂泥巴工作室），
2000 年作品。以"华附"（华南师范大学附属中学，广州知名中学）为原型，属于
"风云3"引擎系列（与本项目转换的 zzfy/fy2/fy2005/fengyun434 等同一底层
引擎）。

## 简介

这不是传统的武侠/仙侠泥巴，而是一款把中学校园生活搬进文字游戏的另类作品：
新生要先上"军训课程"，之后拿到文具盒、运动鞋、校服作为初始装备，指标是
"膂力""悟性""根骨""身法"这类校园化的属性名，还有班级、社团、运动队、
校园卡等系统。整体氛围轻松、带点校园幽默，是这批归档里题材最特别的一个。

## 如何运行

```
cd libs/moniHuafu
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40051**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40051
```

登录流程比较直接，没有隐藏的编码/年龄前置问题：

1. 输入一个英文 ID（3-10 位小写字母）。
2. 确认创建新角色 (y/n)。
3. 输入真实的中文名字。
4. 设置密码（需大小写字母+数字组合），再输入一次确认。
5. 电子邮箱。
6. 选择性别 (m/f)。
7. 选择人物类型（0=聪明好学型 等，按提示输入编号）。

完成后会直接进入"模拟华附军训课程"这个新手教室，`look`、`score`、
`quit` 均已验证正常工作；`quit` 时会自动丢下初始的文具盒/运动鞋/校服。
用同样的账号+密码重新连接即可读档回到原来的角色。

## 已知问题

- 少量历史遗留的内部邮件/内网服务相关守护进程因缺少配套头文件而无法编译，
  但它们从未出现在预加载列表中，不影响正常登录和游戏。
- 有两个示例/模板性质的孤立文件（一个引用了并不存在的技能，一个调用了未
  实现的函数）不能编译，但没有任何地方引用它们，纯属历史遗留的废弃样例。
- 整体 lpcc 静态编译扫描通过率 98.7%，其余问题均已确认与正常登录、上课、
  校园游玩无关。
- WASM 版本可以正常启动，但目前无法完整体验：安全守护进程
  （securityd.lpc）在初始化时无条件调用了 DNS 解析函数 resolve()，而
  WASM 版驱动明确不支持真实 DNS 解析，导致第一次登录时的权限检查报错，
  卡在角色名提示之前。这是 WASM 驱动本身的已知限制，不是本库的 bug——
  同一段代码在原生（native）驱动下已反复验证可以完整走完注册流程。
