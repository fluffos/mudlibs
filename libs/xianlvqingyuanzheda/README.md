# 仙侣情缘·浙大版

## 游戏名称

**《仙侣情缘》"浙大版"（ZJU Fork）**，由 bugbug 与 alading 在"缥缈水云间"
站点基础上二次开发。属于"仙侣情缘/XLQY"引擎家族的一个独立分支（与本项目
另收录的《仙侣情缘》#38 版本代码不同，虽然核心引擎同源）。

## 简介

一个西游记题材的仙侠世界：你将扮演一名踏上取经之路的少年，在长安城的
南城客栈开始冒险，逐步领悟"道行境界""武学境界""法力修为"等修行体系。
整体基调偏神话/仙侠而非纯武侠，人物成长围绕"西天取经""大闹天宫"等
西游记经典桥段展开。

## 如何运行

```
cd libs/xianlvqingyuanzheda && ~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40033**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40033
```

或用任意 MUD 客户端 telnet 连接。注册流程有几个连续的"过滤"问题，
按顺序如实回答即可：

1. **编码选择**：`Select GB or BIG5 (gb/big5)` —— 简体/UTF-8 客户端选
   `gb`。
2. **"是否为中小学生"年龄限制问题**：只有明确回答 `no` 才会继续；回答
   其它任何内容（包括手滑输入了别的东西）都会被当作"是"，礼貌地结束
   连接——这不是故障，是站方刻意设置的门槛。
3. 英文ID：输入 `new` 开始注册流程，然后取一个 **3-8 位纯英文字母**
   的ID（不可以有数字）。
4. 确认新建角色后，取一个**中文名字**代表你的人物（往后不能修改）。
5. 设置密码（需两次输入确认）、填写邮箱、选择性别(m/f)。
6. 最后会进入"天赋分配"界面：体格/根骨/悟性/灵性四项属性，可以选
   `0-3` 挑一项重新设置数值，或直接输入 `9` 接受系统给出的默认天赋，
   再确认一次(y)即可正式进入游戏。

## 已知问题

- 游玩过程中偶尔会看到一行系统提示"你发现事情不大对了，但是又说不上
  来。"反复出现几次——这是站点内部的一个非致命提示，不影响注册、看
  房间(look)、查看属性(score)等正常操作，可以直接忽略。
- lpcc 编译扫描约98.4%通过，剩余缺口多为个别脚本的语法瑕疵，日常游玩
  基本碰不到。
- WASM 版本表现良好：开场画面、取中文名字等步骤均可正常进行，未发现
  阻塞性问题；原生（native）驱动下完整体验不受影响。
