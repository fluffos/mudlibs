# 天下 Beta

## 游戏名称

本游戏自称 **《天下》Beta**，作者署名"发现号（Find@tx）"，与本项目中的
"泥潭"（nitan）系列师出同门（同一作者），但代码库本身是完全独立的一套。

## 简介

一款正处于早期开发阶段的中文武侠 MUD（自我介绍即写着"正处于发展时期，
会有经常的更改和增添"）。新角色会先进行天赋点数自由分配（六项属性各有
上下限，可手动加减或交由系统随机分配），然后被"师傅"安排到"松竹小院"这
座清幽的院落中开始故事，由 NPC 书童递上入住手册，带有一点角色扮演的仪式
感。

## 如何运行

```
cd libs/tianxia && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40044**。请务必在 `libs/tianxia` 目录下启动。**注意**：驱动
自带一个 30 秒的启动保护期——启动日志出现 `Accepting telnet connections
on 0.0.0.0:40044.` 后，仍需再等待约 30 秒，过早连接会看到
"《天下》Beta正在启动过程中，请稍候再来。"并被断开，属于正常设计，稍等
片刻重连即可。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40044
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40044`。注册流程为：英文代号
→ 确认新建角色 → 中文姓名（**注意：不可以"唐"或"踏雪"开头**——游戏内有
一个"唐门"势力，这两个开头的姓名会被系统保留拒绝，换个姓氏即可）→ 密码
（两次）→ 性别 → 天赋点数分配（输入 0 交由系统随机产生）→ 确认天赋，全
部完成后即进入"松竹小院"这一起始场景。

## 已知问题

- lpcc 静态编译检查显示约 99.1% 的文件通过，未通过部分主要是巫师个人建
  设/测试目录下的孤立内容、旧式的邮件/网络中继守护进程（本环境未启用），
  以及两件武器/防具类型（"叉"和"面具"）缺少对应的基础类定义，涉及的物品
  和 NPC 极少，均不在注册与主线游玩路径上。
- 核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
  反复验证工作正常，且已确认游戏不会再把普通的程序编译"警告"误当作严重
  错误显示给玩家。技能查询指令（skills）也已确认工作正常。
- **WASM 版本兼容性**：在新的 WASM 构建下能正常启动（无严重的预加载错
  误），但由于本 lib 自带的 30 秒开机保护期与本测试工具"启动后立即建立
  连线"的机制冲突，测试工具在这个 harness 下暂时无法验证完整的登录流
  程；这不是 WASM 驱动的限制，也不是 mudlib 的缺陷（该保护期是游戏本身
  的正常设计，原生驱动下等待 30 秒后完全正常，如上所述）。
