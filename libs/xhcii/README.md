# 笑红尘Ⅱ (xhcii)

笑红尘Ⅱ由拓勘资讯组（topkan.com）开发，地图（华山、武当、峨嵋、丐帮、明教、大理、荆州等门派与城池）以及"世界之巅"跳崖场景（连 `out` 跳崖指令、`wizardp()` 免摔死判定都完全相同）几乎逐字与本项目的 `tybxjh`（该血统的源头版本）、`wlhd` 一致，属于同一支"天涯"家族的又一分支——这层关系还延伸到 `zxty`（再现天涯）、`ffxymud`（非凡夕阳MUD）、`jhfy2`（江湖风云2）、`xysylmhb`（夕阳三·炎龙美化版）、`xyzxiiylzymh`（夕阳再现II·炎龙专用美化客户端）等多部同源作品，此前的 AGENTS.md 里未记录这层完整关系。注册流程比 `tybxjh` 的双密码机制更简洁，只需单一密码加二次确认。

## 内容亮点

- 注册横幅文字里有一处历史遗留的字符集乱码（"也会渌婕乙桓龊玫镊
  印象"，大概率原意是"也会给其他玩家一个好的印象"），是内容/本地
  化问题，不影响游戏功能，本次未做改动。
- 深度功能测试（§10.7）发现并修复两个从未被记录过的严重 bug：一
  个让**每一次注册都会在性别选择后卡死**（之前被误判为 WASM 客户
  端计时竞态，实际是缺失的 `/log/login/` 目录导致注册流程被截
  断，新增 AGENTS.md §7.86），另一个让**全档案约 90 块留言板的
  `post` 指令全部立刻崩溃**（`inherit` 一个类之后又多余地对自己
  `replace_program()` 成同一个类，同一条 AGENTS.md §7.86），详见
  下方和 NOTES.md。

## 本次处理内容

WASM 修复阶段的结论过于乐观。深度功能测试（§10.7）修复了：

- `adm/daemons/logind.lpc` 的 2 处 printf 调试残留（与 `tybxjh` 逐
  字节相同）。
- §8.9 食物/饮水年龄检查错对象（`ob->query("age")` 应为
  `user->query("age")`）。
- **注册流程本身的致命 bug**：`get_gender()` 里一次没有保护的
  `log_file("login/newid.log", ...)` 调用，档案里根本没有
  `/log/login/` 这个目录，导致每一次注册在性别选择之后都会被无声
  截断——`init_new_player()`/`enter_world()` 从未执行，玩家的指令
  系统从未挂上去，之后任何输入都是"什么？"，角色也从未真正存盘。
  这正是此前 WASM 修复笔记里"计时竞态，无法稳定复现"那段描述的真
  正原因——不是客户端计时问题，是每次注册都 100% 命中的真实 bug。
  已创建 `log/login/` 目录并给这次 `log_file()` 调用加上 `catch()`
  防护。
- **约 90 处留言板文件里同一个多余的 `replace_program()` 自我替
  换**，导致 `post` 指令在任何留言板上都会立刻崩溃（`*cannot bind
  an lfun fp to an object with a pending replace_program()`）。既然
  这些文件已经 `inherit BULLETIN_BOARD`，编译期就拿到了全部留言板
  功能，运行时再自我替换成同一个类纯属多余且有害——已全部删除这行
  多余调用，保留 `inherit`。发现至少 4 份文件里这行代码早被前任巫
  师注释掉，大概率是各自独立踩过这个坑但没找到根因。

另外确认 `tybxjh` 发现的两个 bug 在这里**不适用**：这份档案是单一
密码注册（没有 `tybxjh` 那套双密码机制），源码里也确实没有对应的
明文密码泄漏（§7.84）；`score.lpc` 的进度条渲染用的是完全不同、正
确的循环式实现，没有 §7.85 那种残留宽度乘数问题。

唯一的账号播种动作：在 `/adm/etc/wizlist` 里加入管理员账号（原文
件是空的，`SECURITY_D` 正确指向 `/adm/daemons/securityd`，
`wiz_levels` 阶梯最高是 `(admin)`）。

顺带一提：注册横幅文字里有一句"也会渌婕乙桓龊玫镊印象"，看起来是
原始档案某次字符集转换出问题留下的乱码（大概率原意是"也会给其他
玩家一个好的印象"），这是内容/本地化问题，不是程序 bug，未做改
动。
