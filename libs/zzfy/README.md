# 郑州风云3

## 游戏名称

游戏登录后自报家门为 **"天下无敌"**（压缩包标题"郑州风云3"是收藏者对这个
具体服务器实例的称呼），属于 **风云（Fengyun）引擎系列**，与本项目里的
`fy2`/`fy2005`/`fengyun434`/`moniHuafu` 等同属一个大家族。

## 简介

游戏自我介绍是"一个以古龙小说为背景的泥巴游戏"——不同于大多数金庸题材的
武侠 MUD，本作走的是古龙风格的江湖路线，节奏明快，人物设定也偏古龙小说
那种潇洒不羁的气质。角色创建时还能选择"汉族/苗族/满族/蒙古族"四种民族
背景，算是这个引擎系列里比较有特色的一点。

## 如何运行

```
cd libs/zzfy
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40025**

## 如何连接游玩

```
telnet 127.0.0.1 40025
# 或
python3 scripts/mudclient.py 127.0.0.1 40025
```

注册流程：

1. 输入英文名字，系统会问"确定要创建新角色吗(y/n)"，回答 `y`。
   （注意：`new` 这个词本身是被禁止用作英文 ID 的保留字，不是什么触发
   注册的特殊命令——任何一个没被注册过的合法英文名，都会直接走到创建
   新角色的流程。）
2. 输入真实中文姓名。
3. 设置密码：**密码必须同时包含大写字母、小写字母，以及至少一个数字或
   符号，长度不少于 6 位**（例如 `Test1234`），否则会一直提示格式不对，
   这是这个服务端自带的强制规则。密码需要输入两次确认。
4. 输入邮箱地址。
5. 选择性别（`m`/`f`），再选择民族（`0`-`3`），随后就会正式进入游戏世界。

## 已知问题

少量周边剧情脚本（涉及个别故事/排行榜类的辅助系统）存在历史遗留的内容
缺失，不影响正常注册、探索、`look`/`score` 等基础玩法。角色创建成功后
偶尔能看到一行显示内部对象编号的调试信息，是原作者遗留的调试输出，无
实际影响。
