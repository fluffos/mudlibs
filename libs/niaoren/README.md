# 鳥人世界 (The Bird-Man World)

## 游戏名称

本游戏自称 **鳥人世界**（英文 THE BIRD-MAN WORLD），登录横幅标注底层为
`MudOS v22c2` / `MudOs V22pre11`。

## 简介

这是一个以金庸武侠小说（作者原话："这里的故事和情节，谜语的基本依据是
金庸的十五本小说"）为背景设定的繁体中文 MUD，玩家从"龙门客栈"起步，
在各大门派、城市间闯荡江湖，修习内功、外功与各类技能。整体是传统的
武侠 MUD 框架（属性、门派、师徒、帮派、排行），繁体中文界面，登录时
带有彩色 ASCII 艺术标题。

## 如何运行

```
cd libs/niaoren && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40100**。请在 `libs/niaoren` 目录下启动（保证日志正确写入
同目录 `log/debug.log`），看到 `Accepting telnet connections on
0.0.0.0:40100.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40100
```

或直接用支持 ANSI 颜色、繁体中文（BIG5 风格显示习惯，但游戏内部已是
UTF-8）的 MUD 客户端 telnet 连接 `127.0.0.1 40100`。

注册流程（注意顺序，与本项目其它 lib 不同——中文名在密码之前）：
1. 按任意键跳过开场横幅
2. 输入英文代号（纯英文字母，3-12 位）
3. 确认创建新角色（y/n）
4. 输入中文姓名（1 到 6 个中文字）
5. 设置密码（两次）
6. 是否接受随机分配的天赋属性（y/n）
7. 输入电子邮箱
8. 选择性别（m/f）

完成后角色会直接进入"龙门客栈"这一起始场景。

## 已知问题

- 少数房间/道具存在原始资料包自带的遗留问题：个别公告板/道具在创建时
  尝试进入一个资料包中并不存在的房间，会在后台报错但不影响其余场景。
- 少数管理员专用的内部工具（NPC/装备批量生成器）、以及依赖底层网络
  socket 功能的后台服务（如自建 mail/ident 相关守护进程）在当前驱动上
  无法使用，均为幕后管理工具或历史遗留的网络服务，普通玩家接触不到。
- 一部分武功/门派场景的 NPC 文本或房间尚有原始资料包自带的孤立小问题
  （多为个别文件的手误），不影响主线游玩体验。

核心的注册（含中文姓名）、登录、探索（look）、查看状态（score）、退出
存档流程，以及管理员账号登录与权限，均已在原生（native）驱动与 WASM
（浏览器）驱动两种模式下反复验证工作正常。
