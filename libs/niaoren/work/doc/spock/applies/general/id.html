id(4)　　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 id - 此函式被 present() 呼叫, 以鑑定一個物件的名稱.
　語法:
    　 int id( string an_id );

    　 整數 id( 字串 an_id );

　用法:
    　 present(3)　 外部函式 (efun) 呼叫 id() 以判斷一個指定的物件是否以字串 an_id　 為識別名稱 (id) . 如果 an_id　 是此物件的識別名稱之一, 就傳回 1, 不是則傳回 0.
　參考:
    　 present(3)
　翻譯:
