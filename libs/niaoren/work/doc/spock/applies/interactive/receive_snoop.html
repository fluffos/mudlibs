receive_snoop(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 receive_snoop - 抓住送進來的窺視 (snoop) 文字.
　語法:
    　 void receive_snoop( string message) ;

    　 無傳回值 receive_snoop( 字串 message );

　用法:
    　 如果驅動程式編譯時, 在 options.h　 中定義 RECEIVE_SNOOP, 則一個使用者窺視另一個使用者時, 所有窺視的文字會送給玩家物件中的 receive_snoop()　 函式. 在此函式中, 您可以處理這些文字. receive_snoop() 程式的內容, 通常把這些文字再送給 receive() 函式.
　參考:
    　 catch_tell(4), receive(3), receive_message(4)
　翻譯:
    　 Spock @ FF 97.Aug.5.　 (printed 3/16/95)
