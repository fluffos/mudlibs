logon(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 logon - 初始化 (initialize) 一個連線過程 (login connection).
　語法:
    　 object logon( void );

    　 物件 logon( 無參數 );

　用法:
    　 主宰物件 (master) 中的 connect() 函式傳回的物件會呼叫 logon(). 此函式將新的使用者設定好.
　參考:
    　 connect(4)
　翻譯:
    　 Spock @ FF 97.Aug.5.　 (printed 3/16/95)
