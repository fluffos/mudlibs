process_input(4) mudOS v21c2　 (5 Sep 1994)

　名稱:
    　 process_input - 讓 MudOS　 驅動程式將玩家正在輸入的文字送給玩家物件.
　語法:
    　 string process_input( string );

    　 字串 process_input( 字串 );

　用法:
    　 如果玩家物件中有 process_input(), 則 MudOS　 驅動程式則會將玩家所輸入的每行資料送給 process_input(). process_input() 使得像命令回溯 (command history)　 和防止 wizcuffs.　 process_input() 可以在分析 (parse) 命令前, 修改玩家輸入的資料. 如果 process_input() 傳回一個非零字串, 則此字串就代替玩家輸入的內容.
