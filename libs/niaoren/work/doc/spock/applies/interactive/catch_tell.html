catch_tell(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 catch_tell - 提供一個與使用者互動的介面 (interface).
　語法:
    　 void catch_tell( string message );

    　 無傳回值 catch_tell( 字串 message );

　用法:
    　 如果編譯驅動程式時, 於 options.h　 中定義了 INTERACTIVE_CATCH_TELL, 無論驅動程式對一個物件送出任何訊息 ( say(), shout(), tell_object()　 等等函式) , 都會呼叫 catch_tell() 處理這些訊息. 訊息可以依照需要經由 catch_tell() 顯示、丟棄、修改. catch_tell() 可以當作耳罩擋住某些訊息, 也可以用於訊息處理程式.
　參考:
    　 message(3), receive(3), receive_message(4)
　翻譯:
    　 Spock @ FF 97.Aug.5.　 (printed 3/16/95)
