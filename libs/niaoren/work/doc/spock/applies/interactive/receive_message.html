receive_message(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 receive_message - 提供 message() 外部函式 (efun) 的介面 (interface).
　語法:
    　 void receive_message( string class, string message );

    　 無傳回值 receive_message( 字串 class, 字串 message );

　用法:
    　 message() 這一類的外部函式呼叫在玩家物件中的 receive_message().　 參數 parameter　 通常用於指示訊息的種類 (說話 say, 傾訴 tell,　 表情 emote, 戰鬥 combat, 房間敘述 room description).　 receive_message()　 和 message() 的外部函式結合在一起, 可以提供一個「聰明的」訊息處理程式介面.
　參考:
    　 catch_tell(4), message(3), receive(3), receive_snoop(4)
　翻譯:
    　 Spock @ FF 97.Aug.5.　 (printed 3/16/95)
