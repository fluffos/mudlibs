terminal_type(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 terminal_type - 告知 mudlib 使用者的終端機型態 (terminal type).
　語法:
    　 void terminal_type( string term );

    　 無傳回值 terminal_type( 字串 term );

　用法:
    　 為使用者設定終端機型態時, 可互動的物件會呼叫此函式. 此型態與 telnet 交涉 (negotiation)　 時所報告的相同. 如果使用者端的程式沒有回應 (例如此程式不是 telnet), 則永遠不再呼叫此函式.
　翻譯:
