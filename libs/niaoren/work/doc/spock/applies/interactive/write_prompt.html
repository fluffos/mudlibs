write_prompt(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 write_prompt - 當命令分析器 (parser) 想顯示提示符號 (prompt)　 時, 就呼叫此函式.
　語法:
    　 void write_prompt( void );

    　 無傳回值 write_prompt( 無參數 );

　用法:
    　 如果在玩家物件中有 write_prompt(),　 則預設的提示符號該顯示時, 驅動程式將呼叫此函式. 當玩家正處於 input_to (輸入文字) 和 ed (編輯程式)　 狀態時, 驅動程式不會呼叫 write_prompt()
