view_errors(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 view_errors - 檢查一個使用者是否能看到錯誤訊息.
　語法:
    　 int view_errors( object user );

    　 整數 view_error( 物件 user );

　用法:
    　 如果編譯驅動程式時, options.h 中關閉了 MUDLIB_ERROR_HANDLER　 選項, 一旦使用者遇到了錯誤, 就會呼叫 view_errors( user ). 如果此函式傳回非零值, 則使用者就會收到一份詳細的錯誤訊息. 反之, 則會印出預設的錯誤訊息.　 (譯按: 通常是「程式發生錯誤, 請通知巫師. 」一類的訊息)
　參考:
    　 MUDLIB_ERROR_HANDLER(3)
