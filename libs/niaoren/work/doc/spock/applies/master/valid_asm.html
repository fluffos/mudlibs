valid_asm(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_asm - 控制 LPC->C 編譯的物件是否能使用 asm { }
　語法:
    　 int valid_asm( string file );

    　 整數 valid_asm( 字串 file );

　用法:
    　 編譯驅動程式時如果開啟 LPC_TO_C 選項, 則 LPC　 程式碼中一旦出現 asm { }　 結構就會呼叫 valid_asm()　 函式. 如果此函式傳回 0, 就中斷編譯過程並產生錯誤.

    　 asm { } 結構的用法如下:

    　 asm {
    　　 < C 程式碼 >
    　 }

    　 如此一來, 可以在 asm { } 之間插入 C　 程式碼.

　參考:
    　 valid_compile_to_c(4)
