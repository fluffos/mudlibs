retrieve_ed_setup(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 retrieve_ed_setup - 取得使用者的編輯程式設定 (setup) 或組態設定 (configuration settings).
　語法:
    　 int retrieve_ed_setup( object user );

    　 整數 retrieve_ed_setup( 物件 user );

　用法:
    　 ed()　 呼叫此函式, 以取得一個使用者的編輯程式設定／組態設定. 此函式應傳回設定值 (設定於一個整數中).
　參考:
    　 save_ed_setup(4)
　翻譯:
