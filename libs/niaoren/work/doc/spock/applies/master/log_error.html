log_error(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 log_error - 聰明地紀錄錯誤.
　語法:
    　 void log_error( string file, string message );

    　 無傳回值 log_error( 字串 file, 字串 message );

　用法:
    　 無論編譯程式 (compilation)　 時發生任何錯誤, 驅動程式都會以發生錯誤的檔案名稱為 file 參數、錯誤訊息為 message 參數, 呼叫主宰物件 (master object)　 中的 log_error() 函式. 呼叫此函式時, log_error() 可以做任何您認為應該做的資料紀錄. 通常 log_error()　 根據發生錯誤的檔案名稱, 決定該紀錄要寫入哪個錯誤訊息檔案中.
