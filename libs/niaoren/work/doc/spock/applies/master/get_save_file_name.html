get_save_file_name(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 get_save_file_name - 於使用者不正常斷線時, 備份其修改過的內容.
　語法:
    　 string get_save_file_name( string );

    　 字串 get_save_file_name( 字串 );

　用法:
    　 當一個玩家於編輯程式中編輯檔案時斷線的話, ed()　 函式會呼叫 get_save_file_name().　 此函式應傳回與原來檔案不同的名稱, 以免覆寫原來的檔案.
    　 注意:
    　 此函式以前名為 get_ed_buffer_save_file_name().
　參考:
    　 ed(3)
