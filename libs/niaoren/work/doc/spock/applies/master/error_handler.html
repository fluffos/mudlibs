error_handler(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 error_handler - 主宰物件處理錯誤的函式.
　語法:
    　 void error_handler( mapping error, int caught );

    　 無傳回值 error_handler( 映射 error, 整數 caught );

　用法:
    　 此函式讓 mudlib 代替驅動程式處理錯誤情形. 映射變數 error 的內容為:

    　 ([
    　　 "error"　　 : 字串,　　　　　　　 // 錯誤名稱
    　　 "program" : 字串,　　　　　　　 // 出錯的程式
    　　 "object"　 : 物件,　　　　　　　 // 目前的物件
    　　 "line"　　　 : 整數,　　　　　　　 // 錯誤出現在第幾行
    　　 "trace"　　 : 映射*　　　　　　　 // 追蹤回溯
    　 ])

    　 追蹤回溯的每一行都是映射, 包含以下資料:

    　 ([
    　　 "function"　 : 字串,　　　　　　　 // 函式名稱
    　　 "program"　　 : 字串,　　　　　　　 // 程式
    　　 "object"　　　 : 物件,　　　　　　　 // 物件
    　　 "file"　　　　　 : 字串,　　　　　　　 // 行數所在的檔案名稱
    　　 "line"　　　　　 : 整數　　　　　　　　 // 行數
    　 ])

    　 如果錯誤被 catch() 函式抓到, caught 旗標 (flag) 為 1.

　參考:
    　 catch(3), error(3), throw(3), log_error(4)
