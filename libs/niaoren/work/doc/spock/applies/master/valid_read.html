valid_read(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_read - 檢查一個人是否有權限讀取一個檔案.
　語法:
    　 int valid_read( string file, mixed user, string func );

    　 整數 valid_read( 字串 file, 混合 user, 字串 func );

　用法:
    　 每次當一個使用者嘗試讀取檔案時, 驅動程式會呼叫主宰物件的 valid_read() 以檢查此人的讀取權限. 此函式的參數 file　 為檔案名稱, user　 為嘗試讀取此檔的人名, func 為造成呼叫 valid_read() 的函式名稱. 如果 valid_read() 傳回非零值, 則准許讀取.
　參考:
    　 valid_write(4)
　翻譯:
    　 Spock @ FF 97.Aug.7.　 (printed 3/16/95)
