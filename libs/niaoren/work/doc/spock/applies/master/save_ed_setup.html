save_ed_setup(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 save_ed_setup - 儲存一個使用者的編輯程式設定或組態設定.
　語法:
    　 int save_ed_setup( object user, int config );

    　 整數 save_ed_setup( 物件 user, 整數 config );

　用法:
    　 ed()　 呼叫此函式以儲存一個使用者的編輯程式設定／組態設定 (存於一個整數中). 儲存成功時, 此函式應傳回 1　 或「真」值 (譯按: 即非零值). 反之則傳回 0　 或「偽」值 (譯按: 即零值).
　參考:
    　 retrieve_ed_setup(4)
　翻譯:
    　 Spock @ FF 97.Aug.5.　 (printed 3/16/95)
