valid_shadow(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_shadow - 控制哪些物件可以作為投影 (shadow).
　語法:
    　 int valid_shadow( object ob );

    　 整數 valid_shadow( 物件 ob );

　用法:
    　 當一個物件嘗試作為 ob 的投影時 (使用 shadow() 外部函式 (efun) ) , 會呼叫主宰物件中的 valid_shadow() 函式. 物件 ob 為此函式的參數, ob　 是 previous_object()　 嘗試投影的物件. 如果不准投影 ob, valid_shadow() 應傳回 0 , 導致 shadow() 的呼叫失敗並傳回 0. 如果 valid_shadow()　 傳回 1, 則投影成功.
　參考:
    　 shadow(3), query_shadowing(3)
　翻譯:
    　 Spock @ FF 97.Aug.7.　 (printed 3/16/95)
