valid_write(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_write - 檢查一個人是否有權限寫入一個檔案.
　語法:
    　 int valid_write( string file, mixed user, string func );

    　 整數 valid_write( 字串 file, 混合 user, 字串 func );

　用法:
    　 每次當一個使用者嘗試寫入檔案時, 驅動程式會呼叫主宰物
    　 件的 valid_write()　 以檢查此人的寫入權限. 此函式的參
    　 數 file 為檔案名稱, user　 為嘗試寫入此檔的人名, func
    　 為造成呼叫 valid_write()　 的函式名稱. 如果
    　 valid_write() 傳回非零值, 則准許寫入.
　參考:
    　 valid_read(4)
　翻譯:
    　 Spock @ FF 97.Aug.7.　 (printed 3/16/95)
