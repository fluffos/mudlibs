valid_save_binary(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_save_binary - 控制一個物件是否可以儲存它的程式碼.
　語法:
    　 int valid_save_binary( string file );

    　 整數 valid_save_binary( 字串 file );

　用法:
    　 驅動程式編譯時, 如果定義了 ALWAYS_SAVE_BINARIES; 或是一個物件中定義了 #pragma save_binary,　 就會以檔案名稱 作為參數呼叫 valid_save_binary().　 如果此函式傳回 1, 則准許儲存. 反之就不准儲存.
