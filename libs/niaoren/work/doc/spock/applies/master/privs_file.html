privs_file(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 privs_file - 為新創造的物件指定一個私有字串 (privs string).
　語法:
    　 string privs_file( string filename );

    　 字串 privs_file( 字串 filename );

　用法:
    　 當新檔案創造出來時, 會呼叫主宰物件 (master object) 中的 privs_file() 函式. 物件的檔案名稱為其參數, 而
    　 privs_file()　 傳回的字串就用作此新物件的私有字串.

    　 只有在驅動程式編譯時定義 PRIVS　 選項, privs_file() 才有作用.

　參考:
    　 query_privs(3), set_privs(3)
　翻譯:
    　 Spock @ FF 97.Aug.6.　 (printed 3/16/95)
