valid_seteuid(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_seteuid - 保障使用 seteuid(3) 的系統安全.
　語法:
    　 int valid_seteuid( object obj, string euid );

    　 整數 valid_seteuid( 物件 obj, 字串 euid );

　用法:
    　 在 seteuid( euid ) 函式裡面, 驅動程式呼叫主宰物件 (master object)　 中的 valid_seteuid( ob, euid ) 函式. 如果 valid_seteuid() 傳回 0, 則 seteuid(3) 失敗. 如果 valid_seteuid() 傳回 1, 則 seteuid(3) 成功.
　參考:
    　 seteuid(3), geteuid(3), getuid(3), export_uid(3)
　翻譯:
    　 Spock @ FF 97.Aug.7.　 (printed 3/16/95)
