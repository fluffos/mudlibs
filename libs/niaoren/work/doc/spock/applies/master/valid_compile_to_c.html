valid_compile_to_c(4) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_compile_to_c - 控制一個物件在執行時段 (runtime) 中, 是否可以由 LPC->C 的方式編譯 (compile).
　語法:
    　 int valid_compile_to_c( string file );

    　 整數 valid_compile_to_c( 字串 file );

　用法:
    　 當驅動程式編譯時, 如果定義了 LPC_TO_C 和 RUNTIME_LOADING,　 則載入以「.C」結尾的程式 (不是「.c」) 時, 將呼叫主宰物件 (master object)　 的 valid_compile_to_c() 函式. 如果此函式傳回 1, 此程式就編譯為 C　 程式. 如果傳回 0 , 則編譯為普通的 LPC　 物件. 參數中的檔案名稱包括結尾的「.C」.
　翻譯:
