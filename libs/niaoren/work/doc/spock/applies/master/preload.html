preload(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 preload - 將一個物件預先載入記憶體.
　語法:
    　 string *epilog( int load_empty );
    　 void preload( string filename );

    　 字串 *epilog( 整數 load_empty );
    　 無傳回值 preload( 字串 filename );

　用法:
    　 驅動程式於載入主宰物件 (master object)　 之後, 會呼叫 epilog()　 函式. mudlib　 通常用 epilog() 初始化主宰物件的資料結構 (例如系統安全表等等). epilog() 應傳回一個檔案名稱的陣列, 此陣列的內容為啟動遊戲前, mudlib 預先想載入的物件表. 也就是說, 這些是玩家連線之前必須載入的檔案. 對於陣列中的每一個檔案名稱, 驅動程式都會為它呼叫主宰物件中的 preload( filename ).

    　 如果啟動驅動程式時加上 -e 的選項, load_empty　 參數就是非零值. 這個參數可以給 mudlib 一個信號, 決定要不要載入某些檔案, 例如城堡等等.
