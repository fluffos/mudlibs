crash(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 crash - 當驅動程式異常終止 (crash) 時, 就呼叫主宰物件 (master.c)　 中的此函式.
　語法:
    　 void crash( string crash_message, object command_giver, object current_object );

    　 無傳回值 crash( 字串 crash_message, 物件 command_giver, 物件 current_object );

　用法:
    　 當驅動程式異常終止 (crash)　 時 (節段錯誤 segmentation fault,　 匯流排錯誤 bus error　 等等嚴重的錯誤. 譯按: 最常見的原因是用 kill 指令終止驅動程式執行, 包括主機重新開機的情形. 至於一些原因不明的錯誤, 也是常有的事), 驅動程式此時會呼叫主宰物件的 crash()　 函式. crash() 讓 mudlib 可以在驅動程式終止之前將玩家和其他重要資料儲存起來. crash() 也可以讓你紀錄一些有用的資料, 像是驅動程式如何終止的信號 (signal) 、正執行哪些物件、當時有哪些玩家等等.
　參考:
    　 slow_shutdown(4), shutdown(3)
　翻譯:
    　 Spock @ FF 97.Aug.6.　 (printed 3/16/95)
