valid_object(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_object - 控制是否載入某個物件.
　語法:
    　 int valid_object( object obj );

    　 整數 valid_object( 物件 obj );

　用法:
    　 載入一個物件之後, 驅動程式會以新創造的此物件為參數, 呼叫主宰物件 (master object)　 的 valid_object(). 如果 valid_object() 存在, 並傳回 0, 則會摧毀此物件並使載入物件的外部函式 (efun) 產生錯誤輸出. 如果此函式不存在或是傳回 1, 則載入物件的過程就跟平常一樣. 在模擬外部函式 (simul_efun) 中使用 nomask 和 inherit() 外部函式, 再與 valid_object() 併用的話, 可以安全限制 destruct() 函式.
　參考:
    　 valid_override(4)
