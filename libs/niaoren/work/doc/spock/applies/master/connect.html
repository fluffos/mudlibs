connect(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 connect - 為新的使用者取得一個物件.
　語法:
    　 object connect( void );

    　 物件 connect( 無參數 );

　用法:
    　 當一個新使用者與驅動程式連線時, 驅動程式會呼叫主宰物件 (master object) 中的 connect(). connect() 傳回的物件, 其作用在於當作初始使用者物件 (initial user object). 請注意, 可以使用 exec(3)　 函式將使用者連線的物件從初始使用者物件轉換到其他的物件上.
　參考:
    　 exec(3), logon(4)
　翻譯:
    　 Spock @ FF 97.Aug.6.　 (printed 3/16/95)
