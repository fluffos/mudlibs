object_name(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 object_name - 驅動程式呼叫此函式以知曉一個物件的名稱.
　語法:
    　 string object_name( object );

    　 字串 object_name( 物件 );

　用法:
    　 當 sprintf(3) 函式要印出一個物件的「值」時, 會呼叫此函式. 此函式應傳回一個字串, 此字串對應於物件 object 的名稱 (如一個使用者的名稱).
　參考:
    　 file_name(3)
　翻譯:
    　 Spock @ FF 97.Aug.6.　 (printed 3/16/95)
