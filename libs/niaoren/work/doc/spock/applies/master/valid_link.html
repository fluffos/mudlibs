valid_link(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 valid_link - 控制使用 link(3) 函式的情形.
　語法:
    　 int valid_link( string from, string to );

    　 整數 valid_link( 字串 from, 字串 to );

　用法:
    　 在 link( from, to ) 外部函式 (efun) 中, 會呼叫主宰物件 (master object) 裡面的 valid_link( from, to ) 函式. 如果 valid_link() 傳回 0, 則 link() 的動作失敗. 如果傳回 1, 還需要以同樣的參數呼叫 rename() 成功, 此次的 link()　 才算完成.
　參考:
    　 link(3)
　翻譯:
    　 Spock @ FF 97.Aug.7.　 (printed 3/16/95)
