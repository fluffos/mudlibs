get_root_uid(4)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 get_root_uid - 取得 root 使用者識別名稱.
　語法:
    　 string get_root_uid( void );

    　 字串 get_root_uid( 無參數 );

　用法:
    　 驅動程式每次載入主宰物件 (master object)　 時, 會呼叫此函式以檢驗主宰物件是否已經載入了, 並取得該 mud　 所自行定義的 root 使用者識別名稱. 此函式必須傳回一個字串, 譬如 ROOT 定義的字串.
　參考:
    　 get_bb_uid(4)
　翻譯:
    　 Spock @ FF 97.Aug.6.　 (printed 3/16/95)
