LPC 的 while 迴圈:

LPC 的 while　 迴圈與 C　 提供的相同. 語法如下:

    while (運算式)
      敘述;
敘述可以換成一段用 {} 大括號圍起來的程式. 舉例如下:
    while (運算式) {
      敘述一;
      敘述二;
    }
只要運算式得到的結果為非零值 (non-zero),　 就會重覆執行 while　 迴圈裡面的敘述. 如果在執行一次迴圈週期之前, 運算式得到零, 就不會執行裡面的敘述. 在迴圈中如果有 break; 敘述, 則此 while　 迴圈終止 (跳過所有尚未執行的敘述). 迴圈裡面如果有 continue;　 敘述, 則會從頭開始執行迴圈 (跳過此週期中還未執行的敘述).
　
    int test(int limit)
    {
      total = 0;
      j = 0;
      while (j < limit) {
        if ((j % 2) != 0)
          　continue;
        total += j;
        j++;
      }
      return total;
    }
此段程式碼的結果, 是把 0　 到 limit - 1　 之間的偶數全部加起來.
