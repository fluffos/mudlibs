* LPC 的 for 迴圈 :

LPC 的 for 迴圈與 C 提供的相同. 語法如下:

    for ( 運算式 0; 運算式 1; 運算式 2 ) {
      敘述;
      ...;
    }
執行迴圈之前, 會先計算「運算式 0」. 每次迴圈週期開始時, 計算「運算式 1」. 如果「運算式 1」計算的結果得到 0, 則迴圈停止. 「計算式 2」則於每次迴圈週期結束時計算之.

迴圈裡面的 break 會讓迴圈停止. continue 則會跳過此次迴圈週期剩餘的部分, 從下一個週期開始 (會先計算「運算式 2」).

典型的 for 迴圈, 用以固定的次數重覆執行一段迴圈中的敘述.

範例:

    int i;
    for (i = 0; i < 10; i++) {
      write("i == " + i + "\n");
      write("10 - i == " + (10 - i) + "\n");
    }
