* LPC 的函式 (function 或稱之為 method) :

LPC 的函式與 C 提供的相似, 但是有些差異 (與 ANSI C 提供的最為相似).
語法如下:

    傳回值的型態 函式名稱( 參數一的型態 參數一, 參數二的型態 參數二, ... )
    {
      宣告變數;
      ...;

      程式敘述;
      ...;

      return 傳回值變數;
    }
請注意, 「傳回值變數」必須符合傳回值的型態.

如果函式不必傳回一個值, 則宣告傳回值型態為 void (無傳回值). 舉例來說:

    void 函式名稱( 參數一的型態 參數一, ... )
    {
      敘述;
      ...;
    }
下面此行呼叫上面的函式:
    函式名稱( 參數一, 參數二, 參數三, ... );
您可以呼叫其他物件中的函式, 方法如下:
    物件->函式名稱( 參數一, 參數二, 參數三, ... );
或是:
    call_other( 物件, 函式名稱, 參數一, 參數二, ... );
