map(3)　　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 map() - 經過一個函式修改一個映射變數、陣列或字串.
　語法:
    　 mapping map( mapping | mixed* | string x, string fun, object ob, mixed extra, ... );
    　 mapping map( mapping | mixed* | string x, function f, mixed extra, ... );

    　 映射 map( 映射 或 混合* 或 字串 x, 字串 fun, 物件 ob, 混合 extra, ... );

    　 映射 map( 映射 或 混合* 或 字串 x, 函式指標 f, 混合 extra, ... );

　用法:
    　 如果第一個參數是一個映射變數, map() 的做法與 map_mapping() 相似. 如果是一個陣列, map() 的做法就像 map_array() . 如果是一個字串, 則 map()　 會把字串中的每一個字元 (character)　 以整數的型態傳入函式, 而且以函式傳回的非零整數值替換原來的字元.
　參考:
    　 filter_array(3), sort_array(3), map_array(3), map_mapping(3)
　翻譯:
    　 Spock @ FF 97.Feb.18.　 (printed 3/16/95)
