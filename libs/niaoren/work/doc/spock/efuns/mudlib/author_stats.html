author_stats(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 author_stats() - 傳回作者的一些統計資料.
    　 domain_stats() - 傳回區域的一些統計資料.
　語法:
    　 mapping author_stats( string domain | void );
    　 mapping domain_stats( string domain | void );

    　 映射 author_stats( 字串 domain 或 void );
    　 映射 domain_stats( 字串 domain 或 void );

　用法:
    　 author_stats() 和 domain_stats()　 都會傳回一個儲存在映射變數的資料. 如果沒有加上參數 (argument) , 就會傳回所有作者 (或所有區域) 每個人 (或每個區域) 的映射資料. 每份映射資料包含有: 移動數 (moves), 耗費時間數 (cost), 錯誤數 (errors),　 心跳數 (heart_beats), 價值數 (worth), 陣列數 (array_size),　 和 物件數 (objects). 每一項都是包含在傳回的映射變數中的整數值. 移動數是在指定作者 (或區域) 中, 物件被移動到另一物件中的多寡. 耗費數是所有在指定作者 (或區域) 裡的物件所耗費的計算數目 (eval_cost). 錯誤數是在指定作者 (或區域) 中物件總共發生的系統錯誤多寡. 心跳數是在指定作者 (或區域) 中, 所有物件呼叫 heartbeat　 的次數. 價值數則是使用 add_worth(3)　 函數的情形 (這項數值常常用來追蹤指定巫師作者所流出和流入的金錢數目) . 陣列數是指定區域中陣列所配置的記憶體位元數. 物件數是指定區域中被創造出來的物件總數. 當這兩個函數被呼叫時, 如果沒有指定參數, 傳回的映射就會像這樣:
    　
      　 ([ domain0 : info0, domain1 : info1, ... ])
    　 而 info0 的內容格式是:
    　
      　 ([ "moves" : moves, "cost" : cost, "errors" : errors, "heart_beats" : heart_beats, "worth" : worth, "array_size" : array_size, "objects" : objects ])
    　 有指定參數時, 就會傳回像 info0 的格式.
　參考:
    　 domain_file(4), author_file(4), set_author(3)
