query_privs(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 query_privs() - 傳回一個物件的私有字串 (privs string).
　語法:
    　 string query_privs( object ob );

    　 字串 query_privs( 物件 ob );

　用法:
    　 傳回一個物件的私有字串. 此私有字串由主宰物件 (master object) 於編譯程式時, privs_file()　 函式決定. 而此字串可由 set_privs()　 函式更改.

    　 query_privs() 只有在驅動程式 (driver) 編譯時, 定義 PRIVS 才有效.

　參考:
    　 privs_file(4), set_privs(3)
　翻譯:
