replace_program(3) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 replace_program() - 把 this_object() (目前這個物件) 的程式置換掉.
　語法:
    　 void replace_program( string str );

    　 無傳回值 replace_program( 字串 str );

　用法:
    　 replace_program() 會把 this_object()　 替換成這個物件繼承的物件. 字串 str　 是要進行置換的檔案名稱. 物件進行置換之後, 目前的物件就相當於繼承物件的複製品. 只是保留目前物件的檔案名稱和全域變數 (global variable) 不變. 在目前的物件程式執行完畢以前, 不會進行置換的動作.
　參考:
    　 clone_object(3), new(3)
　翻譯:
    　 Spock @ FF 97.May.27.　 (printed 3/16/95)
