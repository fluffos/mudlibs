reclaim_objects(3) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 reclaim_objects - 清除殘留在記憶體中的物件.
　語法:
    　 int reclaim_objects( void );

    　 整數 reclaim_objects( 無參數 );

　用法:
    　 這個函式重複檢查每一個載入的物件, 並盡力把殘留在記憶體中的物件清除掉. 這樣可以清出一些記憶體, 清理的數量多寡要看　 mud 本身的程式是如何寫的. 如果一個物件被其他物件裡面的全域變數 (global variable)指標 (pointer)　 指向到, 就會殘留在記憶體中, 然後再被摧毀掉. 這個外部函式 (efun)　 會傳回變數遇到的被摧毀的物件數目.
　參考:
    　 destruct(3)
　翻譯:
