set_eval_limit(3) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 set_eval_limit() - 設定執行耗費時間 (evaluation cost) 的上限值.
　語法:
    　 void set_eval_limit( int );

    　 無傳回值 set_eval_limit( 整數 );

　用法:
    　 以一個非零值的參數指定給 set_eval_limit() 函式, 則設定任何一個執行緒 (thread) 在發生錯誤之前所允許的最高執行耗費時間. 如果參數為 0, 則將目前的執行耗費時間計數器 (counter) 歸零, 並傳回目前執行耗費時間的上限值. set_eval_limit(-1) 傳回剩下的執行耗費時間.
　參考:
    　 catch(3), error(3), throw(3), error_handler(4), eval_cost(3)
