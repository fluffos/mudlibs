all_previous_objects(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 all_previous_objects() - 傳回所有呼叫目前函式的物件陣列.
　語法:
    　 object *all_previous_objects();
　用法:
    　 傳回一個所有呼叫目前函式的物件陣列 (an array of object). 注意, 區域函式 (local function) 的呼叫不會更動目前的物件 (current object) previous_object()　 的內容.
　參考:
    　 call_other(3), call_out(3), origin(3), previous_object(3)
　翻譯:
    　 Spock @ FF 96.Oct.12.　　 (printed 3/16/95)
