inherits(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 inherits() - 判斷一個物件是否繼承一個指定的檔案
　語法:
    　 int inherits( string file, object obj );

    　 整數 inherits( 字串 file, 物件 obj );

　用法:
    　 如果 obj 不是繼承 file, inherits() 傳回 0. 如果 obj 繼承最新複製的 file 則傳回 1, 如果繼承舊的複製的 file 則傳回 2.
　參考:
    　 deep_inherit_list(3), inherit_list(3)
　翻譯:
