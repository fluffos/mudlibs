find_call_out　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 find_call_out() - 找到行程中下一個會被呼叫的點召 (call out)
　語法:
    　 int find_call_out( string func ):

    　 整數 find_call_out( 字串 func );

　用法:
    　 因為執行函式 func 而找到第一個點召 (call out), 並傳回剩下的時間. 如果無法找到則傳回 -1.
　參考:
    　 call_out(3), remove_call_out(3), set_heart_beat(3)
　翻譯:
    　 Spock @ FF 97.Feb.12.　 (printed 3/16/95)
