read_buffer(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 read_buffer() - 以緩衝區資料 (buffer) 的型態傳回檔案的內容, 或是以字串型態 (string) 傳回緩衝區一部份的資料.
　語法:
    　 string | buffer read_buffer( string | buffer src, int start,　 int len );

    　 字串 或 緩衝區 read_buffer( 字串 或 緩衝區 src, 整數 start, 整數 len );

　用法:
    　 如果 src　 是一個字串 (檔案名稱) , 就會從 start　 指定的第幾位元組 (byte) 開始, 讀取 len　 指定長度的檔案內容. 讀取的內 容以緩衝區的資料型態傳回. 如果不指定 start 和 len , 則會讀取整個檔案的內容.

    　 如果 src　 是一個緩衝區, 就從 start　 指定的第幾位元開始讀取 len 長度的內容. 然後以字串的型態傳回.

    　 請注意, 你可以從一個檔案讀進緩衝區的資料, 受到編譯時段組態檔案 (runtime config file)　 中定義的 maximum byte transfer (最大位元組傳輸量) 控制.

　參考:
    　 write_buffer(3), allocate_buffer(3), bufferp(3), read_bytes(3), write_bytes(3)
