write_buffer(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 write_buffer() - 將一個暫存區 (buffer) 寫入一個檔案, 或從某個資料來源讀進一個暫存區.
　語法:
    　 int write_buffer( string | buffer dest, int start, mixed source );

    　 整數 write_buffer( 字串 或 暫存區 dest, 整數 start, 混合 source );

　用法:
    　 如果 dest 是一個檔案, 則 source 必須為一個整數 (並以 network-byte-order　 寫入檔案) 、一個暫存區、或一個字串, 而從檔案 dest 的第 start　 位元組開始寫入 source 的內容.

    　 如果 dest 是一個暫存區, 則 source 會從第 start　 位元組開始寫入暫存區. 如果 source 是整數, 則會以 network-byte-order　 的格式寫入.

　參考:
    　 read_buffer(3), allocate_buffer(3)
