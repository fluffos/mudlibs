destruct(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 destruct() - 從遊戲中銷毀一個物件.
　語法:
    　 void destruct( object ob );

    　 無傳回值 destruct( 物件 ob );

　用法:
    　 完全摧毀物件 ob. 在呼叫 destruct() 之後, 會清除所有的全域變數 (global variables), 只剩下區域變數和參數. 如果 ob 是 this_object() , 此函式仍會執行, 但是最好立刻傳回一個數值.
　參考:
    　 clone_object(3), new(3), destruct_env_of(4), move(4)
　翻譯:
    　 Spock @ FF 97.Feb.04.　 (printed 3/16/95)
