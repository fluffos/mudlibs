load_object(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 load_object() - 以檔案名稱來尋找或載入一個物件
　語法:
    　 object load_object( string str );

    　 物件 load_object( 字串 str );

　用法:
    　 用檔案名稱 str　 尋找物件. 如果檔案存在而且物件尚未載入, 則載入檔案. 否則此函式就傳回 0.
　參考:
    　 file_name(3), stat(3), find_object(3)
