objects(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 objects - 傳回一個已載入之物件的陣列 (array).
　語法:
    　 object *objects( string func, object ob );
    　 object *objects( function f );

    　 物件 *objects( 字串 func, 物件 ob );
    　 物件 *objects( 函式指標 f );

　用法:
    　 objects() 傳回 mud　 裡已經載入之物件的陣列. 請注意, 如果系統設定的最大陣列長度 (maximum array size)太低, objects() 傳回的陣列內容會中斷在最大長度的地方. 這樣一來, objects() 也就沒有什麼用處.

    　 如果指定了 func 和 ob 兩個參數, 則會呼叫 ob->func(), 並以所有已經載入的物件作為 func() 的參數. 如果函式傳回非零值, 此物件就會被 objects()　 傳回來. 如果是零則不會.

    　 如果指定 f, 所有已載入的物件都會呼叫函式指標 f. 例如: objects( (: clonep :) ) 會傳回現存全部的複製物件的列表.

　參考:
    　 livings(3), users(3)
