map_array(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 map_array() - 經由一個函式修改一個陣列的元素 (element)
　語法:
    　 mixed *map_array( mixed *arr, string fun, object ob, mixed extra, ... );
    　 mixed *map_array( mixed *arr, function f, mixed extra, ... );

    　 混合 *map_array( 混合 *arr, 字串 fun, 物件 ob, 混合 extra, ... );
    　 混合 *map_array( 混合 *arr, 函式指標 f, 混合 extra, ... );

　用法:
    　 經由 ob->fun()　 或 f　 處理每一個 arr　 中的元素之後, 傳回一個新的陣列. 每一個 arr　 中的元素會當成指定函式的參數並呼叫一次指定的函式. 參數 extra　 會在每次呼叫函式時當成第二個以後的參數. 原則上函式的運作如下:

    　 foreach (index) arr[index] = ob->fun(arr[index],extra);

    　 ob->fun( arr[.index.], extra ) 傳回的值會替換掉陣列中的元素. 如果 arr 不是一個陣列, 則 map_array()　 傳回 0.

　參考:
    　 filter_array(3), sort_array(3), map(3)
