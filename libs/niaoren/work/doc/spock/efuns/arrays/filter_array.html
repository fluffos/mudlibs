filter_array(3)　　　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 filter_array() - 傳回一個過濾舊陣列內容的新陣列.
　語法:
    　 mixed *filter_array( mixed *arr, string fun, object ob, mixed extra, ... );
    　 mixed *filter_array( mixed *arr, function f, mixed extra, ... );

    　 混合 *filter_array( 混合 *arr, 字串 fun, 物件 ob, 混合 extra, ... );
    　 混合 *filter_array( 混合 *arr, 函式 f, 混合 extra, ... );

　用法:
    　 filter_array()　 傳回一個陣列, 這個陣列裡保留 arr 經過物件 ob 中的函式 fun　 過濾之後的結果. 每一個在陣列 arr 中的元素 (element)　 會呼叫函式 fun　 一次, 並且當成 fun 的參數 (parameter). 如果指定參數 extra　 與之後的參數, 則在每一次呼叫函式 fun　 時當成第二、第三個參數....一個物件在 fun　 傳回 1　 之後, 才視為成功地通過 fun　 的過濾 (之後物件也包含在傳回的陣列中) . 在第二種語法中, 如果指定的參數是函式 f, 就與第一種語法中的 ob->fun()　 的用法相同. 如果 arr　 不是一個陣列, filter_array()　 傳回 0.
　參考:
    　 sort_array(3), map_array(3)
　翻譯:
    　 Spock @ FF 97.Feb.12.　 (printed 3/16/95)
