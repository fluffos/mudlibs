query_load_average(3) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 query_load_average()　 - 報告 mud 的系統平均負載量 (load average).
　語法:
    　 string query_load_average( void );

    　 字串 query_load_average( 無參數 );

　用法:
    　 這個函式傳回一個字串, 報告兩個統計數字:
      　 (1) 平均每秒鐘的使用者命令數量.
      　 (2) 平均每秒鐘編譯的程式行數.
　參考:
    　 rusage(3)
　翻譯:
    　 Spock @ FF 97.May.1.　 (printed 3/16/95)
