mud_status(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 mud_status() -　 報告一些驅動程式 (driver) 及 mud 函式庫 (mudlib)　 的統計數字.
　語法:
    　 void mud_status( int extra );

    　 無傳回值 mud_status( 整數 extra );

　用法:
    　 這個函式把一些驅動程式及 mud　 函式庫的統計數字顯示在呼叫這個函式的人的螢幕上. 如果參數 extra　 為非零值, 則會顯示更多的附加資料. 這個函式取代了 vanilla 3.1.2 版本中的 status 及 status tables 指令.
　參考:
    　 debug_info(3), dumpallobj(3), memory_info(3), uptime(3)
　翻譯:
    　 Spock @ FF 97.Apr.15.　 (printed 3/16/95)
