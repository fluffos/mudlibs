get_config(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 get_config() - 詢問一些驅動程式 (driver) 的系統設定值 (config settings)
　語法:
    　 string | int get_config( int );

    　 字串 或 整數 get_config( 整數 );

　用法:
    　 這個外部函式 (efun) 用來詢問一些驅動程式的系統設定值. 請參考 runtime_config.h 以了解目前有哪些可以使用的選擇項目.
　參考:
    　 /include/runtime_config.h
　翻譯:
    　 Spock @ FF 97.Feb.14.　 (printed 3/16/95)
