dumpallobj(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 dumpallobj() - 報告所有載入之物件的一些統計資料.
　語法:
    　 void dumpallobj( string | void );

    　 無傳回值 dumpallobj( 字串 或 無參數 );

　用法:
    　 這個函數會印出所有已經載入之物件列表. 如果沒有指定參數, 這些資訊會傾印在 /OBJ_DUMP　 這個檔案裡. 如果有指定參數, 則參數就是指定要輸出的檔案名稱.
　參考:
    　 mud_status(3), debug_info(3)
    　
　翻譯:
