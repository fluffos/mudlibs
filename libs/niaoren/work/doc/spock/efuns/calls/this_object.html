this_object(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 this_object() - 傳回呼叫此函式物件的物件指標 (object pointer).
　語法:
    　 object this_object( void );

    　 物件 this_object( 無參數 );

　用法:
    　 傳回這個物件的物件指標. 如果想呼叫同一個物件卻非同一個程式碼檔案的函式時 (即呼叫所繼承 (inherite) 物件的函式), 可用 this_object()　 達到目的.
　參考:
    　 this_player(3), previous_object(3), origin(3)
　翻譯:
    　 Spock @ FF 97.Jul.25.　 (printed 3/16/95)
