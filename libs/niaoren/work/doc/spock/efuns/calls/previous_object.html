previous_object(3) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 previous_object() - 傳回呼叫目前這個函式的物件 (或物件列表).
　語法:
    　 mixed previous_object( int | void );

    　 混合 previous_object( 整數 或 無參數 );

　用法:
    　 傳回一個呼叫目前函式之物件的物件指標. 請注意, 區域函式 (local function)　 的呼叫不會讓 previous_object()　 設定為目前的物件, 不會改變 previous_object()　 傳回的物件. 如果指定一個正整數為參數, 就傳回先前第幾個呼叫的物件. previous_object(0) 如同 previous_object(), previous_object(1) 是 previous object 的 previous_object(), 以此類推.　 previous_object(-1) 則傳回所有的 previous object 陣列.
　參考:
    　 call_other(3), call_out(3), origin(3)
