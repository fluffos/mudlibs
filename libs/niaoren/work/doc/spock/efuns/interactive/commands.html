commands(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 commands() - 傳回一些關於此使用者可以使用的命令資訊
　語法:
    　 mixed *commands( void );

    　 混合 *commands( 無參數 );

　用法:
    　 傳回一個包含四項資料的陣列 (array), 說明 this_object() 可以使用的動作 (action) . 第一項資料是命令名稱 ( 即 add_action()　 的命令) ; 而第二項是命令的旗標 (flags) (即 add_action() 的第三個參數, 預設值為 0　 );　 第三項資料是定義此動作的物件. 第四項資料是被此動作呼叫的函式 (function) (此項資料如果是個函式指標 [function pointer] 則傳回 "<function>").
　參考:
    　 add_action(3), enable_commands(3), disable_commands(3)
　翻譯:
    　 Spock @ FF 97.Jan.27.　 (printed 3/16/95)
