notify_fail(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 notify_fail() - 傳回一段錯誤訊息.
　語法:
    　 int notify_fail( string | function str );

    　 整數 notify_fail( 字串 或 函式指標 str );

　用法:
    　 以 str　 代替系統在命令無效時傳回的錯誤訊息 :「什麼 ?」當 add_action() 設定的動作傳回 0　 時, 就會顯示此段 str 的訊息. 使用 notify_fail()　 顯示錯誤訊息是一個比較好的方法, 因為此函式允許其他的物件能對同一個命令作出反應. 別用 write()　 來顯示一段錯誤訊息, 因為這樣做需要傳回 1. ( 除非你想在看到「什麼 ?」之後再看到 write() 的結果 ) 如果你傳回 1, 其他的物件就沒有機會對使用者的命令作出反應.

    　 如果參數用的是一個函式指標, 則會呼叫指定的函式. 如果此函式傳回一個字串, 此字串就會當作錯誤訊息. 只要在此函式中正確地設定 this_player(), 就可以使用 write().

    　 如果 notify_fail()　 被呼叫一次以上, 只有最後一次的呼叫有效.

    　 這個函式主要是傳回比「什麼 ?」要來得清楚的錯誤訊息.

　傳回值:
    　 notify_fail() 永遠傳回 0.
