exec(3)　　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 exec() -　 將一個可互動的 (interactive) 玩家 (player) 物件切換連結 (connection) 到另外一個物件上.
　語法:
    　 int exec( object to, object from );

    　 整數 exec( 物件 to, 物件 from );

　用法:
    　 這個函式允許指定的物件把可互動的連結 (link) 遷移到另外一個物件上. 也就是說, 成功地執行 exec( to, from ) 之後, interactive( to ) 會傳回 1, 而 interactive( from ) 會傳回 0. 而控制 from 的玩家會轉移控制權到 to 的身上.

    　 請注意這個函式的權力非常大, 不當地使用會危及 MUD　 的系統安全. 正確地限制使用此函式的方法是另外寫一個同名的模擬外部函式 (simulated emulated function, simul_efun), 並使用 valid_override(4)　 來限制此一模擬外部函式的使用. (意即 efun::exec() )

    　 exec() 函式在成功地轉換之後傳回 1, 轉換失敗則傳回 0.

　參考:
    　 interactive(3), valid_override(4)
