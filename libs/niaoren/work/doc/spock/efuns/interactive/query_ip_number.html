query_ip_number(3) MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 query_ip_number() - 傳回玩家物件的 ip 號碼.
　語法:
    　 string query_ip_number( object ob );

    　 字串 query_ip_number( 物件 ob );

　用法:
    　 傳回玩家 ob 的 ip 號碼 (aaa.bbb.ccc.ddd 的格式).
　參考:
    　 query_ip_name(3), query_host_name(3), resolve(3), socket_address(3)
　翻譯:
    　 Spock @ FF 97.May.1.　 (printed 3/16/95)
