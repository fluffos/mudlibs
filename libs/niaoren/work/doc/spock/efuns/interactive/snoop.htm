snoop(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 snoop() - 窺視一個可互動的使用者 (interactive user).
　語法:
    　 varargs object snoop( object snooper, object snoopee );

    　 不定參數 物件 snoop( 物件 snooper, 物件 snoopee );

　用法:
    　 有兩個參數時, 則 snooper 開始窺視 snoopee. 如果不指定第二個參數, 則停止 snooper 所有的窺視狀態. 通常會使用 simul_efun　 作為控制 snoop() 的安全措施. 有兩個參數時, snoop() 成功會傳回 snoopee. 只有一個參數時, 則傳回 snooper. 傳回 0　 表示失敗.
