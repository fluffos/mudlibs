ed(3)　　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 ed() - 編輯一個檔案.
　語法:
    　 void ed( string file, string exit_fn, int restricted );
    　 void ed( string file, string write_fn, string exit_fn, int restricted );

    　 無傳回值 ed( 字串 file, 字串 exit_fn, 整數 restricted );
    　 無傳回值 ed( 字串 file, 字串 write_fn, 字串 exit_fn, 整數 restricted );

　用法:
    　 這個函式只有在定義了 __OLD_ED__ 之後有效.

    　 這個函式很有趣. 它會啟動一個文書編輯程式來編輯一個指定的檔案. 這個程式與 UNIX 的 ed 程式幾乎相容. 當你進入這個程式後, 可以輸入 h 了解用法.

    　 write_fn　 函式可以讓 mudlib 控制檔案的寫入權限和檔案修改紀錄. 當編輯程式寫入一個檔案時, MUD 驅動程式 (driver) 會呼叫 write_fn 兩次. 第一次呼叫時, 是在寫入檔案之前, 而 flag 旗標為 0. 如果被呼叫的函式傳回「真」值 (true, 即為非零值) , 編輯程式就會繼續寫入檔案. 第二次呼叫時, 是在寫入檔案完成之後, 此時的 flag 旗標為非零值. 被呼叫的函式必須符合以下的格式:

    　　 int write_fn(string fname, int flag)

    　 離開編輯程式時, MUD 驅動程式 (driver) 會呼叫 exit_fn 函式. 這個被呼叫的函式可以讓 mudlib 清除. 這個函式要符合以下的格式:
    　

      　　 void exit_fn()
    　 而可以省略的 restricted 旗標則限制編輯程式的功能. 像是: 插入一個檔案, 以不同的名字儲存檔案. 這些功能在 restricted 旗標為「真」值時, 就無法使用.
　參考:
    　 regexp(3), valid_read(4), valid_write(4), get_save_file_name(4)
