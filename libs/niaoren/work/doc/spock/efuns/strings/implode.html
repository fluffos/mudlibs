implode(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 implode() - 連結多個字串.
　語法:
    　 string implode( mixed *arr, string del );

    　 字串 implode( 混合 *arr, 字串 del );

　用法:
    　 把陣列 arr 中可以找到的所有字串連結在一起, 每一個字串之間以字串 del 隔開. 這個函式只會使用陣列中的字串. 陣列中不是字串的元素 (element) 會予以忽略.
　參考:
    　 explode(3), sprintf(3)
　翻譯:
    　 Spock @ FF 97.Feb.14.　 (printed 3/16/95)
