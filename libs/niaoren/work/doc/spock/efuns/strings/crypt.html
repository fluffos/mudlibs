crypt(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 crypt() - 對一個字串進行編碼.
　語法:
    　 string crypt( string str, string seed );

    　 字串 crypt( 字串 str, 字串 seed );

　用法:
    　 以字串 seed 的前兩個字元當作種子數, 對字串 str　 進行編碼. 如果 seed 為 0　 , 就會用隨機數字進行編碼.

    　 傳回字串的前兩個字母即為種子數.

　翻譯:
    　 Spock @ FF 97.Jan.27.　 (printed 3/16/95)
