strsrch(3)　 MudOS v21c2　 (5 Sep 1994)

　名稱:
    　 strsrch() - 在一個字串中尋找特定的字串.
　語法:
    　 int strsrch( string str, string substr | int char, int flag );

    　 整數 strsrch( 字串 str, 字串 substr 或 整數 char, 整數 flag );

　用法:
    　 strsrch() 在字串 str　 中尋找第一個出現的 substr. 如果 flag 為 -1,　 則尋找最後一個出現的 substr. 如果第二個參數是整數, 則只尋找一個字元 (character) (如同 C　 的 strchr() 及 strrchr() ). strsrch() 無法尋找空字串或 (empty string) 是空值 (null value).
　傳回值:
    　 strsrch() 傳回符合的第一個或最後一個字串出現在 str 中的位置. 如果沒有符合的字串, 則傳回 -1,　 或是錯誤訊息 (有問題的參數等等).
　參考:
    　 explode(3), sscanf(3), replace_string(3), regexp(3)
