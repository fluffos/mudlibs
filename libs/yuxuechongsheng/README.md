# 浴血重生

## 游戏名称

**浴血重生**（登录横幅自称 "1.YXCS"/"浴血重生"）。血统比较特殊：既有
**ES II 引擎系列**的痕迹（`chinesed.lpc` 等文件署名可追溯到 "ES"→"XKX"
一支），又混入了 "Lonely"（"nitan/NT" 系列的作者）后期改写的部分模块，
属于一个 ES 系底子上被二次深度魔改的分支，不是纯血统的任何一支。

## 简介

设定是传统武侠江湖，主线围绕"浴血重生"这个带有江湖恩怨、重新做人的主题
展开。角色创建时可以自由选择"国际挑战者"式的比武活动、门派拜师、以及各
类武功技能，整体内容比较完整、系统衔接也比较扎实。

## 如何运行

```
cd libs/yuxuechongsheng
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40056**

## 如何连接游玩

```
telnet 127.0.0.1 40056
# 或
python3 scripts/mudclient.py 127.0.0.1 40056
```

没有隐藏的编码/客户端版本门槛，注册流程比较直白：

1. 英文名字（新老玩家都直接输入，系统会自动判断是否已注册）。
2. 新玩家会问"确定要创建新角色吗(y/n)"，回答 `y`。
3. 输入真实中文姓名（不需要额外确认，输入合法的中文名字后会直接进入下一
   步）。
4. 设置密码（两次输入确认）。
5. 选择初始"品质"（数字 0-4 中选一个），再确认一次。
6. 输入邮箱地址、选择性别（`m`/`f`），随后就会正式进入游戏世界。

## 已知问题

- 极少数周边小功能（例如某个 NPC 身上"写日记"式的互动）因为原始压缩包
  本身就缺少对应的配置文件，暂时无法使用，不影响主线剧情和正常打怪、拜师
  等核心玩法。
- 少数很深、很偏的技能文件存在历史遗留的语法错误，基本不会在正常游玩中
  被触发到。
- 本轮重新验证：LPC 代码已全部跑过格式化工具，并在重新编译的最新驱动上
  完整回归测试通过。**WASM（浏览器/纯 JS）模式下暂时无法完整登录**——
  这个服务端的登录流程会检查连线 IP 是否被封禁，而 WASM 驱动目前无法
  正确提供连线的 IP 地址格式，导致每次连接都会被误判为"被封禁"而立即
  断开（提示"本站正在进行内部调整"），这是 WASM 驱动本身的已知限制，
  并非本 mudlib 的问题；原生（telnet）模式下完全不受影响，可以正常注册
  和游玩。
