# 书剑2002

## 游戏名称

**书剑2002**（源文件包名为"金庸文字版"）。经比对确认，这与本项目中的
"bxsj"（书剑天下）、"bxsj1" 是**同一套代码库**的不同历史快照，属于同一
门派/同一支血脉的武侠 MUD。

## 简介

取名自金庸小说《书剑恩仇录》的武侠题材 MUD，江湖门派、地图区域大量沿用
金庸小说的设定（少林、武当、明教、天山派等），玩家从选择一门入门绝学
开始（如一阳指、九阳神功、易筋经、太极拳等），逐步在江湖中历练成长。

## 如何运行

```
cd libs/jinyongwenzi
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务端口：**40083**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40083
```

或用任意 UTF-8 telnet 客户端连接 `127.0.0.1:40083`。

注册流程：输入一个纯英文字母的角色代号 → 确认创建（y）→ 输入你的中文
名字 → 直接回车（不用输入内容，这是本游戏这个版本的一个小怪癖，直接按
下回车即可看到系统给出的天赋数值）→ 输入 y 接受天赋 → 选择一门入门绝学
（输入数字 1-5）→ 进入游戏世界。没有隐藏的前置身份/版本验证关卡。

## 已知问题

登录、`look`、`score` 等基本指令均已验证正常工作。个别非核心内容存在
历史遗留的小缺口，不影响正常游玩：
- 极少数门派/技能内容在原始存档里本就没有随包附带（比如个别绝招文件缺
  失），这是资料本身的缺口，不是程序错误。
- 内置的"任务系统"（questd）依赖一个真实的 MySQL 数据库，本环境未配置，
  相关查表功能目前不可用，但不影响正常练功、打怪、聊天等日常玩法。
- 少数个人巫师（管理员）测试用的草稿房间/工具命令存在遗留小毛病，均属
  管理员专用内容，普通玩家不会接触到。
- 已在 WASM（浏览器/Node 沙盒）构建下测试：可完整注册、登录并进行
  `look`/`quit` 等基本操作，游玩体验与原生版本一致。
