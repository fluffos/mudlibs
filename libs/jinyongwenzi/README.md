# 书剑2002

源文件包名为"金庸文字版"，取名自金庸小说《书剑恩仇录》。新角色开局
就是一段"越狱"场景——在皇宫广场遭遇守卫拦截——随后立刻要从一阳指、
九阳神功、易筋经、太极拳四门绝学里选一门修炼，直接决定日后的武学发
展方向；此外仍可通过传统拜师制度加入少林、武当、明教、天山派等取自
小说设定的门派。死亡是真实可用的复活循环而非软锁：死亡房间和新手出
生点是同一地点，角色死后会直接回到开局的越狱场景重新经历一遍。经比
对确认，这与本项目中的"bxsj"（书剑天下）、"bxsj1" 是**同一套代码
库**的不同历史快照，属于同一支血脉的武侠 MUD。

## 内容亮点

- 江湖门派、地图区域大量沿用金庸小说的设定（少林、武当、明教、天山
  派等）。
- 新角色一开局就要选择一门入门绝学（一阳指、九阳神功、易筋经、太极
  拳等任选其一），直接决定后续武学发展方向。
- 一处有趣的历史遗留：本快照的登录代码曾被原作者改写为已注册角色
  登录时不校验密码，任意输入即可进入——本项目转换时按原样保留了这个
  设计，未做"纠正"。
- 内置的任务系统（questd）原本依赖真实 MySQL 数据库，本环境未配置，
  相关查表功能不可用，但不影响日常练功、打怪、聊天等玩法。
