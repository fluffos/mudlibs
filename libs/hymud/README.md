# 海洋V·星月传奇

## 游戏名称

本游戏自称 **海洋V**，游戏内招牌名字为 **星月传奇**（登录后横幅显示
〖海洋V-星月传奇〗）。属于经典的 "ES II" 引擎家族的 **海洋II** 一支的
后续版本（与本项目中的 haiyang2/海洋II 同源，是它的独立演化版本）。

## 简介

这是一个传统的中文武侠 MUD，世界观以江湖门派、拜师学艺、行侠仗义为主
线。新角色从"世界之树"这个古村中心出发，四通八达通向各个地图分区（钱
庄、当铺、村口、青石小路等）。游戏内含完整的武功、门派任务、婚姻、帮
派等一整套传统武侠 MUD 玩法。这是本项目迄今处理过的最大一个压缩包
（工作目录内约 5.7 万个源码文件）。

## 如何运行

```
cd libs/hymud && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40103**。启动后请确认在 `libs/hymud` 目录下执行（日志会写
到同目录的 `log/debug.log`），控制台看到 `Accepting telnet connections
on 0.0.0.0:40103.` 即表示启动成功。

## 如何连接游玩

用任意 MUD 客户端或 telnet 连接 `127.0.0.1 40103` 即可，也可以用本项
目自带的测试脚本体验：

```
python3 scripts/mudclient.py 127.0.0.1 40103
```

**特别提醒**：连接后的第一个提示不是取名字，而是一个编码选择——

```
Please select 国标码 〖GB〗 or き絏 〖Big5〗 (GB/Big5):
```

**必须先回答 `g`（或 `gb`）** 才能进入正式的角色创建流程（本游戏只支
持简体显示）。之后依次会问：英文代号 → 是否确认新建角色 → 中文姓名
（2-5 个汉字，直接输入即可，不需要额外确认）→ 密码（两次，需同时包含
大小写字母和数字，至少 5 个字符）→ 随机天赋是否接受 → 邮箱 → 性别，
即可进入游戏。

浏览器/WASM 版同样支持完整的注册流程，玩法与原生版一致。

## 已知问题

- 一个送货任务的后台调度（`taskd.lpc`）偶尔会在无人操作时抛出一个已被
  捕获的非致命报错，不影响正常登录游玩。
- 少量武功技能文件（练习功法内容）中调用了 `remove_ansi`/
  `noansi_strlen` 两个未定义的旧版模拟函数，不在主线注册/登录/游玩路
  径上，不影响正常游玩。
- 部分角色存档目录（`data/user/`、`data/login/`、`data/mail/` 按英文
  首字母分片存储）在压缩包内完全为空；本项目已为全部 26 个字母预先建
  好目录以便本地测试，但由于 Git 不追踪空目录，全新克隆仓库后只有实
  际测试过的字母（如 `f`）会保留下来——如果某个全新的英文代号首字母此
  前从未被用过，其注册存档可能在首次尝试时失败，需要手动创建对应目
  录（例如 `mkdir -p data/user/z data/login/z`）。
