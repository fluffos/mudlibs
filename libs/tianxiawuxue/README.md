# 天下无雪

## 游戏名称

本游戏自称 **天下无雪**（"A World Without Snow"），作者署名"Dream"，鸣谢
名单包括 Poor、Sinb、Lonely、Zjb 等多位巫师，是一个运营较久、拥有独立世
界观的中文武侠 MUD。

## 简介

一款传统中文武侠 MUD，新角色会被随机安排到北疆小镇、铁枪庙、武庙或客店
四处起始场景之一，体验属性天赋分配、门派拜师、江湖历练等经典玩法。游戏
本身明确表态"严禁 PK"，更偏重交友与探索，而非对抗竞技。

## 如何运行

```
cd libs/tianxiawuxue && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40045**。请务必在 `libs/tianxiawuxue` 目录下启动，看到
`Accepting telnet connections on 0.0.0.0:40045.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40045
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40045`。注册流程为：英文代号
→ 确认新建角色 → 中文姓名（**注意：游戏明确禁止使用金庸小说中已有人物姓
名**）→ 密码（两次）→ 天赋分配（六项属性，输入 0 交由系统随机产生）→ 确
认天赋 → 电子邮箱 → 性别，全部完成后随机进入四处新手场景之一。

## 已知问题

- lpcc 静态编译检查显示约 97.6% 的文件通过，未通过部分主要是巫师个人沙
  盒目录下的孤立内容（甚至包含一整套私人测试用的登录系统），以及少量已
  知的旧式战斗提示文字缺失，均不在注册与主线游玩路径上。
- 极少数情况下（测试中出现过一次，之后反复重试十余次均未再现），新角色
  在完成注册的瞬间可能会被安排到一处"空空如也"的场景而非四个正常新手场
  景之一；这种情况一旦出现，只需重新连线登录即可回到正常场景，不影响存
  档数据本身。
- 核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
  反复验证工作正常，且已确认游戏不会再把普通的程序编译"警告"误当作严重
  错误显示给玩家。
- **WASM 版本兼容性**：在新的 WASM 构建下能正常启动，但由于本 lib 的
  `band.lpc`（禁止名单守护进程）在 IP 地址格式无法解析时默认判定为
  "禁止"，而 WASM 环境下 `query_ip_number()` 无法返回正常格式的地址，
  导致任何连线都会被提示"你的地址在本 MUD 不受欢迎"而无法登录。这是
  WASM 驱动本身的已知限制（原生驱动下登录完全正常），不是本 mudlib 的
  缺陷，未做修改。
