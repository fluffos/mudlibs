# 江湖风云

## 游戏名称

本游戏自称 **江湖风云单机**。经过与本项目内另外两个同源作品
（夕阳再现·疯狂江湖、未明空间）的核心文件比对，确认三者同出一脉，都源自
"夕阳再现之江湖风云"这一支中文武侠 MUD 血脉——本作在三者中与共同祖先最
接近，可以看作这一系列的核心版本。

## 简介

传统中文武侠题材 MUD，江湖门派林立，玩家从"客店"起步闯荡江湖，可在武当、
少林、丐帮、明教、桃花岛等门派间游历、拜师习武、经营人物成长。地图规模
中等（约八千文件），门派、任务、武功体系较为完整，是一款可以踏实玩下去
的传统门派养成类武侠 MUD。

## 如何运行

```
cd libs/jianghufengyun && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40053**。请在 `libs/jianghufengyun` 目录下启动（保证日志写
入同目录 `log/debug.log`），看到 `Accepting telnet connections on
0.0.0.0:40053.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40053
```

或用任意 MUD 客户端 telnet 连接 `127.0.0.1 40053`。注册流程为：英文代号
→ 确认新建角色 → 中文姓名 → 密码（两次）→ 随机天赋是否接受 → 电子邮箱
→ 性别，全部通过后随机进入四个新手出生点之一（如"客店""北疆小镇""铁枪
庙"等），流程简洁，没有额外的隐藏前置关卡。**注意**：英文代号只能用纯
英文字母，不能带数字，否则会被要求重新输入。

## 已知问题

- 少数支线 NPC 与道具（比如"六道轮回剑法"一类的功法文件、某几处商店逻辑）
  在原始资料包里就缺少配套代码或存在明显未完工的语法错误，均为原作者
  遗留的边角内容，不影响主线闯荡江湖的体验。
- 个别地图房间引用的功法/招牌文件确实缺失（例如判官笔一类的稀有兵器），
  属于原始资料包本身没有随附完整内容，不是运行环境的问题。
- 少量管理员/巫师专用的维护指令因依赖的旧版接口在现代驱动上不存在而无法
  使用，均为幕后工具，不影响普通玩家。

核心的注册、登录、探索（look）、查看状态（score）、退出存档等流程已多次
验证，均可正常使用。

- 已在重新编译的驱动上复测（2026-07-23），未发现新的回归问题。
- WASM 版本下可以正常启动，但由于 WASM 驱动获取连线 IP 地址格式的已知
  限制（详见 AGENTS.md），本 mudlib 登录时的地址黑名单检查会误判每个连
  线为"不受欢迎"，导致 WASM 下无法登录；这是驱动 WASM 构建的已知限制，
  并非本 mudlib 的缺陷，原生（native）驱动下完全不受影响，可正常游玩。
