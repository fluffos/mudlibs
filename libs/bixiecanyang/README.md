# 碧血残阳 之「豪侠晚歌」

属于"夕阳再现"引擎家族(与 xiyangzaixian_fengkuang、
xiyangzaixian_fengyun2、weimingkongjian、jianghufengyun 同宗)。

## 简介

「碧血残阳」副标题「豪侠晚歌」,是一款经典武侠题材 MUD,作者自述基于
"夕阳再现－江湖风云 2－风云再起"开发而成。游戏世界横跨嘉兴、扬州等多
个江湖地点,新角色随机从其中一处(如"铁枪庙""北疆小镇"等)起步,并配
有男女不同的称谓与场景描写,细节比较讲究。

## 如何运行

```
cd libs/bixiecanyang
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口:**40065**。启动后请稍等几秒再连接——服务器刚启动时会有短暂
的"正在启动过程中"提示。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40065
```

注册流程比较特别,分为"管理密码"和"普通密码"两组,依次为:
1. 英文 ID(3-10 个英文字母)
2. 确认创建新角色(y/n)
3. 中文姓名(1-5 个汉字,请避开金庸小说角色名等违禁词)
4. **管理密码**(找回密码用,至少 5 位)
5. 确认管理密码
6. **普通密码**(平时登录用,至少 5 位)
7. 确认普通密码
8. 分配天赋点数(0-4 选择某一项,或输入 0 全部随机)——系统会显示随机
   结果并询问是否同意(Y/N)
9. 电子邮件地址
10. 选择性别(m/f)

完成后自动进入游戏世界,`look`/`score` 等指令均正常工作,系统会按性别
显示不同的称谓(如"少年侠士"/"妙龄少女")。
