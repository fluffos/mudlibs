# 金庸群侠传（2008 标准版）

## 游戏名称

本游戏自称 **金庸群侠传**，本压缩包对应"2008版"（标准版）这一内容版本。
经比对确认与本项目中的"金庸群侠传2008加强版"是完全相同的服务端引擎核心
（master、登录、安全模块等关键文件逐字节一致），仅任务数量和个别场景
描写比加强版更精简，可以理解为"同一套服务端程序的轻量内容配置"。

## 简介

以金庸武侠小说世界观为背景的中文 MUD：少林、武当、丐帮、明教、桃花岛
等门派悉数登场，玩家从"客店"起步拜师习武、行走江湖。系统偏传统门派
养成路线（属性、武功、任务、帮派声望），内容量比"加强版""超豪华版"略
精简，适合想快速上手体验这套引擎玩法的玩家。

## 如何运行

```
cd libs/jinyongqunxiazhuan2008_std && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40084**。请在 `libs/jinyongqunxiazhuan2008_std` 目录下启动
（保证日志写入同目录 `log/debug.log`），看到 `Accepting telnet
connections on 0.0.0.0:40084.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40084
```

或用任意 MUD 客户端 telnet 连接 `127.0.0.1 40084`。注册流程为：英文
名字 → 确认新建角色 → 中文姓名 → 密码（两次）→ 随机天赋是否接受 →
电子邮箱 → 性别，通过后进入"客店"这个新手起点，没有额外的隐藏前置关卡。

## 已知问题

- 与"加强版"共享同一套引擎，已知的内容缺口也基本相同：明教分舵几名
  NPC 引用的两门功法、以及一整片地图区域在本包中未随附，属于原始资料
  本身内容不全。
- 少量公告板存档、姓名互译词典存档在原始版本中已损坏，会自动按空数据
  处理，不影响正常游玩。
- 少数管理员专用指令因依赖的旧版接口在现代驱动上不存在，暂不可用，属于
  幕后维护工具，普通玩家不会用到。
- 已在重新编译的驱动上复测（2026-07-23），未发现新的回归问题；WASM 版本
  下也可以完整走完注册、登录、look、quit 全流程，几乎完全可玩（仅有一处
  无害的时间显示小问题：刚注册角色的"上次连线"时间戳会显示成 1969 年，
  这是 WASM 环境时钟的显示瑕疵，不影响实际游玩）。

核心的注册、登录、探索（look）、查看状态（score）、退出存档等流程均已
验证可正常使用。
