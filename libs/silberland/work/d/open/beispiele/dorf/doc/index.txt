    Verzeichnis ueber alle Dateien
    ==============================
    Die Dateien sind nach steigenden Nummwern in den jeweiligen
    Verzeichnissen aufgelistet. Dabei bedeuten groessere Nummern eine
    steigende Komplexetitaet. In komplexeren Dateien werden einfachere
    Sachen nicht oder nur noch nach Notwendigkeit erklaert. 

    Verzeichnis room
    ----------------

    platz_001    : Der prinzipielle Aufbau eines Raum wird gezeigt.
                   Kurz- und Lang- beschreibung, setzen der
                   Umgebungsvariablen, einige Details sowie Ausgaenge
                   werden beschrieben.
    eingang_010  : AddSpecialDetail Beispiel. Beim untersuchen des
                   Bodens ist manchmal ein kleiner Kaefer zu beobachten.
    schuppen_020 : AddCmd Beispiel. Es wird gezeigt, wie man Kommandos
                   hinterlegt und den Spieler Sachen finden laesst.
    wiese_030    : Mit Hilfe von all_inventory und filter_objects werden
                   Haustiere auf einer Wiese gezaehlt. Gleichzeitig
                   werden NPCs mit AddItem in den Raum gestellt.
    schmiede_040 : Ein Feuer kann mittels AddCmd an- und ausgemacht
                   werden. Je nach Zustand aendert sich die Umgebung des
                   Raumes (Temperatur). say/write, tell_object/
                   tell_room und Message zur Ausgabe an die Spieler
                   werden vorgestellt und
    wiese_050    : Ein Objekt im Inventar des Spielers wird
                   ausgetauscht. Problem des Gewichts wird aufgezeigt.
                   Desweiteren wird ein Objekt im Inventar des Spielers
                   veraendert. Die Funktionen present und move werden
                   eroertert.
    platz_060    : Eine Heilstelle wird aufgezeigt (AddHp). Desweiteren
                   werden Probleme aufgezeigt, wenn der Spieler Netztot
                   wird bzw stirbt. Mit beiden Situationen muss man
                   eigentlich immer rechnen, wenn der Spieler
    baum_070     : Ein Ausgang wird gezeigt, der nicht ueber AddExit
                   realisiert ist, sondern ueber move. Der Spieler wird
                   in einen anderen Raum bewegt.
    baum_080     : Landeplatz fuer einen Transporter (Ballon). Siehe
                   auch den Raum eingang_001.c und das objekt ballon.c.
                   Desweiteren wird eine Tuer aufgezeigt (mittels
                   NewDoor), die in ein Baumhaus fuehrt.
    laden_100    : Ein typischer Laden mit Ladenbseitzer.
    lagerraum_110: Ein Lagerraum fuer den Laden. Jeder Laden muss einen
                   Lagerraum zugeordnet haben, in welchem die
                   Gegenstaende, die ein Spieler verkauft,
                   zwischengelagert werden.
    kneipe_120   : Kneipe mit Kneipenbesitzer.
    baumhaus_130 : Zielraum fuer NewDoor von baum_080 aus gesehen.

    -*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*-*

    Verzeichnis npc
    ---------------

    schaf_010          : Ein einfacher NPC(non playing character).
    schaefer_020       : Schon etwas komplizierter: der NPC kann
                         selbststaendig herumlaufen und traegt
                         Ausruestung.
    schmied_030        : Beispiel fuer Sequenzen. Der Schmied erzaehlt
                         einen Witz, kann sich aber nicht erinnern. Kann
                         Sachen reparieren, jedoch nur Waffen aus Metall
    lamm_040           : Dieser NPC kann auf knuddeln, treten usw
                         reagieren. Desweiteres hinterlaesst er keine
                         Standardleiche.
    heilerin_050       : Heilen, ver- und entfroschen werden gezeigt.
                         Desweiteren wie man Spielern Geld abknoepft.
    ladenbesitzerin_060: Eine typische Ladenbesitzerin.
    wirt_070           : Ein Kneipier.
    papagei_080        : Der Papagei plappert alles, was man sagt, nach.
                         Beispiel fuer catch_tell.

    Verzeichnis obj
    ---------------

    ballon    : Transporter. AddRoute, AddMsg und AddFun werden gezeigt.
                Der Ballon fliegt zwischen platz_001 und baum_080 hin
                und her.
    braten_010: Beispiel fuer tragbare Nahrung. Tragbare Nahrung immer
                mit der Balance absprechen und fuer Limits sorgen!
    braten_011: Noch ein Beispiel fuer tragbare Nahrung. Diesmal
                gebraten.

    Verzeichnis weapon
    ------------------

    stab_010       : Eine einfache, grundlegende Waffe
    knueppel_020   : Ein einfacher Knueppel. Er wird als unhandlich
                     beschrieben. Dies wird mittels zweier Properties
                     beschrieben und auch textuell ueber zwei
    speer_030      : Ein Speer, welchen man einhaendig und zweihaendig
                     zuecken kann. Fuer beide Arten braucht man ungleich
                     viel Staerke, fuer einhaendifzuecken viel mehr.
                     Dafuer kann man noch etwas anderes tragen, zB einen
                     Schild.
    speer_031      : Ein Speer, welchen man einhaendig und zweihaendig
                     zuecken kann. Fuer beide Arten braucht man ungleich
                     viel Staerke, fuer einhaendifzuecken viel mehr.
                     Dafuer kann man noch etwas anderes tragen, zB einen
                     Schild
    schwert_040    : Ein Schwert mit einer Hitfunc, Wieldfunc und
                     Unwieldfunc. Der Spieler bekommt beim Zuecken /
                     Zurueckstecken eine Meldung und beim Kaempfen
                     richtet die Waffe manchmal Schaden beim Spieler an
    axt_050        : Eine axt mit einer Hitfunc, welche in einer anderen
                     (zentralen) Datei liegt (axt_htfunc_051)
    axt_hitfunc_051: Hilfsdatei fuer axt_050
