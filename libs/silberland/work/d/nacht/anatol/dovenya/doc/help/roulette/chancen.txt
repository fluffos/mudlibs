HILFE CASINO 'COMET': Chancen

Wird eine Chance gewonnen, behaelt man den Einsatz und erhaelt einen 
Gewinn zu ihm hinzu. Alle Chancen sind mit denselben Schluesselwoertern
untersuchbar, die auch fuer die >>Platzierung<< einer Wette gelten.

(1) Einfachen Chancen
---------------------

Bei Wettgewinn auf eine einfache Chance wird dem Einsatz ein Betrag 
in einfacher Hoehe des Einsatzes hinzugefuegt. 

Es gibt sechs verschiedene einfache Chancen, die jeweils 18 Zahlen
umfassen:

... Farbe Rot            eine roten Zahl
... Farbe Schwarz        eine schwarzen Zahl
... Paritaet Gerade      eine geraden Zahl (ausgen. der Null)
... Paritaet Ungerade    eine ungeraden Zahl
... Haelfte Niedrig      Zahlen von 1-18
... Haelfte Hoch         Zahlen von 19-36

Die Gewinnwahrscheinlichkeit ist bei allen sechs Chancen gleich hoch.


(2) Mehrfache Chancen
---------------------

Bei Gewinn einer mehrfachen Chance wird ein mehrfaches des Einsatzes
dem Einsatz hinzugefuegt.

Kolonnenn werden die Laengsreihen genannt; sie umfassen jeweils zwoelf
Zahlen. Die Zahlen sind darueber hinaus in Dutzende aufgeteilt. Jene 
umfassen ebenfalls je zwoelf Zahlen.  Die Gewinnwahrscheinlichkeit ist 
fuer diese sechs Chancen gleich. Bei Gewinn kommt zum getaetigten Einsatz 
das Doppelte seines Betrags hinzu.  

Des Weiteren koennen Wetten auf mehrere benachbarte Zahlen platziert werden.
Hier gibt es verschiedene Moeglichkeiten, die auch verschieden viele Zahlen
umfassen und entsprechend verschiedene Gewinnquoten haben.

Wird ein Jeton am aeusseren Rand einer der Randzahlen abgelegt, gilt der
Einsatz fuer die Querreihe. Diese umfasst drei Zahlen (aufeinander folgende)
Zahlen, bei Gewinn kommt zum Einsatz das Elffache dessen hinzu.

Soll die Wette auf zwei Querreihen gleichzeitig platziert werden, kommt
der Jeton auf der aussen liegenden mittleren Ecke zum liegen. Die Doppelreihe
umfasst 6 (aufeinander folgende) Zahlen und entsprechend kommt bei Gewinn
der Chance das Fuenffache des Einsatzes zu ihm hinzu. 

In der Gewinnwahrscheinlichkeit und Quote dazwischen liegend ist die Chance
der Ecke (Carre). Hier wird auf vier im Quadrat angeordnete Zahlen (von 
welchen dann je zwei automatisch aufeinander folgend sind) gewettet. Der
Jeton wird auf die mittig liegenden Ecken gelegt. Bei Gewinn der Chance 
wird das Achtfache zum Einsatz gegeben.

Schlussendlich gibt es noch die Nachbarn: Hier liegt der Jeton auf der
Feldkante zweier Zahlen, die Chance wird gewonnen, wenn eine dieser Zahlen
gewinnt. In diesem Fall wird das Siebzehnfache zum Gewinn gegeben.

Wetten auf Querreihen, doppelte Querreihen, Quadrate und Nachbarn werden
durch Angabe der niedrigsten und hoechsten Zahl definiert.

Durch die Position der Null, die an die Zahlen 1, 2 und 3 grenzt, ergeben
sich zwei genannte Sonderfaelle: Die "ersten drei" und die "ersten vier",
welche gewinnen, wenn eine der ersten drei bzw. ersten vier Zahlen gewinnt.
Eine Wette auf die "ersten drei" verhaelt sich wie die Wette auf eine 
Querreihe, eine Wette auf die ersten vier wie die auf eine Ecke. Diese
Trennung ruehrt moeglicherweise daher, dass die Announce "zero deux" 
sowohl die Platzierung auf die Nachbarn null und zwei als auch die Platzierung
auf die (Dreier-)Ecke zwischen null, eins und zwei haette bedeuten koennen.
Da die Wetten auf null-eins-zwei und null-eins-zwei-drei besonders benannt
sind, gibt es diese Mehrdeutigkeit nicht mehr.

Den Abschluss bilden die Wetten auf eine einfache Zahl. Diese Chancen
gewinnen genau dann, wenn diese eine Zahl faellt. Bei Gewinn kommt zum 
Einsatz das fuenfunddreissigfache (35-fach!) dessen hinzu.

... Erste Kolonne        eine Zahl der Kolonne 34 (i)
... Zweite Kolonne       eine Zahl der Kolonne 35 (ii)
... Dritte Kolonne       eine Zahl der Kolonne 35 (ii)
... Erstes Dutzend       eine Zahl von 1 bis 12
... Mittleres Dutzend    eine Zahl von 13 bis 24
... Letztes Dutzend      eine Zahl von 25 bis 36
... Querreihen (12)      eine Zahl der gewaehlten Querreihe
... Doppelreihen (11)    eine Zahl der zwei gewaehlten Querreihen
... Quadrat (22)         eine Zahl des gewaehlten Quadrats
... Nachbarn (60)        eine der zwei gewaehlten benachbarten Zahlen
... Erste drei           eine Zahl von 0 bis 2
... Erste vier           eine Zahl von 0 bis 3
... Zahl (37)            die gewaehlte Zahl    

Damit gibt es 150 verschiedene Mehrfachchancen, die insgesamt sechs
verschieden hohe Gewinnquoten haben.
