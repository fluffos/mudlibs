
Murmelspielen:
--------------

Wird ueber den Skillmaster geregelt. Man kann mit anderen Spielern
Murmeln spielen. Setzt man eine Murmel ein, so kann man wenn man
den Gegner schlaegt, eine Anzahl Murmeln hinzugewinnen. Die
Gesamtanzahl der Murmeln ist (Gewicht im Murmelbeutel) auf 100
Stueck limitiert.
Je nach Skill kann man andere Spiele auswaehlen, je nach Spiel
kann man mehrere Murmeln dazugewinnen.

Hat man eine Anzahl Murmeln gesammelt, so kann man die im Shop
gegen Upgrades fuer Hirelings umtauschen.
