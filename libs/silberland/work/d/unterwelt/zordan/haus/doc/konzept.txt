                      Das Haus von Elvira und Zordan 

-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-


Vorgeschichte:

Nachdem der Weg des Lebens Elvira und Zordan zusammengefuehrt hat, war es nun 
an der Zeit, dass die beiden ein gemeinsames Heim aufbauten. Als Dunkelelfen 
entschlossen sie sich, ihr bescheidenes Heim im Suedosten von Dhrkion zu 
errichten. Zuerst musste man natuerlich eine passende Stelle finden und dann 
mit den Behoerden vor Ort alle Formalitaeten regeln. Das gestaltete sich 
allerdings nicht als so schwer, da beide rechte gute Beziehungen zu der 
Koenigin der Dunkelelfen haben. Der Eingang befindet sich heute inmitten des 
Wohnbereiches von Dhrkion. Allerdings wurde es den Beiden gestattet, ihr 
gesamtes Vermoegen in einen prunktvollen Bau unterhalb der Stadt zu 
investieren, so dass sie sich weit ausgedehnt haben. Noch heute erzaehlen die 
Ureltern ueber die Massen von Erdreich, die man damals unterhalb Dhrkion 
entfernt hat um dieses Heim zu errichten.

-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-


Realisierung:

Da dieses Heim einem ganz normalen Gebiet im SilberLand entspricht, gibt es 
keine Auflagen oder Dinge an die man sich halten muesste. D.h. es wird NPC's 
geben, FP's, Objekte uswusf. Einzige Ausnahme ist der Workroom von Zordan als 
Magier. Diesen Raum koennen Sterbliche von Aussen nicht betreten. Ausnahme 
bildet natuerlich Elvira. Aus diesem Grund wird der Workroom das Schlafgemach.

Insgesamt hat das Heim 11 Raeume:

- Flur          ( F )
- Arbeitszimmer ( R )
- Abstellraum   ( A )
- Bad           ( B )
- Empfangsraum  ( P )
- Esszimmer     ( E )
- Gaestezimmer  ( G )
- Kinderzimmer  ( K )
- Kueche        ( U )
- Schlafzimmer  ( S - gleichzeitig der Workroom )
- Vorratsraum   ( V )
- Wohnbereich   ( W )
