TEIL 1.: KOBOLD FANGEN
----------------------

1. Umpf nach Hilfe Fragen -> Questitem

2. In Bibliothek: unt buchstabe t -> Trankbuch 

3. In Speisekammer: -> rieche nebengeruch -> unt nische -> Kaese

4. Im Badezimmer: -> oeffne kaestchen -> unt kaestchenen -> 
   unt Flaeschchen -> unt flasche -> Saranostin

5. Bei Kellereingang: -> unt ostwand -> unt loch -> greife in loch -> Rattengift

6. garten12: -> rupfe kresse aus -> Kresse 

7. garten2: -> pfluecke rose -> reisse rosenbluete aus -> Rosenbluete

8. garten8: -> nimm holzscheit -> Holzscheit 

9. garten10: -> pfluecke tomate -> faule Tomate 

10. garten16: -> ziehe an faden -> Netz 

11. garten13: -> schneide schnittlauch mit <waffe> ab (Waffe muss entweder
    Schwert oder Messer sein) -> Schnittlauch					
		    
12. garten21: -> grabe in erde -> rote Erde 

13. garten10: -> ziehe ast mit seil herunter(seil muss vorhanden sein) ->
    pfluecke walnuss -> Walnuss

14. In Schuppen: -> unt rost -> unt schimmern -> unt schaufel -> 
    drehe schaufel um -> Pistill 
    unt hornissennest -> angriff der hornissen -> in leiche Hornissenstachel ->
    breche stachelspitze ab -> Spitze eines Hornissenstachels

15. In Kueche: unt kaesten -> unt kasten -> Moerser gefunden
    Alle Gegenstaende in Moerser legen mit:
             ->  leg <gegenstand> in moerser
    Wenn alles drin ist:
             ->  zerkleinere gemisch
    Dann noch:  ->schuette saranostin in moerser -> zaubertrank

16. Im Zimmer von Umpf:
            -> schuette zaubertrank in kessel 
            -> schmeisse tomate auf kobold 
            -> fang kobold mit netz -> Kobold

17. Bei Umpf: Kobold Umpf geben -> Rubin


2.TEIL: ZUSAMMENBAUEN DES INSTRUMENTES
--------------------------------------

18. Im Schlafzimmer des Soundmagiers -> ziehe Hebel -> 1.Stock

19. Im Ahnenraum: -> unt quarzschild -> unt quarz -> unt kratzer ->
                  -> drehe Quarzschild um -> Brecheisen 

20. In Musikbibliothek: -> unt graues regal -> lies blaues buch -> anleitung

21. In Abstellraum: -> schiebe schachteln weg -> unt truhe -> unt magisches symbol ->
                    -> breche magisches symbol heraus -> Magisches Symbol

22. Im Arbeitsraum: -> unt harfe -> unt verzierungen -> unt hermes -> druecke knopf ->
                    -> Melodie

23. Instrumentenraum: -> spiele xylophon -> magiedurchflutete Kugel

24. Wohnzimmer: -> heize ofen mit holzscheit ein -> unt ofen -> 
                -> breche mystisches symbol mit brecheisen herunter ->
                -> mystisches Symbol 

25. Kristallzimmer -> steige auf tisch -> lockere aufhaengung -> 
                   -> schlage auf aufhaengung -> Kristallhebel

26. Musikzimmer -> steck magisches symbol in schlitz 
                -> steck mystisches symbol in einbuchtung
                -> steck magiedurchflutete kugel in aushoehlung
                -> steck kristallhebel in loch
                -> ziehe kristallhebel 
                -> tonfolge spielen (Bei Problemen damit, 
                   kann man Umpf fragen);
                 
                 Tonfolge:
                       -> spiel ton a
                       -> spiel ton c
                       -> spiel ton h
                       -> spiel ton d
                       -> spiel ton g
                       -> spiel ton a -> Quest geloest(Endsequenz)
