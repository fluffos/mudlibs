FUNKTION:
      static int RegisterNewItem(object item, int flag)

BESCHREIBUNG:
      Registriert ein Item, so das es nachtraeglich veraendert bzw zerstoert
      werden kann. Wenn die Anzahl der Items von dem entsprechenden Magietyp
      ueberschreitet, wird das 1. Element (0) zerstoert. Der Spieler bekommt
      eine Meldung. Sollte er nicht anwesend sein, so erscheint diese Meldung
      erst beim naechsten Login.

RUECKGABEWERT:
      1

FUNKTION: 
      int CheckObject(object ob)

BESCHREIBUNG:
      Ueberprueft ob eine Waffe / Ruestung magisch werden kann. 
      Gegenstaende werden nicht magisch, wenn folgendes eintritt:
        - keine Waffe oder keine Ruestung
        - ist im /players/ Verzeichnis,
        - liegt in einem Verzeichnis ../test/.., 
        - ist keine Waffe / keine Ruestung, 
        - ist magisch (P_MAGIC),
        - ist verflucht (P_CURSED),
        - veraendert den Lichtlevel (P_LIGHT),
        - hat keinen Artikel (P_ARTICLE),
        - ist eine Ruestung mit Ruestungstyp (P_ARMOUR_TYPE) AT_MISC,
        - ist ein autoload object (P_AUTOLOADOBJ),
        - hat eine der folgenden Funktionen definiert:
             -P_WIELD_FUNC,
             -P_UNWIELD_FUNC,
             -P_WEAR_FUNC,
             -P_HIT_FUNC,
             -P_DEFEND_FUNC,
        - ist eine Waffe mit magischem Schaden (P_DAM_TYPE, 
          MAGICAL_DAMAGE_TYPES),
        - ist eine Ruestung mit magischem Schutz (P_DAM_PROTECTION,
          MAGICAL_DAMAGE_TYPES),
        - hat eine ueberschriebene P_LONG oder P_SHORT
        - wenn zufaellig gerade die ITEMD-Liste ueberprueft wird (check_magic)

RUECKGABEWERT:
      1
