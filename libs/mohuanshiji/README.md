# 魔幻世纪 (mohuanshiji)

## 游戏名称

《魔幻世纪》，青岛站，作者"小宝(suannai)/西瓜太郎(gslxz)/桃心太郎"，由
"星月传奇"发布。属于"神话西游"(SJXY) 一脉，是 ES II 引擎的一个西游记
（Journey to the West）改版分支，与本项目转换的 mhxy/rzrmud 等同为
"西游记"神话世界观，但代码血统各自独立，并非彼此的换皮版本。

## 简介

同样以《西游记》取经故事为背景：新角色要先"选择一个合适的天赋"，随后从
"南城客栈"启程，唐僧、店小二、千里眼等经典角色以 NPC 身份驻场迎接新人。
本作在原有 xyj 玩法基础上加入了武当、移花宫等原创门派内容，整体在同类
西游题材泥巴中算是内容比较丰富、系统比较完整的一支。

## 如何运行

```
cd libs/mohuanshiji
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40092**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40092
```

登录流程：

1. 先问 `gb`/`big5` 编码，回答 **`gb`** 即可。
2. 一个"是否是中小学学生"的年龄提示，回答 `no` 继续。
3. 输入一个英文 ID，然后确认创建新角色 (y/n)。
4. 输入真实的中文名字（例如"秦岚"）——这一步已验证可以正常接受任何合法
   的中文姓名。
5. 设置密码，再输入一次确认；输入电子邮箱；选择性别 (m/f)。
6. 进入游戏前会有一次天赋分配界面：直接输入 `9` 接受默认天赋，再输入
   `y` 确认，即可正式进入"南城客栈"。

登录后 `look`、`score` 等指令均已验证正常，角色性别相关的文字（称谓、
NPC 招呼语等）也会正确区分男女。

## 已知问题

- `d/hen/`（一个以"恨"为主题的小型分区，约 38 个文件）缺少其共用的头
  文件，本身就是原始归档的内容缺口，不影响其余场景。
- 武馆的两三个 NPC 引用了未定义的装备宏，是原始归档遗留的小缺口。
- 有一个巫师专用的状态查询命令文件本身就有轻微的语法损坏（疑似原始
  归档自带），仅影响该一条管理员工具，不影响普通玩家。
- 整体 lpcc 静态编译扫描通过率 97.4%，其余未通过的文件绝大多数是"职业
  技能片段"类内容（设计上依赖被组合进角色对象后才能正常工作，单独编译
  检测本就会报错），并非真正的运行缺陷。
- WASM 版本经过完整测试：注册、进入长安城南城客栈、look/quit 均可正常
  体验。日志里有一条无害的、不影响游戏的报错（进入游戏时查询连线 IP
  归属地信息失败，只是少显示一行欢迎文字），这是 WASM 驱动本身对连线
  IP 格式支持不完整导致的已知限制，不影响实际登录和游玩。
