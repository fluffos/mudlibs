# 魔幻世纪 (mohuanshiji)

青岛站，作者"小宝(suannai)/西瓜太郎(gslxz)/桃心太郎"，由"星月传奇"
发布。属于"神话西游"(SJXY) 一脉，是 ES II 引擎的一个西游记（Journey
to the West）改版分支，与本项目转换的 mhxy/rzrmud 等同为"西游记"神话
世界观，但代码血统各自独立，并非彼此的换皮版本。

## 内容亮点

- 以《西游记》取经故事为背景：新角色从"南城客栈"启程，唐僧、店小二、
  千里眼等经典角色以 NPC 身份驻场迎接新人。
- 在原有西游记玩法基础上加入了武当、移花宫等原创门派内容，整体在
  同类西游题材泥巴中算是内容比较丰富、系统比较完整的一支。
