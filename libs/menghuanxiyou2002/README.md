# 梦幻西游（青岛站）

## 游戏名称

**梦幻西游**，2002 年版本，"青岛站"分线。与本项目中的 "mhxy" 是同一套
2002 年代码库（仅站点名称品牌不同），属于西游记题材、ES II 引擎家族的
一支（与 fluffos_xiyou2000 等同宗）。

## 简介

取材自《西游记》的神话/仙侠题材 MUD：新手从"南城客栈"起步，途中会遇到
黄飞鸿、孙悟空等耳熟能详的角色，游戏内的成就体系也紧扣原著——"西天取经"
"大闹天宫"等都是角色档案里会记录的经历。整体偏休闲，新闻公告、门派、
帮会系统一应俱全。

## 如何运行

```
cd libs/menghuanxiyou2002
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务端口：**40050**。世界数据量较大，服务器启动后大约还需要 1-2 分钟
在后台继续加载全图 NPC/场景，但这期间已经可以连线注册、游玩。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40050
```

或用任意 UTF-8 telnet 客户端连接 `127.0.0.1:40050`。

**连接后请注意几个容易让新玩家卡住的前置提示：**
1. 第一个提示是选择编码，直接输入 `gb`（简体）即可，无需管 BIG5 选项。
2. 接下来会问"是否是学生"一类的年龄确认问题，回答 `no` 即可继续（回答
   除"否/no"以外的内容会直接断开连接，这是原始设计如此，并非故障）。
3. 到英文代号提示时，新玩家请输入 `new` 触发注册流程，而不是直接输入
   代号。
4. 之后依次是：英文代号 → 中文名字 → 密码（两次）→ 一个"身份标识"
   （类似第二密码，需同时包含大小写字母和数字/符号，长度不少于 6 位，
   输入两次确认）→ 电子邮箱 → 个人主页（可直接回车留空）→ ICQ 号码
   （可随意填写或留空）→ 性别（m/f）。
5. 最后会进入天赋分配环节：屏幕会列出体格/根骨/悟性/灵性四项数值，
   可以输入 0-3 选择重新调整某一项，**满意后输入 `9` 接受当前设置**，
   再输入 `y` 确认即可正式进入游戏世界。

## 已知问题

登录、`look`、`score` 等基本指令均已验证正常工作，男女角色的性别化
NPC 对话（如"这位小姑娘"/"这位小兄弟"）也都正确。少数非核心内容存在
历史遗留的小问题，不影响正常游玩：
- 后台的"新闻/公告"系统偶尔会在极大批量刷新场景宝物时短暂超时一次，
  自动跳过，不影响其他功能。
- 一份历史遗留的存档（表情动作记录）本身已损坏，程序会自动忽略，不
  影响正常聊天/表情功能。
- 内置的"任务系统"个别环节依赖的一个查询在特殊情况下会返回空结果，
  影响面很小，不影响日常练功、打怪、逛街等主线玩法。
- 在 WASM（浏览器/Node 沙盒）构建下测试：驱动能正常启动，但由于该驱动
  版本对 WASM 连线 IP 格式化的已知限制，游戏自带的"地区/线路识别"功能
  会在登录过程中报错，导致 WASM 环境下暂时无法完成注册登录——这是驱动
  侧的已知限制，并非本游戏程序的错误，原生（非 WASM）环境下登录完全
  正常。
