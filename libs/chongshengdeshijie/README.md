# 重生的世界 (Revival World)

RWlib v1.0.1,台湾团队开发的生活模拟/城市经营类 MUD,与本项目其他武侠
类 mudlib 完全不属于同一谱系,是一套独立自制的引擎。

## 简介

「重生的世界」不是打怪升级的武侠 MUD,而是一款以经营、生活为核心的模
拟游戏:种田、钓鱼、养殖、开工厂、买卖房地产、炒股、打麻将、抽奖样样
俱全,还有完整的城市市长、税收、企业系统。新角色从"巫师神殿"出发,可
以选择加入某个城市定居,体验经营与养成的乐趣,风格更接近生活模拟游戏
而非传统砍杀 MUD。

## 如何运行

```
cd libs/chongshengdeshijie
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口:**40081**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40081
```

连接后会先看到一段较长的"系统加载中"画面(游戏在每次连线时都会展示
一次完整的模块加载动画,属于该游戏的特色开场,并非卡住,请耐心等待几
秒)。加载完毕后:

1. 输入 `new` 创建新角色
2. 设置英文 ID
3. 输入中文姓名
4. 设置密码
5. 确认密码
6. 电子邮件地址(可直接按回车跳过)
7. 选择性别(M/F)

完成后会显示游戏公告栏,几秒后自动进入游戏(或按任意键立即进入),从
"巫师神殿"开始。`look`/`score` 等指令均正常工作。

## 已知问题

- 目前主线注册、基础指令与存档功能均验证正常,未发现影响新手体验的
  内容缺失。
- 重复使用同一账号短时间内多次注册会触发防灌水限制,属于正常的防护
  机制,稍等片刻或重启服务器即可清除。
- 本游戏暂不支持 WASM/浏览器模式:核心颜色处理模块依赖 WASM 版驱动未
  提供的正则表达式(pcre)功能,导致游戏本身无法启动,这是驱动层面的
  限制而非本游戏的缺陷。
