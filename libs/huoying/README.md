# 火影

## 游戏名称

本游戏自称 **火影**（英文 Naruto），底层引擎注释自称 `Neolith 0.0.2`，
是 "ES2" 引擎家族的一员（与本项目中的武汉站、雪影奇缘等同宗）。

## 简介

这是一个以日本动漫《火影忍者》为题材背景的中文 MUD，玩家扮演忍者角色，
在木叶村等场景中修炼查克拉、习练忍术、体验师徒与门派系统。整体沿用武侠
类 MUD 的基本框架（属性、装备、门派、任务），但把设定和用语都改成了忍者
世界的风格，登录界面还带有相当精美的 ANSI 彩色 ASCII 艺术 Logo，用支持
ANSI 色彩的客户端（如 ZMUD 等）观感尤佳。

## 如何运行

```
cd libs/huoying && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40059**。请在 `libs/huoying` 目录下启动（保证日志正确写入
同目录 `log/debug.log`），看到 `Accepting telnet connections on
0.0.0.0:40059.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40059
```

或直接用支持 ANSI 颜色的 MUD 客户端 telnet 连接 `127.0.0.1 40059`。
注册流程为：英文代号 → 确认新建角色 → 密码（两次）→ 电子邮箱 → 性别 →
中文姓名，全部通过后即进入"巫师神殿"这一起始场景。整个流程没有额外的
隐藏关卡或客户端版本校验，比较直观。

## 已知问题

- 少数支线小游戏道具（如麻将、五子棋）以及一件饮水道具，在原始资料包中
  就没有配套的功能代码，属于作者当年未完工的内容，不影响主线体验。
- 当铺（hockshop）房间和悬赏任务系统的存档数据在原始版本中已损坏，这两
  处功能会退化为空数据，不影响其余场景与玩法。
- 个别管理员专用指令（版本查询、底层 socket 调试）因原始设计依赖的底层
  接口在当前驱动上不存在而无法使用，均为幕后管理工具，普通玩家接触不到。

核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
反复验证工作正常。
