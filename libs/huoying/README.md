# 火影

本游戏自称 **火影**（英文 Naruto），底层引擎注释自称 `Neolith 0.0.2`，
是 "ES2" 引擎家族的一员（与本项目中的武汉站、雪影奇缘等同宗）。以日本
动漫《火影忍者》为题材，玩家扮演忍者角色，登录界面带有相当精美的
ANSI 彩色 ASCII 艺术 Logo。

## 内容亮点

- 归属 ES2/Neolith 谱系，属性、装备、门派、任务框架沿用武侠类 MUD
  的基本结构，但设定与用语都改成了忍者世界的风格。
- 存档内的武功/道具/NPC 模板库其实相当可观（忍术、查克拉相关技能、
  装备分类一应俱全），但经深度实机测试确认：本快照实际可通行的房间
  仅有巫师公会设施（公告板、举报处、议事厅等 5 个房间），并未随附
  可探索的正式忍者村/江湖地图——`START_ROOM` 就硬编码指向巫师公会。
  换言之，这份存档更像是引擎/框架的技术快照，而非完整关卡内容包。
