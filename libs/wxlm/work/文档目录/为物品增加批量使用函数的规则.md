# 为物品增加批量使用函数的规则

## 概述

本文档基于 `wusheng_book.c`（武圣经义）的实现，总结了为MUD游戏中的物品增加批量使用功能的标准规则和实现方法。

## 基本要求

### 1. 继承基类
物品必须继承 `COMBINED_ITEM` 基类，以支持数量管理和批量操作。

```lpc
inherit COMBINED_ITEM;
```

### 2. 必要的设置函数

#### setup() 函数
```lpc
void setup()
{
    set_amount(1);
    ::setup();
}
```

#### create() 函数中的关键设置
```lpc
void create()
{
    // 基本物品属性设置
    set_name(物品名称, 别名数组);
    set_weight(重量);
    
    if (clonep())
        set_default_object(__FILE__);
    else {
        // 物品描述和属性
        set("long", 物品描述);
        set("base_unit", 单位);
        set("base_weight", 基础重量);
        set("base_value", 基础价值);
        set("yuanbao", 元宝价格);
        set("no_sell", 1);           // 不可出售
        set("only_do_effect", 1);    // 只能使用效果
        set("day_limit_number", 每日限制数量);
    }
    setup();
}
```

## 核心函数实现

### 1. 单次使用函数 - do_effect()

```lpc
/**
 * @brief 单次使用物品的效果函数
 * @param object me 使用物品的玩家对象
 * @return int 返回1表示使用成功，0表示使用失败
 * @details 处理单个物品的使用逻辑，包括条件检查、效果应用和物品消耗
 */
int do_effect(object me)
{
    // 局部变量声明
    int 变量1, 变量2;
    
    // 1. 显示使用动作
    message_vision("$N" + 使用动作描述 + "\n", me);
    
    // 2. 获取必要的数据
    变量1 = 获取数据1();
    变量2 = me->query("属性名");
    
    // 3. 使用条件检查
    if (不满足使用条件)
    {
        tell_object(me, 失败提示信息);
        return 1;  // 使用失败，不消耗道具
    }
    
    // 4. 应用效果
    if (满足效果条件)
    {
        // 应用具体效果
        me->add("属性名", 效果值);
        
        // 成功提示
        tell_object(me, 成功提示信息);
        
        // 记录日志
        log_file("日志文件路径", 
                sprintf("日志格式字符串\n", 参数列表));
    }
    else
    {
        tell_object(me, 条件不满足提示);
        return 1;  // 使用失败，不消耗道具
    }
    
    // 5. 消耗道具
    add_amount(-1);
    return 1;
}
```

### 2. 批量使用函数 - do_effect_more()

```lpc
/**
 * @brief 批量使用物品的效果函数
 * @param object me 使用物品的玩家对象
 * @param int amount 使用的数量
 * @return int 返回1表示使用成功，0表示使用失败
 * @details 处理批量物品的使用逻辑，需要考虑累积效果和数量限制
 */
int do_effect_more(object me, int amount)
{
    // 局部变量声明
    int 变量1, 变量2;
    
    // 1. 显示使用动作
    message_vision("$N" + 使用动作描述 + "\n", me);
    
    // 2. 获取必要的数据
    变量1 = 获取数据1();
    变量2 = me->query("属性名");
    
    // 3. 批量使用条件检查（重要：考虑累积效果）
    if ((变量2 + 效果值*amount) > 上限值)
    {
        tell_object(me, 超出限制提示);
        return 1;  // 使用失败，不消耗道具
    }
    
    // 4. 应用效果
    if (满足效果条件)
    {
        // 应用批量效果
        me->add("属性名", 效果值*amount);
        
        // 成功提示（显示总效果）
        tell_object(me, 成功提示信息);
        tell_object(me, "你获得了" + (效果值*amount) + "点属性。\n");
        
        // 记录日志
        log_file("日志文件路径", 
                sprintf("日志格式字符串\n", 参数列表));
    }
    else
    {
        tell_object(me, 条件不满足提示);
        return 1;  // 使用失败，不消耗道具
    }
    
    // 5. 消耗道具
    add_amount(-amount);
    return 1;
}
```

## 实现要点

### 1. 变量声明规则
- **必须在函数开头或代码块开头声明所有局部变量**
- 不能在可执行语句之间声明变量

### 2. 条件检查顺序
1. 基本使用条件检查
2. 累积效果限制检查（批量使用时）
3. 特殊条件检查

### 3. 批量使用特殊考虑
- **累积效果检查**：`(当前值 + 效果值*数量) > 上限值`
- **数量参数处理**：所有效果值都要乘以 `amount`
- **消耗处理**：使用 `add_amount(-amount)` 而不是 `-1`

### 4. 返回值规则
- 返回 `1` 表示函数执行完成
- 使用失败时也返回 `1`，但不消耗道具
- 通过是否调用 `add_amount()` 来控制道具消耗

### 5. 用户反馈
- 使用 `message_vision()` 显示动作给所有人
- 使用 `tell_object()` 给使用者私人消息
- 成功时显示具体获得的数值
- 失败时给出明确的失败原因

### 6. 日志记录
- 使用 `log_file()` 记录重要的使用信息
- 包含玩家信息、使用数量、效果值、相关属性等
- 便于后续的数据分析和问题排查

## 注意事项

1. **代码风格**：遵循LPC语言规范，变量声明必须在代码块开头
2. **错误处理**：充分考虑各种边界情况和错误情况
3. **用户体验**：提供清晰的反馈信息，让玩家了解使用结果
4. **数据安全**：避免数值溢出，设置合理的上限检查
5. **日志记录**：记录关键操作，便于后续维护和分析
6. **性能考虑**：避免不必要的重复计算和数据库查询

通过遵循以上规则，可以为MUD游戏中的各种物品实现标准化的批量使用功能。
