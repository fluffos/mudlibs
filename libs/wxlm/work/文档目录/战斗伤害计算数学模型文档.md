# 战斗伤害计算数学模型文档

## 概述

本文档使用数学语言描述游戏中**单招伤害**（技能伤害）和**普攻伤害**的计算逻辑。两套系统的计算流程和修正方式存在显著差异。

## 1. 单招伤害计算模型

### 1.1 基础伤害阶段

设单招基础伤害为 **基础值D₀**，第一阶段伤害为：

```
伤害₁ = 基础值 + 武器加成 + 冲脉伤害/2 + 宝石增伤/2
```

### 1.2 技能防御阶段

经过**招架技能**修正：
```
伤害₂ = 招架修正(伤害₁)
```
若 伤害₂ < 1，计算终止。

经过**轻功技能**修正：
```
伤害₃ = 轻功修正(伤害₂)
```
若 伤害₃ < 1，计算终止。

### 1.3 装备防护阶段

```
伤害₄ = 护甲修正(伤害₃)
```

### 1.4 武器特效阶段

```
伤害₅ = 武器特效(伤害₄)
```

### 1.5 加力伤害阶段

当 **加力值 > 0** 且 **内力 ≥ 加力值** 时：

```
内力 -= 加力值

加力伤害 = {
    加力值 × 伤害₅ / 350,  远程攻击
    加力值 × 伤害₅ / 500,  近身攻击
}

如果是近身攻击：
    加力伤害 = 内功修正(加力伤害)

伤害₅ += 加力伤害
```

### 1.6 力量加成阶段

设 **力量 = 基础力量 + 临时力量**，力量系数计算：

```
力量系数 = {
    力量 / 50,                        力量 < 20
    ((力量 - 20) / 2 + 20) / 50,      20 ≤ 力量 < 40
    ((力量 - 40) / 4 + 30) / 50,      力量 ≥ 40
}

伤害₆ = 伤害₅ × (1 + 力量系数)
```

### 1.7 伤害上限修正

```
最终伤害 = {
    (伤害₆ - 1600) / 3 + 1600,  伤害₆ > 2000
    (伤害₆ - 1200) / 2 + 1200,  1200 < 伤害₆ ≤ 2000
    伤害₆,                      伤害₆ ≤ 1200
}
```

### 1.8 伤害结算

```
实际伤害 = 最终伤害 × 伤害百分比 / 100
内伤值 = 内伤计算(实际伤害)
气血伤害 = 气血伤害计算(实际伤害)

目标气血 -= 气血伤害
目标内伤 += 内伤值
```

## 2. 普攻伤害计算模型

### 2.1 命中判定阶段

设**攻击力**、**闪避力**、**招架力**分别为三个核心数值。

**闪避判定**：
```
if random(攻击力 + 闪避力) < 闪避力 && 目标气血 > 0:
    返回闪避消息，伤害为0
```

**招架判定**：
```
if random(攻击力 + 招架力) < 招架力 && 目标气血 > 0:
    返回招架消息，伤害为0
```

### 2.2 攻击力计算

```
攻击力 = 技能威力计算(攻击技能)

如果性格 = "阴险奸诈"：
    攻击力 += 攻击力 × 20%

根据土元素数量：
- 土元素 ≥ 12：攻击力 += 攻击力 × 25%
- 土元素 ≥ 8：攻击力 += 攻击力 × 15%

如果有攻击增强丹：
    攻击力 += 攻击力 × 10%
```

### 2.3 闪避力计算

```
闪避力 = 轻功威力计算()
闪避力 += 闪避力 × 轻功特效 / 200
闪避力 = 好运天赋修正(闪避力)

如果目标繁忙：
    闪避力 /= 3

闪避力 = max(1, 闪避力)
```

### 2.4 基础伤害计算

```
基础伤害 = {
    武器伤害加成,    使用武器
    徒手伤害加成,    徒手攻击
}

基础伤害 = (基础伤害 + 随机(基础伤害)/2) / 2

如果招式有伤害加成：
    基础伤害 += 招式伤害加成 × 基础伤害 / 100
```

### 2.5 伤害加成阶段

```
伤害加成 = 攻击者力量

如果使用加力且内力充足：
    伤害加成 += 内功加力伤害

如果招式有力量加成：
    伤害加成 += 招式力量加成 × 伤害加成 / 100

最终伤害 = 基础伤害 + (伤害加成 + 随机(伤害加成)) / 3
```

### 2.6 防御减伤链

按以下顺序逐一处理，每步若伤害 < 1 则终止：

1. **内功防御**：伤害 = 内功减伤(伤害)
2. **轻功防御**：伤害 = 轻功减伤(伤害)  
3. **招架防御**：伤害 = 招架减伤(伤害)
4. **护甲防御**：伤害 = 护甲减伤(伤害)
5. **武技加成**：伤害 = 武技修正(伤害)
6. **武器特效**：伤害 = 武器特效(伤害)

### 2.7 性格修正阶段

```
如果攻击者性格 = "心狠手辣"：
    伤害 += 伤害 × 20%

内伤值 = 伤害
```

**伤害上限修正**：
```
伤害 = {
    (伤害 - 400) / 4 + 300,    伤害 > 400
    (伤害 - 200) / 2 + 200,    200 < 伤害 ≤ 400
    伤害,                      伤害 ≤ 200
}

内伤值 = {
    (内伤值 - 400) / 4 + 300,  内伤值 > 400  
    (内伤值 - 200) / 2 + 200,  200 < 内伤值 ≤ 400
    内伤值,                    内伤值 ≤ 200
}
```

**防御性格修正**：
```
如果目标性格 = "光明磊落"：
    内伤值 -= 内伤值 × 20%
```

### 2.8 特殊效果阶段

**暴击计算**：
```
暴击率 = 攻击者暴击 - 目标抗暴 + 临时暴击加成

根据金元素数量调整：
- 金元素 ≥ 12：暴击率 +5，周期性 +40
- 金元素 ≥ 8：暴击率 +4，周期性 +30  
- 金元素 ≥ 4：暴击率 +3

如果暴击率 > 随机(150)：
    暴击倍率 = 2.0 + 暴击伤害加成/100
    如果12金且随机(100) < 10：
        暴击倍率 += 0.5
    伤害 = 伤害 × 暴击倍率
```

**吸血效果**：
```
如果当前时间 > 吸血冷却 且 吸血百分比 > 0：
    吸血量 = 伤害 × 吸血百分比 / 100
    攻击者气血 = min(最大气血, 当前气血 + 吸血量)
```

### 2.9 伤害结算

```
最终伤害 = 战斗系统伤害计算(伤害)
最终内伤 = 战斗系统内伤计算(内伤值)

目标气血 -= 最终伤害
目标内伤 += 最终内伤
```

## 3. 两套系统的核心差异

### 3.1 计算流程对比

| 阶段 | 单招伤害 | 普攻伤害 |
|------|----------|----------|
| 第一步 | 基础伤害叠加 | 命中判定 |
| 第二步 | 技能防御修正 | 基础伤害计算 |
| 第三步 | 装备防护 | 防御减伤链 |
| 第四步 | 加力计算 | 特殊效果 |
| 第五步 | 力量加成 | 性格修正 |

### 3.2 伤害公式简化

**单招伤害核心**：
```
最终伤害 = 基础伤害 × 防御修正 × 力量修正 × 上限修正 × 百分比
```

**普攻伤害核心**：
```
最终伤害 = 基础伤害 × 加成修正 × 防御链 × 暴击修正 × 性格修正
```

### 3.3 随机性特点

- **单招伤害**：确定性强，随机性主要来源于防御技能效果
- **普攻伤害**：随机性强，包含命中、伤害、防御、暴击等多重随机判定

### 3.4 设计理念

- **单招伤害**：精确控制，技能配合，稳定输出
- **普攻伤害**：随机变化，连续输出，爆发潜力

## 4. 结论

两套伤害系统通过不同的数学模型实现差异化设计：

- 单招系统注重**可预测性**和**技能策略**
- 普攻系统注重**随机性**和**持续输出**  
- 伤害上限机制确保**游戏平衡**
