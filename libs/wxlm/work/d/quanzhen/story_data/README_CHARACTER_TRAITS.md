# 统一品格系统说明

## 概述
为了解决原有品格类型混乱的问题，现已建立统一的品格系统，将所有品格类型约束为6种标准品格。

## 标准品格类型

### 1. brave（勇敢）
- **显示名称**：勇敢
- **描述**：面对危险和困难时展现的无畏精神
- **颜色代码**：HIR（高亮红色）
- **别名**：bold, fearless, decisive

### 2. wise（智慧）
- **显示名称**：智慧
- **描述**：善于思考和分析，能够洞察事物本质
- **颜色代码**：HIB（高亮蓝色）
- **别名**：intelligent, analytical, strategic, detective

### 3. compassionate（仁慈）
- **显示名称**：仁慈
- **描述**：对他人的苦难和需要表现出的关怀之心
- **颜色代码**：HIY（高亮黄色）
- **别名**：merciful, kind, helpful

### 4. cautious（谨慎）
- **显示名称**：谨慎
- **描述**：行事小心，深思熟虑，不鲁莽冒进
- **颜色代码**：HIC（高亮青色）
- **别名**：careful, prudent, vigilant

### 5. cunning（机敏）
- **显示名称**：机敏
- **描述**：善于运用智谋和技巧解决问题
- **颜色代码**：HIM（高亮洋红色）
- **别名**：clever, resourceful, tactical, practical

### 6. noble（高尚）
- **显示名称**：高尚
- **描述**：品格高洁，不为私利所动
- **颜色代码**：HIW（高亮白色）
- **别名**：honorable, righteous, selfless

## 使用规范

### 在故事配置中
- 所有 `choices` 数组中的 `type` 字段必须使用标准品格名称
- 所有 `effects` 映射中的键必须使用标准品格名称
- 不再支持旧的混乱品格名称

### 分数范围
- **极其缺乏**：-50 ~ -21
- **明显不足**：-20 ~ -6
- **略有不足**：-5 ~ -1
- **普通水平**：0 ~ 9
- **略有体现**：10 ~ 24
- **明显突出**：25 ~ 49
- **极为突出**：50 ~ 100

## 自动转换
系统会自动将旧的品格类型转换为标准类型：
- `bold` → `brave`
- `strategic` → `wise`
- `practical` → `cunning`
- `prudent` → `cautious`
- 等等...

## 配置文件
- **品格配置**：`/d/quanzhen/story_data/character_traits.json`
- **故事配置**：`/d/quanzhen/story_data/wushan_qiyu.json`

## 注意事项
1. 新增故事时，请严格按照6种标准品格类型设计选择和效果
2. 品格效果值建议控制在 -20 到 50 之间
3. 重要的品格选择可以给予更高的分值（如仁慈选择给予20-25分）
4. 系统会在发现无效品格类型时输出警告信息
