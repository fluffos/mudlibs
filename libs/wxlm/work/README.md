# 武侠黎明(wxlm)

一套基于 FluffOS(LPC)的中文武侠 MUD mudlib 源码。

## 前言

这里承载的,是「武侠黎明」开发团队与玩家们共同积攒下的一些基石与经验。

无数个日夜里,一行行代码敲下又重写;玩家们在江湖中来来往往——闯荡、论剑、相逢与别离,都沉淀进了这套源码的每一处细节里。

如今将它开源,不为别的,只希望这些基石与经验,能为 MUD 开发爱好者们提供一些参考意义。

江湖路远,薪火相传。愿每一位心怀武侠梦的开发者,都能从这里带走一点火光。
