# 冲脉丹自选宝箱使用说明

## 文件位置
`/clone/box/chongmai/chongmai_zixuan_box.c`

## 功能说明
冲脉丹自选宝箱允许玩家从四种不同等级的冲脉丹中选择一种：

1. **下品冲脉丹 × 160** - 适合冲击前5个经脉
2. **中品冲脉丹 × 80** - 适合冲击第二排的5个经脉  
3. **上品冲脉丹 × 40** - 适合冲击第三排的经脉
4. **极品冲脉丹 × 20** - 适合冲击最后的4个经脉

## 使用方法

### 基本操作
1. 获得冲脉丹自选宝箱后，查看箱子描述了解选项
2. 使用命令 `select 1|2|3|4` 选择对应的冲脉丹类型
3. 系统会自动发放对应数量的冲脉丹到玩家背包

### 命令说明
- `select 1` - 选择下品冲脉丹 × 160
- `select 2` - 选择中品冲脉丹 × 80
- `select 3` - 选择上品冲脉丹 × 40
- `select 4` - 选择极品冲脉丹 × 20

### 注意事项
- 每个自选宝箱只能使用一次
- 必须先拿起自选宝箱才能使用
- 战斗中无法使用自选宝箱
- 选择后无法更改，请谨慎选择

## 技术实现
- 继承自 `COMBINED_ITEM`
- 支持数量叠加和自动加载
- 使用 `select` 命令进行交互
- 自动销毁已使用的自选宝箱
