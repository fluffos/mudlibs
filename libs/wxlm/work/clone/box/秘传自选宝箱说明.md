# 秘传自选宝箱系统说明

## 概述

秘传自选宝箱系统允许玩家从五种不同的秘传宝箱中选择一种，每种宝箱都有机会获得对应的秘传传承。这个系统为玩家提供了更多的选择自由度，让玩家可以根据自己的需求和偏好来获取特定的秘传传承。

## 宝箱类型

- **传承等级**: 九曜级别

- **传承等级**: 七曜级别

## 使用方法

### 基本操作
1. **获取宝箱**: 通过游戏活动、充值奖励或积分商店获得秘传自选宝箱
2. **打开宝箱**: 直接使用宝箱物品，会弹出选择弹窗
3. **选择宝箱**: 在弹窗中点击按钮选择想要的秘传宝箱类型
4. **获得宝箱**: 系统自动发放选择的秘传宝箱到背包

### 弹窗界面
- **弹窗显示**: 使用popup_comb弹窗显示所有可选宝箱
- **按钮格式**: 宝箱名称(秘传名称):select_mizhuan 类型
- **交互方式**: 点击弹窗按钮即可完成选择

### 命令操作
- **打开选择界面**: 直接使用秘传自选宝箱
- **命令选择**: `select_mizhuan <类型>` 
  - `select_mizhuan dugu` - 选择独孤宝藏
  - `select_mizhuan taiji` - 选择太极宝藏
  - `select_mizhuan yinwuji` - 选择阴无极宝藏
  - `select_mizhuan yangwuji` - 选择阳无极宝藏
  - `select_mizhuan kuihua` - 选择葵花宝藏

## 秘传获取机制

### 概率系统
- **基础概率**: 每个秘传宝箱有1%的概率直接获得对应秘传传承
- **机缘系统**: 未获得秘传时，机缘点+1
- **保底机制**: 机缘点达到100时，必定获得对应秘传传承
- **触发概率**: 40%概率触发秘传机缘判定

### 额外奖励
每个秘传宝箱除了秘传传承外，还会获得以下物品：
- **70%概率**: 百家宝匣
- **30%概率**: 先学遗训图谱
- **50%概率**: 单抽卡片

## 使用限制

### 基本限制
- **等级要求**: 玩家等级必须达到100级
- **状态限制**: 战斗中或忙碌状态下无法使用
- **持有要求**: 必须持有宝箱才能使用
- **负重检查**: 背包负重必须足够容纳新物品

### 数量限制
- **宝箱消耗**: 每次选择消耗一个秘传自选宝箱
- **绑定物品**: 宝箱为绑定物品，无法交易
- **自动加载**: 支持自动加载和数量叠加

## 技术实现

### 继承关系
- **主宝箱**: 继承自 `COMBINED_ITEM`
- **子宝箱**: 各秘传宝箱均继承自 `COMBINED_ITEM`
- **支持功能**: 数量叠加、自动加载、绑定属性

### 核心函数

#### `get_mizhuan_info(string type)`
- **功能**: 获取指定类型秘传宝箱的详细信息
- **参数**: type - 宝箱类型标识
- **返回**: mapping - 包含名称、文件路径、描述等信息

#### `do_select_mizhuan(string arg)`
- **功能**: 处理玩家的宝箱选择逻辑
- **参数**: arg - 选择的宝箱类型
- **返回**: int - 1表示成功处理
- **逻辑**: 安全检查 → 验证类型 → 创建宝箱 → 移动到玩家背包

#### `do_effect(object me)`
- **功能**: 显示弹窗选择界面
- **参数**: me - 使用宝箱的玩家
- **返回**: int - 1表示成功处理
- **界面**: 使用popup_comb弹窗展示所有可选宝箱和选择按钮

### 秘传系统集成
- **秘传管理**: 调用 `MIZHUAN_MASTER` 进行秘传传承管理
- **机缘系统**: 通过玩家属性 `mizhuan_jiyuan/<秘传名称>` 记录机缘点
- **重复检查**: 防止玩家重复获得相同秘传传承

## 安全机制

### 输入验证
- **类型验证**: 严格验证选择的宝箱类型是否有效
- **对象验证**: 检查玩家对象和宝箱对象的有效性
- **数量验证**: 确保宝箱数量足够进行选择

### 状态检查
- **战斗状态**: 战斗中无法使用宝箱
- **忙碌状态**: 忙碌时无法进行选择操作
- **等级限制**: 100级以下玩家无法使用
- **负重检查**: 确保背包空间足够

### 错误处理
- **无效选择**: 提供清晰的错误提示和可选类型列表
- **创建失败**: 宝箱创建失败时给出明确提示
- **权限检查**: 确保只有持有者可以使用宝箱

## 配置说明

### 宝箱属性
- **基础价值**: 80000（比单个秘传宝箱更高）
- **元宝价值**: 4000（反映其稀有性）
- **重量**: 1（便于携带）
- **绑定属性**: 不可出售、不可丢弃

### 概率配置
所有概率都可以通过修改对应宝箱文件进行调整：
- **秘传概率**: 1%（可在各宝箱文件中修改）
- **触发概率**: 40%（可在各宝箱文件中修改）
- **物品概率**: 70%百家宝匣，50%单抽卡

## 维护说明

### 添加新宝箱
1. 在 `/clone/baoxiang/` 目录下创建新的宝箱文件
2. 在 `get_mizhuan_info()` 函数中添加新的case分支
3. 在 `do_effect()` 函数中添加新的选择界面
4. 更新帮助文档和说明信息

### 修改概率
- **秘传概率**: 修改各宝箱文件中的 `random(100) < 1` 部分
- **触发概率**: 修改各宝箱文件中的 `random(100) < 40` 部分
- **物品概率**: 修改各宝箱文件中对应的随机判定

### 调试建议
- **测试边界**: 重点测试等级边界、数量边界等特殊情况
- **状态测试**: 测试各种玩家状态下的使用限制
- **概率验证**: 通过大量测试验证概率设置的合理性
- **性能监控**: 关注宝箱使用的性能影响

## 注意事项

1. **数据一致性**: 确保秘传名称在所有相关文件中保持一致
2. **版本兼容**: 新增功能时注意与现有系统的兼容性
3. **平衡性**: 定期评估各秘传传承的获取难度和游戏平衡
