# 五脏材料自选宝箱系统说明

## 概述

五脏材料自选宝箱是武圣系统的配套功能，允许玩家自选所需的五脏炼体材料，为武圣之躯的修炼提供便利。

## 宝箱信息

### 基本属性
- **文件位置**: `/clone/box/wuzang/wuzang_zixuan_box.c`
- **物品名称**: 五脏材料自选宝箱
- **颜色标识**: 黄色 (HIY)
- **绑定属性**: 绑定物品，无法交易
- **价值**: 100000铜钱，3000元宝

## 使用方法

### 基本操作
1. **获取宝箱**: 通过游戏活动或充值获得
2. **打开宝箱**: 直接使用宝箱物品
3. **选择材料**: 在弹出的界面中选择需要的五脏材料
4. **确认获得**: 系统自动发放对应材料到背包

### 命令操作
- **打开宝箱**: 直接使用宝箱物品
- **选择材料**: `select <材料类型>` (如: `select xuecanguo`)

### 材料代码对照
- `xuecanguo` - 血参果
- `longgan` - 龙肝草
- `dipi` - 地脾黄
- `tianfei` - 天肺莲
- `xianshen` - 仙肾石

## 技术实现

### 继承关系
- 继承自 `COMBINED_ITEM`
- 支持数量叠加和自动加载

### 核心函数
- `get_material_info()`: 获取材料信息映射
- `do_select()`: 处理材料选择逻辑
- `do_effect()`: 宝箱开启效果和界面显示
- `init()`: 初始化选择动作

### 材料创建
- 使用 `new_bind()` 创建绑定材料
- 自动设置材料数量为10个
- 支持负重检查和移动验证

## 安全机制

### 使用限制
- 战斗中无法使用
- 忙碌状态下无法使用
- 必须持有宝箱才能使用
- 负重不足时无法获得材料

### 输入验证
- 严格验证材料类型参数
- 防止无效选择和错误输入
- 提供清晰的错误提示信息

## 与武圣系统的关联

### 五脏对应关系
- **心脏**: 血参果 → 提升气血上限、气血恢复
- **肝脏**: 龙肝草 → 提升内力极限、内力恢复
- **脾脏**: 地脾黄 → 提升精力极限、悟性加成
- **肺脏**: 天肺莲 → 提升轻功等级、身法加成
- **肾脏**: 仙肾石 → 提升根骨加成、暴击伤害

### 炼体等级体系
- **初炼期** (1-20级): 基础材料需求
- **小成期** (21-50级): 中等材料需求
- **大成期** (51-80级): 高级材料需求
- **圆满期** (81-100级): 大量材料需求

## 边界条件测试

### 测试场景
1. **无效选择**: 输入不存在的材料类型
2. **状态检查**: 战斗、忙碌状态下的使用限制
3. **负重限制**: 背包满载时的处理
4. **数量验证**: 宝箱数量为0时的处理
5. **材料创建**: 材料文件不存在时的错误处理

### 预期结果
- 所有边界条件均应正确处理
- 错误提示信息清晰明确
- 不会出现材料重复获得或丢失

## 注意事项

1. **固定数量**: 每次选择固定获得10个材料
2. **绑定物品**: 所有获得的材料都是绑定状态
3. **一次性使用**: 每次选择会消耗一个宝箱
4. **材料价值**: 所有五脏材料价值相同（50000铜钱）
5. **存储建议**: 建议根据当前炼体需求选择对应材料

## 维护说明

- 如需修改材料数量，请更新 `get_material_info()` 中的 `amount` 值
- 如需添加新材料，请在材料信息映射中添加对应条目
- 所有修改都应进行充分测试，确保材料路径正确
- 注意保持与武圣系统材料文件的一致性
