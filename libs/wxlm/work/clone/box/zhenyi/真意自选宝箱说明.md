# 真意自选宝箱系统说明

## 概述

本系统实现了三种真意自选宝箱，允许玩家根据自己的等级选择合适的真意等级和品质。

## 宝箱类型

### 1. 红色真意自选宝箱 (red_zixuan_box.c)
- **文件位置**: `/clone/box/zhenyi/red_zixuan_box.c`
- **真意品质**: 玄奥真意
- **颜色标识**: 红色 (HIR)
- **适用场景**: 中等品质真意需求

### 2. 黄色真意自选宝箱 (yellow_zixuan_box.c)
- **文件位置**: `/clone/box/zhenyi/yellow_zixuan_box.c`
- **真意品质**: 灵犀真意
- **颜色标识**: 黄色 (HIY)
- **适用场景**: 基础品质真意需求

### 3. 紫色真意自选宝箱 (purple_zixuan_box.c)
- **文件位置**: `/clone/box/zhenyi/purple_zixuan_box.c`
- **真意品质**: 真武真意
- **颜色标识**: 紫色 (HIB)
- **适用场景**: 最高品质真意需求

## 等级限制规则

### 核心规则
- **可选等级上限**: 玩家当前等级的整百数
- **等级范围**: 100-600级之间的整百等级
- **可选等级**: 100级、200级、300级、400级、500级、600级

### 示例说明
- 玩家等级为 **643级** 时，可选最高等级为 **600级**
- 玩家等级为 **250级** 时，可选最高等级为 **200级**
- 玩家等级为 **99级** 时，可选最高等级为 **100级**（最低保障）
- 玩家等级为 **700级** 时，可选最高等级为 **600级**（上限限制）

## 使用方法

### 基本操作
1. **获取宝箱**: 通过游戏活动或充值获得
2. **打开宝箱**: 直接使用宝箱物品
3. **选择等级**: 在弹出的界面中选择想要的真意等级
4. **确认获得**: 系统自动发放对应等级和品质的真意

### 命令操作
- **打开宝箱**: 直接使用宝箱物品
- **选择等级**: `select_level <等级>` (如: `select_level 300`)

## 技术实现

### 继承关系
- 所有宝箱均继承自 `COMBINED_ITEM`
- 支持数量叠加和自动加载

### 核心函数
- `calculate_max_zhenyi_level()`: 计算玩家可选最高等级
- `get_available_levels()`: 获取可选等级列表
- `do_select_level()`: 处理等级选择逻辑
- `do_effect()`: 宝箱开启效果和界面显示

### 真意发放
- 调用 `/system/wusheng/zhenyi_master` 的 `drop_zhenyi_to_player()` 函数
- 严格按照等级限制规则进行验证
- 支持不同品质的真意发放

## 安全机制

### 使用限制
- 必须达到100级才能使用
- 战斗中无法使用
- 忙碌状态下无法使用
- 必须持有宝箱才能使用

### 等级验证
- 严格验证选择的等级是否在允许范围内
- 动态计算可选等级上限
- 防止越级获取真意

## 边界条件测试

### 测试场景
1. **等级边界**: 玩家等级刚好为整百数时的情况
2. **最低等级**: 玩家等级低于100级的处理
3. **最高等级**: 玩家等级超过600级的限制
4. **无效选择**: 选择超出范围等级的错误处理
5. **状态检查**: 战斗、忙碌状态下的使用限制

### 预期结果
- 所有边界条件均应正确处理
- 错误提示信息清晰明确
- 不会出现越级获取真意的情况

## 注意事项

1. **等级计算**: 使用向下取整到百位数的方式计算可选上限
2. **品质固定**: 每种颜色的宝箱对应固定的真意品质
3. **一次性使用**: 每次选择会消耗一个宝箱
4. **绑定物品**: 宝箱为绑定物品，无法交易
5. **数量显示**: 支持显示当前拥有的宝箱数量

## 维护说明

- 如需修改等级范围，请同时更新三个宝箱文件中的相关逻辑
- 如需添加新的真意品质，请参考现有实现方式
- 所有修改都应进行充分的测试，特别是边界条件
