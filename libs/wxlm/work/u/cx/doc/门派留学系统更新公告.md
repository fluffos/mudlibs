## 🎯 功能概述

**门派留学系统** 是一个全新的多门派学习机制，允许玩家在保持主门派身份的同时，前往其他门派学习武艺，体验不同门派的武学精髓。

### ✨ 核心特性
- 🏛️ **多门派学习**：可同时隶属多个门派
- 📚 **技能请教**：直接向留学门派师父请教技能
- 👨‍🏫 **简化拜师**：留学门派拜师无需复杂条件
- 🛡️ **信息保护**：主门派信息完全不受影响
- ⚠️ **职责边界**：只提供学习途径，不处理技能使用限制

## 🔧 系统机制

### 📊 等级要求
| 等级范围 | 可用门派数量 | 解锁槽位 |
|---------|-------------|---------|
| 1-299级 | 1个（主门派） | family |
| 300-499级 | 2个 | family + family_2 |
| 500-699级 | 3个 | family + family_2 + family_3 |
| 700-899级 | 4个 | family + family_2 + family_3 + family_4 |
| 每+200级 | +1个门派槽位 | 依此类推 |

### 🎓 学习方式

#### 方式一：直接请教技能（推荐）
```
xue <师父名称> <技能名称> <次数>
```
- ✅ **无需拜师**：留学后直接可以请教
- ✅ **操作简单**：一步到位
- ✅ **效率高**：省去拜师流程
- ⚠️ **潜能倍数**：根据门派优先级调整消耗

#### 方式二：传统拜师学习
```
bai <师父名称> as shi
```
- ✅ **深度学习**：获得正式师父指导
- ✅ **师徒关系**：建立留学门派师徒关系
- ✅ **信息安全**：不影响主门派信息

#### 方式三：技能研究提升
```
yanjiu <技能名称> <提升等级>
```
- 🔬 **深入研究**：200级以上技能可通过研究提升
- 🎯 **精确控制**：可指定提升到目标等级
- ⚠️ **倍数机制**：留学门派技能研究也受倍数影响

### 💰 潜能消耗机制

**门派优先级倍数系统**：根据门派在您学习序列中的位置，调整潜能消耗倍数

| 门派类型 | 优先级 | 潜能消耗倍数 | 示例说明 |
|---------|-------|-------------|---------|
| 主门派 | 第1门派 | 1倍（正常） | 武当派弟子学太极拳 |
| 第一留学门派 | 第2门派 | 2倍 | 武当弟子留学少林学金刚拳 |
| 第二留学门派 | 第3门派 | 3倍 | 武当弟子留学峨嵋学峨嵋剑法 |
| 第三留学门派 | 第4门派 | 4倍 | 武当弟子留学华山学华山剑法 |

**计算公式**：`实际潜能消耗 = 基础潜能消耗 × 门派优先级`

**适用范围**：
- 📚 **技能请教**：`xue` 命令学习技能
- 🔬 **技能研究**：`yanjiu` 命令研究技能
- ⚖️ **一致原则**：学习和研究使用相同倍数机制

**设计理念**：
- 🎯 **鼓励专精**：主门派学习成本最低
- ⚖️ **平衡机制**：防止无限制学习所有门派
- 📈 **递增成本**：越多门派，学习成本越高

## 🚀 使用指南

### 第一步：进入留学系统
```
指令：new_family
```
在主门派界面点击 **"门派留学"** 建筑

### 第二步：申请留学
1. 确认等级达到300级
2. 选择想要留学的门派
3. 点击 **"📚 门派名称"** 申请留学

### 第三步：开始学习

#### 🎯 直接请教（推荐）
```bash
# 示例：向少林清法比丘请教金刚拳
xue qingfa jingang-quan 5

# 示例：向武当谷虚道长请教太极拳  
xue guxu taiji-quan 3
```

#### 🎯 正式拜师
```bash
# 前往留学门派找到合适的师父
go_family_npc 清法比丘

# 拜师（留学身份会简化条件）
bai qingfa as shi
```

## ⚠️ 重要注意事项

### 🛡️ 数据安全保障
- **主门派信息完全保护**：留学不会影响原门派身份
- **独立师父关系**：留学拜师建立独立的师徒关系
- **技能学习分离**：各门派技能独立学习和提升

### 🚨 技能使用限制说明
**重要提醒**：留学系统只负责技能学习，不改变技能本身的使用规则！

#### 🔒 门派身份限制
- **主门派专属技能**：某些技能可能要求主门派身份才能使用
- **门派冲突检测**：部分技能间存在互斥关系，系统会自动处理
- **属性要求检查**：技能使用仍需满足原有的属性、等级、装备等要求

#### ⚖️ 技能兼容性
- **正邪冲突**：正派技能与邪派技能可能无法同时使用
- **内功冲突**：不同门派的内功可能存在冲突，需要手动切换
- **技能覆盖**：学习新技能可能会覆盖或影响已有技能

#### 🧩 搭配策略
- **自主研究**：技能搭配和使用策略需要玩家自行探索
- **实战验证**：建议在安全环境下测试技能组合效果
- **灵活调整**：根据实际情况调整技能配置和门派选择

**系统职责边界**：
- ✅ **提供学习途径**：绕过拜师限制，开放技能学习
- ✅ **记录学习信息**：追踪技能来源和学习历史  
- ✅ **计算潜能消耗**：应用合理的成本倍数机制
- ❌ **不负责技能兼容**：技能间的冲突和限制由原系统处理
- ❌ **不修改使用规则**：技能的使用条件和效果保持不变

### 📝 使用限制
- **等级要求**：必须达到300级才能开始留学
- **槽位限制**：每200级只能增加一个门派槽位
- **技能上限**：通过请教提升的武学技能最高200级

### 💡 最佳实践
1. **先留学，后学习**：建议先申请留学再开始学技能
2. **合理规划**：根据自己的发展方向选择留学门派
3. **技能搭配**：注意不同门派技能的兼容性
4. **渐进学习**：优先学习基础技能，避免高风险冲突
5. **测试验证**：在安全环境下测试新学技能的效果
6. **成本意识**：考虑潜能倍数，优先学习最需要的技能
7. **备用方案**：准备多套技能配置以应对不同情况
8. **关注反馈**：留意系统提示和其他玩家的经验分享

```bash
500级：主门派（武当） + 留学（少林）+ 留学（峨嵋）

- 少林技能：双倍消耗（2x）

700级：主门派（武当） + 留学（少林）+ 留学（峨嵋）+ 留学（华山）
- 武当技能：正常消耗（1x）
- 少林技能：双倍消耗（2x）
- 峨嵋技能：三倍消耗（3x）
- 华山技能：四倍消耗（4x）

💡 建议：合理规划学习顺序，优先学习最重要的留学门派技能
```

### 示例3：技能冲突处理案例
```bash
场景：武当弟子留学少林，学习冲突技能

# 成功案例
```
