# 🚨 脱离门派系统更新说明

## 📅 更新时间
**版本：** v2.1  
**发布日期：** 2025年1月  

---

## 🎯 更新概述

针对门派留学系统，我们完善了脱离门派功能，确保玩家在脱离门派时能够彻底清除所有相关信息，避免数据残留问题。

---

## ✨ 更新内容

### 1. 🏛️ 清除留学门派信息
- **功能说明**：脱离门派时自动清除所有留学门派关系
- **清除范围**：`family_2`, `family_3`, `family_4`, ... 等所有留学门派槽位
- **智能识别**：自动检测并清除所有形如 `family_N` 的留学门派数据
- **用户反馈**：清除过程中提供详细的提示信息

### 2. 📚 清除技能学习记录
- **功能说明**：彻底清除所有从留学门派学习的技能记录
- **清除范围**：所有 `family_N/learned_skills` 相关的数据
- **记录追踪**：清除所有技能学习历史、师父信息、学习时间等
- **数据完整性**：确保不残留任何留学相关的学习痕迹

### 3. 🔧 多门派管理器增强
- **新增函数**：`clear_all_learning_records(object player)`
- **功能用途**：专门用于清除玩家的所有技能学习记录
- **安全机制**：只清除留学门派相关记录，保护主门派数据
- **返回详情**：提供清除操作的详细统计信息

## 🔍 技术实现

### 核心修改文件
1. **`cmds/usr/new_family.c`** - 脱离门派主逻辑
2. **`adm/special_ob/multi_family/multi_family_master.c`** - 多门派管理器

### 脱离门派流程
```
1. 检查门派状态
2. 清除所有留学门派信息 (family_2, family_3, ...)
3. 清除所有技能学习记录 (family_N/learned_skills/*)
4. 清除技能（保留抽奖技能）
5. 返还潜能
6. 清除主门派信息
7. 发布脱离公告
```

### 数据清除机制
```javascript
// 留学门派信息清除
{
  "family_2": null,     // 第一留学门派
  "family_3": null,     // 第二留学门派
  "family_4": null,     // 第三留学门派
  // ... 所有 family_N 槽位
}

// 技能学习记录清除
{
  "family_2/learned_skills": null,           // 第一留学门派所有技能记录
  "family_2/learned_skills/jingang-quan": null,  // 具体技能记录
  "family_3/learned_skills": null,           // 第二留学门派所有技能记录
  // ... 所有相关记录
}
```

## ⚠️ 重要注意事项

### 🔒 数据安全
- **主门派保护**：脱离操作不会影响主门派信息
- **抽奖技能保护**：通过抽奖获得的技能会被保留（最高180级）
- **武学修养保护**：武学修养技能不会被清除

### 🛡️ 清除范围
- **✅ 会被清除**：
  - 所有留学门派信息（family_2, family_3, ...）
  - 所有留学门派技能学习记录
  - 门派相关的普通技能（非抽奖）
  
- **❌ 不会清除**：
  - 主门派信息（family）
  - 抽奖获得的技能（保留至180级）
  - 武学修养等特殊技能
  - 角色基本属性

### 💰 潜能返还机制
- **返还比例**：按照脱离次数递减
  - 1-5次：100%-60%（每次递减10%）
  - 6-10次：固定50%
  - 超过10次：不返还
- **计算基础**：基于已使用的潜能总量
