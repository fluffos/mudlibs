# 游戏登录注册流程文档

## 一、概述

本文档详细说明了游戏的登录注册流程，包括前后端交互的数据格式、验证机制和完整的流程步骤。

## 二、数据交互格式

### 2.1 通用响应格式

所有服务器响应均采用JSON格式：

```json
{
  "code": 200,      // 状态码：200成功，405错误
  "msg": "消息内容"  // 提示信息
}
```

**关键函数：**
- `login_result(int code, string msg)` - 成功响应（logind.c:104-112）
- `error_result(string msg)` - 错误响应（logind.c:85-101）

### 2.2 客户端请求格式

#### 登录请求格式
```
账号║║密码║手机号║ip地址║验证码║验证码起始位置
```

**字段说明：**
- `账号`：4-20位英文字母开头，可包含数字和下划线
- `密码`：用户密码
- `手机号`：用户手机号
- `ip地址`：客户端IP地址
- `验证码`：包含10位数字的验证码字符串
- `验证码起始位置`：验证码在字符串中的起始下标

**示例：**
```
demodemo║asd123║17808080808║127.0.0.1║abc1234567890def║3
```

#### 注册/创建角色请求格式
```
性别║昵称║出生地点║天赋║属性(力量,悟性,根骨,身法)║性格║流派
```

**字段说明：**
- `性别`：男/女
- `昵称`：2-4个汉字
- `出生地点`：如"关外人氏"、"欧阳世家"等
- `天赋`：如"速行"、"好运"等（中文名称）
- `属性`：四项属性用逗号分隔，总和必须为80，每项10-30
- `性格`：如"光明磊落"、"狡黠多变"等
- `流派`：如"自主流"、"沧海九剑流"、"极道降龙流"

**示例：**
```
男║张三║关外人氏║好运║20,20,20,20║光明磊落║自主流
```

## 三、完整登录流程

### 3.1 连接建立阶段

**流程：**
1. 客户端连接到服务器
2. 服务器调用 `logon(object ob)` 函数（logind.c:120-133）

**处理步骤：**
```
1. 检查IP是否被封禁（BAN_D->is_banned()）
   - 如果被封禁：返回错误并断开连接

2. 发送连接确认消息
   - 返回：{"code":200, "msg":"正在等待连接确认..."}

3. 等待客户端输入（调用input_to("jiance")）
```

### 3.2 验证阶段

**入口函数：** `jiance(string arg, object ob, string str)` (logind.c:135-141)

直接调用 `get_user(arg, ob)` 进行验证

### 3.3 账号密码验证阶段

**核心函数：** `get_user(string arg, object ob)` (logind.c:143-390)

#### 步骤1：格式验证
```
1. 检查输入是否为空
2. 解析输入字符串（用"║"分隔）
3. 验证字段数量（至少4个字段）
```

#### 步骤2：维护时间检查
```
if (time() < 1735646400 && 账号 != "demodemo") {
    返回错误："正在维护中，请在20:00后登录"
}
```

#### 步骤3：账号合法性检查
```
1. 调用 check_legal_id() 验证账号格式（logind.c:869-896）
   - 长度：4-20位
   - 格式：英文字母开头，可包含数字和下划线

2. 转换为小写
```

#### 步骤4：封禁检查
```
调用 BAN_D->is_user_banned(账号)
如果被封禁：返回封禁原因
```

#### 步骤5：权限等级检查
```
if (wiz_level(账号) < wiz_lock_level) {
    返回错误："正在维护中"
}
```

#### 步骤6：验证码验证（非测试账号）

**豁免账号：** demo222, demo123, demodemo, sxpcgq7zsgw0, demo7788

**验证规则：**
```
1. 字段数量检查（至少6个字段）

2. 长度检查
   if (strlen(验证码字符串) + 1 < 验证码起始位置) {
       拒绝连接，错误码:00
   }

3. 提取验证码（从起始位置开始，提取10位）
   验证码 = 验证码字符串[起始位置..起始位置+9]

4. 重复使用检查
   if (验证码 in yz_msg_list) {
       拒绝连接，错误码:11
   }

5. 长度检查
   if (strlen(验证码) != 10) {
       拒绝连接，错误码:22
   }

6. 偶数位累加验证
   sum = 0
   for (i = 0; i < 10; i++) {
       if ((i + 1) % 2 == 0) {  // 偶数位（下标1,3,5,7,9）
           sum += 验证码[i]的数值
       }
   }
   if (sum != 20) {
       拒绝连接，错误码:33
   }

7. 记录已使用的验证码
   yz_msg_list += 验证码

8. 清理机制
   if (sizeof(yz_msg_list) > 500) {
       yz_msg_list = ({})
   }
```

**验证码示例：**
```
验证码字符串："abc1234567890def"
起始位置：3
提取结果："1234567890"
偶数位：2(下标1) + 4(下标3) + 6(下标5) + 8(下标7) + 0(下标9) = 20 ✓
```

#### 步骤7：密码验证

**新用户：**
```
1. 文件不存在：设置默认body为USER_OB
2. 跳转到步骤8
```

**老用户：**
```
1. 恢复用户数据（ob->restore()）
2. 验证密码
   if (crypt(密码, 已保存密码) != 已保存密码) {
       返回错误："角色密码错误"
   }
```

#### 步骤8：密码加密保存
```
保存加密后的密码：crypt(密码, 0)
```

#### 步骤9：重连/新登录判断

**重连情况：**
```
if (find_body(账号)) {
    1. 踢掉旧连接
    2. 返回：{"code":200, "msg":"登录成功"}
    3. 调用 reconnect(ob, user)
    退出流程
}
```

**新登录情况：**
```
1. 创建用户对象 make_body(ob)
2. 尝试恢复存档
   - 成功：返回登录成功，调用 enter_world()
   - 失败：返回错误
3. 如果存档不存在：
   - 返回：{"code":200, "msg":"建立角色"}
   - 等待角色创建输入（调用input_to("get_char")）
```

## 四、角色创建流程

**核心函数：** `get_char(string arg, object ob)` (logind.c:392-601)

### 4.1 输入等待
```
if (arg为空或"wait") {
    返回：{"code":200, "msg":"等待输入角色名中"}
    继续等待输入
}
```

### 4.2 格式验证
```
1. 解析输入（用"║"分隔）
2. 验证字段数量（必须7个字段）
```

### 4.3 天赋映射转换

**天赋映射表：**（logind.c:400-423）
```
"速行" -> "agile"
"好运" -> "lucky"
"天生真气" -> "mystery"
... 等22种天赋
```

### 4.4 流派检查

**预设流派：**（logind.c:20-31）
```
if (流派 != "自主流") {
    从liupai映射表中获取：
    - 天赋
    - 属性分配
    - 性格
    覆盖用户输入
}
```

**流派配置示例：**
```
"沧海九剑流": {
    "天赋": "lucky",
    "属性": "13,29,25,13",
    "性格": "狡黠多变"
}
```

### 4.5 昵称验证
```
调用 check_legal_name(昵称, 8)（logind.c:898-917）
1. 长度：2-4个字符
2. 必须是中文
3. 调用 NAME_D->invalid_new_name() 检查是否重名/违规
```

### 4.6 出生地和姓氏设置

**世家系统：**（logind.c:49-64）
```
if (born[出生地点] 是映射) {
    设置：
    - 姓氏：born[出生地点]["surname"]
    - 出生地：born[出生地点]["born"]
    - 初始房间：born[出生地点]["startroom"]
    完整姓名 = 姓氏 + 昵称
}
else {
    直接使用出生地点
}
```

**世家示例：**
```
"欧阳世家": {
    "born": "西域人氏",
    "surname": "欧阳",
    "startroom": "/d/baituo/dating"
}
```

### 4.7 属性验证
```
1. 解析属性字符串（用","分隔）
2. 检查数量（必须4个）
3. 验证范围（每项10-30）
4. 验证总和（必须等于80）
```

### 4.8 创建角色对象
```
1. 调用 make_body(ob) 创建用户对象
2. 设置基础属性：
   - 世家信息
   - 出生地
   - 初始房间
   - 天赋
   - 属性（力量、悟性、根骨、身法）
   - 性格
   - 性别（自动转换"男"->"男性"，"女"->"女性"）
   - 福缘、容貌默认10
```

### 4.9 萌新流派特殊处理
```
if (流派 == "沧海九剑流") {
    设置：newbie_guide/family = "华山派"
}
else if (流派 == "极道降龙流") {
    设置：newbie_guide/family = "丐帮"
}
```

### 4.10 初始化新玩家

**调用函数：** `init_new_player(user)` (logind.c:626-652)

```
设置：
1. 称号："普通百姓"
2. 生日：当前时间戳
3. 潜能：99
4. 食物/饮水：(力量 + 10) * 10
5. 频道列表：chat, rumor, party, bill, sos, family, ic, rultra

6. 潜能池计算：
   周数 = (当前时间 - 开服时间) / 604800
   潜能池 = 周数 * 1,300,000

7. 记录名字到NAME_D
8. 设置环境参数（wimpy = 20）
```

### 4.11 进入游戏
```
1. 恢复VIP数据（VIP_D->restore_vdata()）
2. 返回：{"code":200, "msg":"登录成功"}
3. 调用 enter_world(ob, user)
```

## 五、进入世界流程

**核心函数：** `enter_world(object ob, object user, int silent)` (logind.c:654-820)

### 5.1 基础设置
```
1. 设置连接对象
   - user->set_temp("link_ob", ob)
   - ob->set_temp("body_ob", user)

2. 记录IP地址
   - user->set("last_ip", 查询到的IP)

3. 日志记录
   log_file("loginip", "时间:账号从IP进入游戏")
```

### 5.2 执行连接
```
1. exec(user, ob) - 将交互对象切换到user
2. user->setup() - 初始化用户对象
```

### 5.3 新手初始化
```
if (age == 14) {  // 新手
    设置食物和饮水为最大值
}
```

### 5.4 保存和更新
```
1. user->save() - 保存用户数据
2. 设置最后保存时间
3. 执行好友请求（friend_order requests）
4. ob->save() - 保存连接对象

5. 系统更新检查
   - UPDATE_D->check_user(user)
   - TOP_D->map_user(user)
```

### 5.5 天赋系统检查（logind.c:699-718）
```
if (!user->query("special_skill_place")) {
    统计天赋数量

    if (天赋数量 > 1) {
        执行天赋重置补偿（ask_bufa）
    }
    else if (天赋数量 == 1) {
        更新天赋格子
    }
}
```

**补偿规则：**（logind.c:976-1043）
- 3个天赋：60个天赋书 + 600绑定元宝
- 2个天赋：30个天赋书 + 300绑定元宝
- 1个天赋：10个天赋书 + 100绑定元宝
- 所有情况都重置为"tblade"天赋

### 5.6 确定出生位置
```
优先级：
1. 监狱（is_in_prison）-> query_prison()
2. 鬼魂（is_ghost）-> DEATH_ROOM
3. 储物袋2特殊处理 -> "/d/death/block"
4. 用户设置的startroom
5. 默认START_ROOM
```

### 5.7 移动到房间
```
1. 尝试加载目标房间
2. user->move(startroom)
3. 失败则移动到START_ROOM
```

### 5.8 广播进入消息
```
1. 房间内广播："XXX连线进入这个世界。"
2. 系统频道广播："XXX(id)由IP连线进入。"
```

### 5.9 自动装备
```
user->force_me("wear auto")   // 自动穿戴防具
user->force_me("wield auto")  // 自动装备武器
```

### 5.10 延迟任务
```
1. 1秒后：五绝登录通报（announce_wujue_login）
2. 2秒后：显示更新公告（check_and_show_update）
```

## 六、重连流程

**核心函数：** `reconnect(object ob, object user, int silent)` (logind.c:826-867)

### 6.1 基础设置
```
1. 设置连接对象
2. 处理web登录标记
3. 执行重连：exec(user, ob)
4. user->reconnect()
```

### 6.2 广播消息
```
如果不是静默重连且不是隐身巫师：
- 房间内广播："XXX重新连线回到这个世界。"
- 系统频道广播："XXX[id]由IP重新连线进入。"
```

### 6.3 执行命令
```
1. user->force_me("hp1 hp") - 显示状态
2. user->force_me("look") - 查看房间
3. user->force_me("friend_order requests") - 处理好友请求
```

### 6.4 延迟任务
```
1. 1秒后：五绝登录通报
2. 2秒后：显示更新公告
```

## 十、流程图总结

```
连接建立
   ↓
IP封禁检查 → 通过
   ↓
发送确认消息
   ↓
接收登录数据
   ↓
格式验证 → 账号验证 → 封禁检查 → 验证码验证
   ↓
密码验证
   ↓
判断是否重连
   ├─是→ 踢旧连接 → reconnect() → 进入游戏
   └─否→ 检查存档
          ├─有→ enter_world() → 进入游戏
          └─无→ 返回建立角色 → get_char()
                                    ↓
                            验证角色信息
                                    ↓
                            创建角色对象
                                    ↓
                            init_new_player()
                                    ↓
                            enter_world() → 进入游戏
```

## 十一、错误码对照表

| 错误码 | 含义 | 触发条件 |
|--------|------|----------|
| 00 | 验证码格式错误 | 验证码字符串长度不足 |
| 11 | 验证码重复使用 | 验证码已在缓存中 |
| 22 | 验证码长度错误 | 提取的验证码不是10位 |
| 33 | 验证码校验失败 | 偶数位累加不等于20 |

## 十二、注意事项

1. **所有字符串分隔符统一使用"║"**（全角竖线）
2. **验证码机制仅对非测试账号生效**
3. **验证码缓存超过500条时自动清空**
4. **属性总和必须严格等于80**
5. **流派会覆盖用户自选的天赋、属性和性格**
6. **世家会自动添加姓氏前缀**
7. **潜能池根据开服周数动态计算**
8. **新手（14岁）会自动填满食物和饮水**
9. **登录会自动装备防具和武器**
10. **五绝和特殊称号登录会全服通报**
