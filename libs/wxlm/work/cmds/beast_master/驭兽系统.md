# 驭兽系统说明文档

## 系统简介

驭兽系统允许玩家通过驭兽术技能来驯服、控制和使用野兽。玩家可以让野兽跟随、战斗、骑乘等。

## 基础要求

- 需要学习驭兽术(training)技能
- 驭兽术等级需要达到30级才能指挥野兽战斗
- 每次指挥野兽都会消耗精力值

## 指令列表

### 基本指令

| 指令 | 格式 | 说明 |
|------|------|------|
| follow | `follow <野兽名称>` | 让指定野兽跟随主人行动 |
| nofollow | `nofollow [野兽名称]` | 停止指定或所有野兽的跟随状态 |
| attack | `attack <目标>` | 命令野兽攻击目标 |
| stop/ting | `stop <野兽名称>` | 命令野兽停止攻击 |
| release | `release <野兽名称>` | 解除主奴关系,放生野兽 |

### 骑乘指令

| 指令 | 格式 | 说明 |
|------|------|------|
| ride/qi | `ride <坐骑名称>` | 骑乘坐骑 |
| unride/xia | `unride` | 从坐骑上下来 |

## 使用限制

1. 战斗限制
   - 在战斗中不能进行驯兽操作
   - 野兽正在战斗时不能执行其他指令
   - 禁止战斗的地图中不能让野兽攻击

2. 骑乘限制
   - 同一时间只能骑乘一匹坐骑
   - 坐骑被他人骑乘时无法骑乘
   - 坐骑在战斗或忙碌状态下无法骑乘

3. 其他限制
   - 野兽晕倒时无法执行任何指令
   - 野兽忙碌时无法执行新指令
   - 不能攻击年龄小于16岁的玩家

4. 跟随限制
   - 每个玩家最多同时让5只野兽跟随
   - 野兽在战斗中无法切换跟随状态
   - 只能指挥自己驯服的野兽

## 注意事项

1. 精力消耗
   - 每次指挥野兽攻击都会消耗精力值
   - 精力值消耗计算公式: max_jing / (training_level / 10) - 10
   - 精力不足时无法指挥野兽

2. 所有权
   - 野兽必须先被驯服才能使用
   - 每个野兽只能有一个主人
   - 试图控制他人的野兽会导致野兽攻击你

3. 安全建议
   - 在重要场合使用野兽前请确认环境是否允许战斗
   - 注意控制野兽不要误伤他人
   - 保持足够的精力以便随时控制野兽

## 代码维护说明

系统核心文件位于 `cmds/beast_master/` 目录下:
- attack.c: 野兽攻击指令
- nofollow.c: 停止跟随指令
- release.c: 放生指令
- ride.c: 骑乘指令
- ting.c: 停止战斗指令
- unride.c: 下坐骑指令

别名文件:
- qi.alias -> ride
- xia.alias -> unride
