# 武圣真意加成系统接口说明

## 概述

武圣真意系统会将玩家装备的真意效果应用到玩家属性上，这些加成存储在 `zhenyi_bonus/` 路径下，与武圣之躯的 `wusheng_bonus/` 分开管理。

## 系统设计

### 加成存储方式
- **存储路径**：`player->query("zhenyi_bonus/效果类型")`
- **自动更新**：装备/卸下真意时自动重新计算和应用
- **与武圣之躯分离**：避免两个系统的加成冲突

### 支持的效果类型
- `max_qi` - 气血上限
- `max_neili` - 内力上限  
- `max_jingli` - 精神上限
- `force` - 内功等级
- `dodge` - 轻功等级
- `parry` - 招架等级
- `sword` - 剑法等级
- `blade` - 刀法等级
- `cuff` - 拳法等级
- `strike` - 掌法等级
- `finger` - 指法等级
- `hand` - 手法等级
- `claw` - 爪法等级

## 提供的接口

### 1. 查询特定属性加成

```lpc
int query_player_zhenyi_bonus(object player, string effect_type)
```

**功能**：查询玩家特定属性的真意加成  
**参数**：
- `player`：玩家对象
- `effect_type`：效果类型（如 "max_qi"）

**返回值**：加成数值，无加成返回0

**使用示例**：
```lpc
// 查询玩家气血上限的真意加成
int qi_bonus = "/system/wusheng/zhenyi_master"->query_player_zhenyi_bonus(player, "max_qi");

// 查询内功等级加成
int force_bonus = "/system/wusheng/zhenyi_master"->query_player_zhenyi_bonus(player, "force");
```

### 2. 获取所有真意加成

```lpc
mapping query_all_zhenyi_bonus(object player)
```

**功能**：获取玩家所有真意加成的简化版本  
**参数**：
- `player`：玩家对象

**返回值**：属性类型到加成数值的映射

**使用示例**：
```lpc
mapping all_bonus = "/system/wusheng/zhenyi_master"->query_all_zhenyi_bonus(player);

// 遍历所有加成
string *effect_types = keys(all_bonus);
foreach (string effect in effect_types)
{
    int bonus_value = all_bonus[effect];
    printf("真意加成 %s: +%d\n", effect, bonus_value);
}
```

### 3. 获取详细加成信息

```lpc
mapping query_zhenyi_bonus_detail(object player)
```

**功能**：获取包含统计信息的详细加成数据  
**参数**：
- `player`：玩家对象

**返回值**：包含加成和统计信息的映射

**使用示例**：
```lpc
mapping detail = "/system/wusheng/zhenyi_master"->query_zhenyi_bonus_detail(player);

int total_zhenyi = detail["total_zhenyi"];  // 总装备真意数量
int *equipped_slots = detail["equipped_slots"];  // 已装备槽位
int qi_bonus = detail["max_qi"] || 0;  // 气血上限加成
```

## 应用场景示例

### 1. 属性计算系统集成

```lpc
// 在计算玩家最大气血时
int calculate_max_qi(object player)
{
    int base_qi = player->query("eff_qi");
    int wusheng_bonus = player->query("wusheng_bonus/max_qi") || 0;
    int zhenyi_bonus = "/system/wusheng/zhenyi_master"->query_player_zhenyi_bonus(player, "max_qi");
    
    return base_qi + wusheng_bonus + zhenyi_bonus;
}

// 在计算内功等级时
int calculate_force_level(object player)
{
    int base_level = player->query_skill("force", 1);
    int wusheng_bonus = player->query("wusheng_bonus/force_level") || 0;
    int zhenyi_bonus = "/system/wusheng/zhenyi_master"->query_player_zhenyi_bonus(player, "force");
    
    return base_level + wusheng_bonus + zhenyi_bonus;
}
```

### 2. 战斗系统集成

```lpc
// 在战斗伤害计算中考虑真意加成
int calculate_damage(object attacker, object victim)
{
    int base_damage = 1000;
    
    // 获取攻击者的武技等级加成
    string weapon_type = query_weapon_type(attacker);
    int skill_bonus = "/system/wusheng/zhenyi_master"->query_player_zhenyi_bonus(attacker, weapon_type);
    
    // 应用加成
    base_damage += skill_bonus * 10;  // 假设每级技能加成10点伤害
    
    return base_damage;
}
```

// 在显示玩家属性时包含真意加成
void show_player_attributes(object player)

### 4. 装备评分系统集成

```lpc
// 计算玩家总体战力时包含真意加成
int calculate_combat_power(object player)
{
    int power = 0;
    mapping zhenyi_bonus = "/system/wusheng/zhenyi_master"->query_all_zhenyi_bonus(player);
    mapping detail = "/system/wusheng/zhenyi_master"->query_zhenyi_bonus_detail(player);
    
    // 基础属性加成评分
    power += (zhenyi_bonus["max_qi"] || 0) / 100;      // 气血转换为战力
    power += (zhenyi_bonus["max_neili"] || 0) / 50;    // 内力转换为战力
    power += (zhenyi_bonus["max_jingli"] || 0) / 50;   // 精神转换为战力
    
    // 技能等级加成评分
    power += (zhenyi_bonus["force"] || 0) * 20;        // 内功等级权重高
    power += (zhenyi_bonus["dodge"] || 0) * 15;        // 轻功等级
    power += (zhenyi_bonus["parry"] || 0) * 15;        // 招架等级
    
    // 武技等级加成评分
    string *weapon_skills = ({ "sword", "blade", "cuff", "strike", "finger", "hand", "claw" });
    foreach (string skill in weapon_skills)
    {
        power += (zhenyi_bonus[skill] || 0) * 10;
    }
    
    // 真意数量奖励
    power += detail["total_zhenyi"] * 100;  // 每个真意增加100战力
    
    return power;
}
```

## 注意事项

1. **自动更新**：装备/卸下真意时，系统会自动调用 `apply_zhenyi_bonus()` 更新加成，无需手动干预

2. **与武圣之躯分离**：真意加成存储在 `zhenyi_bonus/` 路径，武圣之躯加成在 `wusheng_bonus/` 路径，避免冲突

3. **数值累加**：在计算最终属性时，应该将基础值、武圣之躯加成、真意加成等分别计算后累加

4. **性能考虑**：接口调用有参数检查，但高频调用时仍需注意性能

5. **容错处理**：所有接口都有完整的错误检查，调用失败会返回0或空映射

## 总结

武圣真意加成系统提供了完整的接口供其他系统查询和使用玩家的真意加成。通过合理使用这些接口，可以将真意效果无缝集成到属性计算、战斗、显示等各个系统中，为玩家提供完整的武圣真意体验。
