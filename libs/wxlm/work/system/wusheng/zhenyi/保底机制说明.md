# 武圣真意保底机制说明

## 功能概述

武圣真意系统现已实现保底机制，确保玩家在连续掉落低品质真意后能够获得更好的真意。

## 保底规则

1. **品质分类**：
   - **蓝色以下**：凡尘真意（白色）、通明真意（绿色）
   - **蓝色及以上**：灵犀真意（蓝色）、玄奥真意（红色）、无我真意（金色）、真武真意（紫色）

2. **保底机制**：
   - 当玩家连续获得29次蓝色以下品质的真意时
   - 第30次掉落必定为蓝色及以上品质的真意
   - 获得蓝色及以上品质真意后，计数器重置为0

3. **计数存储**：
   - 使用玩家数据字段 `"zhenyi/low_quality_count"` 存储连续低品质次数
   - 数据持久化保存，重新登录后仍然有效

## 技术实现

### 新增函数

1. **`is_quality_below_blue(string quality)`**
   - 判断真意品质是否为蓝色以下
   - 返回1表示蓝色以下，0表示蓝色及以上

2. **`generate_blue_or_above_quality()`**
   - 保底机制触发时调用
   - 只从蓝色及以上品质中随机选择

3. **`generate_random_quality(object player)`**（修改）
   - 新增可选的玩家参数
   - 包含保底机制逻辑
   - 自动更新和检查保底计数

### 修改的函数

1. **`generate_zhenyi(object player)`**
   - 调用时传递玩家对象给 `generate_random_quality`

2. **`drop_zhenyi_to_player(object player, int level, string quality)`**
   - 当quality为空时，传递玩家对象启用保底机制

## 使用方式

保底机制对现有代码完全兼容，无需修改调用方式：

```lpc
// 正常掉落（自动启用保底机制）
ZHENYI_GENERATOR->drop_zhenyi_to_player(player);

// 指定品质掉落（不触发保底机制）
ZHENYI_GENERATOR->drop_zhenyi_to_player(player, 0, "玄奥真意");

// 批量掉落（每次都检查保底机制）
ZHENYI_GENERATOR->batch_drop_zhenyi_to_player(player, 5);
```

## 测试方法

使用测试文件验证保底机制：

```lpc
// 加载测试文件
load_object("/system/wusheng/zhenyi/test_baodi");

// 测试保底机制（模拟50次掉落）
"/system/wusheng/zhenyi/test_baodi"->test_baodi_mechanism(this_player());

// 强制触发保底测试
"/system/wusheng/zhenyi/test_baodi"->test_force_baodi(this_player());
```

## 注意事项

1. 保底机制只在未指定品质的随机掉落中生效
2. 如果指定了具体品质，不会触发保底机制
3. 保底计数器在获得蓝色及以上品质时自动重置
4. 玩家数据会自动保存，无需手动处理

## 兼容性

- 完全向后兼容现有代码
- 不影响现有的掉落概率配置
- 可以随时启用或禁用保底机制
