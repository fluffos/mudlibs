# 武圣真意掉落系统使用指南

## 概述

武圣真意采用掉落机制，类似暗黑破坏神的装备掉落系统。真意通过战斗、任务、事件等方式掉落给玩家，系统提供了多种掉落接口适配不同的使用场景。

## 掉落接口说明

### 1. 基础掉落接口

```lpc
mapping drop_zhenyi_to_player(object player, int level, string quality)
```

**功能**：给玩家掉落一个武圣真意  
**参数**：
- `player`：玩家对象（必需）
- `level`：真意等级（可选，默认为玩家当前等级）
- `quality`：指定品质（可选，不指定则随机）

**返回值**：成功返回真意数据mapping，失败返回0

**使用示例**：
```lpc
// 随机掉落（使用玩家当前等级和随机品质）
"/system/wusheng/zhenyi_master"->drop_zhenyi_to_player(this_player());

// 指定品质掉落
"/system/wusheng/zhenyi_master"->drop_zhenyi_to_player(this_player(), 0, "玄奥真意");

// 指定等级掉落
"/system/wusheng/zhenyi_master"->drop_zhenyi_to_player(this_player(), 200);

// 指定等级和品质
"/system/wusheng/zhenyi_master"->drop_zhenyi_to_player(this_player(), 300, "真武真意");
```

### 2. 批量掉落接口

```lpc
int batch_drop_zhenyi_to_player(object player, int count, int level, string quality)
```

**功能**：批量给玩家掉落多个真意  
**参数**：
- `player`：玩家对象（必需）
- `count`：掉落数量（必需）
- `level`：真意等级（可选）
- `quality`：指定品质（可选）

**返回值**：成功掉落的数量

**使用示例**：
```lpc
// 掉落3个随机真意
"/system/wusheng/zhenyi_master"->batch_drop_zhenyi_to_player(this_player(), 3);

// 掉落5个指定品质的真意
"/system/wusheng/zhenyi_master"->batch_drop_zhenyi_to_player(this_player(), 5, 0, "灵犀真意");
```

### 3. 概率增强掉落接口

```lpc
mapping drop_zhenyi_with_boost(object player, int level, float rare_boost)
```

**功能**：带稀有度加成的真意掉落，适用于BOSS掉落、特殊事件等  
**参数**：
- `player`：玩家对象（必需）
- `level`：真意等级（可选）
- `rare_boost`：稀有度加成倍率（默认1.0，设为2.0则稀有品质概率翻倍）

**返回值**：成功返回真意数据mapping，失败返回0

**使用示例**：
```lpc
// 普通掉落
"/system/wusheng/zhenyi_master"->drop_zhenyi_with_boost(this_player(), 0, 1.0);

// BOSS掉落（2倍稀有度）
"/system/wusheng/zhenyi_master"->drop_zhenyi_with_boost(this_player(), 0, 2.0);

// 超级BOSS掉落（5倍稀有度）
"/system/wusheng/zhenyi_master"->drop_zhenyi_with_boost(this_player(), 0, 5.0);
```

## 应用场景示例

### 1. 战斗系统集成

```lpc
// 在怪物死亡时调用
void die_event(object killer)
{
    if (!killer || !objectp(killer))
        return;
        
    // 检查玩家等级
    if (killer->query("level") < 100)
        return;
    
    // 根据怪物等级决定掉落概率
    int monster_level = query("level");
    int drop_chance;
    
    if (monster_level >= 150)
        drop_chance = 10; // 10%概率
    else if (monster_level >= 120)
        drop_chance = 5;  // 5%概率
    else
        drop_chance = 2;  // 2%概率
    
    if (random(100) < drop_chance)
    {
        if (monster_level >= 200)
        {
            // 高级怪物，使用概率增强掉落
            "/system/wusheng/zhenyi_master"->drop_zhenyi_with_boost(killer, 0, 2.0);
        }
        else
        {
            // 普通怪物，基础掉落
            "/system/wusheng/zhenyi_master"->drop_zhenyi_to_player(killer);
        }
    }
}
```

```lpc
            break;
            
        case "hard":
            // 困难任务：必定掉落1个，20%概率掉落第2个
            "/system/wusheng/zhenyi_master"->drop_zhenyi_to_player(player);
            if (random(100) < 20)
                "/system/wusheng/zhenyi_master"->drop_zhenyi_to_player(player);

            // 传说任务：掉落3个真意，使用概率增强
```

```lpc
    }
}
```

## 品质控制建议

### 品质概率分布（基础）
- 凡尘真意（白）：60%
- 通明真意（绿）：25%  
- 灵犀真意（蓝）：10%
- 玄奥真意（红）：4%
- 无我真意（金）：0.9%
- 真武真意（紫）：0.1%

### 稀有度加成效果
- `rare_boost = 1.0`：正常概率
- `rare_boost = 2.0`：适合精英怪物
- `rare_boost = 3.0`：适合小BOSS
- `rare_boost = 5.0`：适合大BOSS
- `rare_boost = 10.0`：适合超级BOSS或特殊活动

## 注意事项

1. **等级检查**：系统会自动检查玩家是否达到100级，未达到则掉落失败
2. **背包容量**：真意存储在玩家属性中，不占用物品背包空间
3. **掉落通知**：系统会自动通知玩家获得真意
4. **错误处理**：所有接口都有完整的错误检查，调用失败会返回0或适当的错误值
5. **性能考虑**：批量掉落时建议控制数量，避免一次性掉落过多真意

## 总结

武圣真意掉落系统提供了灵活的接口，可以轻松集成到各种游戏系统中。通过合理使用不同的掉落接口和参数配置，可以为玩家提供丰富的真意获取体验，增强游戏的可玩性和成就感。
