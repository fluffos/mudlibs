# 妖魔配置注册表

本文件用于记录所有妖魔的配置信息，避免ID和名称冲突。

## 使用说明

1. 创建新妖魔前，请先查阅此文档确认ID和名称未被使用
2. 创建新妖魔后，请立即更新此文档
3. ID格式：`yaomo_XXX`（XXX为三位数字，从001开始）
4. 名称不允许重复

## 当前已使用的ID范围

- yaomo_001 ~ yaomo_012 (已使用)
