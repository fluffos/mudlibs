# 风云四解密版

一个以古龙小说为背景的"风云Ⅳ"MUD（Sumxin 风云），和本合集里的
`xsfyssjb`（心声风云四升级版）是同一套代码库——`d/dreamland/`
等场景文件逐字节相同，此前两份档案都没有互相记录这层关系。

## 内容亮点

- 和 `xsfyssjb` 共享同一套地图：楼兰、新疆、藏北、流沙等大漠/西域
  场景，配合华山、武当、少林等中原门派地图，突出古龙笔下"大漠孤
  烟"式的江湖背景。
- `d/neon_playground/` 目录名虽然很跳脱，实际内容却是"新月客栈"
  为中心的常规场景（常青草地、黑羽之帐等），推测是历史上借用过的
  英文目录名，和实际游戏内容（依旧是传统武侠场景）没有关系。
- 注册时选择内码（GB/BIG5）、设定密码复杂度（大小写字母+特殊符
  号/数字）、再选民族，是这批"风云"系档案里步骤最完整的注册流程
  之一。
- 中心广场"盘龙摩天柱"是一块真正可读写的公共留言板（`read <编
  号>`），实测已有其它测试留言留存。

## 注册流程

连线后先选择内码（0 国标码 GB / 1 大五码 BIG5，两者都正常）→ 英文
名字 → 确认建立（y/n）→ 中文名字（1-5 个中文字，回车可用系统随机
名）→ 密码（≥6 字元，需大写+小写英文字母+特殊符号/数字，且不能和
英文名字太像）→ 确认密码 → 电子邮件地址 → 性别（m/f）→ 民族
（0-3）。

## 本次修复的关键 bug

- `is_chinese()` 沿用旧版 GBK 字节区间判断（`strlen>=2` 且
  `str[0]>160&&<255`），`check_legal_name()` 的长度界限
  （`strlen<2||>10`）也和提示文字本身声明的"一到五个中文字"对不
  上，加上逐字符判断循环仍然是 `i%2==0` 双字节跳步——导致包括标准
  测试名字在内的所有真实中文名字都被拒绝。已将 `is_chinese()` 改为
  Unicode 码点区间判断，长度界限改为匹配提示文字的 1-5，判断循环
  改为逐字符（AGENTS.md §8.1）。
- 实测了 GB 和 BIG5 两个内码选项，画面均正常，不是这个档案的实际
  问题。
- 排版格式化工具的第三类盲点检查（CJK 重新加空格）在少数几个"误
  报"中抓到了一处真正的损坏：`daemon/damage-1.lpc`（一份纯文本的
  战斗记录数据表）被格式化工具压成一行并加了空格，已直接还原。

## 深度功能测试新发现的 bug（§10.7，2026-08-04）

- **§7.68 复活软锁死（第 12 例）**：`d/death/npc/panguan.lpc`（鬼门
  关的"朱笔判官"，文件头注释显示血统来自风云Ⅲ，与本项目 `fy330`/
  `fy2mg` 的同款判官同源）把"玩家暂时不在场"和另外三个应当永久放
  弃的条件（对象已销毁、已经不是鬼、战斗经验超出判官处理上限）合
  并成同一个提前 `return`，导致复活序列一旦被打断就永久卡死。已拆
  分为"暂时不在场→5 秒后重试"与其余条件"→永久放弃"两种情况。现场
  验证：死亡→鬼门关→未被打断的完整复活序列→成功落地随机复活点
  （本次为"天主教堂"）。
