# 西游记 (A Journey to the West)

## 游戏名称

**西游记**，登录画面自称 *A Journey to the West*，版本号 2.01，最早制作于
1996-1998 年。本项目考证认为它极可能是"ES II / 西游记"这一整个引擎家族
（包括 `fluffos_xiyou2000`、`mhxy`、`xiyouji2003`、`xiyouji2006`、
`xiyouji450`、`shenmo` 等在内的众多同题材姊妹游戏）**最早的祖先版本**——
文件时间戳最早，且没有任何后续站点加上的"破解者"署名痕迹。

## 简介

以《西游记》原著世界观为背景的武侠/神话文字 MUD，玩家将扮演初入江湖的少年
少女，从长安城出发游历天下，探索小说中的经典地点（如盘丝洞、五指山、南海等）
，习练各路武功与法术，逐步在这个混合了武侠与神魔色彩的世界中成长。作为整个
"西游记" MUD 世系的源头版本，其世界内容相对朴素，是这一系列游戏最原始的
样貌。

## 如何运行

```
cd libs/xiyouji
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40079**

## 如何连接游玩

```
telnet 127.0.0.1 40079
# 或
python3 scripts/mudclient.py 127.0.0.1 40079
```

登录时会先问 `Do you want to use BIG5 code?(y/n)`，简体中文用户直接输入
`gb` 即可；接下来会问是否为在校学生（一个简单的年龄相关问题），如实回答
`no`/`yes` 均可继续。之后依次是：英文代号 -> 确认新建角色(y) -> 中文名字
（1 到 6 个汉字）-> 密码 -> 确认密码 -> 电子邮箱 -> 性别(m/f) -> 确认接受
随机分配的天赋(y)，即正式进入游戏，最终落地在"南城客栈"。

## 已知问题

- 少量深层地图/道具文件为原始压缩包自带的文字截断或数据损坏（如个别 NPC
  的存档数据、少数几个古老剧情文件的结尾缺失），均不在新手主线路径上，不
  影响日常跑图与游戏体验。
- 一个古老门派体系遗留的"旧武学"（essencemagic/perception/celestial 等）
  在本存档中并未被真正实现，属于游戏自身"旧内容"目录标注的已淘汰功能，
  不影响现役门派与技能系统。
- **WASM（浏览器/无网络监听端口运行模式）下可以完整游玩**：注册、登录及
  look/quit 等基本指令均已验证可以正常工作，没有遇到其它同系列存档中出现
  的"连线地址格式"限制问题。
