# 西行战记

## 游戏名称

游戏自称《西行战记》，配置文件里写着"总站"，但实际登录横幅打的是
"西行战记[宜昌站]"——这是同一套源码在不同地区搭建的分站，内容是一样的，
只是站点名字没改而已。它属于 ES II（Eastern Stories II）架构的一个
独立分支，和本项目里其他好几个西游/ES II 系 Mud 是远房同门。

## 简介

以《西游记》故事为底色的江湖 Mud，新手会从长安城的"南城客栈"起步，
围绕取经、降妖、门派历练展开。系统保留了不少 ES II 家族典型的老派
元素：留言板、天赋点数分配、体格/根骨/悟性/灵性四维属性等，适合喜欢
慢节奏文字养成的玩家。

## 如何运行

```
cd libs/xixingzhanji
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口固定为 **40080**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40080 --timeout 30 --idle 1 \
  --send "gb" --send "no" --send "new" --send "<英文ID>" \
  --send "<中文名字>" --send "<密码>" --send "<密码>" \
  --send "<邮箱>" --send "m或f" --send "9" --send "y" --send "look"
```

1. 选择编码 `gb`（简体）或 `big5`（繁体）
2. "您是否是中小学学生或年龄更小？"——回答 `no`（或 `yes`，都不影响
   后续流程，只是个提示性问题）
3. 英文名字：新玩家输入 `new`
4. 再输入一个 3-8 位纯小写字母的新英文名字
5. 真实中文姓名
6. 设置密码、再输一次确认
7. 电子邮箱
8. 性别 m/f
9. 天赋分配界面：输入 `9` 直接接受默认分配，再输入 `y` 确认

完成后会直接落地在"南城客栈"，`look`、`score` 都能看到正常的中文场景
描述和角色状态卡片。

## 已知问题

个别 NPC（比如皇宫里的"唐太宗"）身上设置了要穿戴的道具或要施展的技能，
但这份存档里恰好没带这几样具体内容，NPC 本身不会报错，只是那个道具/
技能效果不会出现，基本不影响正常探索。另外有一小撮"旧版/废弃"任务
目录缺少对应的说明文件，同样是历史遗留的内容缺口，不在正常游玩路径上。
