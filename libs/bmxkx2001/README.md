# 侠客行 (The Quest of Oriental Chivalry) — 北美 2001 版

取材自金庸同名武侠小说《侠客行》，以"侠客岛"为核心背景——新玩家一入游戏就由岛上的"赏善使"或"罚恶使"两位使者之一迎接，带去挂名处登记，之后再次登录才真正踏入自由行动的江湖世界；中文姓名还会刻意避开原著已有人物（如"韦小宝"会被系统直接拒绝）。门派、武功体系完整，紧扣原著世界观，是早期中文 MUD 里颇具代表性的武侠作品。死亡后有一整套"鬼门关"体验：鬼魂在白/黑无常面前听完五段风味十足的台词后自动复活，落脚扬州武庙，死亡流程在同类档案里做得比较细致。本作属于 ES II/"侠客行"引擎家族（与 xkx2001、xuanjianlu 等同宗，`chinese.c`/`master.c` 字节级相同），是 1996-1999 年 XiaKeXing Gaming Group 制作、于北美地区运营的一个版本；场景文件头带着"Cracked by Roath"署名，与同批处理过的 `jym` （金庸梦）、`xkm`（侠客梦）同属一批"Cracked by Roath"流通版本（`xkx2000zxb` 则是"Cracked by Kafei"的另一份流通版本）。

## 内容亮点

- 取材自金庸同名武侠小说，以"侠客岛"为核心背景——新玩家一入游戏就会由
  岛上的"赏善使"或"罚恶使"两位使者之一迎接，带你前往挂名处登记，随后
  才能真正踏入江湖。
- 新角色第一次进入游戏会先经历侠客岛的迎宾/登记流程，此时只能使用
  `look`、`follow`、`say`、`quit` 等少数指令——这是游戏本身刻意设计的
  新手引导限制，需先跟随迎宾使者完成登记，之后再次登录才会进入真正可
  自由行动的江湖世界。
- 门派、武功体系完整，紧扣金庸原著世界观，是早期中文 MUD 里颇具代表性
  的武侠作品。
- 中文姓名会避开小说中已有的人物姓名（如"韦小宝"等会被系统直接拒绝）。
- 死亡有完整的"鬼门关"体验：鬼魂在白/黑无常面前听上五段风味十足的
  台词后自动复活，落脚扬州武庙——是这批档案里死亡流程做得比较细致
  的一个。

## 深度功能测试新发现的 bug（详见 NOTES.md）

- 死亡复活的五段计时序列如果被无关的场景引导 NPC 中途强行拽走鬼
  魂，会静默永久卡死在【鬼魂】状态，没有任何报错提示，reconnect
  也无法自愈（AGENTS.md §7.68 新分类）。已把"暂时不在场就放弃"改
  成"暂时不在场就重试"，修复三份鬼差 NPC 档案。
- 引导 NPC `longx.lpc` 的 `greeting()` 有一处未判空就解引用的
  隐患，玩家不在场时会报 `Bad argument 1 to EFUN call_other()`。
  已加空指针防御。
- 真正生效的 `include/globals.h` 漏了 `EDITOR_D` 宏定义，导致留言
  板基类编译失败、任何布告板 clone 都无法使用（AGENTS.md §7.69 新
  分类）。已补上缺失的一行宏定义。
