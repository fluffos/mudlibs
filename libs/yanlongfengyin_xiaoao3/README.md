# 炎龙封印（笑傲江湖·阿飞站）

属于"夕阳再现"（XYZX/YLFY）引擎家族，游戏内登录横幅显示为「夕阳再现」之
「笑傲江湖」，是由"阿飞"在"碎梦"修改的炎龙分支基础上再次深度改造而成的独立
版本，与同引擎家族的其它"夕阳再现"系游戏是关系较远的表亲，而非同一份内容。

## 简介

以金庸小说《笑傲江湖》为背景的武侠 MUD，玩家从南阳城附近的客栈开始自己的
江湖之旅，可以自行分配膂力、悟性、根骨、身法四项天赋，另有福缘、容貌两项
隐藏属性影响解谜、拜师等际遇。

## 如何运行

```
cd libs/yanlongfengyin_xiaoao3 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

端口：**40062**

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40062
```

登录流程：

1. 输入英文名字（不能带数字），确认时回答 `y`。
2. 输入中文名字（可以不输入姓氏直接回车略过）。
3. 设置普通密码（两次确认）。
4. 设置"身份标识"（用于找回密码等场合，两次确认，不可更改，请自行妥善
   保管）。
5. 天赋分配：输入 `0` 由系统随机分配（也可输入 1～4 指定微调某一项），随后
   还需要回答 `y` 确认接受这组天赋。
6. 输入电子邮件、性别（`m`/`f`），完成后进入游戏世界，系统会提示新手礼物的
   领取路径。

## 已知问题

- 如果使用普通 telnet 或本项目的测试客户端连接（而不是游戏原生配套客户端），
  房间描述里偶尔会夹杂形如 `lbadd1 ...` `lbclear0...` 的一小段文字，这其实是
  游戏发给专用客户端的界面数据（例如装备栏、地图提示），只是普通文字客户端
  没有能力过滤掉它们，不影响正常阅读和游玩，可以直接忽略。
- 新注册的角色如果在半小时内就退出游戏，系统会为了减轻服务器负担而删除该
  账号，这是站方明确的规则提示，并非故障。
- 少数冷门区域、道具存在历史遗留的内容缺口，不影响主线的正常探索。
- 本存档在新的 WASM（浏览器/Node 沙盒）模式下暂时无法登录：存档自带的 IP
  地址检查功能在 WASM 沙盒里读到的地址格式不正常，导致每次连接都被误判为
  "地址不受欢迎"而被直接拒绝。这是 WASM 沙盒本身的已知限制（并非本存档的
  问题），不影响原生模式下的正常游玩（已重新验证注册、look、score 均
  完整正常）。
