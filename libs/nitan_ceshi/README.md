# 泥潭III测试版 / 《終極魔界》 (nitan_ceshi)

## 游戏名称

站点内部配置自称"泥潭三"(nitan.3)，但连线后看到的实际招牌是《終極魔界》
("Ultimate Demon Realm")——一个套在"泥潭"引擎上的主题皮肤。属于
NT/nitan/Lonely 一脉（与本项目转换的 nitan170911、nitan6、nitan_san 同源），
是这条脉络里比较早期的一个内部快照版本。

## 简介

传统的中文武侠/仙侠泥巴：新玩家要先取姓名、选性格、"洗"天赋点数，再到
"生命之谷"由盘古安排投胎，才算真正"出生"进入江湖。世界观走的是盘古开天、
转世投胎的神话路线，登陆后的常驻场景是客店一类的传统江湖据点。与同系的
nitan170911 不同，这一支**不需要外部 MySQL 数据库**，注册与存档全部走
本地文件，开箱即可完整体验注册到游戏内的整个流程。

## 如何运行

```
cd libs/nitan_ceshi
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40054**。这个库文件数量较多（约1.3万个文件），驱动启动后需要
**二三十秒**完成预加载，过早连接会看到"正在启动过程中，请稍候再来"的提示，
耐心等待即可。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40054
```

完整流程比较长，按顺序会经过：

1. 编码选择，回答 **`gb`**。
2. 输入一个 3-10 位英文 ID，确认创建新角色 (y/n)。
3. 依次输入中文**姓**、中文**名**（各自不超过两个汉字，单字姓名也完全
   支持）。
4. 设置"管理密码"（找回密码用）和"普通密码"（日常登录用），均需再输入
   一次确认。
5. 选择性别 (m/f)。
6. 进入一个"注册房间"，提示可以用 `register 你的邮箱地址` 登记邮箱以延长
   账号保留期——这一步不是必须的，不影响继续游戏。
7. 移动到"生命之谷"后，依次执行：
   - `choose <1-4>` 选择性格（光明磊落/狡黠多变/心狠手辣/阴险奸诈）
   - `washto 20 20 20 20`（四项天赋，总和需固定，具体数值游戏会提示）
   - `born <籍贯>`（例如 `born 扬州人氏`）正式"投胎"完成角色创建
   - 之后会有一段较长的规则公告，连续按回车翻页即可

完成以上步骤后就正式进入游戏世界（默认落地在"客店"），`look`、`score`
等指令均已验证正常工作。

## 已知问题

- 少数任务类 NPC（`clone/quest/` 下的几个文件）因为脚本自身的类型不匹配
  无法编译，这是原始归档自带的内容缺陷，不影响主线注册和日常游玩。
- 排行榜相关的存档目录在原始归档中缺失，导致一条無害的后台警告，不影响
  玩家操作。
- 由于文件数量较多，本次验证没有对全库做静态编译扫描，而是以实际启动+
  连线游玩作为验证标准（与同系列的大型库一致）。
- WASM 版本可以正常启动，但本次测试工具无法在其短生命周期的单次运行内
  验证登录流程：本库自带一个"服务器刚启动 30 秒内谢绝连线"的保护机制，
  而且地址黑名单检查同样依赖 WASM 驱动尚不能正确提供的连线 IP 格式，
  两者叠加导致无法在一次性测试里走到登录提示。这些都是 WASM 驱动/测试
  工具本身的限制，不是本库的 bug——原生（native）驱动下注册、进入
  生命之谷、盘古 NPC 正确称呼玩家中文名等全部验证通过。
