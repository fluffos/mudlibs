# 仙侣情缘（知秋站 2001版）

## 游戏名称

**《仙侣情缘》**，又称 XLQY，2001年"知秋站"（www.mudfan.com）快照版本。
属于"仙侣情缘"引擎家族，与本项目另收录的"浙大版"分支同源但代码更早、
更接近原始版本。游戏内自称"西游传奇之仙侣情缘"（A Journey To The West /
Fairy Love Story）。

## 简介

以西游记为背景的仙侠世界：从长安城南城客栈踏上取经之路，逐步修炼
"道行境界""武学境界""法力修为""内力修为"，最终目标是"西天取经"与
"大闹天宫"式的成长历程。整体是神话/仙侠题材，节奏偏休闲，适合喜欢
西游记世界观的玩家。

## 如何运行

```
cd libs/xianlvqiyuan && ~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40032**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40032
```

或用任意 MUD 客户端 telnet 连接。这个版本的注册流程和很多同类 MUD 略
有不同，请注意：

1. **编码选择**：`Select GB or BIG5 (gb/big5)` —— 简体/UTF-8 客户端选
   `gb`。
2. **"是否为中小学生"问题**：必须明确回答 `no` 才能继续，回答其它任何
   内容（包括手滑把用户名当成答案输进去）都会被当作"是"而礼貌地结束
   连接——这是站方设置的门槛，不是故障。
3. 英文ID：输入 `new` 开始注册，取一个ID。
4. **中文名字环节没有额外的确认(y/n)步骤**——直接输入你的中文名字即可，
   系统会当场判断是否接受（必须是真正的中文字符）。
5. 设置密码（两次输入确认）、填写邮箱、选择性别(m/f)。
6. 最后进入"天赋分配"界面：可以选 0-3 挑一项属性重设数值，或直接输入
   `9` 接受默认天赋，再输入 `y` 确认即可正式进入游戏。

## 已知问题

- 游玩中偶尔会看到一条系统提示"你发现事情不大对了，但是又说不上
  来。"反复出现几次——这是这个引擎家族的一个非致命提示噪音，不影响
  注册、看房间(look)、查看属性(score)等正常操作，可以直接忽略。
- lpcc 编译扫描约98.5%通过，缺口集中在个别脚本文件，日常游玩基本不
  会碰到。
- WASM 版本表现良好：开场画面、取中文名字等步骤均可正常进行，未发现
  阻塞性问题；原生（native）驱动下完整体验不受影响。
