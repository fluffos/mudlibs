# 夕阳再现·风云再起Ⅱ

站点子名"风云再起Ⅱ"（域名 www.zhaoshu.net），玩家从平民少年少女出发，降生在几个随机分配的江湖城镇/据点之一（如北疆小镇、铁枪庙等），游历各地、结交门派、习练武功、行侠仗义，游戏公开声明不禁止玩家间的 PK 对战，注册时还要求同时设置"管理密码"和"登录密码"两套独立密码。与本项目中的 `xyzxfk`（疯狂江湖）同属"夕阳再现"这一支武侠 MUD 引擎家族，而且关系远比"共享引擎"来得紧密——对两者共同的世界文件逐字节比对，发现约 97% 完全相同（含 `d/city/sj.lpc` 逐字节相同），双方都只是在同一份原作地图上叠加了少量各自独立的改动（如 `xyzxfk` 多出的一条门派传送指令），更接近同一份地图的两个并行维护快照，而不是两个彻底独立的游戏，只是各自的登录、安全代码是独立实现的。这一支血统（也见于本项目的 `xyzx`/`jhfy3`/`xajh4gkb`/`xyzxyl201412`）和本项目里另一批同样打着"夕阳再现"招牌、地图却属于不相关"天涯"家族的档案（`xysylmhb`/`xyzxiiylzymh`/`yzxiiizylfy`/`xyzx3` 等）是完全不同的血统，品牌名称不能作为判断血统的依据。
