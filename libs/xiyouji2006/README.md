# 西游记2006·大唐西游

## 游戏名称

存档里出现过三个不同的名字：压缩包标题叫"最终幻想"，游戏登录横幅自称
"西游记2006 之 最后的疯狂"，游戏内公告则说已正式更名为**《大唐西游》**。
属于 mhxy/梦幻西游 一支"西游记"引擎家族——与本项目中的 `mhxy`、`shenmo`
（西游记之神魔传说）同源，但由不同站点独立开发维护多年，内容已大幅分化。

## 简介

以《西游记》取经故事为主线的武侠/神魔文字 MUD。玩家从长安城的南城客栈出发，
一边扮演凡人成长（拜师习武、经营人生），一边逐步踏上"西天取经"与"大闹天宫"
两条特色主线剧情，游戏内还设有"排行榜"系统（财富、杀敌、修为等各类榜单）。
世界中"唐僧师徒"一行会作为背景 NPC 在地图各处巡游，为世界增添了不少西游
氛围。

## 如何运行

```
cd libs/xiyouji2006
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40077**

## 如何连接游玩

```
telnet 127.0.0.1 40077
# 或
python3 scripts/mudclient.py 127.0.0.1 40077
```

**登录时第一个提示看起来像是在问"你的英文名字"，但其实是一个隐藏的客户端
版本校验，必须先输入固定的暗号 `2060`，才能进入真正的英文代号输入环节**——
如果直接输入你想用的代号，会被当作"客户端不对"拒绝并断开连接，这是原始
游戏为配合"Tomud"专用客户端设计的握手机制，与你的名字本身无关，请照输
`2060`。

之后依次是：`new`（新玩家注册关键字）-> 英文代号 -> 中文名字 -> 管理密码
（至少 7 位，需含大小写字母和至少一个非字母字符，且不能包含你的代号）->
确认管理密码 -> 登录密码（至少 5 位，需与管理密码不同）-> 确认登录密码 ->
电子邮箱 -> 性别(m/f) -> 天赋数值确认（输入 `9` 接受默认分配，再输入 `y`
确认），即可正式进入游戏，落地在南城客栈。

## 已知问题

- 世界中巡游的"唐僧师徒"背景 NPC 系统偶尔会在后台触发一次较耗资源的场景
  切换，这只会在服务器日志里留下一条无害的内部提示，**不会影响任何玩家的
  正常操作**，登录、查看状态、走动等指令均不受影响。
- 少量边缘剧情区域（如"开封旧区"的部分支线任务）缺少个别配套文件，属于原始
  压缩包本身的内容缺口，不影响主线取经剧情与日常游戏。
- 一套内部邮件/寻呼通讯子系统在本存档中不完整，未在正常游戏流程中使用。
