# 西游记2006·大唐西游

存档里出现过三个不同的名字：压缩包标题叫"最终幻想"，游戏登录横幅自称 "西游记2006 之 最后的疯狂"，游戏内公告则说已正式更名为《大唐西游》。 属于 mhxy/梦幻西游 一支"西游记"引擎家族——与本项目中的 `mhxy`、 `shenmo`（西游记之神魔传说）同源，但由不同站点独立开发维护多年，内容已大幅分化。

## 内容亮点

- 以《西游记》取经故事为主线的武侠/神魔文字 MUD：一边扮演凡人成长
  （拜师习武、经营人生），一边逐步踏上"西天取经"与"大闹天宫"两条特色
  主线剧情。
- 游戏内设有"排行榜"系统（财富、杀敌、修为等各类榜单）。
- "唐僧师徒"一行会作为背景 NPC 在地图各处巡游，为世界增添了不少西游
  氛围。
- 连线时有一道隐藏的客户端版本暗号校验（固定输入 `2060`），与本项目
  其他几款同期"夕阳再现/Tomud"系作品共享这一握手机制。
