# 大唐西游 YWX人造人 (rzrmud)

## 游戏名称

《大唐西游》，站点自称"YWX人造人"（原开发者的昵称/团队名），北美总站，自
2006 年 2 月 3 日运行至今（存档信息显示已有五百多个注册玩家）。与本项目
转换的"梦幻西游"(mhxy) 同属西游记神话世界观的一支，但引擎实现是独立的一
支（不使用 nitan/Lonely 家族那套有问题的全局属性存取机制，而是每个对象
自带属性存取方法，架构上更规范）。

## 简介

同样取材于《西游记》，新角色要为自己起一个"符合〖大唐西游〗神话世界"的
中文名字，新手村在长安城"南城客栈"，白素贞、唐三藏、店小二等经典角色以
NPC 形式登场。游戏强调门派、五行攻击/防御属性、道行境界等修真类成长线，
整体节奏偏休闲，也有较完整的新手礼包机制。

## 如何运行

```
cd libs/rzrmud
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40020**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40020
```

连接后依次会经历：

1. 一个"是否是中小学学生"的年龄提示，回答 `no` 继续（形式化提示，不做真
   实年龄核实）。
2. 一段较长的规则/论坛信息展示后，提示"您的英文名字：（新玩家请键入 new
   注册）"，输入 `new` 开始注册。
3. 依次设置：英文 ID（3-8 位英文字母）、真实中文名字、"管理密码"（用于改
   密码/自杀等敏感操作，需再次确认）、"游戏登陆密码"（日常登录用，也需确
   认）、电子邮箱、性别 (m/f)。
4. 进入游戏前有一次天赋分配界面，输入 `9` 接受默认天赋分配，再输入 `y`
   确认，即可正式进入"南城客栈"。

登录后 `look`、`score` 等指令均已验证工作正常。

## 已知问题

- 少数城市（如"开封"）的任务类 NPC 存在缺失基础类声明的内容缺口（约 55
  个文件），是原始归档本身的疏漏，不影响正常登录和绝大部分场景游玩。
- 少数 NPC 在生成"徒弟"关系时（如猪八戒收徒逻辑）偶尔会触发一次性能超时
  的后台警告，纯属世界模拟内部日志噪音，不会影响玩家的正常操作。
- 全库 lpcc 静态编译扫描通过率约 97.5%，其余失败集中在长尾的场景/任务专属
  内容，属于历史遗留的边角缺口。
