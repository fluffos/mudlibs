# Shattered World Core Mudlib (`swlpc`, 0.9.1)

Shattered World Core Mudlib (`mlib-0.9.1`, September 2001 GPLv2 release) is the public core mudlib of Australia's long-running Shattered World LPMud (founded 1991 at Monash University). Explorers arrive in Sanom City's *Common Sleeping Quarters* inn overlooking the city clocktower and can traverse the connected core rooms (*Noisy room*, *Storage*, and *The Void*).
