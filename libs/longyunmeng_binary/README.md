# 龙云梦·炎龙封印（二进制版）

龙云梦（Wenwu）的《夕阳再现之炎龙封印》3.5 版，2006 年在「江西一站」运行，属于"夕阳再现/炎龙封印"（XYZX/YLFY）家族，是本项目 033-2 `longyunmeng` 源码版同一个游戏较早的一版。这是一部带奇幻色彩的武侠 MUD：注册时除了膂力、悟性、根骨、身法四项天赋（另有隐藏的福缘和容貌），还要从光明、土、火、水、木、气、雷、心灵、黑暗、空间、金十一系魔法元素里选一种先天的魔法天赋。玩家从扬州客店出发，世界有七十多个区域，可以拜入少林、武当、峨嵋、华山、昆仑、明教、古墓、丐帮、桃花岛、星宿、白驼山、灵鹫宫、移花宫、大雪山、侠客岛等二十来个门派；城外有十五层的地下迷宫和闯关的黄金十二宫，有每十五个小时重新随机生成一次的迷雾森林（传说是通往精灵神界的必经之路），还有幽灵山庄、红梅山庄、飞天楼擂台。经验累积到一千五百万即可升级、分配属性点，另有闭关、彩票、帮会和每月的华山论剑。

## 内容亮点

- 迷雾森林（`d/automap`）：一千五百个房间的随机迷宫，由地图精灵按 `/clone/map/map` 的模板定时重建，
  里面出没着森林贼盗和贼盗头领。
- 地下迷宫十五层（`d/migong`），第六层的山洞和第七层的钟乳石洞里有一百多个房间只存在于这个版本。
- 黄金十二宫（`d/migong/12gong`）：从白羊宫开始逐宫闯关。
- 幽灵山庄（`d/ghost`）：取材于古龙《陆小凤传奇·幽灵山庄》，原始丛林、钢索桥、石屋和地窖；山庄的大厅、几间屋子
  和老刀把子、叶孤鸿、叶雪、叶灵、花寡妇、狗郎君、勾魂使者这些人物只在这个版本里有。
- 巫师 snow 的五毒教区域（`u/snow/wudujiao`）：五毒山路、黑森林、桃花江、万毒窟、百毒窟。

## 注册流程

英文名 → 确认（y）→ 中文名（1 到 5 个汉字，直接回车随机生成）→ 密码（至少五个字符）→ 再输一次 →
身份标识（至少九个字符，自杀和取回密码时用）→ 再输一次 → 天赋（0 随机，或 1–4 指定一项）→ 同意（y）→
魔法天赋（0–10）→ 电子邮件 → 性别（m/f）。注册后半小时内 `quit` 会删除帐号（原设计）。

## 关于源码

这份档案只带 Win32 驱动编译后的 14,395 个 MudOS `.b` 文件，源码几乎都删掉了。这里的源码树由三部分组成：
本版自带的原文、和本版 `.b` 编译结果完全一致的 033-2 源码原文（文件第一行注明出处）、以及从 `.b`
反编译还原的部分；每个文件都用 v22pre11 编译器重新编译，和档案里的 `.b` 逐条比对过。还原工具在
`scripts/mudos_b/`，过程见 `NOTES.md`，`rebuild.sh` 可以从档案重做一遍。
