# 仙侣情缘（早期测试版）

属于 ES II 引擎家族，与同批的"新仙侣情缘之飘渺纪元"（xlqy_new2007）同宗同源，
是同一套代码更早、更粗糙的一个开发快照。

## 简介

这是一款以《西游记》为背景的仙侣题材 MUD，讲述一段人与妖、仙与凡之间的情缘
故事。游戏世界围绕西天取经的旅程展开，穿插各类神话人物与门派恩怨。根据这份
存档自带的说明文件，它原本就是作者用来测试驱动兼容性的"半成品"版本，内容不算
完整，但核心的登录、探索、战斗流程都可以正常运作。

## 如何运行

```
cd libs/xlqy_early && ~/src/fluffos/build-debug/src/driver config.fluffos
```

端口：**40076**

## 如何连接游玩

用任意 telnet 客户端或本项目自带的测试客户端连接：

```
python3 scripts/mudclient.py 127.0.0.1 40076
```

登录流程依次是：

1. 选择编码 `gb`（国标码，普通用户直接选这个）或 `big5`。
2. "您是否是中小学学生或年龄更小？" —— 这是一个年龄提示，回答 `no` 才能继续
   （回答 `yes` 会直接断开连接）。
3. 输入 `new` 开始注册新角色，然后依次设置英文名字、中文姓名、密码（需输入
   两次确认）、电子邮件、性别。
4. 完成后会直接进入游戏世界，无需额外的天赋分配步骤。

## 已知问题

- 这个存档自带 100 个自动游走的"人造人"NPC，开服几分钟后它们会逐渐把地图上
  的房间全部触发编译一遍，期间服务器 CPU 占用会明显升高（一般在开服后几分钟
  内出现），属于游戏本身的设定，不影响正常游玩，稍等即可恢复流畅。
- 作为一个"半成品"快照，个别道具、NPC 引用的目标不存在（比如某个和尚的僧袍
  找不到对应道具），属于内容缺失而非故障，遇到时不必上报为 BUG。
- 输入中文名字后系统会打印出一行看起来像调试信息的文字（角色对象编号），是
  历史遗留的无害小瑕疵，可以忽略。
- 本存档也可在新的 WASM（浏览器/Node 沙盒）模式下完整游玩，注册、登录、
  look/score/quit 等指令均正常；唯一已知小瑕疵是"上次连线的地址"这一行在
  WASM 模式下会显示乱码而非真实 IP（WASM 驱动本身的已知限制，不影响功能）。
