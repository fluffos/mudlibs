# 红尘

源自 2026-07-29 批量归档 `mudlib.rar` 中的 `红尘.rar`（游戏内全名"红尘
录"）。ES II 引擎家族的一支独立作品。

## 内容亮点

- 经典武侠题材，开局在岳王庙"武庙"正殿，殿内供奉着诸葛亮等历史/
  小说人物，往北可通往"名人堂"。
- 角色天赋系统包含膂力、悟性、根骨、身法四项明面属性，以及福缘、
  容貌两项隐藏属性，影响解谜、奇遇与拜师际遇。
- 登入画面会显示历史累计人数、注册玩家数、历史最高在线人数等站务
  统计信息。
