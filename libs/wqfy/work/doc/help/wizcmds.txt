

arch以下指令使用
(注意有些指令一定要小心使用,使用不当者降级)

[arch]指令：
ban (禁止某一ip 连线）
banid(禁止某一id 连线)
call(这个不用说了吧）
changelong(用以描述房间的指令,小心使用）
checkout(查看玩家的装备武功)
cleanup(清楚复制物件,小心使用）
clone(复制物件)
data（观看所指定物件的资料)
edit(编辑）
exec(将某个玩家踢出风云,将禁止玩家ip连线，小心使用)
fei(传送到指定的目标,不显示移动信息）
fuhuo(让某人起死回生)
full(恢复生物的状态）
gift(发放礼物到所有的在线玩家)
kickout(将某玩家踢出风云,玩家将一个小时内不能进入游戏）
nk(让两个NPC或玩家或NPC与玩家互相攻击。)
overview(辅助性文件，用于查看当前风云的基本情况）
possess(嘿嘿，附身哦）
promote(提升巫师等级,小心使用）
purge（永久删除玩家档案,小心使用，绝对不能将purge 后面加数字）
random_name(随机姓名产生系统)
reboot(重新启动游戏）
reclaim(将存在於记忆体里无用的变数清除掉)
recoor(更新系统内部的指令表)
rm(删除档案）
setskill(设置生物的技能）
snoop(监听）
socket(你可以用这个指令显示当前 socket 程序会话情况。)
spy(这个指令可以让你查看在线有那位玩家假装蒙面人、运镖和通缉犯.)
test_npc(随机姓名NPC范例)
tongzhi(添加玩家连线后的通知信息)
update(更新档案)
votetimu(添加玩家投票的题目通知信息,暂时不开通)
wizlock(限制某个等级以下的使用者进入游戏。)

[wizard]指令：
alarm(你可以用这个指令警告任何人。)
chblk(关闭某人的所有频道)
chinese(中英文添加）
config(Show 出本 MUD 的Startup Configuration 。)
cost(这个指令让你测量另一个指令执行所需的时间。)
cp(拷贝档案）
cskill(这个指令让你复制对象的战斗经验和所有的武功技能。)
dest(清除物件)
ff(这个指令可以找出指定物件中的某个函数定义在哪一个档案里。)
fullme(恢复自己的状态)
ghost(这个指令让你在人鬼之间切换！）
halt(可以停止战斗。)
ilist(列出一个物件所继承的所有物件。)
info(利用此一指令可得知一些有关该物件的资讯。)
kickout(将某个玩家踢出风云，并且使其在一个小时内不可以联线)
localcmds(列出你身上及四周的物品与所在的环境提供的所有指令。)
mkdir(建立一个子目录。)
mudlist(这个指令让你列出目前跟这个 Mud 取得联系中的其他 Mud。)
mv(修改某个档案或目录名称。)
nulock(限制风云是否接受新人物．小心使用)
off(此命令将关闭某个频道)
on(开启某个频道）
qiujin(将某个玩家禁锢在风云的轻犯监狱里。)
qlaod(这个指令显示出目前 CPU 的负担)
ran(测试随机函数的分布。)
showbot(显示出目前玩家的进程速度)
showtop(显示出目前玩家的进程速度)
smash(呵呵,消灭生物）
summon(将某人抓到你面前。)
tail(直接读取某档案最末尾的几行。)
tojianyu(将某个玩家禁锢在风云的重犯监狱里)
upemote(这个指令可以自动修正 emote 中的一些错误。)
ulist(将线上所有玩家的/obj/user number 显示出来。)
unchblk(开启某人的所有频道)
uncon(使生物昏迷不醒)
user1(玩家信息查询）
user2(玩家信息查询）
version(这个指令会显示游戏目前所用的 MudOS driver 版本.)
where(得知玩家目前所在的位置.)
who1(玩家信息查询）
who2(玩家信息查询）
who3（玩家信息查询）
whoami(Show 出你的 User ID 及 Effective User ID 。)
whohave(可列出目前携带某个物品的玩家。)

其他巫师指令：
cat(这个指令让你可以查阅一个文件的内容。)
cd(将目前参考的目录移至指定的子目录或回到上一主目录)
checkip(让你察看有关一个IP的所有在线玩家。)
color(这个指令可以让你知道游戏中各种色彩的ANSI控制字元及色彩的试样，从而方便您选择中意的色彩。)
edmote(这个指令可以修改, 删除 emote 或列出其内容. 加上 -d 参数会删除)
goto(将你传送到指定的目标)
ls(列出目录下所有的子目录及档案)
mem(这个指令告诉你某个物件占用的记忆体数量。)
pwd(这个指令会显示出你目前的工作目录 (cwd) 及工作档案 (cwf).)
status(这个指令可以显示出目前游戏的一些相关资料及状况.)
ulist(将线上所有玩家的/obj/user number 显示出来。)
