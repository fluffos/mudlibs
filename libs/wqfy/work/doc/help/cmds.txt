
郑州风云玩家全面指令集：

abandon (放弃某样武功）
alert（召唤大内高手替自己战斗，只有朝廷官员才能使用）
apprentice（拜师的指令）
ask(问，这个指令在解谜时很重要。
本游戏可以使用ask 某人 about all,npc会告诉你他有什么可以询问的。）
beg(乞讨指令，只有丐帮弟子可以使用）
bid(这一指令让你可以参与拍卖，单位为 两银子。)
bingqi(这个指令可以让你知道在线玩家的兵器谱排名。 )
buildroom(建房子的指令）
buy(买物品指令）
cast(战斗指令，咒术）
ce(你可以用这个指令对你的伴侣说悄悄话。)
cemote(这个指令可以让你表达一个系统没有预设的动作词。)
cfy(这个指令可以让你表达一个系统没有预设的动作词, 系统会将你所输入
的文字加上你的姓名後显示给所有在风云的人看．)
cha(这个指令可以让你查询此项技能的功能和绝招。)
close(关，冒险指令）
conjure(战斗指令，法术）
cpu(查看cpu使用情况）
curse(战斗指令，降头术）
dazuo(打坐能恢复精气神）
diaoji(可召唤护卫帮助战斗，大理官员才能使用）
drop(丢掉某样物品）
editskill(这是用来创建自己风格武功的指令)
emote(这个指令可以让你表达一个系统没有预设的动作词)
enable(这个指令让你指定所要用的技能，需指明技能种类和技能名称)
enchant(这个指令让你设定使用魔法武器时要用来导引武器魔力所用的灵力强度)
enforce(这个指令让你指定每次击中敌人时，要发出几点内力伤敌。)
exercise(练内力，提高内力的指令）
exert(特殊内功的功能激发指令）
expell(···用了这个指令，你真是个坏蛋哦，把弟子逐出师们的指令）
fight(切磋武功）
follow（跟随某人）
get(拣东西）
give(给某人东西）
go(行动指令，去某地）
inquire(打听别人的技能，只有丐帮弟子可以使用）
j_wei(召唤卫士替自己战斗，只有锦衣卫头衔的玩家可以使用）
jiasi(装死，魔教弟子可以使用）
kantou(这个指令可以让你砍下地上死者的头颅.）
kill(杀某人！！不可调和的战斗指令！）
lead(这个指令让你主动邀请某个玩家跟随你。)
learn(向师傅学习武功必须的指令）
lianzhi（炼丹指令）
locate(这个指令是用来得知使命物品的大概位置。
朝廷官员还可以用此指令察寻人物的大概位置。)
look(看咯）
map(地图指令）
meditate(练习法力）
open（打开物品，门，窗等，对应于close)
perform(激发特殊武功）
practice（联系特殊武功）
preach（布道，只有剑客才能布道）
put(放某样东西到某样容器里，对应于get)
recruit(收某人为弟子）
remove（fool,宽衣解带····）
reply（回答别人）
research（研究武功，能师傅所不能,青出于蓝）
respirate（练习灵力）
say(聊天指令，说话，同一房间的玩家可以看到你说话的内容）
scribe(战斗指令，使用符咒）
shout（大叫，没开放给玩家，好象从100年前就说准备开放，到现在还是没开放）
sk(最新指令,功能很多。)
sos(这个指令可以在系统出现bug时来向巫师求助。)
steal(偷东西，嘿嘿）
study(风云里面有很多书可以读，这个指令能够读书哦）
suicide(你为什么想不开要自杀，来和我说说···）
surrender（投降，遇到紧急情况可以投降啊，虽然比较那个···）
task(风云使命榜，让你知道有哪些使命没完成）
team（组队指令）
teamkill（组队砍人，嘿嘿）
tell(和某人说话，对应于reply)
tingzhan(可以让对手停止战斗，但是你不可以在战斗中使用。少林弟子专用）
top(天 下 无 敌 在 线 十 大 高 手 )
topten(各项排行榜）
unwield(放下兵器）
wear（穿衣服）
whisper（说悄悄话）
wield（装备武器）
alias(设置快捷键）
alter(改变自造武器的描述）
assign(这个指令可以让你传让一帮之主的地位给另外的人物。)
bang(开帮命令）
bangtalk（门派频道，只有同门弟子能看到）
bangtitle（为弟子取头衔，只有掌门能用）
baohu（可以保护自己的配偶）
boss(老板来了，快····！！）
bossgone(老板走了，继续再战风云。：））
cha(这个指令可以让你查询此项技能的功能和数据。)
ctime(让你知道现实的北京时间）
describe(miaosu)(这个指令让你设定当别人用 look 指令看你时，对你的描述)
destroy（摧毁自造武器）
distribute（分配参数点）
drag(当你被箭一类兵器所伤之后,该兵器会留在你的体内,所以,你需要拔除他们.)
exam(这个指令可以显示你自制的武器的详细资料。)
femote(列出目前所有含指定关键字的 emote.)
finger(这个指令, 如果没有指定使用者姓明, 会显示出所有正在线上玩家
的连线资料. 反之, 则可显示有关某个玩家的连线, 权限等资料.）
help(帮助指令）
hp(查看自己的状态）
lock（锁住屏幕）
id (这个指令可以让你知道物品的英文名称及名字. 只打 id 会显示
你身上所携带物品的名称. 'id here' 则显示所有跟你在同一个
环境里的物件名称.)
inventory(可列出你目前身上所携带的所有物品。)
jiebai(这个指令用来和别人的结拜，当然对方必须也同意。)
news(查看新闻）
nick(设置自己的外号）
noqm(这个指令让你设定当你留言的时候能显示你的签名。)
notskill(这个指令用来设置不传授什么武功给弟子的)
passwd(更改密码）
qianming（这个指令让你设定当你留言的时候能显示你的签名。）
quest(这个指令可以显示出你当前的任务。)
quit(退出游戏）
save（保存）
score(查看自己的状态）
seek(这个指令让你查看玩家的中文名字是哪个英文名字?)
semote(这个指令可以列出目前所能使用的emote.)
set(这个指令让你设定一些环境变数)
skills(查看自己的武功）
to(可以一次输出多行以上的文字)
tune(关掉某个聊天频道）
unset(这个指令让你删除环境变数的设定。)
uptime(这个指令告诉你游戏已经连续运行了多久.)
vote(投票指令）
whistle（叫唤自己的宠物）
who(这个指令可以列出所有在线上的玩家及其等级。)
wimpy(这个指令让你设定当精力，气血，或心神剩下百分之多少时，要开始「转进」。)
wizlist(列出目前所有的巫师名单。)
