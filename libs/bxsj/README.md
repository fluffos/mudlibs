# 书剑天下 (ShuJian MUD)

属于早期 MudOS 武侠 mudlib 系(与 bxsj1《书剑·经典》同源，两者共享大部
分核心引擎代码)。

## 简介

「书剑天下」是一款经典的武侠题材 MUD,由重庆电信 ShuJian MUD Wizard
Group 自 1997 年起开发维护。游戏以门派、武功、江湖恩怨为主线,新人物从
武馆前院起步,可以习武、结交江湖人物、参与门派任务。整体风格偏传统金
庸式武侠,包含完善的个人资料卡、短消息、新闻公告等系统。

## 如何运行

```
cd libs/bxsj
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口:**40004**。

## 如何连接游玩

用支持中文(UTF-8)的 telnet 客户端或 mudclient.py 连接:

```
python3 scripts/mudclient.py 127.0.0.1 40004
```

连接后会先看到一个隐藏提问 **"Are you using BIG5 font(Y/N)?"**——这其
实和游戏内容无关,只是询问客户端字体编码,直接回答 `n`(本项目环境统一
使用 UTF-8/简体显示)即可继续。

注册流程顺序如下:
1. 英文 ID(3-8 个英文字母,不能有数字)
2. 确认创建新角色(y/N)
3. 设置密码(至少 5 位,必须同时包含数字和英文大写字母)——比较容易被
   忽略的一点,很多人第一次设密码会因为漏了大写字母或数字而反复失败
4. 确认密码
5. 输入中文姓名(2-4 个汉字,系统会自动拒绝金庸小说角色名等违禁名字)
6. 选择天赋点数(可输入 0 让系统随机分配,或手动指定其中一项数值)
7. 电子邮件地址
8. 选择性别(m/f)

完成后会直接进入游戏世界(初始地点"武馆前院"),可以用 `look`、
`score`、`i` 等基本指令查看周围环境和个人资料。

## 已知问题

- 少数 NPC(如 `guidao1`)与个别道具脚本存在原始存档遗留的小瑕疵,不影
  响主线注册和基础游玩体验。
- 部分邮件/论坛相关的辅助功能(依赖外部数据库)在本环境下未启用,普通
  游玩不受影响。
- 本游戏在 WASM/浏览器模式下可以启动,但由于底层驱动的 IP 检测限制,
  注册流程无法完成(游戏自带的地区限制模块依赖真实 IP 格式)。
