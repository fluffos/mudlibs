# 大话西游 (A Chinese Odyssey)

原始压缩包名为"武汉站"，但这只是收藏者标注的站点标签——游戏自身的
config 与登录横幅都写明真正的名字是**"大话西游"**，由湖北楚天热线旗
下的襄樊分站运营。属于 ES II（Eastern Stories II）引擎系列，与本项目
中的 weimingkongjian、tiexuejianghu 等同宗但各自独立开发。

## 简介

「大话西游」取材自周星驰同名电影，以搞笑轻松的西游/江湖世界观为底
色，融合门派、武功、装备养成等传统 MUD 玩法。新人物从"南城客栈"起
步，可以找店小二、邮差等 NPC 互动，逐步在江湖中闯出名堂。

## 如何运行

```
cd libs/wuhanzhan
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40052**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40052
```

注册流程没有隐藏的编码/年龄询问：

1. 英文 ID（新角色）
2. 确认创建新角色（y/n）
3. 中文姓名（1-6 个汉字）
4. 设置身份识别码（找回密码用），并确认
5. 设置游戏登陆密码，并确认
6. 电子邮件地址
7. 选择性别（m/f），再确认一次天赋分配

完成后会进入"南城客栈"，`look`、`score` 等指令均已确认能正确显示中文
内容。

## 已知问题

- 少数道具脚本（部分武器、防具）存在原始作者遗留的小瑕疵，均属边角内
  容，不影响主线注册和基础游玩。
- 游玩过程中可能会看到"编译时段错误"一类的提示，是驱动器把一部分无
  害的编译警告显示给了玩家，并非真正故障，可放心忽略。
- 已在 WASM（浏览器/无网络端口）构建下测试：启动、注册、登录、`look`/
  `quit` 均正常，可完整游玩，无 WASM 特有限制。
