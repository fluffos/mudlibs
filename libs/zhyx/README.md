# 中华英雄

本游戏自称 中华英雄，源码自述为"中华英雄MUD FluffOS v2017 版"，
是原作者仍在长期运营中的 mud.ren:5000 的实际线上版本。属于经典的
"ES II" 引擎家族（与本项目中的 es1_win、xkx2001、rzrmud、xo、武汉站、
炎黄武魂等同宗，master.lpc 自带的作者传承注释一字不差），但独立演化
多年，已与家族内其它成员有大量差异，拥有自己独立的近百个地图分区
和完整的门派、武功、任务体系。

## 内容亮点

- 世界观以传统江湖门派、拜师学艺、行侠仗义为主线，注册流程与
  这一引擎家族的经典写法一致（英文账号名、中文姓氏+名字、双重
  管理/普通密码、1-5 种角色资质、性别），登录后落在"世外桃源"
  起始场景。
- 游戏规模很大（转换后近一万六千个 `.lpc` 文件），涵盖武功、门派、
  转世投胎、拍卖、留言板等一整套传统武侠 MUD 玩法。
- 本次移植修复的最大影响的 bug：`master.lpc` 的 `log_error()` 把
  "warning"（小写，本驱动实际输出的拼写）误判成了真正的编译错误，
  导致此前几乎每一次场景/NPC 第一次被懒加载编译时只要带有任何一
  条普通警告（非常常见），就会把系统默认错误提示直接广播给当时在
  线的玩家——修复前一次简单的进场就能连续弹出十几条"你发现事情
  不大对了，但是又说不上来。"，修复后完全消失。
- `dns_master.lpc` 会真实监听一个 UDP 端口，并在测试期间实际收到过
  来自另一个真实运行中的中文 MUD 的"泥潭列表"广播——这是本收藏中
  少数几个会产生真实对外网络流量的档案之一。
