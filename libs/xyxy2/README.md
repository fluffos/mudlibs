# 小雨西游Ⅱ (Xiaoyu Xiyou II)

原始压缩包名为"20150716未知lib.zip"（来源不明），实际是"小雨西游"（Xiaoyu Xiyou）引擎家族的第二份快照，和本项目里的 `xiaoyuxiyou`、`xyxyutf8` 同属一支——三者共享同一张"傲来国"地图（`chinese.c` 档案与世界地图数据一致），但内容哈希比对显示彼此并非字节级重复，各自是游戏开发不同阶段留下的独立快照。新角色其实是从傲来国的"翠香楼"起步——《西游记》原著里孙悟空的出生地——而不是长安酒楼；玩家先找陪练 NPC 安全练级，再拜入武馆师傅门下学艺，之后能乘筏渡江前往长安，加入百花谷门派；死亡后会被送往地府的一处驿站小镇，那里设有专属的生死公告栏，复活时还会有真实的属性惩罚。

## 内容亮点

- 以《西游记》神话世界为背景，围绕取经路上的门派、法宝、妖魔展开，
  融入了经验值/潜能等类 RPG 数值成长要素。
- 游戏从傲来国"翠香楼"起步，新人物可以拜师习武、结交
  江湖侠士、闯荡各地妖魔盘踞的秘境。
- 整体风格轻松、偏合家欢向，站点自述"多谢你看一看上面的游戏建议，
  祝你游戏愉快"。
- 注册需要设置两组密码（管理密码 + 登陆密码），管理密码强度要求较高
  （需混合大小写字母和数字/符号）。
