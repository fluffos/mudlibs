# 紫藤站

## 游戏名称

**大唐西游之紫藤站**（登录后横幅也作【紫藤西游】），属于 **ES II 引擎
系列**（与 `es1_win`/`xkx2001`/`rzrmud` 等同源，master 文件署名同样能
追溯到 "for ES II mudlib, original from Lil, rewritten by Annihilator"）。

## 简介

以《西游记》世界观为背景的老牌武侠/仙侠 MUD，"大唐西游"这个招牌在本项目
处理的多个压缩包里都出现过，本作是其中"紫藤站"这一具体分支/服务器实例。
新角色创建后会经历天赋点分配的小游戏，随后进入以"南城客栈"为起点的江湖
世界，整体内容和游戏系统比较完整。

## 如何运行

```
cd libs/zitengzhan
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40071**

## 如何连接游玩

```
telnet 127.0.0.1 40071
# 或
python3 scripts/mudclient.py 127.0.0.1 40071
```

注册流程：

1. 先选编码 `gb`/`big5`，输入 `gb` 即可。
2. 接着有一个"1=进入 2=退出"的选择，输入 `1`。
3. 英文名字提示里，新玩家输入 `new` 进入注册流程，再输入一个新的英文名。
4. 输入真实中文姓名（可以正常一次性通过）。
5. 依次设置"管理密码"和"普通密码"（各输入两次），再输入邮箱地址。
6. 选择性别（`m`/`f`）。
7. 最后有一个"体格/根骨/悟性/灵性"天赋点分配小游戏：直接按 `9` 使用默认
   属性，再输入 `y` 确认，即可正式进入游戏世界。

**小提示**：如果在天赋点分配这一步之前就急着输入 `look`/`score` 等指令，
会被当成对分配菜单的（无效）回答而被吞掉，等确认完天赋点分配之后再输入
即可正常使用。

## 已知问题

少量非主线的周边内容（个别道具、极少数深层区域的 NPC 文件）在原始压缩包
里就存在缺失，属于原始存档本身内容不全，不影响主线的拜师、探索、
`look`/`score` 等基础玩法。此外角色创建成功后偶尔能看到一行显示内部对象
编号（如 `/obj/login#0`）的调试信息，是原作者遗留的调试输出，无实际影响。
