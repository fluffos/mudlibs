# 星战英雄

## 游戏名称

本游戏全名《乱世风沙之星战英雄》，属于早期国产 MudOS（xkx 系）派生的
武侠 Mud。虽然名字听起来像科幻题材，实际是一款以江湖门派、内功外功为
核心玩法的传统武侠 Mud，"星战"只是原作者取的一个响亮站名，与太空战争
无关。

## 简介

游戏开场会让新人物在"新手集中营"里选择投奔凤凰星、特种部队、圣殿、
皇族四个门派之一，之后便正式踏入江湖，靠杀敌、历练来提升膂力、悟性、
根骨、身法等天赋修为。整体节奏偏传统练级流，人物档案、称谓体系都做得
比较完整，适合喜欢老派文字 Mud 战斗与门派养成的玩家。

## 如何运行

```
cd libs/xingzhanyingxiong
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口固定为 **40002**。

## 如何连接游玩

用任意 telnet 客户端或脚本连接 `127.0.0.1 40002` 即可，示例：

```
python3 scripts/mudclient.py 127.0.0.1 40002 --send "" --send "look" --send "quit"
```

注册流程没有任何隐藏门槛，按提示顺序输入即可：

1. 英文名字（3-12 位纯小写英文字母，不能有数字或大写）
2. 确认使用该名字创建新人物（y/n）
3. 中文姓名（真实汉字，2 个字以上都可以正常通过）
4. 设置密码、再输入一次确认
5. 是否接受随机分配的天赋（y/n，选 n 会重新随机一组）
6. 电子邮箱（格式需要包含 @ 和 .，可随便填一个测试邮箱）
7. 选择性别（m/f）

完成后就会直接进入新手集中营，可以用 `look`、`score` 等指令查看周围
环境和角色状态。

## 已知问题

这份存档看起来是当年"核心版"，没有带上完整的世界地图——武当、少林、
华山、峨眉、唐门、明教等经典门派对应的场景文件都不在这个压缩包里，
只有留言板等少量对象还残留着指向这些地方的引用，实际游戏中不会遇到，
纯粹是历史遗留的空引用。另外极少数 NPC 设定的武功招式在这份存档里也
没有对应实现，属于同类内容缺失，不影响正常游玩。
