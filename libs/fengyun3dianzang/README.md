# 风云典藏版 — fengyun3dianzang

## 游戏名称

**风云典藏版**（风云 3.8.0，"风云工作室"内部整理的一份"收藏版"合集，
在"风云3.7.4"基础上补充了此前未发布/散佚的原创内容）。属于本批次的
**"风云3"（Fengyun III）引擎分支**，核心引擎代码与 `fengyun3xiuding`
（星星修订版）几乎完全一致。

## 简介

以古龙武侠小说为背景的江湖世界，是"风云3"引擎中内容最完整的一个
打包版本之一。新角色从凤求凰客栈起步，可以自由选择任意喜欢的中文
名字（这一版对中文名字没有额外限制），再选择性别和民族（汉族/苗族
/满族/蒙古族）后即可正式踏入江湖。

## 如何运行

```
cd libs/fengyun3dianzang
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务器监听端口：**40090**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40090 --timeout 25 --idle 0.5 \
  --send "英文名字(3-10位纯小写字母)" --send "y" \
  --send "你的中文名字" --send "m" --send "0-3选择民族" \
  --send "look" --send "score"
```

连接后直接是英文名提示。依次输入：英文登录名（3-10 位纯小写字母）
→ 确认新建角色 (y/n) → 中文名字（此版本没有密码设置这一步，直接
跳到性别）→ 性别(m/f) → 民族（0=汉族/1=苗族/2=满族/3=蒙古族）。
完成后立即进入游戏。

也可使用普通 telnet：`telnet 127.0.0.1 40090`。
