蟠桃会／封神榜

蟠桃会／封神榜已经基本组装调试运行，因为设计有点复杂，尚有很多不
妥之处。尤其是在分块测试时往往无大错，组装后特别是在众多玩家加入
后会有意外发生。

请各位巫师巫婆对蟠桃会／封神榜鉴定。由于此项设计是多玩家游戏，在
试玩时可能需要近十名玩家＋巫师巫婆联合行动。

下面是主要的三个部分：

１。邀请
  －蟠桃会／封神榜放在/d/pantao/, 暂时没有直接入口，需要有巫师
    监督，将种子选手抓进方可开始。等以后蟠桃会／封神榜通过了鉴
    定再考虑设置正常入口。
  －种子选手向太白金星（可以是其他ＮＰＣ，以下每次涉及太白金星
    都如此）寻问蟠桃会／封神榜，太白金星向玉皇大帝请示。
  －如果该选手道行过低（＜５０年），拒绝。否则玉皇大帝御批：先
    进行封神演礼，成功后方可举行蟠桃宴。
  －太白金星宣布蟠／封仪式开始，玩家可以用accept让太白金星一一
    护送上天。

２。封神演礼
  －太白金星请玩家带去见日月金木水火土天神去会战。
  －每场会战需有点占在线总玩家１／４的人在场，否则太白金星拒绝。
  －赢者取代输者夺榜，由太白金星宣布神号，如果赢家原来已有神号，
    旧神号取消；如果输者是另一玩家，神号降低一级（日＞月＞金＞
    木＞水＞火＞土）。
  －会战时禁止使用多人战术，禁止杀，偷，和使用法术逼迫对方杀人。
    道行过低者无权挑战，神号高的不得向神号低的挑战。
  －获得神号的玩家将有“永久替身”置于大殿之内直至被另一挑战者
    取代。每次会战前替身将自动康复且采用的玩家最新技艺，以避免
    日久不得不人工复制替身，也可避免挑战者采取疲劳战术。
  －每一次会战后，如果玩家中有任何人想继续挑战，可以向太白金星
    提出邀请。
  －如果在进行了几轮之后，没有人再挑战，夺榜的任一玩家可以带领
    众人去封神台拜榜请宴。
  －新的封神榜在封神台自动公布。
  －太白金星去请王母娘娘批准开宴，宣布蟠桃胜会开始。并亲自带领
    众人去瑶池赴宴。

３。蟠桃大会
  －瑶池蟠桃会开始，彩衣七仙女入场，开始向来宾不断地献上仙桃和
    仙酒。
  －其间酒官和仙女不时送上仙肴琼浆。音乐，舞蹈出现。
  －门外陆续宣告各路名人仙客圣贤ＮＰＣ到场，这类ＮＰＣ只是前来
    赴宴申谢便匆匆退场。
  －在瑶池以外的玩家可以断断续续地看见天上的霞光，或是听见天边
    远处的金钟齐鸣。
  －宴会过半（５分钟）后，玩家可以退席，让太白金星护送回返原处，
    夺榜新封神号的玩家可以提出集体谢宴，太白金星一一将玩家送回。
  －如果宴会１０分钟后，依然没有散场，太白金星主动奉王母之命谢
    客，一一送走来宾。
  －彩衣七仙女退场。


各位巫师巫婆在鉴定和测试时，请注意以下几点：

  －蟠桃会／封神演礼必须由巫师启动：将某一名种子选手抓进该区域。
    等到巫师们认为此区域能够可靠运行之后，再设置入口。
  －在任何情况下，如果巫师和玩家不知道下一步该怎样做时，可以向
    太白金星询问：ask tai bai about help 或 ask tai bai about ?
    均可。
  －太白金星在两种情况下处于busy状态（不能远途接客，送客，不能
    跟随玩家去另一大殿会战：（１）封神演礼时，某一玩家正在交战
    之中；（２）蟠桃宴会前半场时，各项仪式尚在进行中。

有一些已知的问题有可能会发生，也可能会封神演礼或蟠桃会停顿：
  －MUD Driver 拒绝过长的 function execution, 尽管很多functions
    都重新写过以避免其发生，但这种情况在到场人数特别多时或许
    还会发生，比如散场时太白金星将所有赴宴的玩家一一送回地面
    再将七仙女送回各自的霞亭。(too long function execution error)
    典型症状是太白金星做了一半工作就发傻不干了，在程序里已经做
    了修改以杜绝此类意外，但是如果一旦发生了意外请巫师记载下来
    是何时何地发生的并作人工应急处理。
  －今天发生了一起【战斗精灵】报警bad action,但我试了几次未能
    再次重复，请巫师密切注意。
  －封神演礼时，万一出错（演礼因too long function execution error
    而停顿）而导致排版混乱，请去/data/pantao删除相应文件。
  －万一太白金星因为too long function execution error需要清场时
    请将太白金星带回瑶池，将七仙女移出瑶池。万一太白金星由于同样
    原因一直处于busy状态，请call tai->delete_temp("pantao/is_busy")

谢谢各位巫师巫婆的大力帮助！
