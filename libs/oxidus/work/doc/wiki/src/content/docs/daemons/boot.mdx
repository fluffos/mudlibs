<ClassBrowser language="lpc" name="BOOT_D" source="adm/daemons/boot.c" type="object">
  A small persistent daemon that tracks how many times the game has
  booted. The boot number is useful for gating one-time-per-boot
  behaviour. `BOOT_D` listens for `SIG_SYS_BOOT`, increments its counter,
  and saves; everything else just reads the count.

  <ClassExtends label="inherits" name="STD_DAEMON" source="std/daemon/daemon.c" highlight="object" />

  <ClassMethod name="boot" visibility="public" highlight="function">
    Signal handler for `SIG_SYS_BOOT`. Increments and logs the boot
    number, then persists it. Rejects callers other than the signal
    daemon.

  </ClassMethod>
