# 小雨西游

## 游戏名称

游戏自身配置里写的名字是《小雨西游》，但实际登录横幅打出来的是
《小雨西游Ⅱ》（v3.0，2013 年建站），两者是同一套引擎在不同年份、不同
站点的快照，内容基本一致。它与本项目另一个已转换的库
`unknownlib20150716`（20150716未知lib）同属一个引擎家族（`chinese.c`
文件完全一致）。

## 简介

这是一款以《西游记》为背景的西游/仙侠题材 Mud：故事发生在傲来国、
翠香楼一带，人物设定、任务、地名都紧扣西游神话世界观，整体偏向传统
取经/降妖除魔的养成流玩法。系统里还带有帮派（clan）、天界消息、留言板
等比较完整的社区功能。

## 如何运行

```
cd libs/xiaoyuxiyou
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口固定为 **40046**。**注意：驱动刚启动的 30 秒内会拒绝所有连接**
（提示"驱动程序正在启动过程中，请稍候再来"），这是游戏自带的启动保护，
等 30 秒后再连线即可。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40046 --timeout 30 --idle 1.2 \
  --send "gb" --send "1" --send "new" --send "<英文ID>" \
  --send "<中文名字>" --send "<管理密码>" --send "<管理密码>" \
  --send "<密码>" --send "<密码>" --send "<邮箱>" --send "m或f" \
  --send "9" --send "y" --send "look"
```

注册顺序如下，务必按此顺序回答，中间没有隐藏陷阱，但项目较多：

1. 选择编码 `gb`（简体）或 `big5`（繁体）
2. "①进入游戏 ②立即退出"——输入 `1` 进入
3. 英文 ID：新玩家直接输入 `new`
4. 再输入一个 3-8 位的新英文 ID（会自动确认，无需再按一次 y）
5. 真实中文姓名（2-4 个汉字都能正常通过）
6. 一组"管理密码"（用于找回账号，要求 6 位以上且大小写字母都有，
   并至少含一个数字/符号）及确认
7. 一组日常登录密码（5 位以上，且不能和管理密码相同）及确认
8. 电子邮箱
9. 性别 m/f
10. 天赋点数分配界面：输入 `9` 接受当前的默认分配，或 0-3 重新分配某一项，
    再输入 `y` 确认进入游戏

进入游戏后即可用 `look`、`score` 等指令查看角色状态，这套系统的角色档案
是仿古典风格的"个人档案"卡片，中文显示完全正常。

## 已知问题

系统自带的表情文字库（`emoted.o`）存档在原始压缩包里就有轻微损坏，
导致部分 `emote` 指令的花式文字提示不完整，纯粹是历史遗留的存档问题，
不影响正常聊天和战斗。此外游戏里能看到不少"编译时段错误：...warning:
Unused local variable"之类的提示随聊天记录一起弹出——这是这款 Mud
本身的设计（把编译警告实时广播给当前连线玩家），并非真的出错，可以放心
忽略。
