# 小雨西游

游戏自身配置里写的名字是《小雨西游》，但实际登录横幅打出来的是
《小雨西游Ⅱ》（v3.0，2013 年建站），两者是同一套引擎在不同年份、不同
站点的快照，内容基本一致。它与本项目另一个已转换的库
`xyxy2`（20150716未知lib）同属一个引擎家族（`chinese.c`
文件完全一致）。

## 内容亮点

- 以《西游记》为背景的西游/仙侠题材 Mud：故事发生在傲来国、翠香楼
  一带，人物设定、任务、地名都紧扣西游神话世界观，整体偏向传统取经/
  降妖除魔的养成流玩法。
- 系统里还带有帮派（clan）、天界消息、留言板等比较完整的社区功能。
- 注册时设有两套独立密码：一组用于找回账号的"管理密码"，一组日常
  登录密码。
- 驱动刚启动的 30 秒内会拒绝所有连接（"驱动程序正在启动过程中，请
  稍候再来"），是游戏自带的启动保护设计。
