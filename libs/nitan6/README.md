# 笑傲江湖 (nitan6)

## 游戏名称

《笑傲江湖》，底层标注"NT.XAJH Library 5.1g" / "NTOS V2.4"，属于本项目中
体量最大的两个"泥潭/nitan/Lonely"系列引擎库之一（与 nitan170911 同源，
后者需要外部 MySQL 支持，本库不需要）。取材于金庸同名武侠小说的江湖世界。

## 简介

标准的金庸风格武侠泥巴：日月神教、华山、少林等门派体系，取一个响亮的江湖
称号，从"生命之谷"投胎入世后，靠内功、轻功、拳脚、兵器四大类修为闯荡江湖。
这是一个内容非常庞大的库（超过2.3万个文件），系统完整度也相对更高（帮派
威望、军功、结婚生子、坐骑等系统一应俱全）。

## 如何运行

```
cd libs/nitan6
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40019**。作为超大型库，驱动预加载可能需要一点时间，如果连接
后看到空白或提示尚未就绪，等几秒重试即可。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40019
```

完整注册流程：

1. 输入 3-10 位英文名字，确认创建新角色 (y/n)。
2. 依次输入中文**姓**、中文**名**（各不超过两个汉字）。
3. 设置"管理密码"（找回密码用）和"普通密码"（日常登录用），均需再输入
   一次确认。
4. 选择性别 (m/f)。
5. 这里有一个**容易被忽略的"按任意键继续"过渡画面**（3 秒后会自动跳过），
   如果用脚本连接，记得在这一步额外发送一次空行，否则后续指令会被这个
   过渡画面"吃掉"，看起来像是指令毫无反应。
6. 进入"泥潭注册室"后，输入 `register 你的邮箱地址` 完成注册（会被传送到
   "生命之谷"）。
7. 在"生命之谷"依次执行：
   - `choose <1-4>` 选择性格
   - `washto 20 20 20 20` 分配四项天赋（每项 13-30，总和不超过 80）
   - `born <籍贯>`（例如 `born 扬州人氏`）正式"投胎"完成角色创建

完成后即可正式游玩，`look`、`score` 等指令均已验证正常工作。

## 已知问题

- 本次复查中发现并修复了一处会导致 `score`/战斗系统崩溃的问题：部分战斗
  相关代码调用了一个原始归档遗留、本驱动从未支持过的底层运算函数，已经
  用普通整数运算重新实现，现在 `score` 指令可以正常显示完整的角色档案。
- 另发现一处非阻断性的显示问题：角色档案（`score`）里"职称"一栏的中文
  全名有时会显示成"0"而不是真实姓名（英文 ID 和其余属性都是正确的，
  游戏本身可以正常进行）。已定位根因（一个底层特性文件里的属性读写调用
  没有显式指定操作对象，导致落到了错误的存储位置），但尝试修复后会引发
  更严重的注册流程卡死问题，因此本次复查选择保留原状、只记录问题，未做
  修改——两权相害取其轻，避免因小失大。
- 由于文件数量巨大（超过 2.3 万个），本次验证没有进行全库静态编译扫描，
  以实际启动+连线游玩作为验证依据（与同类超大型库的处理方式一致）。
- 本次复查还发现并修复了一处会导致**每一个新角色都无法创建成功**的
  隐藏问题（原始归档自带的一个非法字符常量语法错误，导致角色基础类
  编译失败）；修复后已验证注册、进入游戏世界（含额外的邮箱注册步骤）
  均可正常完成。
- WASM 版本可以正常启动，但每一次连线都会在最开始就被判定为"地址不受
  欢迎"而直接拒绝，无法进入任何提示界面。这是因为 WASM 驱动目前无法
  提供真实的连线 IP 格式，而本库的地址黑名单检查恰好依赖这个格式——
  这是 WASM 驱动本身的已知限制，不是本库的 bug，原生（native）驱动下
  完全没有这个问题。
