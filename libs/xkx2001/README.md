# 侠客行 Ⅰ (The Quest of Oriental Chivalry)

## 游戏名称

**侠客行 Ⅰ**（英文名 *The Quest of Oriental Chivalry*），由 "XiaKeXing
Gaming Group" 制作，登录画面自称 1996-2003 年出品。属于早期"ES II"引擎家族
的一支——与本项目中的 `rzrmud`（大唐西游）、`beimeixiakexing2001`、
`xuanjianlu`（玄剑录）等同属一个更古老的技术谱系，但游戏世界内容各自独立。

## 简介

一款以"侠客岛"为背景的武侠文字 MUD。新角色会先在侠客岛的沙滩上苏醒，由岛上的
"赏善使"张三或"罚恶使"李四迎接并带往登记处办理入岛手续，之后才正式踏入江湖。
游戏世界涵盖少林、武当、华山、丐帮、星宿派等经典金庸门派地图，包含完整的门派
拜师、内功修炼、江湖任务与帮派系统，是一款内容较为丰富的传统门派养成类武侠 MUD。

## 如何运行

```
cd libs/xkx2001
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40021**

## 如何连接游玩

使用 telnet 或本项目的测试客户端连接：

```
telnet 127.0.0.1 40021
# 或
python3 scripts/mudclient.py 127.0.0.1 40021
```

**新手入门流程有两个容易让人困惑的地方，请留意**：

1. **登岛之后不要急着乱按指令**。角色一进入游戏，会先出现在侠客岛的沙滩，
   这时系统只允许极少数指令（`look`、`quit`、`follow`、`say`、`tell`、
   `reply`、`goto`、`suicide`），其余指令（包括 `score`、`inventory`、
   `help` 等）在这个阶段会被静默忽略、没有任何提示——这不是故障，而是游戏
   刻意设计的"新人接引"流程。请耐心等待岛上迎宾的 NPC（张三或李四）主动
   拉着你前往"侠客岛挂名处"（大约十几秒后会自动发生），或者主动输入
   `follow 张三`/`follow 李四`（英文拼音 `zhang san` / `li si`）加快进程。
2. **到达挂名处后，输入 `register 你的邮箱地址`（例如
   `register test@example.com`）完成正式登记**。系统会立刻生成一个全新的
   随机密码并显示给你，同时断开连接——这也是原始游戏的既定设计（一种老式
   防小号验证机制），**不是崩溃**。请记下这个新密码，用同一个英文代号重新
   连线登录，即可正式开始游戏。
3. 首次连接会问 `Do you want to use BIG5 code?(y/n)`，如果你的客户端使用
   简体中文（GB）显示，直接回答 `n` 即可。

## 已知问题

- 游戏内一个"公告栏归档"相关的小功能（`EDITOR_D` 服务）在本存档中缺失，
  属于原始压缩包本身未附带的边缘小功能，不影响正常跑图、拜师与日常游戏。
- 少量边缘剧情文件存在原始压缩包自带的文字缺损或语法小问题，均为深层地图
  内容，不在正常新手路线上，不影响整体可玩性。
- **WASM（浏览器/无网络监听端口运行模式）下可以完整体验注册流程**：包括本
  游戏特有的"侠客岛"新手引导（跟随接引使者到挂名处、`register` 指令领取新
  密码）均已验证可以正常工作；受限于测试工具本身（每次运行都是全新的内存
  文件系统，无法在同一进程内模拟"断线后用新密码重新连线"），本轮未在 WASM
  下进一步验证重新连线之后的 look/score/quit，但原生模式下该完整流程已经
  过完整验证，均正常工作。
