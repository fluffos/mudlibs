# 金庸群侠传（2008 标准版）

本压缩包对应"2008版"（标准版），与本项目中的"金庸群侠传2008加强版"是
完全相同的服务端引擎核心（master、登录、安全模块等关键文件逐字节
一致），仅任务数量和个别场景描写比加强版更精简。

## 内容亮点

- 以金庸武侠世界观为背景：少林、武当、丐帮、明教、桃花岛等门派悉数
  登场，玩家从"客店"起步拜师习武、行走江湖，内容量比"加强版""超豪华
  版"略精简，适合想快速上手体验这套引擎玩法的玩家。
- 拜师系统里有一处彩蛋：向风清扬门下拜师会触发"风清扬现在共有 N 个
  徒弟"的实时播报文案。
- 城内的"武庙"与阴曹地府的死亡转生房间都各自会记录角色的固定复活点，
  是这套引擎里少见的、明确区分"临时安置"与"正式家园"的复活设计。
