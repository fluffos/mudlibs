                            神仙编程规范


先想到这些，请大家多提出意见。

一、写程序时，每一段程序前都要加上版权标志：

/****************************************************************
 * This file is a part of the TianXia(天下, The World)'s MudLib.*
 * Please retain the header if you use it.     -- Micro@TianXia *
 ****************************************************************/

// File     : FILENAME.c
// Purpose  : 这里是文件简单的说明
// Updated  : YYYY-MM-DD
// By       : ID@TianXia

// History  : 1997-06-15  Micro@TianXia 更新文件
//            1997-10-08  Micro@TianXia 添加chinese_time函数

下面进行注释：
File            后填入具体的文件名
Purpose         后填入简单的用法
Modified        通常指小量修改别人的程序
Rewrote
Updated         通常指大量修改别人的程序
Created         通常指基本都是自己的东西
Modified, Updated, Created 后面加上最初日期
By              后签上自己的 ID
History         后写上文件的历史，格式是：时间，人物，事情

注：我觉得有一些事情是要注明清楚的，例如：原始程序从何而来，何人出的想法等等


二、每个函数前要对函数的用法进行说明

// 函数：函数的功用说明
// 注释：一些用法或者注意事项

所有说明行右界为70，加上标点不能超过72。
注释请注明 1. 2. 3. ....


三、变量定义时，前面加上一个字符表示变量类型。

int iSize;
string sTime;
mixed mDict;
mapping mpData;             

mapping 和 mixed 都是以 m 开头的，为了区别。
我们把 mapping 的变量前面加上 mp 而不是 m。

当变量的第一个字符与类型相同时，可以省略类型字符。
当然尽可能不要相同啦。

我们把 i, j, k 内定为整数，而且通常用于循环之中


四、要采用缩入格式写程序，每一个 tab 使用八个空格。


五、判断条件两边要有空格

if( XXXX )
