# 侠客英雄传 III

## 游戏名称

**侠客英雄传**（本次收录的是"III"版本）。属于早期国产 MudOS 自研引擎，
`adm/obj` 目录结构的小型武侠 MUD，没有明确的"系列血统"可归类——是一个
独立开发的小型作品。

## 简介

这是一个颇为特别的"混搭"世界：游戏登录界面自称"以金庸小说、西欧中世纪
传说及漫画为背景"。也就是说，你可以在同一个世界里遇到江湖门派、也能撞见
西欧风格的骑士传说与漫画式的种族设定——新手创建角色时甚至要在人类、矮人、
精灵、妖精、龙人、兽人之间选择种族，这在同类武侠 MUD 里并不常见。整体
规模不大（约3800个文件），适合想尝鲜"东西方奇幻混搭"设定的玩家。

## 如何运行

```
cd libs/xiakeyingxiong3 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40036**。

## 如何连接游玩

用telnet或提供的测试脚本连接：

```
python3 scripts/mudclient.py 127.0.0.1 40036
```

也可以用任意支持 GBK/UTF-8 的 MUD 客户端直接 telnet 到该端口。

创建角色时的实际流程（与常见的"直接输入未注册ID即可注册"不同，这里没有
特殊的隐藏前置问题，但要注意几个容易卡住的细节）：

1. 英文ID：**只能是纯英文字母**（不能带数字），长度 3-12 位。
2. 确认新建角色（y/n）。
3. 中文名字：**必须使用真正的中文字符**，长度 1-6 个字。注意游戏明确
   提示"请勿使用金庸小说中的人名"（如"张三丰"这类历史/小说人物名会被
   禁止），建议自己现取一个。
4. 密码：**必须同时包含大写字母、小写字母和其他字符**（例如
   `Mud-1234` 这种形式），且不少于6位。
5. 确认密码、填写邮箱、选择性别（m/男 或 f/女）。
6. 最后会让你从人类/矮人/精灵/妖精/龙人/兽人中选一个种族（输入
   0-5 的数字）——选择后即正式进入游戏世界。

## 已知问题

- 部分场景内容存在缺口（lpcc 编译扫描约98%通过，剩余多为未被主线触及的
  技能/战斗相关脚本或个别语法小瑕疵），日常游玩不会碰到。
- 属于早期"试运行阶段"存档，游戏内公告也自称"处于试运行阶段"，内容量比
  成熟大型武侠 MUD（如金庸群侠传类）要小一些，胜在设定新颖。
