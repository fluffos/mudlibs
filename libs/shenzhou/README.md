# 神州

自我介绍为**【神州】**（"Divine Land"），站点由"神州开发公会"运营，
属于"ES II"引擎家族（与本项目中的随缘洗剑录、天下无雪等同宗），是一个
经过多代维护者接力开发的老牌中文武侠 MUD。新角色从"新手的殿堂"开始，
逐步熟悉江湖世界后正式踏入游戏，围绕属性天赋、门派拜师、武学修炼的
经典武侠养成核心之外，还建有离线练功、帮派系统与铁匠职业等长期
养成玩法。

## 内容亮点

- 离线练功、帮派系统、铁匠职业等长期养成玩法。
- 巫师账号设有登录地址限制机制（本地 127.0.0.1 登录已在代码层面
