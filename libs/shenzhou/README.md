# 神州

## 游戏名称

本游戏自我介绍为 **【神州】**（"Divine Land"），站点由"神州开发公会"运
营，属于"ES II"引擎家族（与本项目中的随缘洗剑录、天下无雪等同宗），是一
个经过多代维护者接力开发的老牌中文武侠 MUD。

## 简介

一款传统中文武侠 MUD，新角色从"新手的殿堂"开始，逐步熟悉江湖世界后正式
踏入游戏。游戏内建有离线练功、帮派系统和铁匠职业系统等长期养成玩法，整
体风格偏经典武侠养成路线（属性天赋、门派拜师、武学修炼）。

## 如何运行

```
cd libs/shenzhou && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40066**。请务必在 `libs/shenzhou` 目录下启动，看到
`Accepting telnet connections on 0.0.0.0:40066.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40066
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40066`。注册流程为：BIG5 字
体确认（Y/N，直接回车或输入 N 即用简体中文显示）→ 英文名字 → 确认新建角
色 → 中文姓名（1-4 个汉字）→ 使用密码（两次）→ 保密密码（**注意：这是
一个单独的、至少 10 位的密码，专用于日后密码遗忘时找回角色，不是日常登
录密码，务必牢记**）→ 天赋分配（膂力/悟性/根骨/身法/剩余，输入 0 交由系
统随机产生）→ 电子邮箱 → 性别，全部完成后即进入"新手的殿堂"这一起始场景。

## 已知问题

- lpcc 静态编译检查显示约 98% 的文件通过，未通过部分主要是一整套已经不
  再随游戏分发的旧式邮件/网络中继功能（intermud，本环境未启用），以及一
  个从未接入正式地图的"打工"支线小系统，均不在注册与主线游玩路径上。
- 核心的注册、登录、探索（look）、查看状态（score）、查看物品（i）以及
  退出存档流程均已反复验证工作正常。
- **WASM 版本兼容性**：在新的 WASM 构建下不仅能正常启动，完整的注册、
  登录、look、quit 流程也全部验证成功——本 lib 没有依赖 IP 地址格式的
  登录限制机制，是本批次测试中可以在 WASM 下完整游玩的库之一。
