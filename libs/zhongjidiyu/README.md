# 终极地狱之轩辕传说

## 游戏名称

**终极地狱之轩辕传说**（MUD 内部标识为 `hell.local`）。属于 **ES II 引擎
系列**，与 `es1_win`/`xkx2001`/`rzrmud` 等同属一支，master 文件署名一路
写明 "for ES II mudlib" → "Annihilator" → "Xiang for XKX" → "Doing Lu for
hell"。需要特别说明的是：本项目里还有另外两个名字里也带"终极地狱"字样的
压缩包（`zhongjidiyu_airuoyoulan`、`zhongjidiyu_zhijian`），那两个是"地狱"
分支下的另一条独立血脉，与本作**不是同一款游戏**，只是碰巧都叫"终极地狱"，
三者内容互不相同。

## 简介

以"轩辕传说"为主题的武侠/仙侠向 MUD。压缩包自带的说明文件明确写着"这是
供学习研究用的底层源码，不建议直接拿来架设正式对外服务器"——所以这份存档
本身就是一个"骨架版"，很多城市、门派的地图内容并未包含在这个压缩包里。

## 如何运行

```
cd libs/zhongjidiyu
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40072**

## 如何连接游玩

```
telnet 127.0.0.1 40072
# 或
python3 scripts/mudclient.py 127.0.0.1 40072 --idle 0.5
```

（用 `mudclient.py` 测试时建议加上 `--idle 0.5` 或更短——这个游戏的命令行
提示符每秒都会刷新一次实时时钟，脚本的"空闲检测"逻辑如果等待时间设得太长，
会误以为连接一直"不空闲"，导致后续指令迟迟发不出去，看起来像是卡住了，其
实只是提示符刷新太频繁的缘故。）

注册流程没有隐藏的编码/客户端版本门槛：

1. 英文名字 → 确认创建新角色 `y`。
2. 依次输入中文姓氏、名字。
3. 设置管理密码、普通密码（各输入两次）。
4. 选择角色类型（1-5）、性别（`m`/`f`），随后进入游戏世界（起始地点"世外
   桃源"）。

新角色刚进游戏时属于"未出生"状态，需要先找水笙姑娘用 `register <邮箱>`
注册邮箱，然后走"投胎做人"流程选择资质属性，之后 `score` 才会显示完整的
角色数据；在完成投胎之前 `score` 只会提示"还没有出生呐，察看什么？"，这
是正常的游戏设定，不是故障。

## 已知问题

正如压缩包自带说明所说，这是一份"学习用"骨架存档：长安城、武当、少林等
大部分门派/城市场景在这份压缩包里是缺失的（只保留了新手村、死亡结算等少
数区域），因此很多留言板会提示找不到对应的场景。这属于原始压缩包本身内容
不全，而不是搭建过程中的问题，日常在新手区域探索、注册、查看角色信息等
基础功能都正常。
- 本轮重新验证：LPC 代码已全部跑过格式化工具，并在重新编译的最新驱动上
  完整回归测试通过。**WASM（浏览器/纯 JS）模式下暂时无法登录**——这个
  服务端的版本同步系统依赖真实的网络 socket 功能，WASM 沙盒环境不提供
  这项功能，导致每个新连接在看完开场画面后立刻被断开，连输入英文名字的
  提示都看不到；这是 WASM 环境本身的限制，并非本 mudlib 的问题，原生
  （telnet）模式完全不受影响。
