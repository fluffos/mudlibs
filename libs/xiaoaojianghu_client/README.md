# 笑傲江湖之重出江湖

## 游戏名称

**「笑傲江湖」之「重出江湖」**，作者 AKAI，脱胎自"夕阳再现－江湖风云2－
风云再起"引擎（属于"夕阳再现/XYZX"系列衍生分支，与本项目收录的多部
同系列作品——如《侠客风云》《西阳再现疯狂版》等——师出同门，但游戏
内容各自独立开发）。archive名称中的"服务端+客户端"其实指的是同一套
游戏支持两种连线协议（普通 telnet 客户端 和 TOMUD 菜单客户端），并不
是额外附带了一个独立的客户端程序，直接用普通 MUD 客户端连接即可。

## 简介

经典金庸《笑傲江湖》题材江湖世界：从南大街的客店起步，从"武庙""铁枪
庙"等地展开门派与个人历练。游戏设有膂力、悟性、根骨、身法、福缘、容貌
六项天赋（后两项为隐藏属性，影响解谜与NPC印象），整体是偏正统武侠养成
向的体验。

## 如何运行

```
cd libs/xiaoaojianghu_client && ~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40070**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40070
```

或用任意 MUD 客户端 telnet 连接。**注意一个容易卡住新玩家的隐藏步骤**：
连接后的第一个提示看起来像是在问英文名字，但实际上它检查的是一个
固定的"客户端版本号"——**必须先输入 `2060`** 才能通过这一关，输入其它
任何内容都会被当成使用了错误客户端，弹出警告并断开连接。通过这一关
后才是真正的英文ID/注册流程：

1. `2060`（客户端版本校验，必须输入）。
2. 英文ID，输入 `new` 开始注册（或直接输入你的ID）。
3. 确认(y/n)，然后取一个**中文名字**（不要用金庸小说人物名）。
4. 依次设置**管理密码**和**普通密码**（各自需要输入两次确认）——这个
   游戏比较特殊，有两套密码。
5. 天赋选择：输入 `0` 让系统随机分配六项属性，再确认(y/n)。
6. 填写邮箱、选择性别(m/f)，随后正式进入游戏。

## 已知问题

- lpcc 编译扫描约97.6%通过，个别老旧的商店/交易脚本（如某处店铺的
  付款流程）在原始存档中就已经存在语法缺陷，属于历史遗留内容缺口，
  不影响绝大多数日常游玩内容。
- 站内新闻/公告类内容量不大，属于早期个人站点规模，重在体验核心的
  江湖养成玩法。
- WASM 版本目前无法测试完整注册流程：这不是本 lib 的代码问题，而是
  游戏本身"服务器刚启动10秒内拒绝连线"的设计（原生驱动下完全正常，
  因为真实启动到连线之间自然会超过10秒）与 WASM 测试工具"启动后立即
  尝试连线"的时序不匹配所致，属于测试环境的已知限制。原生（native）
  驱动下完整体验不受影响。
