# 新仙侣情缘之飘渺纪元

属于 ES II 引擎家族，与"仙侣情缘（早期测试版）"（xlqy_early）系出同门，是这套
仙侣情缘代码更完整、更成熟的一个版本（子标题"乱世站"）。

## 简介

一款以《西游记》世界观为底色的仙侣题材 MUD，故事围绕西天取经路上的人物羁绊、
仙魔恩怨展开。游戏内建有完整的门派、天赋、新闻系统，新角色创建时还能自行分配
体格、根骨、悟性、灵性四项天赋点数。

## 如何运行

```
cd libs/xlqy_new2007 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

端口：**40022**

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40022
```

登录流程：

1. 选择编码 `gb` 或 `big5`。
2. 回答"是否是中小学学生"的年龄提示，答 `no` 继续。
3. 输入 `new` 注册，英文名字限定 **3～8 个英文字母**（注意不要超过 8 位）。
4. 依次输入中文名字、密码（两次）、电子邮件、性别。
5. 进入天赋分配画面：可以输入数字微调某一项天赋，或直接输入 `9` 接受当前的
   随机天赋组合，之后还需要再输入一次 `y` 确认接受，才会正式进入游戏世界。

## 已知问题

- 天赋分配那一步如果只输入 `9` 而不接着确认 `y`，系统会一直停在"你确定接受
  当前的天赋设置吗？"的提问上，属于正常的二次确认设计，不是卡死。
- 个别边缘功能（如站内新闻播报的某一处时间戳显示）存在无伤大雅的小瑕疵，不
  影响正常登录和游玩体验。
- 本存档也可在新的 WASM（浏览器/Node 沙盒）模式下完整游玩，注册、登录、
  look/quit 等指令均正常；唯一已知小瑕疵是"上次连线的地址"这一行在 WASM
  模式下会显示乱码而非真实 IP（WASM 驱动本身的已知限制，不影响功能）。
