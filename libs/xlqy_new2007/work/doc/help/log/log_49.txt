涉及两个命令(okip,xokip)和一个setting(allowed_player)                                        
help okip                                                                                    
指令格式 : okip [-a|-d ip]                                                                   
这个指令让你设置你允许登录的ip,                                                              
不加参数可以查询你的连线ip以及已设的okip,                                                    
注意,缺省为不设任何okip,如果你不希望有人从其它ip地址登录你的帐号,就请把                      
你常用的ip加入okip里,不过设了okip之后,你自己也不能从okip之外的 ip地址                        
登录,一旦要设置的话,请考虑全面点.                                                            
-a 增加一个okip,                                                                             
-d 删除一个okip,                                                                             
-d all删除所有okip ,                                                                         
okip允许重复,因为只要从okip列表里找到和登录ip匹配的就允许登录.                               
ip可以使用*通配符,不过-d操作不考虑通配符                                                     
例okip -a 202.119.144.5                                                                      
  okip -a 202.119.*.*                                                                        
  okip -d 202.119.*.*                                                                        
之后okip为 202.119.144.5                                                                     

help xokip                                                                                   
指令格式 : xokip ID                                                                          
这个指令可以删除玩家的okip,但是你必须是那个被删除                                            
玩家所制定的ID.同时参考命令okip.                                                             
用此命令是为了防止紧急时刻在别处上机而设置的。否则                                           
你就只能从允许的ip上线，此命令用后，指定玩家的okip                                           
会被删除（无论在线与否）                                                                     
                                                                                                                       
help setting                                                                                 
                                                                                                                       
allowed_player <字符串>         允许该玩家删除你的okip。注意这样你就不受                     
                                 IP限制，能随便登陆。                                        
                                                                                                                       
                                                                                                                       
大家先学着用用，先设置allowed_player,一旦出错可以用                                          
指定玩家删除你的IP限制。
