# 狂想空间

## 游戏名称

游戏配置和进游戏后的横幅上写的都是《狂想空间》，压缩包文件名里的
"新狂想空间II"其实是收藏站点自己加的标题，并非游戏本名。这是一套
1995 年起源自"ES II"（Eastern Stories II）架构的老牌 Mud 引擎，
2002 年由台湾巫师 wade 发布，与本项目里的 es1_win、esI、xkx2001、
辽宁热线站等多个库同属 ES II 大家族。

## 简介

背景设定是一个"古代中国"的江湖世界，主打门派、帮派制度和轻功、内功
养成，新手报到的地方叫"狂想空间新手入门房间"，里面直接给出各个方向的
导览（新手介绍、指令快速上手、帮派说明、小秘技等），非常照顾第一次玩
这类 Mud 的玩家。

## 如何运行

```
cd libs/xinkuangxiangkongjian2
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口固定为 **40047**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40047 --timeout 45 --idle 1 \
  --send "<英文ID>" --send "y" --send "<中文名字>" \
  --send "<密码>" --send "<密码>" --send "<邮箱>" --send "m或f" \
  --send "20" --send "20" --send "20" --send "20" --send "20" --send "20" --send "20" \
  --send "" --send "look"
```

1. 英文名字（3-10 位纯小写字母）
2. 确认创建新人物（y/n）
3. 真实中文名字
4. 设置密码、再输一次确认
5. 电子邮箱
6. 性别 m/f
7. 依次分配 7 项天赋点数（体格、定性、悟性、胆识、根骨、灵性、容貌，
   每项合法范围 10-30，7 项分完后第 8 项"根骨/福气"会自动按剩余点数
   算出，不用再输入）
8. 直接回车进入游戏

**注意**：如果短时间内反复测试注册（比如刚失败一次马上重试），会触发
系统自带的"请勿连续尝试，请您稍后再连线"防灌水限制，这是正常设计，
等个十几秒再连即可，不需要重启游戏。

## 已知问题

有少量高阶/巫师专用的道具名称，在显示颜色代码时缺了个别拼接符号，
只会让极个别道具的名字显示不完整，普通玩家基本不会遇到。另外还有一批
巫师个人测试目录下的废弃文件、以及一套跨站/域名解析相关的辅助功能，
从未在正常游戏流程里出现，不影响实际游玩。
