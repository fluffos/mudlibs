# 江湖 I (Jianghu I)

传统 MudOS 谱系武侠 MUD,与"书剑"系列(bxsj/bxsj1)代码源流不同,是本项
目中体量最大的 mudlib 之一。

## 简介

「江湖 I」是一款经典武侠题材 MUD,故事从桃花源般的"世外桃源"新手村展
开,配有专门的领路 NPC(水笙、狄云)引导新玩家。游戏内容涵盖门派武
学、战斗、社交称谓系统等传统武侠 MUD 要素,规模庞大,内容丰富。

## 如何运行

```
cd libs/chidi
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口:**40006**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40006
```

注册流程(无需回答隐藏问题,直接从英文 ID 开始):
1. 英文 ID
2. 确认创建新角色(y/N)
3. 中文姓名(若直接回车会由系统随机生成一个名字并询问是否满意)
4. 设置**管理密码**(用于密码遗失时找回,至少 5 字元)
5. 确认管理密码
6. 设置**普通密码**(平时登录用,至少 3 字元,且不能与管理密码相同)
7. 确认普通密码
8. 分配天赋点数(0-4 选择,0 为系统随机)
9. 电子邮件地址
10. 选择性别(m/f)

完成后进入"世外桃源"新手村,`look`/`score` 等指令均正常工作,系统会提
示尚未设置 Email(可用游戏内 `chfn` 指令后续补充,不影响游玩)。

## 已知问题

个别技能/道具相关脚本(如涉及 `DIABLO_D`、部分技能名称常量)存在原始
archive 遗留的内容缺口,属边角内容,不影响主线注册与基础游玩。
