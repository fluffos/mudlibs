# 江湖 I (Jianghu I)

一款体量庞大的经典武侠 MUD，传统 MudOS 谱系，与"书剑"系列（bxsj/bxsj1）代码源流不同。新角色从"世外桃源"起步，东南西北四个出口对应四种不同性格，决定初始气质；找路遇的使者一问江湖事，即可一次性获得大量技能点数与装备起步，比正式拜师快得多。拜师门槛因门派而异——少林清无比丘对新人几乎零门槛，华山、武当等名门正派掌门则要求深厚根基，需要先历练一番才可图谋正式拜入师门。切磋（`fight`/`hit`，有别于真正的 `kill`）在任一方气血或精神耗到约五成时会自动收手，不会真正打死人；断线玩家也不会被送往任何暂存空间，重新连线即在原地恢复位置、状态与背包。

## 内容亮点

- 新手从"世外桃源"起步，入口房间提供四条性格分支（东/南/西/北四个出口
  分别对应不同性格，如 `east` → 光明磊落），决定角色初始气质。
- 直接的"新手赠礼"捷径：找到使者一问江湖事，即可一次性获得识字 1000 及
  刀法/闪避/内功/招架/剑法/擒拿六项技能各 300 级，外加属性、潜能、经验
  与两件兵器——比正式拜师快得多的起步方式。
- 拜师体系分层明显：少林派清无比丘不设门槛，是新人唯一"零门槛"可拜的
  师父；而华山岳不群（要求悟性≥20）、武当张三丰（要求神识≥500万、
  悟性≥150、太极神功≥100）等门派掌门则对新手完全遥不可及，需要先历练
  再图谋正式拜师。
- 战斗设计偏"结构性安全"：`fight`/`hit`（区别于真正的 `kill`）在任意一
  方气血/精神降到约五成时会自动停手，不会真正打死人，无需额外的木人/
  陪练机制。
- 断线（net-dead）不会被送入任何"虚空"暂存房间——原地保留，重新连线后
  精确恢复位置、状态与背包，验证过短暂重连和真实等待约 100 秒后重连两
  种情形均正常。
