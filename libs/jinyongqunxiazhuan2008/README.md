# 金庸群侠传（2008 加强版）

本游戏自称 **金庸群侠传**，本压缩包对应"2008加强版"这一内容版本。属于
"ES II"引擎家族的一个独立分支（源自作者 Phoebus.suny 1998 年的 ES2
"天曹地国"版本），本项目中还收录了同一引擎核心的另外两个内容版本
（标准版、超豪华版、2015版），可以理解为"同一套服务端程序，不同的
关卡/内容配置"。

## 内容亮点

- 以金庸武侠小说世界观为背景：少林、武当、丐帮、明教、桃花岛等门派
  悉数登场，玩家从"客店"起步拜师习武、行走江湖。
- 游戏系统偏传统门派养成路线（属性、武功、任务、帮派声望），"加强版"
  相较标准版补充了更多的任务内容与场景描写，是三个版本中内容较为
  丰富的一支。
- 拜师系统里有一处彩蛋：向风清扬门下拜师会触发一段"风清扬现在共有
  N 个徒弟"的实时播报，是这套引擎里少见的、带全局计数状态的收徒文案。
