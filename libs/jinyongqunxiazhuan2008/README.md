# 金庸群侠传（2008 加强版）

## 游戏名称

本游戏自称 **金庸群侠传**，本压缩包对应"2008加强版"这一内容版本。属于
"ES II"引擎家族的一个独立分支（源自作者 Phoebus.suny 1998 年的 ES2 
"天曹地国"版本），本项目中还收录了同一引擎核心的另外两个内容版本
（金庸群侠传2008版·标准版，金庸群侠传2008超豪华版），三者可以理解为
"同一套服务端程序，三种不同的关卡/内容配置"。

## 简介

以金庸武侠小说世界观为背景的中文 MUD：少林、武当、丐帮、明教、桃花岛
等门派悉数登场，玩家从"客店"起步拜师习武、行走江湖。游戏系统偏传统
门派养成路线（属性、武功、任务、帮派声望），"加强版"相较标准版补充了
更多的任务内容与场景描写，是三个版本中内容较为丰富的一支。

## 如何运行

```
cd libs/jinyongqunxiazhuan2008 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40082**。请在 `libs/jinyongqunxiazhuan2008` 目录下启动（保
证日志写入同目录 `log/debug.log`），看到 `Accepting telnet connections
on 0.0.0.0:40082.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40082
```

或用任意 MUD 客户端 telnet 连接 `127.0.0.1 40082`。注册流程为：英文
名字 → 确认新建角色 → 中文姓名 → 密码（两次）→ 随机天赋是否接受 →
电子邮箱 → 性别，通过后进入"客店"这个新手起点，流程直白，没有额外的
隐藏前置关卡。

## 已知问题

- 明教分舵的几名 NPC 引用了本包中并不存在的两门功法（玄猿臂、两仪剑），
  以及一整片没有随附的地图区域，均是原始资料包本身内容不全，不是运行
  环境的问题。
- 极少数公告板的存档数据在原始版本中已损坏，会自动当作空白告示板处理；
  英文/中文姓名互译词典的存档同样属于原始损坏数据，翻译功能会退化为
  原样返回，均不影响正常游玩。
- 少数管理员专用指令因所依赖的旧版底层接口在现代驱动上不存在，暂不可用，
  均为幕后维护工具，普通玩家接触不到。
- 已在重新编译的驱动上复测（2026-07-23），未发现新的回归问题；WASM 版本
  下也可以完整走完注册、登录、look、quit 全流程，几乎完全可玩（仅有一处
  无害的时间显示小问题：刚注册角色的"上次连线"时间戳会显示成 1969 年，
  这是 WASM 环境时钟的显示瑕疵，不影响实际游玩）。

核心的注册、登录、探索（look）、查看状态（score）、退出存档等流程均已
反复验证可正常使用。
