# 书剑天下（小熊泥苑分站）

同样自称**「书剑天下」**，这是"小熊泥苑"（http://dtxy.126.com）站点部署的一个分支——与本项目中的 `shujian2008` 源码几乎完全一致（11,737 个共有路径文件中仅 32 个不同，且几乎都是日志/存档类运维差异，本质是同一款游戏的两次独立部署）。地图借用长安到苏州等真实地名，铺陈少林、武当、峨嵋、昆仑、明教、星宿派、五岳剑派、古墓派等金庸门派世界观；新角色从武馆前院起步，抽取属性天赋后正式拜入门派修炼武学。中文姓名注册禁止使用金庸小说人物姓名，另带短消息、VIP 会员等社区向功能。

## 内容亮点

- 玩法与设定同 `shujian2008`：从"武馆前院"起步，体验属性天赋抽取、
  门派拜师、武学修炼等经典武侠养成玩法。
- 带有短消息、贵宾（VIP）等社区向功能。
- 中文姓名注册同样禁止使用金庸小说中的人物姓名。
