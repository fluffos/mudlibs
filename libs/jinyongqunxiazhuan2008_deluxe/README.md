# 金庸群侠传（2008 超豪华版）

## 游戏名称

本游戏自称 **金庸群侠传**，本压缩包对应"2008超豪华版"这一内容版本。
经比对确认与本项目中的"金庸群侠传2008加强版""金庸群侠传2008标准版"是
完全相同的服务端引擎核心，但本版在门派 NPC、战斗数值配置、部分地图场景
上有独立的内容调整，可以理解为"同一套服务端程序的加量/重新调校内容版"。

## 简介

以金庸武侠小说世界观为背景的中文 MUD：少林、武当、丐帮、明教、桃花岛
等门派悉数登场，玩家从"客店"起步拜师习武、行走江湖。系统偏传统门派
养成路线（属性、武功、任务、帮派声望），"超豪华版"相较另外两个版本在
战斗数值和部分场景内容上做了独立调整，文件规模也是三者中最大的一个。

## 如何运行

```
cd libs/jinyongqunxiazhuan2008_deluxe && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40085**。请在 `libs/jinyongqunxiazhuan2008_deluxe` 目录下
启动（保证日志写入同目录 `log/debug.log`），看到 `Accepting telnet
connections on 0.0.0.0:40085.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40085
```

或用任意 MUD 客户端 telnet 连接 `127.0.0.1 40085`。注册流程为：英文
名字 → 确认新建角色 → 中文姓名 → 密码（两次）→ 随机天赋是否接受 →
电子邮箱 → 性别，通过后进入"客店"这个新手起点，没有额外的隐藏前置关卡。

## 已知问题

- 与另外两个版本共享同一套引擎，明教分舵几名 NPC 引用的两门功法、以及
  少数地图区域（如城外驿馆的部分 NPC 路径指向、几处未完工的支线场景）
  在本包中缺失或存在小的路径不一致，均为原始资料本身内容不全或原作者
  未完工，不影响主线闯荡江湖。
- 少量公告板、姓名互译词典的存档数据在原始版本中已损坏，会自动按空数据
  处理，不影响正常游玩。
- 一个玩家书写多行留言用的小工具指令（`to`）因使用了较旧的闭包写法，在
  现代驱动上暂时无法使用；属于非必需的小工具，不影响核心玩法。

核心的注册、登录、探索（look）、查看状态（score）、退出存档等流程均已
反复验证可正常使用。
