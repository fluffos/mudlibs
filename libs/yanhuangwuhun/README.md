# 「武林群侠传」之炎黄武魂Ⅱ

属于 ES II 引擎家族（2003 年"炎黄"分支），与同批的"炎黄英雄史"系出同门，
都源自同一套 2003 年由"lxtx"改写的引擎版本。

## 简介

一款融合武侠与仙侠元素的 MUD，玩家从"世外桃源"开始自己的江湖之路，可以在
"猛士型""智慧型""耐力型""敏捷型""均衡型"五种角色定位中选择自己的发展方向，
逐步在武林中闯出名堂。

## 如何运行

```
cd libs/yanhuangwuhun && ~/src/fluffos/build-debug/src/driver config.fluffos
```

端口：**40060**

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40060
```

登录流程：

1. 输入英文名字（**只能用英文字母，不能带数字**，否则会被拒绝并要求重新
   输入），确认时回答 `y`。
2. 依次输入中文姓氏、名字（各自不超过两个汉字）。
3. 设置管理密码（用于找回普通密码，两次输入确认）和普通密码（平时登录用，
   两次输入确认）。
4. 选择角色类型（输入 1～5，直接回车默认选"均衡型"）。
5. 选择性别（`m`/`f`），完成后直接进入"世外桃源"。
