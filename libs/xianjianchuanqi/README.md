# 仙剑狂侠2000（仙剑传奇）

## 游戏名称

**《仙剑狂侠2000》**，作者叶雨飞。属于"Century（世纪）家族"武侠 MUD 引擎
（与《书剑2008》《书剑飘零II》等同源，管理层目录结构相似），但游戏内容和
安全模块均为独立开发，并非简单复制。

## 简介

一个以扬州为舞台展开的传统武侠世界：中央广场、扬州城的店铺与巡抚衙门、
各大门派（丐帮、全真教、白驼山、五毒教、日月神教等）、以及颇具特色的
"打劫""送镖"等江湖营生任务(job)。整体氛围偏正统金庸/古龙式武侠，适合
喜欢门派养成与任务体系的玩家。

## 如何运行

```
cd libs/xianjianchuanqi && ~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40034**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40034
```

或用任意 MUD 客户端 telnet 连接该端口。注册流程中有几个容易让人卡住的
提示，务必留意：

1. 连接后会先问 **"Are you using BIG5 font [Y|N]?"**——这是一个纯粹的
   显示编码偏好问题（用简体/UTF-8 客户端连接的话回答 `n` 即可），不影响
   后续注册。
2. 英文ID：**3-8个纯英文字母**（不能有数字）。
3. 确认新建角色后，会先设置**密码**（两次输入确认），**然后**才轮到取
   中文名字——这个顺序和很多同类 MUD 不一样。中文名字明确提示"不要选择
   金庸小说中的人物姓名"。
4. 取名后会有一次"天赋"选择：膂力/悟性/根骨/身法四项属性，输入 `0`
   可以让系统随机分配（也可以选1-4自己指定其中一项的具体数值，范围
   10-30）。
5. 之后是邮箱、性别(m/f)，随后正式进入游戏，出生地点在"中央广场"。
