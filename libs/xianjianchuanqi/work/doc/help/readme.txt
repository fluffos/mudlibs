海洋II正式版

(上海站11月版本，从理论上来说，版本号应该是hy2.0.sh.3也就是说海洋II上海站第三次版本)

这个版本的由来可真是大费周章呀!经历了无数次的内部人事变革，先后有lywin，bill，wuyouhxsd，happy，tiandi，cloth，zzz，pansy，idea，leee，guoshu，cash，fuyunke，cmoc，abc......为它作出过或多或少的贡献!

另外，也不能忘了侠客行的原著的方舟子，翔少爷等人，没有这些人中间任何一个，都不会有今天的海洋，滔滔海洋浪打浪，如今的上海海洋II已改名为星月传奇，所以大家下载回去以后架起来会发现名字叫星月传奇，但那只是个欢迎画面罢了，这个游戏将一直叫做：侠客行100海洋。

关于这个游戏，我没有太多要说明的地方，大家下载回去以后，要注意以下几点！

1，架设问题。本mudlib是由hxsd发给我的，发的时候没有发log目录给我，所以刚架上时，出了点小错，我在login.c中改了些代码才能正常运行起来，缺少的log我已补上了。我初步的试了一下，应该能正常运行了，以后若还有什么地方报错，发mail问我就行了！呵呵！我把mudos和config.cfg都设好了，大家拿到手以后，先运行mudos.exe，出现三个框，在第一个框里输入config.cfg的路径（有浏览按钮可以点），在第二个框中填入3990，在第三个框的心跳中填入2000（也就是两秒一次心跳）！ 运行了以后，可以见到系统栏有一个地球图标，这时就可以用zmud连127.0.0.1 5555了！对了，如果你的系统是win2000或是nt，有可能运行了mudos以后没有反应，你可以用那个play.bat来启动mud。另外，有些初级玩家常分不清一个mud是否有单机版和网络版，是否可以架在局域网中，关于这一点我要说明的是：任何mudlib不可能分别什么单机版和网络版，只要能架，都是网络版，只要你确定另一台电脑和这台电脑能用tcp/ip联上，那么你就可以在另一台电脑上用这台电脑的ip和port:5555来进入mud。所以请不要来信问海洋如何架设于局域网或是互联网，另外，此版本是用于windows架设的，如果你想在linux下架设，请把mudlib里的大部份文件由dos格式转化为unix格式，然后找一个for linux的mudos就可以在linux下架设，所以，也请不要再来信问如何把海洋架于linux（星星每天都会收到好几封信问如何把mud架在XXX操作系统上，实在被问得苦不堪言。）

2，安全系统。本mud使用的是jackyboy的安全系统，可以在线即时改变另一个人的读写权，可以分配任一目录的读写权给任何人，也可以把不在线的巫师进行升降。具体的用法比较复杂，建议一般玩家和不熟悉的巫师不要动安全系统，要升降巫师可以用promote命令，但分配权限的命令最好不要去碰，小心出错，出错的后果就是mud无法正常运行，满严重的！呵呵！这个安全系统默记lywin是天神，就算你把lywin降了成player，下次重启的时候，lywin又会变成天神，所以......你可以把/adm/daemons/securd.c里面的lywin，改成你自己的名字，这样就可以了，不过建议改的时候小心，改错的话........完蛋了！呵呵！如果你不太明白以上问题！只要以lywin这个名字注册登陆，就可以得到天神权限。

3，任务系统。本mud有很庞大的任务系统，非常多的任务，详情你可以见help aboutquest！这些任务系统我并不反对你copy到自己的mud中，也并不反对你对它们进行修改和扩大化，用hxsd的话来说就是：代码就是要拷来拷去！！但是，还请大家保留下制作者的原名，要知道，就算是一个两三个文件的小job，也有原作者数个小时的努力，这些劳动成果如果被人冒名的拿走，还是非常伤心，伤心的结果不外就是再也不编程序了，这对我们大家来说都是一个损失。

4，小小问题。游戏里面有个信息通告，每几秒就会发一些新闻，这个信息通告的小东西是星星的老师cmoc编的！呵呵！你要改信息的话，只需要clone /adm/daemons/msgd.c把这东西变出来，然后就可以用listmsg，addmsg，delmsg这三个命令来管理新闻。

5，版权问题。本游戏没有注册，所以没有版权问题！但是，星星默认这个mudlib的原版权属于侠客行巫师小组，现版权属于海洋的巫师小组，虽然大家都会以为海洋是星星做出来的东西，但是实际上海站的海洋则大部份都是hxsd领头编制的，星星只是搞了其中几个bug，做了几个任务罢了！呵呵！！另外，此版本请不要随便用来架站，或是改个什么名字就架起来，如果真要用来架站，请先来征求一下在下和hxsd的意见，不过如果你懒得来打招呼就架了站，我们也不会追究。反正这样的事我们也见得很多了。（笑）

6，售后服务。哇，搞错没有？这东西是免费提供下载，为什么会有售后服务？？？呵呵！这是星星为了让海洋能更完美而特别开设的互动服务。如果你有任何关于海洋的问题！http://www.lywin.com/club 里面的专题栏目开设了“滔滔海洋”一版！你可以在那儿把问题写出来，或是直接mailto:lywin@21cn.com也可以！我是有信必回的。同时，我也欢迎大家为海洋制作各种形式的补丁包或是增强文件包。
