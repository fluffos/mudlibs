# 风云再起Ⅱ（清华仿写版）— fy2qh

经逐文件核实，本档案与本批次的 `fy2` 实际上是同一份源码的另一个流传副本（只是打包驱动、玩家存档快照不同），"清华仿写版"更像是当年某个下载站/镜像站给这份拷贝起的名字，而非独立重写的版本。内容与 `fy2` 完全一致（详见该库介绍）：以古龙武侠为背景，"金钱帮"新手门派、风云广场留言版与探花诗台、完整表情系统等均可体验。

## 内容亮点

- 以古龙武侠小说为背景的江湖世界，玩家在凤求凰客栈或沉香镇等地起步，
  选择民族（汉族/苗族/满族/蒙古族）扮演一位初出茅庐的江湖新人。
- "金钱帮"是新手可直接加入的门派，总舵设于凤求凰客栈附近，帮主
  荆无命亲自收徒——`apprentice`/`bai` 即可拜入门下，`learn` 系统学
  基本剑术等入门武学。
- 两块活跃的江湖留言板："风云广场留言版"与"探花诗台"，记录着历代
  玩家留下的诗文与感言。
- 完整的表情系统（`smile`/`nod` 等），配有专属的中文动作描述文字。
- 和 `fy2` 是同一份源码的另一个流传副本，内容细节详见该库的介绍——
  这里不重复展开。
