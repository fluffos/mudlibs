# 世纪

## 游戏名称

本游戏自称 **世纪（CENTURY）**，登录banner的版权信息写着"星战英雄之乱世
风沙"，采用 `adm/single/{master,simul_efun}` 布局，与本项目中若干"世纪家
族"（Century）系列的姊妹站点同宗同源。

## 简介

这是一款传统中文武侠 MUD，玩家创建角色后从"天狼中心"这样的城镇场景起步，
体验属性成长、江湖闯荡、门派与战斗系统。整体风格朴素直接，是一个体量不
大、结构清晰的早期 MudOS 时代武侠站点，没有特别复杂或花哨的额外机制。

## 如何运行

```
cd libs/shiji && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40026**。请务必在 `libs/shiji` 目录下启动（保证日志正确写入
同目录 `log/debug.log`），看到 `Accepting telnet connections on
0.0.0.0:40026.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40026
```

或直接用任意 MUD 客户端 telnet 连接 `127.0.0.1 40026`。注册流程为：英文
代号（ID，须为 3-8 位纯英文字母）→ 确认新建角色 → 中文姓名（1-5 个汉字）
→ 使用密码（两次）→ 天赋分配（输入 0 交由系统随机产生，或手动选择一项，
再确认接受）→ 电子邮箱 → 性别，全部通过后即进入"天狼中心"这一起始场景。
整个流程没有额外的隐藏关卡或客户端版本校验，比较直观。

## 已知问题

- lpcc 静态编译检查显示约 93.6% 的文件通过，未通过的部分多为个别巫师
  个人沙盒目录下的孤立/未完工内容，以及少量缺失的任务系统（`QUEST_D`）
  依赖，均不在主线注册与游玩路径上，不影响正常体验。
- 核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
  反复验证工作正常，且已确认游戏不会再把普通的程序编译"警告"误当作严重
  错误显示给玩家。
