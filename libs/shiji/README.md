# 世纪

自称 **世纪（CENTURY）**，登录 banner 版权信息写着"星战英雄之乱世
风沙"。新角色从"天狼中心"这处枢纽出发，在凤凰星、皇族、圣殿、特种
部队四大对立阵营间择一加入；一座星港空间站会为受损的战舰提供维修
与加油服务，消耗的是电子货币——比常见的武侠门派设定多了一层货真
价实的科幻色彩，巫师最高权限头衔也是花哨的"宇宙特警"而非泛用的
管理员称谓。房间级别上，这个世界与本项目另一姊妹档案 sj（银河
世纪）几乎完全一致——天狼星区、四大阵营、星港等内容连文件都能对
上，两者的差异主要在安全精灵/master 对象的实现层面，属于同一款原作
游戏的两次独立服务器部署，而非各自独立的作品；游戏里一间
棋牌室房间的描述仍写着自己身处"古长安"，是这次科幻改版所依托的
某个武侠底本留下的痕迹。

## 内容亮点

- 天狼中心起步、四大阵营（凤凰星/皇族/圣殿/特种部队）与星港维修/
  加油系统，是收藏中少见的科幻底色设定。
- 巫师账号的权限体系颇具特色："宇宙特警"（`zhuguan`）是最高等级，
  可使用 `/cmds/zhu`/`/cmds/adm`/`/cmds/arch`/`/cmds/wiz`/`/cmds/imm`
  等全部巫师命令目录。
