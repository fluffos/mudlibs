# 金庸群侠传（2008 加强版）

本游戏自称 **金庸群侠传**，本压缩包对应"2008加强版"这一内容版本。属于
"ES II"引擎家族（源自作者 Phoebus.suny 1998 年的 ES2"天曹地国"版本），
与本项目中的标准版（`jqxz2008std`）、超豪华版（`jqxz2008dlx`）、
2015版（`jqxz2015`）核心引擎逐字节相同，是同一套服务端程序的四种不
同内容版本；这支血脉还延伸得更远——`xiakexing3`（游戏内同样自称"金
庸群侠传"）与本作 91% 的文件逐字节相同，`xiakexing2017` 又与两者各
有 80%-84% 重合，可以说是同一款底层游戏保留下来的六个快照。新角色
从店小二看店的路边茶馆起步，可在中央广场通过一处树洞暗语机制加入
丐帮、拜入左全门下习武，也可走白驼山使者按资质招人的另一条入门路
线；向风清扬拜师会触发"风清扬现在共有 N 个徒弟"的实时播报彩蛋。明
教九名"缘"字辈弟子的名字里藏着一个数字诅咒梗——一伤、二败、三毁……
直到八衰。深度体验里角色真的死于黑无常之手，完整走过了尸体、化鬼、
转生的死亡仪式。

## 内容亮点

- 游戏系统偏传统门派养成路线（属性、武功、任务、帮派声望），"加强版"
  相较标准版补充了更多的任务内容与场景描写，是三个版本中内容较为
  丰富的一支。
