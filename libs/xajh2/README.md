# 笑傲江湖 II

游戏登录画面自称"虚拟人生"。属于"XO mudlib"引擎家族（源自 TMI-2 /
ES2，由 Falcon 于1996年重写），与本项目另收录的《笑傲江湖迷你版》
《XO最终版1.2》同源但是独立的、更晚的一个站点快照（站内公告显示自
2003年4月1日开站）。

## 内容亮点

- 以金庸《笑傲江湖》为背景的经典武侠世界：从华山派、少林、玄武等门派
  体系出发，讲述"温故知新"的江湖故事。
- 整体偏正统门派养成向武侠 MUD，拳脚、轻功、剑术、刀法等修为体系
  齐全，适合喜欢门派归属感与传统武侠数值成长的玩家。
- 对同一 IP 地址的"新建角色"操作有防刷屏限流（短时间内只能新建一次）。
- 退出游戏(quit)有"必须先玩到10点经验才能存档"的限制，这是游戏本身
  的设计；新角色的新手村场景在本存档中缺失，系统会优雅地把角色放到
  一个空白过渡地带而非报错崩溃，不影响其余指令正常使用。
