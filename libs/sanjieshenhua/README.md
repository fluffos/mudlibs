# 三界神话 (San Jie Shen Hua) — 春节版

与 `sjcs`（三界传说）标题相近，但为独立开发的不同代码库
（核心文件差异巨大，非同一引擎的分支）。

## 内容亮点

- 以"三界"神话世界观为背景，新角色从"南城客栈"起步。
- 可从六种角色类型中选择一种：刀剑侠/魔法师/终结者/精灵族/野蛮人/
  暗黑地狱使者——比一般武侠 MUD 更偏奇幻杂糅的职业设定。
- 注册需设置两组密码：一组"普通密码"用于日常登陆，另一组"管理密码"
  在忘记普通密码时可用来找回。
- 同账号退出后有 60 秒冷却期（巫师账号不受此限制），另外短时间内反
  复重新连线也会被单独限流——都是这套引擎自带的防灌水机制。

## 深度功能测试新发现的 bug（详见 NOTES.md）

- `adm/daemons/logind.lpc` 的 `get_name()` 有一行调试用的
  `printf("%O\n", ob)`，会把登录物件的内部路径打在中文名字和电子邮
  件两个提示之间，每一个新玩家都会看到（AGENTS.md §7.34）。已删除。
- 角色职业选择菜单曾经显示"5. 均衡型"，但实际选中后赋的值是"野蛮
  人"（和这套引擎独立的"地狱业火"战斗子系统实际使用的职业名一致，
  "均衡型"反而是全库唯一一处、从未被消费过的孤立字符串）——是菜单
  文字本身漂移写错了，不是赋值逻辑错（AGENTS.md §7.67）。已把菜单
  文字改成"野蛮人"，和实际赋值、`score`面板显示保持一致。
