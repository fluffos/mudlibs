# 三界神话 (San Jie Shen Hua) — 春节版

与 `sanjiechuanshuo`（三界传说）标题相近，但为独立开发的不同代码库
（核心文件差异巨大，非同一引擎的分支）。

## 简介

以「三界」神话世界观为背景，新角色从「南城客栈」起步。注册时需设置
两组密码：一组「普通密码」用于日常登陆，另一组「管理密码」在忘记普
通密码时可用来找回并修改。还可以从六种角色类型（刀剑侠/魔法师/终结
者/精灵族/均衡型/暗黑地狱使者）中选择一种。

## 如何运行

```
cd libs/sanjieshenhua
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40098**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40098 --idle 1.2
```

注册流程：
1. 内码选择（`gb`）
2. 英文 ID：键入 `new`
3. 新英文 ID（3-8 位纯英文字母）
4. 管理密码（≥5 字元）→ 确认
5. 普通密码（≥5 字元，须与管理密码不同）→ 确认
6. 中文名字
7. 电子邮件地址（须含 `@` 和 `.`，长度 ≥ 9）
8. 角色类型（1-6）
9. 性别（m/f）
10. 首次登录后会有一次天赋点数分配提示：输入 `9` 接受默认分配，
    再输入 `y` 确认

完成后进入「南城客栈」，`look`/`score`/`quit` 等指令均正常。注意：本
游戏有 60 秒同账号退出冷却（巫师账号不受此限制），刚退出后立即用同一
角色重新登录会被拒绝，这是原始游戏设计，非托管限制。

本游戏已确认可在 WASM/浏览器模式下完整游玩（注册、登陆、`look`/
`score`/`quit` 均正常）。
