# 大唐双龙传（LLMUD）

## 游戏名称

**大唐双龙传**（LLMUD，v0.11 版），改编自黄易同名武侠小说《大唐双龙传》。
与本项目中的 "dtsl"（大唐双龙传）为同一血脉的姊妹版本，共享同一套底层
架构。

## 简介

以隋末唐初为背景的武侠 MUD，玩家扮演的角色从"大唐学院"新手村起步，
在乱世江湖中习武、闯荡、结交帮派，体验原著小说中群雄并起的历史武侠
氛围。角色成长围绕膂力、悟性、根骨、身法四项基础天赋展开。

## 如何运行

```
cd libs/llmud_datangshuanglong
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务端口：**40015**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40015
```

或用任意 UTF-8 telnet 客户端连接 `127.0.0.1:40015`。

注册流程：输入一个纯英文字母的角色代号 → 确认创建（y）→ 输入你的中文
名字 → 密码（需输入两次）→ 电子邮箱 → 性别（m/f）→ 一次性输入四项属性
点数（膂力 悟性 根骨 身法，用空格分开，四项总和必须正好是 80，且每项在
10-30 之间，例如 `20 20 20 20`）→ 输入 Yes 确认 → 进入游戏世界。没有隐藏
的前置身份/客户端版本验证关卡。

## 已知问题

登录、`look`、`score` 等基本指令均已验证正常工作。本次复查中发现并修复
了一处会影响所有新角色的问题（已修复，现在游玩不受影响）：此前部分
含有随身物品的场景在少数情况下会加载失败，导致极少数新角色开局时被
放入一个非正常的"虚空"场所而非真正的新手村——现已修复，新角色会正常
进入"大唐学院"。除此之外：
- 少数早期道具/技能文件缺失极小部分周边内容（例如个别兵器所需的特殊
  部件文件未随包提供），均为原始资料的历史缺口，不影响主线练功、闯荡。
- 少数早期个人巫师（管理员）留下的对局部内容有轻微命名冲突的草稿文件，
  均属管理员专用范畴，普通玩家接触不到。
- 已在 WASM（浏览器/Node 沙盒）构建下测试：可完整注册、登录并进行
  `look`/`quit` 等基本操作；由于 WASM 版驱动本身的已知限制，连线横幅里
  显示的来源 IP 会是空白（仅影响这一行文字显示，不影响注册登录本身）。
