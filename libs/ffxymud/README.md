# 非凡夕阳MUD

一个"时空游侠录"（Roaming Swordsman）血统的 MUD，登入横幅另称"非凡公
子·新月传奇录II"。虽然登入横幅和标题都不一样，但地图和"世界之巅"跳
崖场景（`d/city/sj.lpc`）和 `tybxjh`/`xhcii`/`zxty` 内容逐字节一
致，应属同一个"天涯"家族（`wlhd` 也是这个家族，但同一个房间的具
体写法已被独立改写过），此前没有任何一份档案互相记录过这层关系。

## 内容亮点

- 和"天涯"家族共享同一套金庸门派/地图世界观（华山、武当、峨嵋、
  丐帮、明教、天龙寺等门派场景齐全），"世界之巅"跳崖场景与
  `add_action(do_out, out)` 这处历史遗留的无引号写法（这个孤立、
  从未被任何房间连通到的房间从未被编译加载过，所以从来没有暴露过
  这个语法问题）都逐字相同。
- 独有的客户端版本校验握手（连线后第一行必须是字面量
  `shikongyouxia3.0`），是这一支"天涯"分支里独有的接入门槛，其余
  几份手足档案都没有这个要求。
- 这份档案在 WASM 下完全不需要修改任何 mudlib 代码——是本轮"天涯"
  家族成员里唯一一个开箱即用的。

## 注册流程（客户端版本校验）

连线后驱动会先要求输入一个固定的客户端版本字符串
**`shikongyouxia3.0`**（明文比对，不是加密握手），验证通过后才继续
问英文名字。之后是标准流程：英文名字（键入 `new` 会被要求重新输
入——本档案是直接检测重名后自动进入新建流程，不需要额外键入
`new`）→ 确认建立（y/n）→ 中文名字（回车可用系统随机名）→ 密码
（≥5 字元）→ 确认密码 → 天赋选择（0 随机 / 1-4 指定单项数值）→
接受天赋（y/n）→ 电子邮件地址 → 性别（m/f）。

## 本次修复的关键 bug

- 没有发现任何需要修改的 mudlib 代码——在 WASM 下开箱即用（前提是
  知道上面那个客户端版本字符串）。
- 排版格式化工具的第三类盲点检查（CJK 重新加空格）在约 25 个"误
  报"（原文本来就有的装饰性空格，例如房间名"接 天 楼"）中抓到了两
  处真正的损坏：`d/huashan/map.lpc`（一张密集的 ASCII 地图，和
  `cctx` 遇到的同一种损坏形态）、`d/player/fyue_room.lpc`（一段房
  间描述文字，格式化工具的分词器在这里失去同步）。两个文件都直接
  还原成格式化前的版本，没有手工修补格式化结果。
- 顺带发现但**未修复**：`d/city/sj.lpc`（一个没有任何房间连向它、
  完全无法到达的孤立房间）通篇缺少字符串引号（例如
  `add_action(do_out, out);` 应为
  `add_action("do_out", "out");`），这是转换之前就存在的原始档案
  问题。因为没有任何路径能到达这个房间，它从未被编译加载过，不影
  响注册/游戏/退出的核心流程，所以只记录不修复。
