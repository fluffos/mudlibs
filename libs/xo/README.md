# 笑傲江湖（迷你版）

属于 TMI-2/ES2（Falcon 系）引擎家族，是"笑傲江湖"系列里体积最小、内容最精简
的一个版本（作者称之为"mini xo"），与同批的"笑傲江湖最终版"（xo_final）同宗，
后者正是在这个迷你版基础上扩充而成。

## 简介

以金庸小说《笑傲江湖》为背景的武侠 MUD，玩家扮演初入江湖的侠客，从一座扬州城
开始自己的武林生涯。作为"迷你版"，地图和门派数量都比较精简（目前只有扬州城
和无量派两大门派），适合体验这套引擎最原始、最基础的玩法框架。

## 如何运行

```
cd libs/xo && ~/src/fluffos/build-debug/src/driver config.fluffos
```

端口：**40023**

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40023
```

登录流程：

1. 按回车进入欢迎界面。
2. 输入 `new` 注册新角色，然后输入英文名字。
3. 系统会问"确定吗(y/n)？"，回答 `y` 继续。
4. 依次输入中文名字、密码（两次）、电子邮件、性别（`m`/`f`），随后就会直接
   进入游戏世界。

## 已知问题

- 作为"迷你版"，一些完整版才有的辅助系统（例如个别提示/统计类指令）在这里
  没有实现，属于原作者刻意精简的内容，不是故障。
- 由于是较早年代的作品，个别边角房间、道具引用了并未包含在这个精简版里的
  内容，遇到时属于正常的内容缺口。
- 新的 WASM（浏览器/Node 沙盒）模式下：注册流程（英文ID/中文名/密码/邮箱/
  性别选择）都能正常走完，但选完性别、进入游戏世界这一步在 WASM 下未能
  正常完成——之后输入 look/quit 等指令没有正常反应。这个现象在原生模式下
  完全不会出现（已验证完整注册+look/score/quit全部正常），且在同源的
  xo_final 存档上用同样的 WASM 测试也没有出现，目前判断是 WASM 环境下
  这个存档自身代码路径的特殊问题，还未查明根因，不影响原生模式下的正常
  游玩。
