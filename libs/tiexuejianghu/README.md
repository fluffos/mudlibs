# 铁血江湖 (Tie Xue Jiang Hu)

属于 ES II（Eastern Stories II）引擎系列武侠 mudlib，与本项目中的
wuhanzhan《大话西游》、weimingkongjian《未明空间》等同属一个大家族，
但代码库本身是独立分支，不是任何已收录游戏的换皮版本。

## 简介

「铁血江湖」由作者 "hxsd" 开发，是一款以帮派经营和 NPC 招募为核心特色
的武侠 MUD，还内置了一套相当完整的商人/贸易子系统（作者自称"和大航海
时代差不多"）。游戏世界以中州、少林、全真等门派/城镇为骨架展开，新玩
家从"英豪酒楼"起步，可以习武、闯荡江湖、加入帮派赚取产业收入。原始服
务器因人气不足与内部巫师团队矛盾而停运，此后作者公开发布了源码。

## 如何运行

```
cd libs/tiexuejianghu
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40087**。

## 如何连接游玩

用支持 UTF-8 中文显示的 telnet 客户端，或本项目的 mudclient.py：

```
python3 scripts/mudclient.py 127.0.0.1 40087
```

注册流程比较直接，没有隐藏的编码/年龄询问：

1. 英文 ID（新角色）
2. 确认创建新角色（y/n）
3. 中文姓名（2-4 个汉字，系统会拒绝金庸小说人物名等违禁名字）
4. 设置密码，并再次确认
5. 电子邮件地址
6. 选择性别（m/f）

完成后会直接进入游戏世界（起始地点"英豪酒楼"），可用 `look`、`score`
等指令查看周围环境和个人资料，均已确认能正确显示中文内容。

## 已知问题

- 少数支线/个人巫师私有目录下的道具和技能脚本存在原始档案遗留的内容
  缺口（例如个别武器、装备类型未在这一版本中实装），均属边缘内容，不
  影响主线注册和基础游玩。
- 游玩过程中偶尔会看到"编译时段错误"提示——这是驱动器把一部分无害的
  编译警告显示给了玩家，并非真正的错误，可以放心忽略。
