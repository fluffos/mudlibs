# 金庸群侠传（2015版）

## 游戏名称

**金庸群侠传**，2015 年整理发布的版本。属于 ES II 引擎系列（与本项目中的
"金庸群侠传2008加强版"等同门作品共享同一套底层引擎/守护进程代码，七年间
引擎本身几乎没有变化，变化的主要是游戏内容——本版比 2008 版新增了不少区域
和剧情）。

## 简介

一款以金庸武侠小说世界观为背景的武侠 MUD：少林、武当、峨嵋、明教、丐帮等
各大门派悉数登场，玩家从一间普通客栈起步，练武、闯荡江湖、体验金庸小说中
的经典桥段。游戏对练功、内功、装备均有细致的数值设计，江湖气息浓厚，适合
喜欢传统金庸武侠题材的玩家。

## 如何运行

```
cd libs/jinyongqunxiazhuan2015
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务端口：**40086**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40086
```

或使用任意支持中文（UTF-8）的 telnet/MUD 客户端连接 `127.0.0.1:40086`。

注册流程比较直白，没有隐藏的前置关卡：依次输入一个纯英文字母的角色代号
（**只能是字母，不能带数字**，否则会被直接打回重填）、确认创建（y）、
你的中文名字、密码（需输入两次确认）、是否接受系统随机分配的天赋属性
（y/n）、电子邮箱、性别（m/f），随后就会进入游戏世界（客店）。

## 已知问题

整体已可正常游玩，登录、`look`、`score` 等基本指令均验证正常。少数非核心
内容存在缺失或残留的历史小问题，均不影响正常游玩：
- 极少数留言板（布告栏）因原始存档数据本身已损坏而无法读取留言，程序会
  自动忽略，不影响其他功能。
- 个别门派（如明教的"元"字辈弟子）引用的少数绝技文件在原始存档中就没有
  附带，属于原始资料本身的缺失。
- 少数早期的武当桃源支线房间是废弃草稿，不会被实际用到。
