# 泥潭三 / 《終極魔界》 (nitan_san)

## 游戏名称

站点内部自称"泥潭"(nitan)，是 NT/nitan/Lonely 系列真正的"三代"正宗版本
（登陆横幅本身就打出"一入泥潭深似海"字样，驱动版本标注"MudOS v22.2b14
NT-Build"）。实际连线看到的招牌是《終極魔界》，与它的近亲 nitan_ceshi
一样是套在"泥潭"引擎上的一层皮肤。

## 简介

和 nitan_ceshi 是同门师兄弟：新玩家取姓名、选性格、"洗"天赋，再到"生命
之谷"由盘古安排投胎，才算正式踏入江湖。世界观基于盘古开天、转世投胎的
神话设定。这个版本**同样不需要外部 MySQL 数据库**，注册、存档全部走本
地文件。两者虽然血缘很近，但各自独立演化，遇到的具体小毛病也不完全一样。

## 如何运行

```
cd libs/nitan_san
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40055**。文件数量较多（约1.36万个），驱动启动后需要**约二十秒**
完成预加载，过早连接会看到"正在启动过程中，请稍候再来"的提示，耐心等待
即可。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40055
```

完整流程（与 nitan_ceshi 基本一致）：

1. 编码选择，回答 **`gb`**。
2. 输入 3-10 位英文 ID，确认创建新角色 (y/n)。
3. 依次输入中文**姓**、中文**名**（各不超过两个汉字，单字姓名也可以）。
4. 设置"管理密码"和"普通密码"，均需再输入一次确认。
5. 选择性别 (m/f)。
6. 进入"注册房间"，可选执行 `register 你的邮箱地址` 延长账号保留期（非
   必须）。
7. 到"生命之谷"后依次执行：
   - `choose <1-4>` 选择性格
   - `washto 20 20 20 20` 洗四项天赋
   - `born <籍贯>`（如 `born 扬州人氏`）完成投胎
   - 之后有一段规则公告，连续回车翻页

完成后正式进入游戏世界，`look`、`score` 等指令均已验证正常工作。

## 已知问题

- 少量后台"自动出招"逻辑在原始归档转换 `.c`→`.lpc` 后本会永远匹配不到
  文件（导致自动特殊招式功能悄悄失效但不影响正常战斗和指令），已在本次
  复查中一并修复。
- 有一个孤立的拍卖师 NPC 文件本身带有疑似编码遗留问题，不在常规游玩路径
  上，不影响正常登录和主线内容。
- 由于文件数量较多，本次验证以实际启动+连线游玩为准，没有做全库静态编译
  扫描（与同系列大型库的验证方式一致）。
- WASM 版本可以正常启动，但本次测试工具无法在其短生命周期的单次运行内
  验证登录流程：本库自带一个"服务器刚启动 30 秒内谢绝连线"的保护机制，
  加上地址黑名单检查同样依赖 WASM 驱动尚不能正确提供的连线 IP 格式，
  两者叠加导致无法在一次性测试里走到登录提示。这些都是 WASM 驱动/测试
  工具本身的限制，不是本库的 bug——原生（native）驱动下注册、进入
  生命之谷、盘古 NPC 正确称呼玩家中文名等全部验证通过。
