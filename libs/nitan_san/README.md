# 泥潭三 / 《終極魔界》 (nitan_san)

站点内部自称"泥潭"(nitan)，是 NT/nitan/Lonely 系列真正的"三代"正宗版本（登陆横幅本身就打出"一入泥潭深似海"字样，驱动版本标注"MudOS v22.2b14 NT-Build"）。实际连线看到的招牌是《終極魔界》，与它的近亲 nitan_ceshi 一样是套在"泥潭"引擎上的一层皮肤——逐文件比对显示两者远不止"血缘相近"：`d/`（中原城市地图，如长安、北京、洛阳，以及峨嵋、华山、崑崙、恒山、嵩山五大门派和更外围的边疆地区）路径下约 98% 的同名文件字节完全相同，是同一份被写好的江湖世界；只有内功心法、玩家指令、管理员守护进程等引擎层分化明显（约三分之一文件不同），说明这更像是同一套代码在不同时期留下的两份独立快照，而不是各自从零开发的作品。新角色同样取姓名、选性格、"洗"天赋后，由盘古在"生命之谷"安排投胎，才算正式踏入江湖，世界观基于盘古开天、转世投胎的创世神话；也和 nitan_ceshi 一样不需要外部 MySQL 数据库，注册、存档全部走本地文件。
