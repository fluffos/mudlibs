# 笑傲江湖4公开版 (xajh4gkb)

游戏内品牌为「夕阳再现」之「笑傲江湖Ⅳ」，作者阿飞在"炎龙"内核基础
上修改的第四代版本。这份档案在 WASM 下**完全无需修复**——没有编
译错误，没有执行时段错误，整个注册流程一次跑通。`jhfy3`（江湖风
云3，同样打着"夕阳再现"旗号）和 `xyzx`（夕阳再现，同一品牌的源头
版本之一）的"世界之巅"跳崖场景（`d/city/sj.lpc`）都和这份档案逐字
节相同，是同一个"夕阳再现"代码血统的成员——注意打着相同"夕阳再
现"品牌的 `xysylmhb`/`xyzxiiylzymh` 反而是完全不同的"天涯"家族地
图，品牌名称不能作为血统依据。深度功能测试（§10.7）确认没有代码逻
辑 bug，但发现普通移动就会反复触发资源限制中断，详见下方"深度功能
测试"一节。

## 内容亮点

- 地图规模很大，除了华山、武当、峨嵋、丐帮、少林等常见门派场景，
  还有一整片海外区域——`d/japan/` 是日本神户城（东门、海港、海鲜
  等场景），供玩家跨海历练，这在同类档案里比较少见。
- "杀手楼"（`d/shashou/`）是独立于门派体系之外的刺客/杀手势力，
  入口场景描写"豪门巨宅""金刚神师"，走的是黑道路线而非正统江湖。
- 支持自动地图（`automap1`-`automap6`）和组队巡街（`d/party/`）等
  面向专属客户端的配套内容，注册流程也比常规多一道"身份标识"设置
  （找回密码/自杀专用，且不可修改）。
- 权限阶梯比常规的 `(admin)` 更细，最高到 `(ceo)` > `(boss)` >
  `(admin)`，档案里已经预置了两个 `(boss)` 级创始人账号
  （`afei`/`tianya`）。

## 本次处理内容

没有发现需要修复的程序 bug。唯一做的事情是在 `/adm/etc/wizlist`
里加入管理员账号（已有 `afei`/`tianya` 两个 `(boss)` 级创始人账
号；权限阶梯最高是 `(ceo)` > `(boss)` > `(admin)`，但 `(admin)` 已
经足够获得 `/` 的完整写入权限，和本轮其他档案的惯例一致；
`SECURITY_D` 正确指向 `/adm/daemons/securityd`，`globals.h` 里有一
条注释掉的 `securd` 分身档案备用行，未启用）。

注册流程比较特别：除了普通密码之外，还要单独设置一个"身份标识"
（自杀、找回密码时使用，不可修改）。游戏内会夹杂一些
`lbadd0`/`lbclear0` 之类的自定义地图协议标记，这是给专属客户端用
的标记，不是错误。

## 深度功能测试（§10.7）修复的 bug

- **`maximum evaluation cost` 配置过低，正常移动即可反复触发资源
  限制中断**：注册后仅仅是基本移动（走进任何一个从未被访问过、需
  要懒编译的新房间/NPC）就反复撞上 `*Too long evaluation. Execution
  aborted.`，普通玩家看到的是"这里发现了臭虫，请用 SOS 指令将详细
  情况报告给巫师。"。追踪了几条完整调用链（NPC `create()` → `char.
  lpc` 的 `setup()`（`2017.8.5阿飞改` 那段"统一重置NPC技能"会把
  NPC 已经在自己 `create()` 里设过的技能全部 `set_skill()` 重设一
  遍）→ `feature/skill.lpc` 的 `set_skill()` → ACL 的 `file_size()`/
  `valid_read()` 检查），没找到单一"这一行本身很贵"的孤立逻辑 bug，
  更像是这份档案的 NPC 创建链条本身开销偏高，而 `config.fluffos`
  的 `maximum evaluation cost`（700000，这个项目里大多数档案的默认
  值）明显不够用——和 §7.87 存档文件大小限制是同一类"旧配置数值和
  实际内容规模对不上"的问题，只是这次体现在"单次调用允许的执行开
  销"这个维度。已提到 5000000（项目里另外 30 份档案已经在用的数
  值）。live 验证：修复前反复固定路径必现多次崩溃；修复后同一条路
  径连续 12 步移动零次触发，`debug.log` 里也不再出现
  `cost limit reached`。
- **战斗与死亡/复活流程完整验证**：北大街对 NPC 郭靖发起 `kill`，
  攻防判定正常，一记重击致死后自动生成尸体、送往"鬼门关"；"白无
  常"NPC 靠 `call_out` 自动完成判定对白，几秒后自动复活送回武庙，
  `score` 死亡计数与"最后杀你者"记录均正确，全程未受 §7.68 类问题
  打扰（未做任何改动）。
- **§7.86 留言板 `post` 崩溃不适用**：武庙"臭虫留言板" live 实测发
  帖成功。
