# 侠客新传 (New Legend of the Wandering Swordsman)

由"Xkxz MUD Wizard Group"团队开发的武侠 mudlib，config 文件里残留着
一个"海洋II上海总站"的字段，说明这份代码大概率是从"海洋II"的引擎基
础上二次开发而来，但实际游戏内容与登录横幅都是独立的"侠客新传"。

## 简介

游戏以"世外桃源"为起点场景，融合了角色类型（猛士/智慧/耐力/敏捷/均
衡）、门派武功等武侠养成要素。比较有特色的一点是：新角色完成基础注
册后并不会立刻"投胎做人"，而是需要在游戏里找到 NPC"水笙"用
`register <email>` 指令完成邮箱注册，才能进一步选择资质、正式获得完
整属性——这是这款游戏自己的新手引导设计，不是故障。

## 如何运行

```
cd libs/xiakexinzhuan2
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40035**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40035
```

**连接后第一个提示很容易被忽略**：会先出现一行不太起眼的
"Are you using BIG5 font [Y|N]?"，这只是询问客户端字体编码，和游戏内
容无关，直接输入 `n`（本环境统一用 UTF-8/简体显示）即可继续；如果不
小心跳过了这一步，后续的 ID/密码输入会全部错位，出现连续的"只能用英
文字母"之类的报错，重新连接、认真回答这第一问即可解决。

完整注册流程：

1. BIG5 询问：输入 `n`
2. 英文 ID（3-8 个纯英文字母，不能有数字）
3. 确认创建新角色（y/n）
4. 设置密码（需同时包含大小写字母），并确认
5. 中文姓名（不超过 4 个汉字，注册提示会提醒不要使用金庸小说人物名，
   例如"中神通"）
6. 选择角色类型：1 猛士型 / 2 智慧型 / 3 耐力型 / 4 敏捷型 / 5 均衡
   型（直接回车默认选均衡型）
7. 选择性别（m/f）

完成后会进入"世外桃源"，`look` 指令已确认能正确显示中文场景描述；
在完成 `register <email>` 之前，`score` 会提示"还没有出生呐，察看什
么？"——这是游戏本身的设计，注册邮箱后即可查看完整资料。

## 已知问题

- 少数战斗相关函数存在类型使用不严谨的历史遗留小问题，已在本次核对中
  修复，不影响正常游玩。
- 游玩过程中可能会看到"编译时段错误"一类提示，是驱动器把无害的编译
  警告显示给了玩家，并非真正故障。
