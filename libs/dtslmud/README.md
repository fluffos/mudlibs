# 大唐双龙传（LLMUD）

LLMUD v0.11 版，改编自黄易同名武侠小说《大唐双龙传》，故事背景设定
在隋末唐初、群雄并起的乱世。经逐档比对，与本项目中的姊妹版本
"dtsl"共享同一血脉：约 99% 的场景档案逐字节相同，仅新手学院与
"石龙武馆"枢纽区经过重新编写。角色成长围绕膂力、悟性、根骨、身法
四项基础天赋展开，注册时一次性分配（总和须为 80，每项 10-30）；
巫师/管理员的游戏内头衔在此版本中显示为"天帝"。深度测试实机验证
了洛阳的花间派——一处经由候希白引荐、正确拒绝男性拜师的女子专属
门派，海沙帮式"帮主之位可被挑战者以实战击败夺取"的帮派继承机制，
以及经由扬州真实户外野外场景展开的完整杀人-死亡-复活流程，最终
指向阎罗殿的鬼魂对话。

## 内容亮点

- 以隋末唐初为背景的武侠 MUD，玩家从"大唐学院"新手村起步，在乱世
  江湖中习武、闯荡、结交帮派，体验原著小说中群雄并起的历史武侠氛围。
- 角色成长围绕膂力、悟性、根骨、身法四项基础天赋展开，注册时一次性
  分配（总和须为 80，每项 10-30）。
- 巫师/管理员的游戏内头衔显示为"天帝"。
- 深度测试实际玩过注册→新手村→武馆→兵器铺购物→（被合理挡下的）
  切磋与出馆尝试，全程干净；顺手修复了鬼门关复活流程里一处
  §7.68 死亡软锁（`d/death/gate.lpc`，详见 NOTES.md）。

- **更正（2026-08-05）**：上面提到的"7.68 复活软锁"修复已经撤销——经重新评估，鬼魂"不在场"时放弃复活流程更可能是有意的游戏设计（多数这类档案里鬼魂本身就无法自行移动，离开是一种游荡机制，回来时 init() 会重新触发流程），不是需要强制重试的 bug；详见 NOTES.md。
