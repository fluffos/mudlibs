全真教
【全真教简介】

全真教位于终南山麓，始创于真武元年。开山祖师王重阳，身负绝世武学，曾于华山之巅力克江湖四大高手--东邪，西毒，南帝，北丐。从而掌管武林第一武学秘籍--九阴真经。全真教也因此成为当时武林第一大教，以主持武林公道为己任。全真教香火鼎盛数十年，被称为天下道家玄门正宗。教会中的高手亦是层出不穷。其中以全真七子享誉最盛。此七子乃是王重阳的亲传弟子，各人功力均已堪称为武林一流高手。七子联手组成全真教镇教至宝--天罡北斗剑 阵，其威力足可与少林一百零八罗汉阵媲美。
