明教
【明教简介】
明教源于西域波斯国，唐时传至中土。当时称为袄教。唐皇在各处敕建大云兴明寺，为明教的寺院，明教教义是行善去恶，众生平等，若有金银财物，须当救济贫众，不茹荤酒，崇拜明尊。明尊即是火神，也即是善神。只因历朝贪官污吏欺压明教，明教教众不忿，往往起事，自北宋方腊方教主以来，已不知有多少次了。在北宋期间的四大寇：方腊、宋江、王庆、田虎，其中之一的方腊便是第一代教主。在南宋建炎年间，王宗石教主在信州起事。绍定年间有余五婆教主在衢州起事，理宗绍定年间有张三枪教主在江西、广东一带起事。只因明教素来和朝廷官府作对，朝廷官府便说明教是“魔教”，严加禁止，明教在官府的逼迫之下为求生存，作事不免隐秘诡怪，以避官府的耳目。正大门派和明教积怨成仇，更是势如水火。明教这么大的一个教，教众之中也不免偶有不自检点、为非作歹之徒，仗着武功了得，滥杀无辜者有之奸淫掳掠者有之，所以明教的声誉便如江河之目下。但自大宋亡于蒙古鞑子之手后，明教更成了朝廷之死敌，明教更把驱除胡虏为已任，只可惜自阳顶天教主不明死因而亡后，明教群龙无首，教中诸高手为争教主之位，闹得自相残杀，四分五裂，终于有的洗手归隐，有的另立门派，自任教主，乾坤大挪移和九阳真经也都早已失落无寻。教规一堕之后，更与名门正派结的怨更深，之后才有六大门派围攻光明顶之事。现在在张无忌教主的带领之下，由于对各大派有恩，与正派人等尽前嫌，成为一个正派的教。

【明教武功介绍】

明教是天下最大的教，与少林、丐帮并足而立，其中教众众多，武功也十
分的杂。在创建明教时，考虑到武功的设计方面，只对明教的几种主要的武功
写下来，分别有九阳神功、乾坤大挪移、圣火令法；四面大护教法王各一种拿
手武功：谢逊的七伤拳，韦一笑的寒冰绵掌，金花婆婆的夺命金花，殷天正的
搜骨鹰爪擒拿手。内功方面的设计：如有奇遇可得九阳真经，其他的npc 则暂
以九阳神功为其特殊内功。

九阳神功(jiuyang-shengong)：

九阳神功是天下最厉害的内功心法之一，神功有许多功能：狮子吼(yun
roar)，提高战斗力(yun powerup)。要求要有20级的基本内功才可修习，并
且级别的提高多少视你的基本内功而定，对你的悟性也有很高的要求。

enable force jiuyang-shengong

乾坤大挪移(qiankun-danuoyi)：

波斯武功，中原会用之的人几乎没有，自明教三十三代教主阳顶天死后，
几乎失传，但后来张无忌一翻奇遇，以其深厚的内功一朝而成。乾坤大挪移只作招架和轻功用，不具功击。其招厉害所在是可以把别人的招数尽数还于对方。

圣火令法(shenghuo-ling)：

明教圣物圣火令上的武功，以其招式怪异无比而往打之措手不及，加上
圣火令之特殊性，更是厉害无比。

enable sword shenghuo-ling

七伤拳(qishang-quan)：

七伤拳，拳出必伤。是崆峒派的不传之秘，但后来谢逊为报家仇，从崆
峒派手中盗出《七伤拳谱》，从而练成。名为七伤，实则为每出一拳可以有七种不同真气，使人不知如何与之相抗。
七伤拳总诀：五行之气调阴阳，损心伤肺摧肝肠，藏离精失意恍惚，三焦齐逆兮魂魄飞扬！

enable cuff qishang-quan

寒冰绵掌(hanbing-mianzhang)：

寒冰绵掌为韦一笑之武功。中掌后就会寒毒发作，历时发作，其害无比。

enable strike hanbing-mianzhang

夺命金花(duoming-jinhua)： (暂不开放)

为紫衫龙王的绝招。以其狠、毒而闻名。金花一出，其美无比。

enable throwing duoming-jinhua


搜骨鹰爪擒拿手(sougu)：

鹰王之绝招，又手似鹰爪，手到擒来。是明教的入门武功。

enable claw sougu

青蝠身法

明教的轻功身法。主要是从韦一笑的轻功身法而来。
