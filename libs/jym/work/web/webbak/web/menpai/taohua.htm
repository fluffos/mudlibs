桃花岛
【桃花岛简介】

桃花岛一派乃“东邪”黄药师所创。黄药师年青时纵横江湖，快意恩仇，行事亦正亦邪；后与夫人新婚燕尔，隐居桃花岛，收陈、梅、曲、陆、冯五大弟子，桃花岛一派逐渐成形。后来因《九阴真经》一事，黄药师夫人冯氏不幸病逝，而陈玄风、梅超风两大弟子结下私情，将《九阴真经》下卷盗走。黄药师迁怒于众弟子，将门下弟子打断双腿，逐出桃花岛；直到晚年才重收众弟子于门墙。黄药师其人非汤武、薄周孔，素来厌憎世俗之见，思慕晋人率性放诞， 行事但求心之所适，常人以为是的，他或以为非，常人以为非的，他却又以为是，因此上得了“东邪”雅号。虽黄药师常以邪魔外道自称，但东邪之“邪”并非西毒之“毒”，这一点请桃花岛弟子牢记在心。黄药师聪明绝顶，文才武学，书画琴棋，算术韬略，以至医卜星相，奇门五行，无一不会，无一不精；日常所交也尽是名士才子。桃花弟子除了勤练武功，也注意学识修养，个个博学多才，非丐帮、白驼，或粗鄙无文、或心狠手辣之辈能及。黄药师胸中包罗万象；武功中对指法尤有独到造诣，桃花岛的弹指神通与大理段氏威震天南的一阳指各擅胜场，不分伯仲。但是桃 花岛最为精深的却非武功，而是奇门遁甲、阴阳五行之术。黄药师不仅尽通先贤所学，更有不少独特创见，发前人之未见，端的非同小可。桃花岛的桃花奇阵，其中乾坤倒置，阴阳变化，有鬼神莫测之机，陷入者若非精通奇门遁甲，往往困在阵中，至死不能得脱。
