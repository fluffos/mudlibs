华山派
【华山派简介】

五岳剑派共由江湖中的五大门派组成，既：华山派，恒山派，嵩山派，衡山派及泰山派。势力庞大，隐然可与少林武当分庭抗礼。华山派原为五岳剑派中势力最强的一派，但华山两位前辈岳肃和蔡子峰因时机巧合，得以一窥当世无上武学密籍「葵花宝典」；但却又因见解不同，一人主张以修气为本，教导弟子重修气，另一人却以为因当以剑法为主而教导弟子重剑法，华山派至此竟分裂为剑、气二宗。二宗各持己见，终于水火不容，同门操戈！高手伤亡怠尽，华山因此式微。


【华山派拜师必读】

华山派男玩家可拜岳不群为师，女玩家则可拜宁中则为师。到武功具有一定的
水平后，则可尝试寻找风清扬学习「独孤九剑」。


【华山派人物简介】

华山派十三代掌门人岳不群：
岳不群在江湖中侠名远播，嫉恶如仇，甚得人心，博得「君子剑」的好评。

华山派十三代掌门人夫人宁中则：
宁中则更是个不让须眉的女中豪杰，武功与岳不群不相上下。

剑宗长老风清扬：
风清扬为当世唯一身具「独孤九剑」的人物。独孤九剑为宋朝独孤求败所
创。独孤九剑，有进无退，招招都是进攻，攻敌之不得不守！独孤氏以此
称雄武林数十载，号称「剑魔」，走遍天下欲觅一对手而不获，为求一败
而不得，一生寂寂。最终与一神雕归隐，埋剑于「剑冢」。「独孤九剑」
的威力可想而知。

华山派十三代剑宗弟子封不平：
封不平是华山剑宗的第一高手。剑气之争剑宗一败涂地，封不平隐居苦练，
誓雪此辱。他内外兼修，不仅剑法了得，内功亦是不凡。

华山派十三代剑宗弟子成不忧：
成不忧是华山剑宗弟子。剑气之争剑宗一败涂地，他与封不平隐居苦练。
他剑法了得，已获剑宗真传。

华山派十四代弟子：
劳德诺、梁发、施戴子、高根明、陆大有和岳灵姗。

独孤九剑：
无招胜有招，敌强我更强。独孤九剑不含招式，有招既无招，无招亦有招。
独孤九剑要旨在于「悟」，不可拘泥不化，讲究料敌机先，出奇制胜。通晓
了九剑剑意，则无所施而不可。

独孤九剑具有九种特殊功能：
总诀式： 有种种变化，用以体演这篇总诀。
指令：perform po 概括其他八剑功能。
所需等级：２０

破剑式： 用以破解普天下各门各派的剑法。
指令：perfrom pojian 所需等级：５０

破刀式： 用以破解单刀、双刀、柳叶刀、鬼头刀、大砍刀、斩马刀种种
刀法。
指令：perform podao 所需等级：５０

破枪式： 用以破解长枪、大戟、蛇予、齐眉棍、狼牙棒、白蜡杆、禅杖、
方便铲种种长兵刃。
指令：perform poqiang 所需等级：５０

破鞭式： 用以破解钢鞭、铁锏、点穴橛、拐子、蛾眉刺、匕首、板斧、
铁牌、八角槌、铁锥等短兵刃。
指令：perform pobian 所需等级：５０

破索式： 用以破解长索、软鞭、三节棍、链子枪、铁链、鱼网、飞锤流
星等等软兵刃。
指令：perform posuo 所需等级：６０

破掌式： 用以破解拳脚指掌上的功夫，包括长拳短打、擒拿点穴、鹰爪
虎爪、铁沙神掌诸般拳脚。
指令：perform pozhang 所需等级：７０
