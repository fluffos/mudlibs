欢迎来到金庸群侠传。本站招募有创意的游戏设计师。我们将奉献给广大玩家空前的MUD享受。

【留言板】

为了方便宣布事宜、玩家互相交流，金庸群侠传中设有很多留言板。武庙的留言板专供巫师宣布泥潭事务，玩家不能写。巫师会客室的留言板专供玩家向巫师反映情况，最好不要在那里写无关紧要的事情。扬州客店和各门派的中心都有留言板，供玩家交流用。留言板的使用方法，请大家看 look board 。

【个人信箱】

在游戏中，玩家除了使用留言版来交流还可以使用游戏中的邮箱进行联系。具体的使用方法请大家 look mailbox。

【其它】

新手上路应该还有很多地方应该注意，不过，遇上困难，只要肯问(chat)，一定会有老玩家帮你的忙。所以，一定要熟用 chat 这个命令。宝贝是武侠小说非常重要的一个部分，金庸群侠传里也有很多宝贝，倚天剑、伏魔刀、九阴真经、菩提子，各种武功典籍、珍贵药材等等。宝贝人人想要，自然也就不乏争端。“匹夫无罪，怀璧其罪”大家恐怕都清楚，所以新手刚刚诞生，全无功力来保卫宝物，应当小心，乱拣、乱偷，往往引起杀戮。金庸群侠传系统为了防止玩家用dummy 来获取和收藏宝物，防止不公平竞争，设有偷盗和抢劫机制。凡经验低微的人物，不能保有特别贵重的物品，回被扒手偷走；四处走动时，也往往会遇到强盗、土匪、草寇等等抢劫。新手上路，免带宝贝为妙。
