欢迎来到金庸群侠传。本站招募有创意的游戏设计师。我们将奉献给广大玩家空前的MUD享受。
首先，对每一个新手有些忠告。金庸群侠传是网上出了名的高难度泥巴，只有强者才能在这里生存下去。PK大量存在，确实有许多纯粹是变态的玩家，根本不练功，弄一点点基本功夫后就大量屠杀新手为乐。新手需要的第一素质就是勇敢，笑看死亡，把被PK当做练功的动力，躲避PK是练习求生本领。即使没有PK，也有诸如王五、毒蛇、土匪等NPC 攻击玩家，低水平玩家稍有不甚就会送命。乐观勇敢地面对诸多困难，才能不断提高，最终称为一代高手。㈠　哇哇堕地，你第一件事要做的便是设定逃跑系数（set wimpy），一般来说，逃跑系数最好设定在足够你多忍受对手三至四下攻击。例如你跟小孩撕杀， 每一次被他打中会令损失15点气力，而你的最高气力是 120，那你便应在气力剩下15*4 = 60 点时逃跑，所以应 set wimpy 50 (50% of 120)。新手上路，不妨把 wimpy 弄高一点，以作保险，set wimpy 60-70 应该足够了。㈡　第二件事便是要搞清楚ＮＰＣ（non-player character，是指由系统控制的人物）的战斗力。以下是一排名字，他们的战斗力是从低到高排出的。你可以从第一个开使试，如发现砍杀并不长实战经验和学习潜能，换高一个。小孩，女孩，男孩，小动物，老大娘，懒汉，小贩，地痞，流氓等。盲目的砍杀比你差很多的人是毫无用处的。金庸群侠传中有些坏蛋是见人就杀，如：土匪，王五。你如遇上他们，认好方向，逃到就近的避难所，如武庙、客店，逃得越快越好。有时候由于正在战斗中，busy，不能逃走，必须要先 halt 然后再跑。㈢　一般来说，比较安全的打架方式是「较量」（fight）， 这样做双方都不会打死对方，当任何一方的气或精跌到 50%或以下，或其中一方提出停止（halt）时，打斗便会停下来。但有些ＮＣＰ并不喜欢跟别人较量，那便唯有硬迫他出手，如杀（kill），或「偷」他的东西。偷东西失败了（９９％会失败，除非你学了妙手空空的技巧），对方便会来杀你。㈣　有时候你会觉得什么人也打不过，上至老妇人，下至小孩，都吃不了他们两三招，便要跌跌撞撞地逃跑了。想把功夫学好一点才去打架，偏偏师父却说你经验不足，不教你新东西，但不学新东西便打不过敌人，也就无法取得战斗经验……这个循环应该怎样打破呢？答案是用武器来战斗，只要有武器在手，你的攻击力便会比空手高。最简单的武器是鸡腿、石块和树枝。㈤　拜一个好师父很重要。很多师父不轻意收徒，你要自己多多努力。必须达到一定的要求才回收你。一但拜了师，你可用察看你师父会什么（help skill_list）。一般来说，你师父会的你都可以学（help learn），但有些武功要有一定基础的其它武功才可以开始学习。㈥　要有正确的学习途径。无论拜在谁的门下，先学一些基本功夫防身是很首要的，如基本轻功，基本招架，基本内功等。当你学某种技能到一定程度时，会因缺乏实战经验，而对师父的回答无法领会。这时你就只好下山找人实战。另外，你会某种特殊技能并不代表你在实战中会应用它，你需指定要用的特殊技能（help enable）。要想较快的获得实战经验和潜能，高手们总结的经验有：与和你战斗水平差不多的人实战，同时打几个ＮＰＣ，不用特殊轻功（enable dodge none）等等。许多方法还需你自己去发掘。㈧　钱从哪里来？一是由ＮＰＣ或其他人身上偷，二是从尸体上拿（get all from corpse），三是把捡到的东西卖到当铺里去，四是工作挣钱。你可以到武当山做山门守卫、到白驼山打工。丐帮弟子还可以向人讨钱（help beg）。当然你也可以向老玩家要，很多老手都乐于帮助新手。另外有本事的玩家可以挖掘宝贝来得到钱财。作为新手，和NPC 作战来获得实战经验是不大容易的，虽然少林、武当、华山、星宿和桃花岛有木人对新手非常有利。
