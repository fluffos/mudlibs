第三项天赋是根骨，根骨越好，气力的恢复速度越快，运功（exercise）的时间也越短，每次升级时体力的增加也较多，受到攻击时所受的伤也较轻……不过，以上所说的种种好处，有时可以从别的方法获得，例如你的气力的恢复速度，也受到内力的多寡影响，基本上算法是： 每一个 tick 所恢复的气力 =基本气力恢复量 + 内力上限/10，「基本气力恢复量」是由根骨决定，但内力的上限则是你自己通过运功锻炼出来的。在早期阶段，你的内力上限不可能很高（这个上限有其限制），你所倚赖的便只有基本气力恢复量。当然，根骨差的人可以透过穿着较好的防护用具来减少受伤。这些护具都要有 相当的功夫才能从ＮＰＣ那里抢过来，或者花相当多的金钱才能买到。还有一点要注意的是根骨会间接地影响你的武功进度，因为根骨好的人精力和气力都恢复地较快，可以更快地再读书，或者再向师父请教，或者再进行练习（practice），从而加快学习的进度。身法，它影响你的防御及躲避能力。身法越好，便越容易避开对手的攻击。一个拥有高身法的人，可以更轻松地与武功高强的对手打架，从而更快地获得潜能和经验。容貌和福缘是两项隐含的天赋，就是说玩家不能察看自己的这两个参数。这两项天赋目前为止对武功没有什么特别重要的影响。容貌对峨嵋弟子劝架有作用，福缘对星宿弟子运用化功大法有影响，另外某些秘密宝藏需要有好的福缘才能破解。一般来说，每一项天赋皆有其独特性和重要性，在创造新人物时该如何取舍，实在见仁见智。江湖上强手的天赋，分别很大。可见很难说哪一项天赋较重要，哪一项不那么重要。值得注意的是，不同的门派对天赋有不同的偏好，某些高深的武功对某项天赋有特别的要求。比如说：雪山派学日月轮法的，要求高的臂力，学火焰刀的，要求高的根骨；桃花岛要求比较高的悟性，否则某些功夫学不高深。新手正式开始玩以前必须清楚地了解想加入的门派的要求，合理选 择天赋。

（２）天赋选好后还可以改的吗？

答案是肯定的，但其过程却是非常缓慢的。每项天赋都可以透过提高相对应的技能来改善的，每提高一点天赋，便需要把相对应的技能提高十级。天赋与技能的对应如下：

臂力　─　基本爪法(claw)、基本拳法(cuff)、基本手法(hand)、基本指法(finger)、基本掌法(strike)
悟性　─　读书写字 (literate)
根骨　─　基本内功 (force)
身法　─　基本轻功 (dodge)
以上功夫每提高十级，就会提高对应天赋一点。基本空手功夫中，哪一门最高以哪一门的级别为准，不累加。值得注意的是不是所有后天天赋都起作用是，先天太低的，后天的努力不是很有效。比如说如果你想拜张三丰为师，他要求你有30点悟性，而你的天生悟性只有12，那么你需要至少180 级读书写字才能满足要求，这几乎是不可能的，所以一般性的建议，天赋选择的平衡些比较好，不要有“瘸腿”的。
