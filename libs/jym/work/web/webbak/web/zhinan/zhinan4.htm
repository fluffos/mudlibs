【游戏】

金庸群侠传是一个虚拟的武侠世界，每个玩家扮演着他自己所希望的角色。说起目标，人各有志，很难一概而论。一般来说有人迷恋武功，一心想称为武林第一高手；有人喜欢快意江湖、称霸武林；有人贪财好色，喜欢聚敛财富和娶妻；当然，练功并不是玩ＭＵＤ的唯一目的，在这里与来自五湖四海的人聊聊天，也是一乐，很多玩家潇洒游荡，以交朋友、聊天为主的。金庸群侠传还提供玩拱猪的场所 help pig_rules 。

金庸群侠传目前有门派：少林派、武当派、华山派、星宿派、峨嵋派、血刀门、雪山派、白驼山庄、丐帮、大理段家、桃花岛、神龙教，明教、全真教、古墓派、云龙门。除了丐帮在扬州城里，易于寻找外，其他门派都远离尘嚣，处在丛山峻林之中。新手需要不远万里找上门去，或者寻得该门派的老玩家的帮助，带领你前往。新手入门一般在该门派的底层开始，随着武功的提高，逐步拜更高级的师傅学习。很多门派提供升级的机制，比如丐帮弟子从一袋开始逐步升到九袋长老，少林和尚 从低辈一步步升到澄字辈、玄字辈甚至渡字辈。在实战经验达到一万之前，你可以自由地转换门派，不过如果你转换门派次数过多的话，某些门派的师傅会拒绝收你，新师父可能会不愿意教你较高深的武功。一旦实战经验超过一万，很多门派就会拒绝收留。显而易见的，各门派都喜欢对本派忠心的弟子。叛师出门有许多害处，不一而论，总之请务必慎重。金庸群侠传准许PK， PK 意为 Player Killing ，玩家杀玩家的意思。因此玩家之间的矛盾斗争往往以PK的型式得以充分发展。新手从入江湖之日起，就应该牢记，这是一个非常逼真江湖，打打杀杀司空见惯，只有强者生存下去。


【新手上路】

为了要在江湖中生存，在不同的阶段应该有不同的策略。新人物初出江湖，生命至为脆弱，技能既低，金钱又少，面对江湖上风波险恶的人与事，又有什么生存活命之道？
