新手秘籍

【命令】

要想在金庸群侠传里顺利生存，必须学会并熟练使用金庸群侠传的各种命令。金庸群侠传的命令很多，用 help commands 可以列出全部命令。如果想看详细些的介绍，可以 help <命令名> 来察看该命令的信息，大部分命令都有自己的介绍。比如： help say =>

指令格式: say <讯息>

说话，所有跟你在同一个房间的人都会听到你说的话。

【状态】

一旦出生在金庸群侠传里，就是一个新的人物，做为一个“人”有许多状态参数来表示你的健康状况、武功状况等等，每一个玩家必须清楚了结自己的状态。

输入指令 hp 你会看到：

Mud 名称：新金庸群侠传II


人物名称：【 少 年 】农夫 小狗狗(Landy)
★──────────────────────────────────★
【 精 气 】 100/ 100 (100%)   【 精 力 】 0 / 0 (+0)
【 气 血 】 100/ 100 (100%)   【 内 力 】 0 / 0 (+0)
【 食 物 】 200/ 200          【 潜 能 】 99
【 饮 水 】 200/ 200          【 经 验 】 0
★───────────────────── 金庸群侠II ───────★

精就是精神，读书、学习、等脑力活动所消耗的能量值；气就是气血，人体的健康值；内力是内功所赋予的特殊能量，有许多用途。这三个参数都有状态值以及上限值之分，只要还不是全饥饿状态(食物和饮水指数低到零)，状态值会随著时间而恢复，精、气上限值会依年龄或所练的功夫而有所改变；精、气这两个参数的状态值低到零，就会昏到，再受到攻击，就会死亡；内力和精力可以通过打坐、吐纳修炼来提高，参看命令 exercise(dazuo) 和 respirate(tuna) 。战斗中被打伤，气上限值就会降低，中毒精的上限值就会降低，上限值的自然恢复较缓慢，用绷带包扎可以加快气的复原速度，命令是 bandage，但你先得有布条才行(tear cloth)来获得布条。药铺有金创药和无常丹可以迅速治疗，但不便宜，有些门派的内功可以用内力来恢复精气的上限值。内力可以用来恢复精、气的状态值。另外，有很多珍贵药材可以服用( 命令 eat )，可以恢复各项参数。潜能是用来学习武功的点数，学习和领悟需要消耗潜能，通过战斗或完成特定的工作获得。潜能的上限最大值为 底数1000+经验值/10000。
