【死亡】

武侠武侠，自然是打打杀杀，因此死亡是金庸群侠传游戏中非常重要的一个环节。目前金庸群侠传的死亡规则是，死一次，经验降低百分之一，所有武功减少一级，潜能减少一半。死后鬼魂会去到鬼门关，只要停留在黑白无常面前一段时间，就会被发配回人间，落脚在扬州的武庙。对新手上路，金庸群侠传给予特别保护，不能被玩家攻击和杀害。游戏毕竟是游戏，因为死了大吵大闹、哭天嚎地，被PK了就破口大骂，实在是不文明和不明智的行为。鼓励新手努力练功，然后报仇雪恨。口出污言秽语，只会招来其他玩家的鄙视和不齿。希望诸位新手坚强自勉。

【练功】

（１）怎样才算是好的天赋？

天赋一共有六个，分别是臂力、悟性、根骨、身法、容貌、和福缘。臂力主要影响你进攻时的杀伤力，不论是徒手搏击还是持械相斗，臂力越大，敌人受的伤便越重。对于这一个特性，若你主要的打架对象是ＮＰＣ的话，则是宁可不要了！因为杀伤力越大，ＮＰＣ死得就越快，很容易便失去了练功的
对手。只有一种情况我认为大臂力是需要的，就是当你要打断对方的兵器的时候。反过来说，倘若你是一个ＰＫｅｒ（player killer）， 则当然是臂力越大越好了。如果你不以打架为主要经验来源，而是从事各种工作的话，臂力则需要大些，和NPC 拼命战斗当然是臂力越大越好。臂力低的人若要增强杀伤力，唯一的办法便是设法找一些厉害的武器。不过害的武器通常都很重，臂力低的人负荷能力都较低，这会对他们的作能力造成不利的影响。利害之间，如何取舍，则见仁见智了。臂力还有一些次要的影响，首先是你的饭量和水量，等于 (X + 10) * 10，其中 Ｘ 是你的臂力的初始值。这个饭量是不能改变的。不过任何人都有至少有10点臂力，所以至少有200 饭量，足够了，在实际练功中，饭量多少没有什么明显影响。第二项天赋是悟性，就是你的学习能力。学习包括很多方面，例如读书、理解师父的教诲、及从战斗中领悟武功。先说读书，读书都要消耗精力，悟性越高的人消耗的精力越少，而透过读书而获得的技能点数，却与悟性无关，完全是由你的读书识字的等级来决定。至于向师父学习，也是需要消耗精力的，同样的悟性越高，所消耗的精力便越少。最后便是从战斗中学习的能力，悟性越高的人，学习得越快，也就是说潜能和经验的增长也越快，这一点十分十分重要。一个悟性高的人，可以跟武功比他差很多的对手打架而仍然获得潜能和经验，这种战斗又容易又安全又快；但悟性低的人却要跟武功高得多的人打架才能获得潜能和经验，又慢又危险。悟性一项掌握了你的武功进度。臂力差的人还可以用厉害的武器补其不足，悟性差的人却没有外物可以倚赖，所以一个新人物悟性不能太低。
