# NannyMUD (1996-03-29 Lysator snapshot)

NannyMUD (founded 1990 at Lysator, Linköping University) is a classic fantasy LPMud world built around the central village, village church and chapel, Adventurers' Guild, shop, quest system, Tolkien-inspired Middle-earth and Malkuth areas, Profezzorn's Brain programmable wizard shell, and an extensive `/std/` library of rooms, monsters, doors, containers, and daemons.
