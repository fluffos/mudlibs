# 书剑·经典 (ShuJian Classic)

与 bxsj《书剑天下》属同一底层引擎代码,是同一系列的另一份存档/版本。

## 简介

「书剑·经典」是武侠题材 MUD「书剑」系列的一个版本,以门派武学、江湖
恩怨为主线。新角色从"武馆前院"起步,系统会赠送一位领路 NPC(狄云)介绍
基本玩法,整体风格偏传统金庸式武侠。

## 如何运行

```
cd libs/bxsj1
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口:**40005**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40005
```

连接后的第一个问题 **"Are you using BIG5 font(Y/N)?"** 只是询问客户端
字体编码,与游戏内容无关,回答 `n` 即可(本项目环境使用 UTF-8/简体显示)。

注册流程:
1. 英文 ID(3-8 个英文字母)
2. 确认创建新角色(y/N)
3. 设置密码(至少 5 位,必须同时包含数字和英文大写字母——很多新手第
   一次会因漏了这两项之一被拒)
4. 确认密码
5. 输入中文姓名(2-4 个汉字,系统会拒绝金庸小说人物等违禁名字)
6. 分配天赋点数(输入 0 随机分配,或手动指定某一项数值)
7. 电子邮件地址
8. 选择性别(m/f)

完成后直接进入游戏世界,`look`/`score` 等基本指令均可正常使用,系统会
根据性别显示不同的称谓(如"少年"/"少女")。

## 已知问题

目前未发现影响正常游玩的内容缺失;个别边角功能(如需要外部数据库支持
的排行/邮件类功能)在本环境未启用,不影响主线体验。
