# 书剑·经典 (ShuJian Classic)

与 bxsj《书剑天下》同一底层引擎代码，是"书剑"系列更完整、更晚近的一个
存档快照（随包附带多平台生产驱动二进制文件，可见曾真实运营过）。

## 内容亮点

- 新角色从"武馆前院"起步，系统会指派领路 NPC 狄云现场介绍基本操作，
  对新手比较友好。
- 与 bxsj 同源，因此共享其木人陪练、拜师/门派、"礼物使者"新手捷径等
  核心武侠系统（详见 bxsj 的介绍）。
- 收录了一处该谱系特有的历史 bug：角色称号/声望会随时间自然衰减，一旦
  某次 `quit` 恰好在衰减到零的那一刻触发，原始代码会在没有下限保护的
  情况下继续往负数递减并导致存档崩溃——这类"稀有但迟早会撞上"的极端
  情况已在本次转换中修复。
