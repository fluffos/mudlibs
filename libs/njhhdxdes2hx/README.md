## 深度功能测试新发现的 bug（§10.7，2026-08-04）

- **新角色食物/饮水永远初始化为 0**：`adm/daemons/logind.lpc` 在
  角色还没穿上任何衣物、随身负重为 0 时就计算了
  `max_food_capacity()`/`max_water_capacity()`（这两个函数在这份
  档案里是按负重算的，`query_weight() / 200`），算出来自然是 0。
  已把食物/饮水初始化挪到给新手穿上衣服之后。
- **§7.7 留言板崩溃（已归档 bug 类的又一实例）**：留言板存档因编
  码问题导致 `restore()` 失败、连带清空 `id` 属性，`look` 时
  `capitalize(query("id"))` 直接崩溃。已按既有修法给 `capitalize()`
  调用加上 `stringp()` 判断。
- **§7.68 复活软锁死（第 14 例）**：`d/death/npc/{wgargoyle,
  bgargoyle}.lpc`（雪亭镇的白无常/黑无常）已按标准修法拆分。现场
  用一击必杀的强力 NPC 触发死亡，完全不打断地验证复活流程能正常
  走完，角色成功落地"城隍庙"。
- 顺手修复三处确认为原始压缩包本身损坏的字符：白无常/黑无常对话
  "阁上册子"→"合上册子"（凭本项目 12+ 个同款对话逐字印证）；
  `d/snow/npc/fist_trainer.lpc`/`annihir.lpc` 各两处台词里混入的
  游离反斜杠字节（编译时报 `Unknown escape sequence`）。
