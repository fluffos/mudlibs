# 妖神之争

一款以"西游记"神话世界为背景的武侠/仙侠向 MUD，新角色由西行取经的框架切入，起手在长安城"南城客栈"落脚。

## 内容亮点

- 注册流程：`new` 触发注册 → 英文 id → 中文名字 → 密码 → 确认密码 →
  邮箱（可留空）→ 性别（m/f）→ 天赋数值（可反复 reroll，`y` 确认）。
- 天赋属性系统（膂力、胆识、悟性、灵性、定力、容貌、根骨、福缘）随机
  生成，允许拒绝重掷。
- 门派体系分"神"（五庄观/月宫/龙宫/普陀/方寸山）与"妖"（无底洞/
  轩辕古墓/水帘洞/大雪山/地府）两条阵营各五个门派，拳脚/兵刃/法
  术/内功/轻功各有侧重，入门手册甚至提示某些门派对角色性别、容貌
  数值有讲究（如水帘洞看容貌越低越好）。
- 死亡有完整的阴曹地府体验：死后由"朱笔判官 崔珏"接引到"阴阳
  界"，静候片刻后自动复活还阳。
