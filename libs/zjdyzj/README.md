# 终极地狱-指间MUD版

游戏登录后自报家门为"地狱无门"（"No Escape From Hell"，压缩包标题为
"终极地狱-指间mud版服务端"）。属于 ES II → XKX → "地狱"（hell）分支
引擎家族，与 `zjdyaryl`（爱若幽兰）是同一套引擎核心的
姊妹版本，本作在此基础上额外接入了一层"指间MUD"手机客户端专用协议。
与另一个名字里也带"终极地狱"的 `zhongjidiyu` 压缩包不是同一款游戏。

## 内容亮点

- 与"地狱"系其它分支一样，是武侠向 MUD，主打门派、装备、拜师成长等
  传统玩法。
- 最大的特点是原本是为"指间MUD"这款手机客户端定制的服务端：登录第一
  步不是常见的"英文名字"提示，而是一次面向"指间MUD"客户端的版本校验
  握手（`crypt` 挑战应答），用真正的指间MUD客户端连接会自动完成这一步。
- 账号/角色创建信息以特殊分隔符 `║` 拼接成一行整体发送，是这个协议
  特有的设计。
- 创角后有一套自己设计的"投胎"仪式：先在阎罗殿选择"猛士/智慧/耐力/
  敏捷/均衡"五种天赋偏属，再跳入"忘忧池"随机洗点，最后从十余个地名
  （或"欧阳世家"等四大世家）中选择投胎地点，才能真正获得属性并进入
  游戏世界——`score` 在完成投胎前会正确拒绝显示（"还没有出生呐"）。

## 深度功能测试新发现的 bug（§10.7，2026-08-04）

- **§7.68 复活软锁死（第 11 例）**：`d/death/npc/{wgargoyle,
  bgargoyle}.lpc`（鬼门关的白无常/黑无常）在复活序列进行中如果玩家
  暂时不在场就会直接 `return`，永久放弃复活。已按标准修法拆分为
  "彻底缺失→放弃"与"暂时不在场→重试"。现场验证：死亡→鬼门关→未被
  打断的完整复活序列→成功落地 `/d/city/guangchang`（泥潭广场）。
- 主动检查确认 `logind.lpc` 的 `user->query("age") == 14` 食物/饮水
  初始化判断查询的是正确对象（`user`，紧跟 `user->setup()` 之后），
  不是 §8.9 的错误对象变体；也没有发现 §7.34 的调试输出泄漏。
