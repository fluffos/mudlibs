# 风云三

档案名叫"风云三"，但实际登入横幅是"铁血江湖"——内容与档案名无关，只
是命名不一致。

## 内容亮点

- 档案名叫"风云三"，登入横幅却是"铁血江湖"，内容和档案名对不上，
  是这批档案里命名最混乱的一个。
- 地图除了华山、武当、明教等门派场景，也有一片"神户"（`d/japan/`）
  海外场景，和 `xajh4gkb` 的日本区域一样是跨海历练的设定，另外还
  有"台湾"（`d/taiwan/`）场景。
- 登入后有真实的 30 秒退出冷却（提示"档案正在存取中，三十秒后方能
  下线!"），是这批档案里为数不多明确写在游戏设计里的反刷退机制。

## 注册流程

英文名字（3-8 个英文字母）→ 确认建立（y/n）→ 中文名字（2-6 个中文
字）→ 密码（≥3 字元）→ 确认密码 → 电子邮件地址 → 性别（m/f）。

**退出游戏（quit）有一个真实的 30 秒冷却**：登入后 30 秒内无法
`quit`（会提示"档案正在存取中，三十秒后方能下线!"），这是游戏本身
的设计（防止频繁登出刷数据之类），不是 bug。

## 本次修复的关键 bug

- `is_chinese()` 本身已经是正确的 Unicode 码点判断，但
  `check_legal_name()` 的长度界限（`strlen<4||>8`）和逐字符判断循
  环（`i%2==0` 门槛 + `name[i..<0]` 尾部切片）仍然是旧版 GBK 双字节
  假设，导致包括标准测试名字在内的所有真实中文名字都被拒绝——已改
  为匹配错误提示文字本身声明的字符数界限（2-6）和逐字符判断
  （AGENTS.md §8.1）。
