# 书剑天下（小熊泥苑分站）

## 游戏名称

本游戏同样自称 **「书剑天下」**，这是"小熊泥苑"（http://dtxy.126.com）
站点部署的一个分支——与本项目中的 `shujian2008` 源码几乎完全一致（同一
款游戏，不同站点的两次独立部署），仅站点品牌和运行时存档不同。

## 简介

一款传统中文武侠 MUD，玩法与设定同 `shujian2008`：从"武馆前院"起步，体
验属性天赋抽取、门派拜师、武学修炼等经典武侠养成玩法，并带有短消息、贵
宾（VIP）等社区向功能。

## 如何运行

```
cd libs/shujiantianxia && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40030**。请务必在 `libs/shujiantianxia` 目录下启动，看到
`Accepting telnet connections on 0.0.0.0:40030.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40030
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40030`。注册流程与 `shujian2008`
完全一致：BIG5 字体确认（Y/N）→ 英文代号 → 确认新建角色 → 使用密码（至
少 5 位，且必须同时包含数字和英文大写字母，两次输入）→ 中文姓名（**注意：
游戏同样禁止使用金庸小说中的人物姓名**）→ 天赋分配（输入 0 随机产生）→
确认天赋 → 电子邮箱 → 性别，全部完成后进入"武馆前院"这一起始场景。

## 已知问题

- lpcc 静态编译检查通过率与 `shujian2008` 相同（约 99.2%），未通过部分同
  样是个别文件的拷贝粘贴错误和少量缺失定义，不在主线路径上。
- 核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
  反复验证工作正常。
- **WASM 版本兼容性**：与 `shujian2008`（同源代码）相同，在新的 WASM
  构建下能正常启动，但 `sited.lpc` 依据 IP 地址格式判断登录权限，而
  WASM 环境下 `query_ip_number()` 无法返回正常格式的地址，导致任何
  英文名字都会被拒绝登录。这是 WASM 驱动本身的已知限制，不是本 mudlib
  的缺陷，未做修改。
