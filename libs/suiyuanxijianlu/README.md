# 随缘洗剑录

## 游戏名称

本游戏自称 **【随缘洗剑录】**，是"ES II"引擎家族的一员（与本项目中的神
州、火影、武汉站等同宗），由 Annihilator 等人在原始 ES II 基础上多次改
写而成，是一款有较长运营历史的老牌武侠 MUD。

## 简介

一款传统中文武侠 MUD，玩家从"随缘客栈"（扬州城内）起步，NPC"浪子"李寻欢
会在开场热情地引导新手熟悉 look/get/i/hp 等基本指令。游戏整体延续经典武
侠养成路线：属性天赋抽取、门派拜师、武功修炼、江湖闯荡，风格朴实，没有
花哨的额外系统。

## 如何运行

```
cd libs/suiyuanxijianlu && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40088**。请务必在 `libs/suiyuanxijianlu` 目录下启动，看到
`Accepting telnet connections on 0.0.0.0:40088.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40088
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40088`。注册流程为：英文名字
→ 确认新建角色 → 中文姓名（**注意：游戏明确禁止使用金庸小说中已有的人物
姓名**）→ 密码（两次）→ 天赋分配（膂力/悟性/根骨/身法/勇气，输入 0 交由
系统随机产生）→ 确认天赋 → 电子邮箱 → 性别，全部完成后即进入"随缘客栈"
这一起始场景。整个流程没有额外的隐藏关卡或客户端版本校验，比较直观。

## 已知问题

- lpcc 静态编译检查显示约 97.3% 的文件通过，未通过部分主要集中在一个从
  未完工的"侠客神功"技能分支（引用了从未定义的函数和头文件）、旧式的
  邮件/网络中继守护进程（intermud 功能，本环境未启用）、以及少量巫师个
  人沙盒目录下的孤立内容，均不在注册与主线游玩路径上，不影响正常体验。
- 核心的注册、登录、探索（look）、查看状态（score）、查看物品（i）以及
  退出存档流程均已反复验证工作正常。
- **WASM 版本兼容性**：在新的 WASM 构建下能正常启动，但由于测试工具不
  会把 `log/` 目录下的内容（包括记录上次当机原因的 `/log/static/
  LASTCRASH` 参考文件）复制进沙盒文件系统，而 `uptime.lpc` 在每次新连
  线时都会读取该文件并直接显示，读不到文件时的处理不够健壮，会导致连
  线在显示英文名字提示之前就崩溃，注册流程无法在此工具下走完。这是
  WASM 沙盒环境本身缺少历史日志数据所致（原生驱动因为该文件确实存在，
  从未出现此问题），未做修改。
