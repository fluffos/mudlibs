# 炎龙封印（笑傲江湖·阿飞站）

属于"夕阳再现"（XYZX/YLFY）引擎家族，游戏内登录横幅显示为「夕阳再现」之
「笑傲江湖」，是由"阿飞"在"碎梦"修改的炎龙分支基础上再次深度改造而成的
独立版本，与同引擎家族的其它"夕阳再现"系游戏是关系较远的表亲，而非同一
份内容。

## 内容亮点

- 以金庸小说《笑傲江湖》为背景的武侠 MUD，玩家从南阳城附近的客栈开始
  自己的江湖之旅。
- 可以自行分配膂力、悟性、根骨、身法四项天赋，另有福缘、容貌两项隐藏
  属性影响解谜、拜师等际遇。
- 注册时设有一个不可更改的"身份标识"字符串，专门用于找回密码。
- 新注册的角色如果在半小时内就退出游戏，系统会为了减轻服务器负担而
  删除该账号，是站方明确的规则设计。
