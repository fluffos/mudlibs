# Tamedhon (tamedhon)

Tamedhon is a German-language fantasy LPMud in the Silberland / MorgenGrauen lineage, preserved from the public GPLv3 open-source release (`td-mudlib`). Explorers start inside *Die Gilde der Abenteurer* (Adventurers' Guild in Gidhrog) and can walk the connected core hub rooms: the underground *Kreuzung* crossroads, *Die Lehrlingsbude*, the *Mud-Kontrollzentrum* (MKZ), Gott's workroom, *Das Kittchen* jail, *Debugraum*, and *Die Anderswelt*.
