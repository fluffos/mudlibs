# 神魔（西游记之神魔传说）

## 游戏名称

本游戏自我介绍为 **《西游记—神魔传说》**（archive 命名"神魔"是其全名的
后半段），属于"ES II / Neolith"引擎家族（与本项目中的神州、随缘洗剑录等
同宗），是一个从 1994 年一路开发维护到 2013 年的长寿老牌 MUD，多位巫师
先后参与过其代码。

## 简介

一款以《西游记》世界观为背景的中文 MUD：创角时可以选择人类、仙族或妖魔
三大种族，之后从"南城客栈"（长安城中）开始自己的西游之旅。整体延续经典
武侠/仙侠养成框架（属性天赋、师承门派、武学修炼），但把地图和剧情都换成
了西游取经沿途的妖魔鬼怪与神仙世界。这是本项目转换过的体量最大的资料包
之一（三万余个源码文件），内容非常丰富。

## 如何运行

```
cd libs/shenmo && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40067**。请务必在 `libs/shenmo` 目录下启动，看到 `Accepting
telnet connections on 0.0.0.0:40067.` 即表示启动成功（由于资料包体量巨
大，编译预加载会比其他游戏稍慢一些，属正常现象）。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40067
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40067`。注册流程为：先回答一
个"进入/离开"式的青少年保护提示（输入 1 进入）→ 输入 `new` 开始新建角色
→ 英文代号 → 中文姓名 → 管理密码（两次，用于密码遗忘时找回角色，与日常
登录密码是两码事）→ 日常使用密码（两次）→ 电子邮箱 → 主页/QQ号（可直接
回车跳过）→ 选择种族（1-3）→ 选择性别 → 天赋分配（输入 9 接受当前随机方
案）→ **还需再输入一次 `y` 确认接受天赋**（这一步提示文字容易被忽略，
如果输入 look 等指令没有反应，多半是卡在这个确认上），全部完成后进入
"南城客栈"这一起始场景。

## 已知问题

- 由于资料包体量巨大（三万余文件），本项目对其只做了关键路径的编译检查
  和真实登录测试，没有进行全量静态编译扫描，个别偏僻的支线内容可能存在
  未被发现的小问题，但不影响核心的注册、探索与基础玩法。
- 表情/动作指令（emote）系统的存档数据在原始版本中已损坏，游戏内建情绪
  动作列表在本次运行中为空，不影响其余场景与玩法。
- 核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
  反复验证工作正常，且已确认游戏不会再把普通的程序编译"警告"误当作严重
  错误显示给玩家。
- **WASM 版本兼容性**：尽管资料包体量巨大（三万余文件），在新的 WASM
  构建下依然能在一分钟内完整启动，完整的注册、登录、look、quit 流程也
  全部验证成功，是本批次测试中可以在 WASM 下完整游玩的库之一。一处依据
  IP 地址计算所在地区的功能（非登录限制）在 WASM 环境下会因地址格式不
  规范而报一次无害的内部错误，但不影响注册和游玩，且已在驱动的错误处理
  机制下被正确拦截。
