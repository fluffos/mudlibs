# 神魔（西游记之神魔传说）

属于"ES II / Neolith"引擎家族（与本项目中的神州、随缘洗剑录等同宗），
是一个从 1994 年一路开发维护到 2013 年的长寿老牌 MUD，多位巫师先后
参与过其代码。本项目转换过的体量最大的资料包之一（三万余个源码
文件）。

## 内容亮点

- 创角时可以选择人类、仙族或妖魔三大种族，之后从"南城客栈"（长安城中）
  开始自己的西游之旅——地图和剧情都换成了西游取经沿途的妖魔鬼怪与
  神仙世界。
- 整体延续经典武侠/仙侠养成框架：属性天赋、师承门派、武学修炼。
- 南海普陀山门下设有掌门大弟子体系，不同角色可能先后担任"掌门大
  弟子"这一称号，帮派内部权力结构会随实际游玩自然演化。
