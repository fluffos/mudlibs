# 中华英雄苏州站

登录横幅完整标题为《中华英雄II武侠世界》，本压缩包是其中"苏州站"这一
具体服务器实例，2006 年 3 月 1 日开站。核心引擎属于 ES II 引擎系列的
衍生分支（master 文件署名一路可追溯 "Lil" → "Annihilator" → "Xiang for
XKX" → "Doing Lu for hell"，最后由 "Linux@lxtx" 改写为本作），与本项目
其它多个"终极地狱"/"轩辕"系列同属一个大家族，但内容和玩法已经改动很多，
是相对独立的一支。

## 内容亮点

- 传统武侠题材，玩家扮演初入江湖的普通百姓，通过拜师学艺、行走江湖来
  逐步成长。
- 角色创建时可以分别输入姓、名（比如"张"+"三"＝"张三"），并提供
  "猛士/智慧/耐力/敏捷/均衡"五种角色类型可选。
- 2026-07 深度功能测试（真实游玩，含两次完整 15 分钟断线重连等待）修复
  了 5 个真实 bug：断线超时强制退出流程的未捕获运行时错误、重连时无意义
  的"无效的参数"提示、悄悄话重复显示两遍、开服后第一个老玩家重新登录卡死、
  以及"惊雁宫"/"舞蝶山庄"/"麒麟窟"神秘入口系统首次开启必定失效的问题。
