# 中华英雄苏州站

## 游戏名称

**中华英雄苏州站**（登录横幅完整标题为《中华英雄II武侠世界》，本压缩包是
其中"苏州站"这一具体服务器实例，2006 年 3 月 1 日开站）。核心引擎属于
**ES II 引擎系列**的衍生分支（master 文件署名一路可追溯 "Lil" →
"Annihilator" → "Xiang for XKX" → "Doing Lu for hell"，最后由
"Linux@lxtx" 改写为本作），与本项目其它多个"终极地狱"/"轩辕"系列同属一个
大家族，但内容和玩法已经改动很多，是相对独立的一支。

## 简介

传统武侠题材，玩家扮演初入江湖的普通百姓，通过拜师学艺、行走江湖来逐步
成长。角色创建时可以分别输入姓、名（比如"张"+"三"＝"张三"），系统还提供
"猛士/智慧/耐力/敏捷/均衡"五种角色类型可选，兼顾了传统武侠与一定的养成
玩法。

## 如何运行

```
cd libs/zhonghua2
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40028**

## 如何连接游玩

```
telnet 127.0.0.1 40028
# 或
python3 scripts/mudclient.py 127.0.0.1 40028
```

注册流程比较直观，没有隐藏的编码/客户端门槛：

1. 英文名字 → 确认创建新角色 `y`。
2. 依次输入中文姓氏、名字（各自最多两个汉字，也可以只输入名不输入姓）。
3. 设置"管理密码"（找回密码用）和"普通密码"（日常登录用），各输入两次
   确认。
4. 选择角色类型（1-5，回车默认走"均衡型"）。
5. 选择性别（`m`/`f`），随后就会正式进入游戏世界（起始地点是"世外桃源"）。

## 已知问题

游戏本身有一个"系统清理"精灵，每隔一段时间会自动清空调试日志文件——这是
原作者自带的设计，与游戏本身是否正常运行无关，不用在意。除此之外没有发现
影响主线注册、拜师、`look`/`score` 等基础游玩体验的问题。
