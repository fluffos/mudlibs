# 狂想空间

## 游戏名称

**狂想空间**，1995 年 9 月 22 日创建的老牌台湾 MUD（创始团队 wade、
shorst、jcder 等），属于 ES II 引擎系列（与本项目中的 es1_win、esI、
xkx2001、rzrmud、侠客行系列等同宗）。注意：本项目中还有另一个档案
"新狂想空间II"（新增了邮箱注册等更新内容），两者虽然都自称"狂想空间"，
但经比对是两个不同时期、独立流传的版本，并非重复文件。本档案是相对
更早的一个存档快照（附带一份 2002 年 12 月的修复说明文档）。

## 简介

早期台湾武侠/奇幻风格 MUD，世界观相对自由、更偏向"帮派"社群玩法——
新手会先进入"世界的入口"，再决定是否加入某个帮派闯荡江湖。整体节奏
偏休闲，历史悠久，保留了不少早期台湾 MUD 特有的界面风格和玩法设计
（如 tintin 客户端脚本支持提示等）。

## 如何运行

```
cd libs/kuangxiangkongjian
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务端口：**40063**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40063
```

或用任意 UTF-8 telnet 客户端连接 `127.0.0.1:40063`。

注册流程：输入一个纯英文字母的角色代号 → 确认创建（y）→ 输入你的中文
名字 → 密码（需输入两次）→ 性别（m/f）→ 依次为 7 项属性分配点数（每项
系统会提示当前剩余点数，按提示输入 10-30 之间的数字即可，第 8 项会自动
按剩余点数补齐）→ 按回车继续 → 进入游戏世界。没有隐藏的前置身份验证或
BIG5/GB 编码选择关卡，也没有邮箱注册步骤（这点与"新狂想空间II"不同）。

## 已知问题

登录、`look`、`score` 等基本指令均已验证正常工作。少数非核心内容存在
历史遗留问题，不影响主线游玩：
- 极少数装饰性文字（道具描述、NPC 对话等）里有个别输入法产生的错别字/
  乱码符号，纯属原始资料的历史遗留小瑕疵。
- 少数个人巫师（管理员）测试目录下的房间/道具存在编写上的小冲突，均为
  管理员专用内容，不影响普通玩家。
- 一些早期的网络对外服务（如站际通讯/对外邮件转发）功能在本环境中未
  启用，不影响本地游玩。
