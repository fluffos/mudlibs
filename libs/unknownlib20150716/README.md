# 小雨西游Ⅱ (Xiaoyu Xiyou II)

原始压缩包名为"20150716未知lib.zip"（来源不明），实际是**西游记题材、
"泥潭"（nitan）系 MudOS 老牌 mudlib** 家族的一支，与本项目中的
xiaoyuxiyou（同名系列的另一个快照）同源。

## 简介

「小雨西游Ⅱ」以《西游记》神话世界为背景，围绕取经路上的门派、法宝、
妖魔展开，融入了经验值/潜能等类 RPG 数值成长要素。游戏从长安"英豪酒
楼"一类的市井场景起步，新人物可以拜师习武、结交江湖侠士、闯荡各地妖
魔盘踞的秘境。整体风格轻松、偏合家欢向，站点自述"多谢你看一看上面的
游戏建议，祝你游戏愉快"。

## 如何运行

```
cd libs/unknownlib20150716
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40003**。

**注意**：这个 mudlib 内置了 30 秒的"驱动刚启动，请稍候"保护期——启动
后请等待 30 秒以上再连接，太早连接会被直接提示"驱动程序正在启动过程
中，请稍候再来"并断开，这是设计如此，不是故障。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40003
```

连接后的完整流程（比一般 mud 稍长，请耐心）：

1. 内码选择："gb"（简体）或"big5"（繁体）——本环境统一用 UTF-8 显示，
   两个都能正常游玩，建议输入 `gb`。
2. "①进入游戏(Enter) ②立即退出(Exit)"——输入 `1` 进入。
3. 英文 ID：新玩家请输入 `new` 进行注册。
4. 再输入一个自己的英文名字（纯字母）。
5. 中文姓名（游戏内不能再更改，请慎重）。
6. 管理密码——**这里容易卡住**：密码必须同时包含大小写英文字母 **and**
   至少一个数字/标点符号，且不少于 7 位，光是"纯字母+数字"不够，比如
   `Test123!` 这样才能通过。
7. 确认管理密码。
8. 游戏登陆密码（至少 5 位，不能与管理密码相同），再确认一次。
9. 电子邮件地址。
10. 选择性别（m/f）。
11. 天赋分配：会展示一组随机数值，输入 `9` 接受当前设置，或输入
    `0-3` 重新随机；接受后再输入 `y` 确认进入游戏。

完成后角色会被送入长安周边的某个起始场景，`look`、`score` 等指令均已
确认能输出正确的中文内容。

## 已知问题

- 少数问候语/任务相关脚本引用了本压缩包里没有附带的内容（约占全库文
  件的很小一部分），属于原始存档就缺失的边角内容，不影响主线注册和
  日常游玩。
- 游玩过程中偶尔会看到"编译时段错误"提示，是驱动器把无害的编译警告
  显示给了玩家，并非真正故障。
- WASM（浏览器/无网络端口）构建下能干净启动，但本库自带 30 秒开机保
  护期（`uptime() < 30` 才允许登录，见 `adm/daemons/logind.lpc`）与
  WASM 测试工具"启动后立即建立连线"的方式冲突，单次测试脚本内无法等
  过这个保护期——这是测试工具本身的时序限制，不是 WASM 驱动或本库的
  缺陷；注册/登录流程已在原生模式下完整验证无误。
