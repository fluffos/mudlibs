# 金庸群侠传（2015版）

2015 年整理发布的版本，属于 ES II 引擎系列——master、security、
login 等底层代码与本项目中的"金庸群侠传2008加强版"几乎逐字节相同
（匹配度甚至比 2008 版自己与"侠客行3"的引擎匹配度还高），但游戏内容
是独立打磨了七年的真实内容分叉：净增 187 个文件、减少 67 个，新增
红花会等区域，丐帮相关场景也大幅扩充。少林、武当、峨嵋、明教、丐帮
等门派悉数登场，玩家从一间普通客栈起步练武、闯荡江湖。街头就能遇到
乔峰这样武功盖世的成名人物，稍有不慎就会命丧刀下，经历停尸、鬼门关
问话、转世重生的完整流程；追随风清扬习武途中也可能触发叛出师门的
剧情分支。

## 内容亮点

- 对练功、内功、装备均有细致的数值设计，江湖气息浓厚。
