# 书剑飘零Ⅱ

## 游戏名称

本游戏自称 **【书剑飘零Ⅱ】**，英文名 "Stray Book & Sword"，由"飞白工作
室"制作。虽然名字里同样带"书剑"二字，但与 `shujian2008`/`shujiantianxia`
是完全不同、互不相关的两套代码，不要因为名字相似而误认为同一款游戏。

## 简介

一款以"离家飘流、求职谋生"为主题精神的中文武侠 MUD。角色创建时需要选择
一种"出生状况"（书香门第 / 商贾之家 / 贫寒农家 / 武力世家），不同出身会
带来不同的初始属性倾向和专属玩法（例如商贾之家自带"交易"指令，贫寒农家
自带"乞讨"指令），比单纯的门派养成多了一层身世设定的趣味。

## 如何运行

```
cd libs/shujianpiaoling2 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40031**。请务必在 `libs/shujianpiaoling2` 目录下启动，看到
`Accepting telnet connections on 0.0.0.0:40031.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40031
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40031`。注册流程为：英文代号
→ 确认新建角色 → 中文姓名（如打中文有困难可直接回车跳过）→ 使用密码
（**必须同时包含大写和小写英文字母，以及数字/标点等特殊符号，两次输入**）
→ 电子邮箱 → 性别 → 选择出生状况（0-3）→ 回车继续，全部完成后进入起始
场景（一处"民居"）。整个流程没有额外的隐藏关卡或客户端版本校验。

## 已知问题

- lpcc 静态编译检查显示约 95.3% 的文件通过，未通过部分主要是较大的语法
  错误聚集区和少量缺失的全局定义（`MONEY_D`、`prepare_skill` 等），均不
  在注册与主线游玩路径上。
- 核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
  反复验证工作正常，且已确认游戏不会再把普通的程序编译"警告"误当作严重
  错误显示给玩家。
