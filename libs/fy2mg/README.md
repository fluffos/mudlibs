# 风云II（美国版本）

以古龙小说世界观为背景的武侠 MUD，与 jyqxc、jyqxc2、jyqxc2013fwq、
xkx2017 同属"金庸群侠传"/XKX 引擎家族，共享同一份
`adm/obj/master.lpc`；此前记录称其游戏内容与家族其他成员"完全不同"，
但逐文件比对发现这一说法有所夸大——约三成域文件与同属 XKX 框架的
`fy330` 逐字节相同，连中心广场"凤求凰"及晨香镇的房间命名骨架都完全
一致，说明两者其实脱胎于同一套"风云"世界模板，各自在其上独立改写而
成。注册时需选择民族（汉族/苗族/满族/蒙古族），呼应古龙江湖的跨民族
设定；密码规则要求同时包含大小写字母和特殊符号，是本合集里最严格的
之一。负伤会持续降低气血上限而非只扣当前气血，伤势越重上限掉得越
低；风云衙门的衙役会主动追击逃跑的玩家至相邻房间，这在本合集大多数
"逃跑即安全"的战斗设计里较为少见。

## 内容亮点

- 虽然和 `jyqxc`/`jyqxc2`/`jyqxc2013fwq`/`xkx2017` 共享同一份
  `adm/obj/master.lpc`（"金庸群侠传"/XKX 框架家族），但这份档案取
  材古龙小说世界观，游戏内容完全不同，因此在本项目里单独编号。
- 注册密码要求比较特殊：不是单纯的长度下限，而是必须同时包含大小
  写字母和特殊符号，是这批档案里密码复杂度要求最严格的一个。
- 注册时要选择民族（汉族/苗族/满族/蒙古族），呼应古龙小说里跨民族
  的江湖设定。
- 负伤会持续降低气血上限（不只是扣当前气血），伤越重上限掉得越低；
  角色气血逼近临界值时会自动逃跑求生，实测这个安全机制即使被对手
  一路追击到重伤（半昏迷）也依然可靠生效。
- 风云衙门的衙役对玩家有主动追击行为——逃到相邻房间后对方会跟过
  来，和本合集里大多数"逃跑=安全"的战斗设计不同。

- **更正（2026-08-05）**：上面提到的"7.68 复活软锁"修复已经撤销——经重新评估，鬼魂"不在场"时放弃复活流程更可能是有意的游戏设计（多数这类档案里鬼魂本身就无法自行移动，离开是一种游荡机制，回来时 init() 会重新触发流程），不是需要强制重试的 bug；详见 NOTES.md。

## 深度功能测试新发现的 bug（详见 NOTES.md）

`adm/daemons/logind.lpc` 里有两处调试用的 `printf("%O\n", ob)`
（AGENTS.md §7.34，两条平行的姓名输入路径各一处，和姊妹档案
`fy330` 逐字节相同）——已删除。另外在死亡/复活系统里发现并修复了
AGENTS.md §7.68 归档的复活软锁死 bug 类的又一实例：`d/death/npc/
{wgargoyle,bgargoyle}.lpc`（白无常/黑无常，和 `bixiecanyang`/`fy330`
同宗）的 `death_stage()` 把"对象已不在场"和"对象已销毁"这两种本质
不同的情况混在同一个 `return` 里，导致复活序列一旦被打断就会永久
卡死。已按已验证过的修法拆分；本轮测试里角色的自动逃跑机制即使在
被追杀到重伤时依然可靠生效，没能真正把角色打死，所以这个修复是照
抄其他姊妹档案已验证过的修法应用的，未在这份档案本身现场复现死亡
→复活的完整流程。

## 注册流程

`new` 触发注册 → 英文 id（3-12 个英文字母）→ 确认创建（y/n）→ 中文
名字（1-6 个中文字，留空则随机取名）→ 密码（**需同时包含大写字母、
小写字母和特殊符号，仅满足长度下限不够**）→ 确认密码 → 电子邮件
地址 → 性别（m/f）→ 民族选择（0=汉族，1=苗族，2=满族，3=蒙古族）。

## 本次修复的关键 bug

- `adm/daemons/logind.lpc`：`make_body()` 里的 `seteuid(getuid())` 会
  把 `create()` 刚设置好的 euid 重置为空字符串，已改为显式
  `seteuid(ROOT_UID)`。
- `check_legal_name()`：沿用旧版 GBK 字节长度界（提示语说"一到六个
  中文字"，实际检查的却是字节数 2-12），已改为按字符数（1-6）+
  逐字符 `is_chinese()` 判断，并去掉隔位检查。
- `adm/daemons/securityd.lpc`：`get_status()` 加了防御性
  `mapp()`/`arrayp()` 检查（未实际观察到重入崩溃，但成本很低）。
