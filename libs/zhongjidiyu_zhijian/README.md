# 终极地狱-指间MUD版

## 游戏名称

游戏登录后自报家门为 **"地狱无门"**（"No Escape From Hell"，压缩包标题为
"终极地狱-指间mud版服务端"）。属于 **ES II → XKX → "地狱"（hell）分支**
引擎家族，与 `zhongjidiyu_airuoyoulan`（爱若幽兰）是同一套引擎核心的姊妹
版本，本作在此基础上额外接入了一层"指间MUD"手机客户端专用协议。与另一个
名字里也带"终极地狱"的 `zhongjidiyu` 压缩包**不是同一款游戏**。

## 简介

与"地狱"系其它分支一样，是武侠向 MUD，主打门派、装备、拜师成长等传统
玩法。这一版本最大的特点是原本是为"指间MUD"这款手机客户端定制的服务端，
因此登录流程和普通老式 MUD 不太一样，见下方"如何连接游玩"。

## 如何运行

```
cd libs/zhongjidiyu_zhijian
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40074**

## 如何连接游玩

**重要提示**：这个服务端的登录第一步，不是常见的"英文名字"提示，而是一次
面向"指间MUD"客户端的**版本校验握手**——服务器一连上就会发一串形如
`ver1.0,<一串随机字符>` 的质询文本，客户端必须根据这串文本自行计算出一个
对应的"回应码"发回去，服务器验证通过后才会继续（显示"版本验证成功"），
否则连接会卡在这里，看起来像是发什么都没反应。

- 用真正的"指间MUD"手机客户端连接可以直接正常使用，客户端会自动完成这一
  步握手，无需手动处理。
- 用普通 telnet/mudclient 之类的纯文本客户端直接连接，**在这一步会被卡住**
  ——需要一个能按"指间MUD"协议自行计算回应码的脚本（本质上是用系统的
  `crypt` 函数配合固定密钥计算一次简单的挑战应答），普通输入是过不去的。
  这不是故障，是这个版本本身的设计如此；技术细节和验证脚本示例见本目录下
  的 `NOTES.md`。

握手通过后的账号/角色创建信息是以特殊分隔符 `║` 拼接的一整行（账号、密码、
校验码、邮箱一次性发送），随后创建角色只需性别／头像编号／中文昵称三项，
同样用 `║` 拼接成一行发送。正式进入游戏世界后，用纯文本客户端偶尔会看到像
`002`、`003`、`004` 这样的数字前缀——这是给"指间MUD"客户端识别用的富文本
标签，普通文本客户端不会解析，原样显示即可，忽略就好。

新角色进游戏后同样需要先注册邮箱、完成"投胎"流程才能查看完整角色数据，
之前 `score` 会提示"还没有出生呐，察看什么？"，属正常设定。

## 已知问题

有两个比较边缘的联机功能（跨服"版本同步"和内部消息通道）因为一处历史遗留
的端口配置数值对不上而无法正常工作，但这两个功能都是给多服务器联动用的
后台功能，完全不影响单人注册、探索、拜师等正常游玩体验。
