# 金庸群侠传（2008 超豪华版）

本压缩包对应"2008超豪华版"这一内容版本，与本项目中的"2008加强版"
"2008标准版"是完全相同的服务端引擎核心，但在门派 NPC、战斗数值配置、
部分地图场景上有独立的内容调整，文件规模也是三者中最大的一个。

## 内容亮点

- 以金庸武侠小说世界观为背景：少林、武当、丐帮、明教、桃花岛等门派
  悉数登场，玩家从"客店"起步拜师习武、行走江湖。
- "超豪华版"相较另外两个版本在战斗数值和部分场景内容上做了独立调整，
  是三个版本中内容量最丰富的一支。
- 深度测试实际打死过一次角色，验证了完整的战斗→死亡→鬼门关流程；顺
  手移植了同引擎兄弟档案"2008 加强版"（`jqxz2008`）已经发现并修复的
  4 个真实 bug（含一处每次死亡都会触发、且会在心跳里死循环重现的严
  重崩溃），详见 NOTES.md。
- 后续又从"标准版"（`jqxz2008std`）那轮测试里同步修复了第 5 个共同
  bug：食物/饮水初始化检查错了对象，导致每个新角色的食物/饮水从创
  建起就永远是空的。
