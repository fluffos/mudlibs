# 金庸群侠传（2008 超豪华版）

本压缩包对应"2008超豪华版"这一内容版本，与本项目中的"2008加强版"
"2008标准版"是完全相同的服务端引擎核心，但在门派 NPC、战斗数值配置、
部分地图场景上有独立的内容调整，文件规模也是三者中最大的一个。

## 内容亮点

- 以金庸武侠小说世界观为背景：少林、武当、丐帮、明教、桃花岛等门派
  悉数登场，玩家从"客店"起步拜师习武、行走江湖。
- "超豪华版"相较另外两个版本在战斗数值和部分场景内容上做了独立调整，
  是三个版本中内容量最丰富的一支。
