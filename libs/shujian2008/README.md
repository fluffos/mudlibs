# 书剑天下 2008

## 游戏名称

本游戏自称 **「书剑天下」**，2008 年版本，由 ShuJian MUD 开发组制作，站
点归属重庆电信。与同名的 `shujiantianxia`（小熊泥苑分站）源码几乎完全一
致，属于同一游戏在不同站点的两个部署。

## 简介

一款传统中文武侠 MUD，玩家从"武馆前院"这样的门派场景开始自己的江湖之路，
体验属性天赋抽取、门派拜师、武学修炼等经典武侠养成玩法。游戏内建有短消
息、贵宾（VIP）等社区向功能，整体氛围偏经营多年的老牌武侠站点风格。

## 如何运行

```
cd libs/shujian2008 && ~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40029**。请务必在 `libs/shujian2008` 目录下启动，看到
`Accepting telnet connections on 0.0.0.0:40029.` 即表示启动成功。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40029
```

或直接用 MUD 客户端 telnet 连接 `127.0.0.1 40029`（游戏本身建议用 ZMud
4.62 简体中文版，普通客户端也可正常游玩）。注册流程为：BIG5 字体确认（Y/N，
直接回车或输入 N 即用简体）→ 英文代号 → 确认新建角色 → 使用密码（**至少
5 位，且必须同时包含数字和英文大写字母**，两次输入）→ 中文姓名（**注意：
游戏明确禁止使用金庸小说中的人物姓名**，例如"萧峰"会被直接拒绝）→ 天赋
分配（输入 0 交由系统随机产生）→ 确认天赋 → 电子邮箱 → 性别，全部完成后
即进入"武馆前院"这一起始场景。

## 已知问题

- lpcc 静态编译检查显示约 99.2% 的文件通过，未通过的部分主要是个别角色
  文件的拷贝粘贴类型错误和少量缺失的全局定义，均不在注册与主线游玩路径
  上，不影响正常体验。
- 核心的注册、登录、探索（look）、查看状态（score）以及退出存档流程均已
  反复验证工作正常。
