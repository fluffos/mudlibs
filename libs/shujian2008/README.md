# 书剑天下 2008

2008 年版本的《书剑天下》，由 ShuJian MUD 开发组制作，站点归属重庆电信，
铺展出一张相当庞大的金庸武侠地图——少林、武当、峨嵋、昆仑、明教、星宿派、
华山/嵩山/泰山/恒山"五岳剑派"以及古墓，叠加在长安到广州等真实地名之上；
新角色从武馆前院开局，先抽取属性天赋再正式拜入门派修炼武学，中文姓名注册
明确禁止使用金庸小说中的真实人物姓名（例如"萧峰"会被直接拒绝），游戏还
叠加了短信、贵宾（VIP）等运营向功能。其源码与本项目里同名的 `sjtx2`
（小熊泥苑分站）几乎完全一致，是同一款游戏在不同站点上的两个独立部署。
