# 仙剑奇侠传 (nitan170911)

底层标注"NTLIB V7.1x"，是本项目转换的"泥潭/nitan/Lonely"系列引擎中
体量最大的一个（约 5.4 万个文件），取材于同名经典仙侠游戏/电视剧的
世界观。与体量稍小的 nitan6（笑傲江湖）同源，共享同一套 F_DBASE 属性
存取架构。

## 内容亮点

- 仙侠题材泥巴，世界观基于《仙剑奇侠传》故事背景，是这条"泥潭"引擎
  脉络里内容最完整、规模最大的一支。
- 账号系统依赖外部 MySQL 数据库（原作者的账号漫游/跨站系统）——本项目
  在没有配置数据库服务器的环境下运行时，连接会明确提示"由于连接不上
  数据库所在服务器，目前仙剑奇侠传暂时不接受数据漫游或新玩家注册"，
  这是原始设计的预期降级行为，不是故障。
- 更适合用来浏览代码、研究地图内容或做技术参考。

## 在线试玩

https://mudlibs.fluffos.info/nitan170911/

本库的固有设计，详见上文。）

## 管理员账号 / Admin account

**未能预置。** 本库的注册与角色存取完全走 MySQL 后端，在没有配置
MySQL 服务器的环境下，注册流程会在英文名输入后被正常拒绝，因此无法
通过真实注册流程创建 `fluffos` 管理员账号。若将来为本库配置了 MySQL
后端，请按同族库（nitan6/nitan_ceshi/nitan_san）的惯例注册
`fluffos` / `Mud@2026`（中文名 浮浮）并在 `/adm/etc/wizlist` 中加入
`fluffos (boss)`。

## 本地运行

```
cd libs/nitan170911
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40018**。由于文件数量巨大，驱动预加载需要三十秒左右。
