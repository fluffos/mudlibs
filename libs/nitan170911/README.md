# 仙剑奇侠传 (nitan170911)

## 游戏名称

《仙剑奇侠传》，底层标注"NTLIB V7.1x"，是本项目转换的"泥潭/nitan/Lonely"
系列引擎中体量最大的一个（约5.4万个文件），取材于同名经典仙侠游戏/电视剧
的世界观。与体量稍小的 nitan6（笑傲江湖）同源。

## 简介

仙侠题材泥巴，世界观基于《仙剑奇侠传》故事背景。由于是这条"泥潭"引擎脉络
里内容最完整、规模最大的一支，系统和地图内容都相当丰富。

## 如何运行

```
cd libs/nitan170911
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40018**。由于文件数量巨大（约 5.4 万个），驱动预加载需要
**三十秒左右**，请耐心等待后再连接。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40018
```

**重要提示：本地部署暂不支持新玩家注册。** 这个版本的账号系统依赖一台
外部 MySQL 数据库服务器（原作者的账号漫游/跨站系统），而本次部署环境中
没有配置这台数据库服务器。连接后会看到如下的清晰提示：

> 对不起，由于连接不上数据库所在服务器，目前仙剑奇侠传暂时不接受数据
> 漫游或新玩家注册。

这不是驱动或转换的错误，而是这个版本设计上就依赖外部服务——已确认这个
提示是可预期的、正常的降级行为（不会导致程序崩溃或连接卡死），只是本地
环境无法完成真正的新角色注册。如果你想实际体验这个版本的游戏内容，需要
自行搭建一台 MySQL 数据库并按原作者的账号系统接入；就当前配置而言，这个
库更适合用来**浏览代码、研究地图内容或做技术参考**，而不是立即上手游玩。

## 已知问题

- 新玩家注册强制依赖外部 MySQL 服务器，本地环境无法完成注册（见上）。
- 由于文件数量巨大，本次验证没有进行全库静态编译扫描，仅以实际启动+
  连线测试作为验证依据；驱动本身启动干净、无报错。
