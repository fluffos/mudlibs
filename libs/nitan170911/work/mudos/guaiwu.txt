游戏道具栏之指令选单： 〞炼制〞

物品道具之使用 (相克 相辅 复合) 每种原料限一个

用途：　补　ＨＰ／ＭＰ 攻击　吸附　降低力量 (暂时／永久)增强属性
解毒 施毒 退敌 移动 避敌 引敌
对特定种类敌人相克
解特定的毒
施特殊法术的媒介
复合性毒 或配合法术
例如 : 蜂王蜜 + 御蜂术 = 杀伤力三倍
砂糖 + 万蚁穿心 = 必杀
三尸蛊 + 三尸咒 = 伤 1/2 HP (持续有效)
硫磺 + 火咒 = 杀伤力加倍
银针 + 雷咒 = 杀伤力加倍
盐砂 + 冰咒 = 杀伤力加倍

配方资料：　神农百草经　 药材的配方
五毒真经 毒蛊的配方及解法
鬼谷奇书 暗器 合成道具

普通的原料加上"秘方" 可作成一些令人意想不到 又很有用的道具
通常为战斗用道具 药物 毒物 或是剧情上解决任务之关键物
炼制的配方有的是游戏讯息内或是说明书上有交待

材料获得方式:
1. 战斗中得打倒怪物(有时候)可得其身上的道具
如 蛇系怪物 : 蛇卵 蛇皮 蛇骨 蜈蚣 : 蜈蚣卵 古树妖 : 药草,毒草
武夫系 : 刀剑,镖,武器 巫师:法器 毒妇:蛊,毒草

2. 战斗中偷取敌方的道具(成功率比前者高) 男主角的绝技之一:飞龙探云手

3. 用买的: 如 药铺,小贩,当铺偶而也会出现奇特的物品可以买 4. 用换的: 用一种较易从战斗中取得的道具(买不到的 如 ??? )
找某人可以换任选一种的特殊(毒)药材,符咒 如..
毒娘子 ：蛇骨 五毒教练秘药的必需品 依数量换稀世毒蛊或蛇杖
韩药师 ：杏仁子 种银杏树 换珍贵药材
独孤剑圣：玉菩堤 种菩堤树 换强力符咒或降妖宝剑
禅云寺 ：舍利子 找回被妖怪袭击而散失的达摩舍利子 换特殊法器
如圣灵珠 寿葫芦 玉佛珠 或法术防御力高的防具

4. 宝箱 橱柜 瓮 水缸 .... 用拿的


所有物品均有正反两种 即所谓一物克一物

道具的策略攻防战 : 施毒/解毒

一级毒 : (药毒) 战斗结束自动解除 同一级之毒不能并存
赤毒 症状 持续 HP-MaxHP/20
痲弊 不能动 三回合后自动恢复
疯魔 乱砍 无法操控
尸毒 战力减低 3 级

二级毒 : (咒毒) 战斗结束自动解除 伙伴中有人被打倒时会自动恢复
血毒 持续 HP-MaxHP/20 MP-MaxMP/20
眠倒 倒地 被打二下后自动会醒
妖缚 不能动
咒封 不能用法术

特殊毒 : 非解不可
鹤顶红 持续 HP-MaxHP/20
孔雀胆 同上
血海棠 同上
断肠草 同上
九阴散 施法一次 -HP1/2
无影毒 施法一次 -HP1/2
三尸蛊 攻击一次 -HP1/2
金蚕蛊 降低战力 5 级
食妖虫 持续 MP-MaxMP/10
碧血蚕 持续 HP-MaxHP/10
