3。法术的攻击效果
　　我的猜想：（其实这个idea最初是外塞之雾提的，我把它完善了一下）
　　　　法术的攻击效果 = ( 基础攻击 + 附加攻击*r ) * 调整因子，其中：
　　　　　　调整因子 = ( 1 - 抗性 ) * ( 1 + 环境因素 )
　　　　　　r是一个随机数，其值在0.95~1.05之间变动。
　　这个公式在主角灵力很低的时候非常精确（几乎是100%准确），但是灵力高了就不很
准确，而且灵力越高越不准确。问题出在附加攻击上。我只知道附加攻击与攻击者的灵力
有关，与防御者的防御力有关，具体关系并不清楚。我本来猜测：附加攻击=攻击者的灵
力-防御者的防御力，如果减出负数则取0。但是后来发现这个猜测也有问题，有时会有近
20%的偏差，而且怪物的防御力也没测出来，郁闷……
　　不过一般来说，可能是怪物的防御都不会很高，大约在几十吧，而玩家的灵力总有几
百，所以如果要求不高的话，附加攻击可以近似取玩家的灵力。
