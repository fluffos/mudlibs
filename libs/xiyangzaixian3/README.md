# 夕阳再现III之炎龙封印

## 游戏名称

游戏全名《夕阳再现III之炎龙封印》，2006 年由"阿凯工作室"（AKAI Studio）
制作，登录后能看到的实际站点名叫"江湖风云"。这是国产 MudOS 老武侠
Mud 里比较有代表性的一支，风格偏经典门派、内功修炼的江湖养成玩法。

## 简介

游戏以传统武侠世界观展开，玩家从长安城一带的客栈开始闯荡江湖，围绕
门派、内功、武学修为逐步成长。整体节奏偏怀旧文字 Mud 的老派养成体验，
留言板、门派系统、任务链都比较齐全。

## 如何运行

```
cd libs/xiyangzaixian3
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口固定为 **40042**。

## 如何连接游玩

**这款游戏有一个非常容易踩坑的隐藏机关：连上之后看到的第一个提示是
"请输入您的英文名字:"，看起来就是普通的取名提示，但其实这一步在检查
一个写死的客户端版本暗号——必须原样输入 `2060` 才能过关**（这是当年
Tomud/笑傲江湖 WWW 客户端的握手代码，和你自己要取的名字完全无关）。
输入任何其他内容都会被当成"客户端不对"直接踢下线，必须重新连接再试。
如果之后英文 ID 因为不合法被打回重输，也会连带跳回这个"2060"关卡，
每次重试都要重新输入一次 `2060`。

完整流程示例：

```
python3 scripts/mudclient.py 127.0.0.1 40042 --timeout 30 --idle 1 \
  --send "2060" --send "<英文ID>" --send "y" --send "<中文名字>" \
  --send "<密码>" --send "<密码>" --send "0" --send "y" \
  --send "<邮箱>" --send "m或f" --send "look"
```

1. `2060`（客户端版本暗号，见上文说明，必须原样输入）
2. 英文 ID（3-14 位小写字母）
3. 确认创建新人物（y/n）
4. 真实中文姓名
5. 设置密码、再输一次确认
6. 天赋选择：输入 `0` 使用系统随机分配，再输入 `y` 确认
7. 电子邮箱
8. 性别 m/f

完成后会进入客栈场景，`look`、`score` 均可正常查看。

## 已知问题

商店相关的一个底层功能文件（影响约 20 家 NPC 商铺的进货/寄卖逻辑）
在原始存档里就存在比较严重的代码缺损，可能导致个别商店的买卖交互不
正常，这是原始资料本身的问题，不是转换过程引入的。另外少量任务线（如
"quest/mmid"目录下的几个任务）缺少对应的说明文件，属于内容缺失，不会
影响主线探索；跨站/群发邮件一类的网络功能也未启用，仅限单机游玩。

**WASM 版可玩性**：新 WASM 构建下能正常启动，注册流程能走到英文名字
提示这一步，但会被游戏自带的 IP 黑名单机制误判为"地址不受欢迎"而拒绝
——这是 WASM 测试环境本身在显示连线 IP 地址格式上的已知限制（并非真的
被封禁），原生环境下完全正常。属于测试环境限制，不是这份 mudlib 的
问题。
