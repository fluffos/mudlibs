# 月影奇缘

## 游戏名称

**★月影奇缘★**（登录横幅原文亦作"世纪西游之月影奇缘"/"Moon Love Story"），
一个以《西游记》世界观为背景改编的老牌 MUD。属于 **ES II 引擎系列**（与
`es1_win`、`xkx2001`、`rzrmud`、`xo` 等同源，master 文件署名可追溯到
"Lil"→"Annihilator" 这一支）。

## 简介

游戏架设在"西天取经"的大框架之下，新角色一入门便会被卷入"西天取经"的故事
线，还有专属的天赋点分配、师承拜师等武侠/仙侠常见玩法。整体节奏轻松，
文本描述带有明显的世纪之交（2000 年前后）老式中文 MUD 的风味，NPC 对话和
场景描写都比较古早、朴素。

## 如何运行

```
cd libs/yueyingqiyuan
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40048**

## 如何连接游玩

```
telnet 127.0.0.1 40048
# 或
python3 scripts/mudclient.py 127.0.0.1 40048
```

连接后会有几个新玩家容易卡住的提示，按顺序说明：

1. 先问编码 `gb`/`big5`，输入 `gb` 即可（国标码，就是我们现在用的简体环境）。
2. 接着会问"你是否是还有好多工作没有做完？？(yes/no)"——这只是一个无关紧要
   的干扰性问题，随便回答（如 `no`）即可继续，不影响后续流程。
3. 英文名提示里，新玩家要先输入 `new` 才会进入注册流程；随后再输入一个
   3-8 位的英文名。
4. 中文名可以正常输入真实汉字，1 个字也能通过（早期版本这里有编码相关的
   Bug 曾导致合法的中文名字被误判为不合法，目前已修复）。
5. 密码设置两次即可，之后邮箱有一个隐藏要求：**必须包含 "ccb" 这个子串**
   （例如 `xxx@ccb.com`），否则会一直提示格式不对，这是这个服务端历史遗留
   的怪规则，并非输入错误。
6. 最后会有一个"天赋点分配"小游戏：按 `9` 直接使用默认属性，再输入 `y`
   确认即可正式进入游戏世界。

## 已知问题

- 表情语句数据库（`emoted.o`）的存档文件在原始压缩包里就已损坏，每次开机
  都会打印一条无害的报错，实际效果是"表情词库"是空的，不影响正常聊天和
  游戏功能。
- 迷宫/曲径区域里有一处内容（`d/qujing/start/24/12`）在原始压缩包中就已经
  损坏缺失，玩家基本不会碰到。
- 测试阶段曾经出现过两次原因不明的驱动进程意外退出（没有留下任何报错痕迹），
  但之后连续十余次完整注册+游玩测试都未再复现，日常游玩基本不受影响。
- 本轮重新验证：LPC 代码已全部跑过格式化工具，并在重新编译的最新驱动上
  完整回归测试通过（含真实中文名注册、look/score/quit）。**WASM（浏览器/
  纯 JS）模式下同样可以完整注册并游玩**，登录、看房间、查看角色状态都正常；
  唯一的小瑕疵是进站提示的 IP 地址那一行在 WASM 下显示为空白（WASM 驱动的
  已知限制，不影响实际登录和游戏功能）。
