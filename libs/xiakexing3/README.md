# 金庸群侠传 (原名"侠客行三")

压缩包与内部配置文件都叫"侠客行三"，但实际连接进游戏后，登录横幅显示
的名字是**"金庸群侠传"**——经比对，这份存档与本项目中的
jinyongqunxiazhuan2008 系列共享同一套 master 核心代码，是同一引擎不同
时期的换皮/内容版本。

## 简介

以金庸小说人物与门派体系为背景的江湖题材 MUD，新人物从"客店"起步，
可以习武、结交江湖人物、闯荡各大门派。

## 如何运行

```
cd libs/xiakexing3
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40038**。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40038
```

注册流程没有隐藏的编码/年龄询问：

1. 英文 ID（新角色）
2. 确认创建新角色（y/n）
3. 中文姓名（注册提示会提醒不要使用金庸小说人物名）
4. 设置密码（至少 5 位），并确认
5. 天赋点数：系统随机分配后询问是否接受，输入 `y` 接受
6. 电子邮件地址
7. 选择性别（m/f）

完成后会进入"客店"，`look`、`score` 等指令均已确认能正确显示中文角
色资料。

## 已知问题

- 少数道具/NPC 脚本存在原始存档遗留的小瑕疵（例如个别道具缺少显示名
  称、个别函数的类型使用不严谨），均属边角内容，不影响主线注册和基础
  游玩。
- 游玩过程中可能会看到"编译时段错误"一类提示，是驱动器把无害的编译
  警告显示给了玩家，并非真正故障。
- 已在 WASM（浏览器/无网络端口）构建下测试：启动、注册、登录、`look`/
  `score`/`quit` 均正常，可完整游玩，无 WASM 特有限制。
