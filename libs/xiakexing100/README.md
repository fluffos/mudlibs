# 侠客行一百 (Xia Ke Xing - Yi Bai)

取材自金庸小说《侠客行》，作者 "Coollizard" 与 "xkx100" 团队自 2001 年
起维护，属于本项目中"Century 家族"（`adm/single/` 目录结构）武侠
mudlib 分支之一，是这批游戏中文件数量最多的一个（转换后约 1.2 万个
LPC 文件）。

## 简介

游戏世界以北京、长安、洛阳、扬州等真实历史地名为骨架，覆盖全国多个
"出生地"供玩家选择，融合门派、武功、天赋点数分配等传统武侠养成玩
法。新角色从随机分配的出生城市客栈起步，逐步习武、闯荡江湖。

## 如何运行

```
cd libs/xiakexing100
~/src/fluffos/build-debug/src/driver config.fluffos
```

游戏端口：**40037**。这是本批游戏中体积最大的一个，启动后请稍等片
刻，看到 "Accepting telnet connections" 字样再连接。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40037
```

注册流程较长，请耐心按顺序输入：

1. 英文 ID（3-8 个纯英文字母，不能有数字）
2. 确认创建新角色（y/n）
3. 中文姓名（系统会拒绝金庸小说人物名，例如"韦小宝"等违禁名字）
4. 设置密码（至少 5 位），并确认
5. 选择出生地：先输入 1-5 选一个地区分组（如 2 代表长安/洛阳一带），
   系统会在组内随机决定具体城市
6. 分配天赋点数：依次输入膂力、悟性、根骨的数值（游戏会提示当前允许
   的范围，通常在 10-30 之间），身法由系统按剩余点数自动计算，然后
   输入 `y` 确认这组数值
7. 选择性格类型（`0` 为不特别偏向任何一项的"普通"性格，1-5 分别对应
   冒险/谨慎/可人/睿智/坚韧）
8. 电子邮件地址
9. 选择性别（m/f）

完成后会进入对应出生地的起始场景，`look`、`score` 等指令均已确认能
正确显示中文角色资料。

## 已知问题

- 少数战斗相关脚本（如个别"接受挑战"类函数）存在类型不匹配的历史遗
  留小问题，属边角内容，不影响主线注册和基础游玩。
- 游玩过程中可能会看到"编译时段错误"一类提示，是驱动器把无害的编译
  警告显示给了玩家，并非真正故障。
- 已在 WASM（浏览器/无网络端口）构建下测试：启动、注册、登录、`look`/
  `score`/`quit` 均正常，可完整游玩。测试过程中还额外发现并修复了一个
  在"访客计数"文件完全不存在时会导致连线卡死的历史遗留小 bug（详见
  NOTES.md），现已修复，原生模式和 WASM 模式下都更稳健。
- 另外还发现并修复了一个原始存档就存在、与 WASM 无关的老 bug：
  `quit`/`exit` 指令由于一处存档返回值判断写错（判断"等于 1"而不是
  "非零即成功"），几乎每次退出都会先正常显示告别信息、再弹出一条吓
  人的"档案保存失败"警告，且实际上从未真正断线。已修复，现在存盘退
  出完全正常，详见 NOTES.md。
