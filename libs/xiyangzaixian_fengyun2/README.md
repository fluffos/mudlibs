# 夕阳再现·风云再起Ⅱ

## 游戏名称

**夕阳再现**，站点子名"风云再起Ⅱ"（域名 www.zhaoshu.net）。与本项目中的
`xiyangzaixian_fengkuang`（疯狂江湖）同属"夕阳再现"这一支武侠 MUD 引擎家族
——两者共享部分底层文件，但登录、安全、世界内容各自独立开发，是两个不同站点
在同一基础引擎上分别发展出的游戏。

## 简介

一款传统金庸武侠题材的文字 MUD，玩家从平民少年少女出发，游历江湖各地城镇，
结交门派、习练武功、行侠仗义。新手出生地点会在多个不同的江湖城镇/据点中随机
分配（如北疆小镇、铁枪庙等），带有典型的门派养成与角色扮演元素，游戏公开声明
不禁止玩家间的 PK 对战。

## 如何运行

```
cd libs/xiyangzaixian_fengyun2
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40041**

## 如何连接游玩

```
telnet 127.0.0.1 40041
# 或
python3 scripts/mudclient.py 127.0.0.1 40041
```

**请注意：服务器刚启动的前 30 秒内会拒绝所有登录**（会提示"游戏正在启动过程
中，请稍候再login"），这是游戏本身的正常启动保护机制，不是故障，稍等半分钟
后重新连接即可。

登录流程：依次输入英文代号 -> 确认新建角色(y) -> 中文名字 -> 管理密码 ->
确认管理密码 -> 登录密码 -> 确认登录密码 -> 天赋加点选择（输入 `0` 交给系统
随机分配）-> 确认接受天赋(y) -> 电子邮箱 -> 性别(m/f)，之后即正式进入游戏
世界。

## 已知问题

- 少量边缘场景文件（如武当旧区的少数几处对话）存在原始压缩包自带的文字排版
  小瑕疵，均为深层内容，不影响主线游戏体验。
- 极个别非主线区域（一些巫师个人练习用的场景）在脱离主线跑图路径单独编译时
  会报告依赖缺失，但实际游戏中从未被触发，不影响正常游玩。
