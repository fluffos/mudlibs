# 风云Ⅳ（2005 国内经典版）— fy2005

## 游戏名称

**风云2005**（配置内自报名为"风云Ⅳ"，站内横幅写作"国内经典版"）。
与 `fengyun434` 是同一套"风云Ⅳ"引擎的不同年份/站点快照，同属本批次
的 **"风云"（Fengyun）武侠引擎家族**。

## 简介

以古龙武侠小说为背景的江湖世界，玩法与同引擎家族的 `fengyun434`、
`fy2` 一致：选择民族出身、闯荡江湖门派、行侠仗义。这份 2005 年的
"国内经典版"额外加入了实时的 Quest 奖励倍率播报、在线网吧列表等
细节内容，是风云系列中内容较丰富的一个分支。

## 如何运行

```
cd libs/fy2005
~/src/fluffos/build-debug/src/driver config.fluffos
```

服务器监听端口：**40013**。

**注意：这个版本开服后有一个约 5 分钟的"系统初始化"保护期**——刚启动
时任何人尝试登录都会被提示"风云系统正在初始化，请在五分钟后再登陆"
并断开连接，这是作者刻意设置的启动缓冲机制，不是故障，耐心等待 5
分钟后再连接即可正常游玩。

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40013 --timeout 25 --idle 0.5 \
  --send "0" --send "英文名字(3-8位纯小写字母)" --send "y" \
  --send "屏幕上ASCII数字图案对应的数字" \
  --send "你的中文名字" \
  --send "密码(需含大小写字母)" --send "确认密码" --send "邮箱" \
  --send "m" --send "0-3选择民族" \
  --send "look" --send "score"
```

（用这个脚本测试时，"验证码"那一步无法提前知道具体数字，需要先连接
一次看到图案后再手动填入，或改用真人 telnet 客户端逐步输入。）

连接后先看到一个 **编码选择提示**（输入 `0` 表示国标码 GB，`1` 表示
大五码 BIG5）——普通玩家直接输入 `0` 即可。**开服未满 5 分钟时，即使
正确通过编码选择，输入英文名后也会被系统以"正在初始化"为由拒绝**，
请稍候片刻再试。

5 分钟后依次输入：英文登录名（3-8 位纯小写字母）→ 确认新建角色
(y/n)。**注意：确认新建角色后会出现一个用 ASCII 字符画出来的数字
"验证码"图案**（"请输入以上校验码"），这是本版本特有的防机器人注册
验证，需要玩家自己读出图案里画的是哪几个数字，然后手动输入——用普通
telnet 客户端连接时这一步和真人验证码网站的做法完全一样，直接照着
屏幕上的数字图案输入即可；只有用脚本/程序自动化测试时才需要额外写
识别逻辑。验证通过后依次是：中文名字 → 设置密码（需同时含大写、
小写字母及数字/符号）→ 确认密码 → 邮箱 → 性别(m/f) → 民族（0-3）。
完成后正式进入游戏。

也可使用普通 telnet：`telnet 127.0.0.1 40013`（同样需要等待 5 分钟
保护期结束）。

## 已知问题

- 少数任务/场景相关的纯文本配置文件里仍保留着旧版路径写法，个别房间
  跳转可能因此找不到目标，但不影响主线登录、创角与日常游玩。
- 为防止恶意批量注册，本版本只保存等级达到 L2（40%经验）以上角色的
  存档；新手角色如果直接退出（`quit`），系统会提示"如果决定退出，
  请再次输入 quit，你的数据将不被保留"——这是正常的防刷号机制，不是
  故障。
