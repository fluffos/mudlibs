# 玄剑录

属于 ES II / 侠客行（XKX）引擎家族，与"侠客行 2001"等游戏同源，但拥有自己独立
的武林世界与剧情内容，核心舞台设定在明教、昆仑、侠客岛等门派与地点之间。

## 简介

一款传统武侠题材的 MUD，玩家初入江湖，会先被"侠客岛"的赏善使、罚恶使等人物
迎接，随后展开自己的江湖之旅——习武、结交门派、闯荡各方势力。整体保留了老式
中文 MUD 浓厚的武侠氛围。

## 如何运行

```
cd libs/xuanjianlu && ~/src/fluffos/build-debug/src/driver config.fluffos
```

端口：**40064**

## 如何连接游玩

```
python3 scripts/mudclient.py 127.0.0.1 40064
```

登录流程（注意开头有一个容易被忽略的编码提问）：

1. 连接后会先问 "Do you want to use BIG5 code?(y/n)"——这是选择繁体/简体
   编码的提示，一般玩家回答 `n` 即可使用简体（GB）编码。
2. 输入英文名字，系统提示"确定吗(y/n)？"时回答 `y`。
3. 依次输入中文名字、密码（两次）。
4. 天赋分配环节：输入数字 1～4 可以指定某一项天赋，输入 `0` 由系统随机分配，
   随后需要回答 `y` 确认接受这组天赋。
5. 输入电子邮件、性别（`m`/`f`），随后正式进入游戏世界（新手会被随机分配到
   几个不同的起始地点之一，例如"沙滩"）。

## 已知问题

- 个别偏门的区域或旧内容（如某些废弃的存档、内部测试目录）无法正常访问，
  这些是原始存档自带的内容缺口，不影响主线区域的正常游玩。
- 部分武功、任务系统的边角提示文字偶有历史遗留的小瑕疵，不影响核心玩法。
- 本存档也可在新的 WASM（浏览器/Node 沙盒）模式下完整游玩，注册、登录、
  look/quit 等指令均正常；"上次连线地址"这一行在 WASM 模式下会显示一个
  奇怪的 1969 年日期而非真实 IP，这是 WASM 驱动本身的已知限制，不影响
  功能。另外 score 指令在个别测试中没有产生任何输出，怀疑是一个较小的、
  与本次改造无关的既有小问题，仍在观察中。
