# 夕阳再现·疯狂江湖

## 游戏名称

**夕阳再现**，站点子名"疯狂江湖"。属于"夕阳再现"这一支武侠 MUD 引擎家族——
与本项目中的 `xiyangzaixian_fengyun2`（风云再起Ⅱ）、`weimingkongjian`
（未明空间）、`jianghufengyun`（江湖风云单机）、`bixiecanyang`（碧血残阳）
等同源，各自是不同站点在同一套引擎基础上发展出的独立游戏世界。

## 简介

一款传统金庸武侠题材的文字 MUD，以"江湖"为背景，玩家扮演初入江湖的少年少女，
从平民百姓做起，游历各地城镇、结交门派、习练武功，逐步成长为江湖中人。新手
出生地点会在几个不同的江湖城镇中随机分配（如北疆小镇、铁枪庙等），带有典型
的门派养成与角色扮演元素。

## 如何运行

```
cd libs/xiyangzaixian_fengkuang
~/src/fluffos/build-debug/src/driver config.fluffos
```

分配端口：**40040**

## 如何连接游玩

```
telnet 127.0.0.1 40040
# 或
python3 scripts/mudclient.py 127.0.0.1 40040
```

登录流程比较直接，没有隐藏的前置关卡：依次输入你想用的英文代号 -> 确认新建
角色(y) -> 你的中文名字 -> 密码 -> 确认密码 -> 天赋加点选择（输入 `0` 交给
系统随机分配即可）-> 确认接受天赋(y) -> 电子邮箱 -> 性别(m/f)，之后即正式
进入游戏世界。取中文名字时，游戏会提醒不要使用金庸小说中的知名人物姓名，请
自行发挥想象力起一个原创名字。
